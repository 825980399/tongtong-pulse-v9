# requirements-314t.txt —— Python 3.14 free-threaded（python3.14t / GIL 默认关闭）专用基线
#
# 为什么不能直接用 requirements-ci.txt
# ------------------------------------
# 既有三份清单的上界钉写于 3.12 时代（numpy<2.0 / pyarrow<13 / cryptography<42 /
# Pillow<10 / setuptools<69）。在 3.14 下这些钉子会把**已装好的新版本强制降级**到
# 没有 cp314t 轮子的老版本，pip 退化为源码编译并失败——473 批实测 numpy 1.26.4：
#   meson: Could not find Python3 library ...python314.dll
#   ERROR: Python dependency not found
#
# 故本文件是**独立基线**：不改动 requirements.txt / requirements-ci.txt / requirements.lock，
# 因而也不影响 3.12 侧 CI 的可复现性（tools/ci 两个 requirements 门禁只认那三个固定文件名）。
#
# ★判定口径（473 批踩过两次坑，务必照此执行）
# --------------------------------------------------
# 1) free-threaded 解释器只接受 `cp314t` ABI 轮子或纯 Python 轮子；
#    普通 `cp314` 轮子**不兼容** ⇒「包支持 3.14」不等于「包支持 3.14t」。
# 2) 判定必须用：
#        python3.14t -m pip install --dry-run --only-binary=:all: --no-deps <pkg>
#    不能用 `pip index versions`：该命令**不按 ABI 过滤**，会把「只有 sdist」的包
#    误报成可用（473 批首轮探测因此把 29/29 全报成可装，实测只有 22 个真有轮子）。
# 3) 已安装的包 pip 输出 "Requirement already satisfied"，判据要同时认，
#    否则会把「装好的」误判成「无轮子」。
#
# 安装：
#   python3.14t -m pip install -r requirements-314t.txt
#
# 首次落地：2026-11-06（473 批），全部版本号为本机 python3.14t 实测安装结果。
