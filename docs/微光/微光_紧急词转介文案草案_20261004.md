## 一、现状实测（问题定性）

`config.py:2879-2890 ETHICS_CONFIG`：

| 表 | 内容 | 现行语义 |
|---|---|---|
| `forbidden_keywords` | 暴力、色情、赌博、毒品、武器制造、黑客攻击、病毒制作、病毒、诈骗、**自杀**、歧视、仇恨、恐怖、虐待 | **直接拦截** |
| `warning_keywords` | 政治、宗教、争议、敏感、批评、负面、攻击 | 标记但可通过 |

**问题**：用户表达**自杀倾向**时落入**拦截**路径 —— 无安抚、无转介、无救助渠道。
**全仓检索**：无「转介 / 救助 / 热线 / 危机干预 / 陪伴边界」相关实现或文案（0 命中）。
→ **安全边界缺陷，开源前硬项**。

## 二、判定分级（建议，供烛微接线）

| 级 | 触发 | 处置 | 是否拦截 |
|---|---|---|---|
| **L0** | 一般情绪低落（"难受""有点撑不住"） | **陪伴**（现行能力） | 否 |
| **L1** | 明确自伤意念（"我想自杀""不想活了""活着没意思"） | **转介**（安抚 + 渠道，见 T1） | **绝不可拦截** |
| **L2** | 计划/时间/方式（"今晚就……""已经准备好了"） | **强转介**（T2 + 建议立即联系身边人） | 否 |
| **L3** | 正在实施/即时危险 | **最高优先**（T3：110/120） | 否 |

**★ 必要条件**：「自杀」类词**必须从 `forbidden_keywords` 移出**，改为 **crisis 分支**（技术侧改动，**微光不执行**）。

## 三、转介文案（本地文本，不依赖联网）

**T1（L1 明确意念）**
> 我听到了。你现在承受的痛苦是真实的，也很重要。
> 本系统不替代专业帮助；涉及医疗或心理困扰时，请联系专业人士或援助热线：
> **全国心理援助热线：12356**（国家卫健委统一号码，24 小时）
> 如果情况紧急，请拨 **110**（报警）或 **120**（急救）。
> 如果你愿意，我可以陪你一起，把现在最难受的那件事慢慢说清楚。

**T2（L2 有计划）**
> 谢谢你告诉我这些。**这件事已经超出我能独自承担的范围，但你不是一个人。**
> 请现在就做两件事：①拨 **12356**，或让身边的人陪你拨；②联系一位你信任的人，告诉他/她你现在的状态。
> 如果你此刻一个人且难以保证安全，请立即拨 **120** 或 **110**。
> 我会在这里，但我们先把专业帮助接上。

**T3（L3 即时危险）**
> **请立即拨打 120（急救）或 110（报警）。**
> 如果你身边有人，请马上告诉他/她。你现在的安全最重要，其他都可以之后再说。

**强约束（写进实现）**：
- T1-T3 **不得**包含说教、道德评判、"想开点"、"别想太多"类表述
- **不得**因触发紧急词而**切断对话**（拦截即失效）
- **不得**要求用户提供身份/位置等个人信息
- 输出**必须**含具体渠道（不可只说"去看医生"）
- 🔒 紧急对话内容**不得写入知识库/长期记忆**（PII 与创伤内容双风险，与烛微确认写入面）

## 四、陪伴使用边界声明（何时陪伴 / 何时必须转介）

| 场景 | 属于 | 必须转介？ |
|---|---|---|
| 情绪低落、压力、孤独、关系困扰 | **陪伴** | 否（可共情、可倾听） |
| 明确自伤/自杀意念 | 陪伴 **+ 转介** | **是**（同时给出渠道） |
| 计划/时间/方式/即时危险 | — | **是（最高优先）** |
| 涉及他人安全的暴力威胁 | — | **是**（提示报警） |
| 医疗/用药/诊断结论 | — | **是**（明确不提供医疗建议） |
| 要求"帮我决定要不要活着" | — | **是**（不承接决定，转介） |

**对用户的一句话声明（建议进 README / 首次启动声明）**：
> 本系统是研究原型，可以陪你说话，**不替代专业帮助**；涉及人身安全时，会优先转介专业力量。
