## 一、运行主链（五层单向，层间不直连）

```
   ① 感知
      senses/          眼 · 耳 · 触觉 · 视觉皮层（含视觉引擎族）
                              │ 脉冲
   ② 神经（脉冲信息场）
      nucleus/field/   信息场 · 振荡子 · 梯度 · 请求去重
                       六档优先级队列 + 背压  ← 全部层间通信的唯一通道
                              │
   ③ 认知 / 情感 / 身份
      brain/           推理 · 潜意识 · 内在世界
      identity/        自我认知 · 叙事自我 · 人格内核 · 伦理
      endocrine/       激素与神经递质（情绪化学状态）
      genetic/         进化 · DNA 修复 · 同意 · 养育伦理
                              │
   ④ 内在模型 + 进化引擎
      mnemosyne/       节点池 · 快照 · 经验池（记忆底座）
      reasoning/       安全进化执行 · 补丁管理 · 符号推理
      evolution/       参数补丁闭环 · 主动复现探针
      llm/             渠道调度 · 配额 · 语义缓存 · 调用留存
                              │
   ⑤ 行动 / 表达
      motor/           抓取 · 文件 · 沙箱 · 嘴 · 手 · 腿
      functions/       对话服务 · 健康面板

   底座（贯穿各层，不属主链）
      nucleus/{data,events,pulse,runtime,security,…}   数据访问 · 事件 · 脉冲 · 运行时 · 安全
      nucleus/semantic/ + vector_store/                向量编码/存储/队列（FAISS）
      nucleus/synapsys/                                共振引擎 · 器官协议 · 投票
      base/                                            器官基类（含熔断隔离）
      somatics/                                        身体层（当前未接入主链）
      hardware/                                        硬件抽象 + 机器人本体
      pulses/                                          脉冲配置（纯配置，无代码）
      utils/                                           轻工具
```

**一句话读图**：一切输入都先化为**脉冲**进入信息场，再分发给认知层；认知层产出经内在模型沉淀，最后由行动层表达——**任何两层之间都不直连**，这是故障隔离与可观测性的结构性来源。
