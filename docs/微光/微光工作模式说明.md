## 二、工作闭环

```
        任务书(唯一入口=星轨)                交付报告
  小林 ───────────────→ 路灯 ─────────────────────→ 星轨
  (终裁/拍板)            (唯一编码执行体)              (写单+终验+总账)
      ↑                                              │
      │ 可直接口头指令(需星轨24h补任务书)                 │ 反向验收
      └──────────────── 微光 ←────────────────────────┘
                   (验收星轨 / 文档总管 / 巡 data)
                         ↕ 交叉验证
                       烛微(代码深审) · 第三方(关键节点终审)
```

**制衡铁律**：写单的不施工、施工的不验收、验收的不拍板、巡检的不写代码。

## 六、省耗纪律

**总模型（降耗 v2）**：总成本 ≈ Σ 每一轮上下文长度；**大输出 × 越早出现 = 越贵**。核心改造：把「数据 → 上下文」改为「**数据 → 文件 → 一行摘要进上下文**」。

**省耗十条（最高执行纪律，星轨 2026-09-29 下发）**

| 侧 | 条 |
|---|---|
| 输入 | 1. 输出 >2KB 先落盘，上下文只放 ≤5 行摘要 ｜ 2. >100KB 文件用 `Select-String` 带行号，**禁整文件 Read** ｜ 3. 全量采集脚本化一次跑，脚本留 `.aionclaw-tmp\` 复用 ｜ 4. 已采数据直接引用「见 XX 报告」，**禁重扫** |
| 输出 | 5. 报告两层结构（主报告结论+证据+关键数字，大表落附件）｜ 6. 不重复推导已定论数字 |
| 流程 | 7. 命令批量合并 ｜ 8. 任务书一次读完 + 提炼必答清单，执行中不回翻 |
| 精度 | 9. **结论数字双检**：先输出字段名清单再计数（防口径误读），关键数字附复现命令并注明「已复测」 ｜ 10. **偏差零容忍自报**：与预期不符立即自报「已订正」，不掩盖 |

**量化指标（Q33：旧指标保留，平台无关）**

| 维度 | 硬指标 |
|---|---|
| 工具调用 | ≤12 次/任务 |
| 单条 stdout | ≤2k 字符 |
| poll 空转 | **0 次**（跑完一次性返回，单次长等待） |
| 巨 JSON | 禁止 grep/整读，只 `python` 聚合 |
| 全量扫描 | 1 次（首跑即设超时 + 排除大目录） |
| 临时结果 | 落盘复用，不进上下文 |
| 计费口径 | **「Credits」改记 token / 费用**（新平台计费不同）；报告附 token 用量（如可得） |

**自评锚点（每次任务后）**：轮数 ≤12？单输出 ≤2k？零空转？大输出是否落盘不回流？
