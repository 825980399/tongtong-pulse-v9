### 💡 优化建议

#### 1. **角色职责矩阵（RACI）**
```
R = 负责执行  A = 最终决策  C = 需要咨询  I = 需要通知

                路灯  星轨  烛微  微光
架构设计         A     C     C     I
代码审查         C     A     R     I
流程规范         C     A     C     I
任务执行         I     C     C     R
质量把关         C     A     R     I
```

#### 2. **简化协作流程**
- 减少批次层级（目前 B156 → B156-2 → B156-3 太复杂）
- 用 GitHub Issues 代替部分台账
- 自动化更多 CI 流程

#### 3. **知识传承**
- 建立"关键技术决策文档"
- 核心模块必须有两人以上熟悉
- 定期技术分享

#### 4. **人机协作边界**
- 明确哪些是 AI（Tongtong Dev）做的
- 哪些必须人工确认
- 避免 AI"假装修复"
