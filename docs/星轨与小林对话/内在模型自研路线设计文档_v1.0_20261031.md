## 八、真进化 vs 伪进化判据

**伪进化 = 有写入、无读取；有结论、无对账；有重复、无变化。**

**真进化 = 同一类问题第二次出现时，本地路径变了，且变化可追溯到一条明确的经验/预测记录。**

七条判据（可直接当验收表）：
1. 有输入：单位时间内有真实外部请求进入推理链
2. 有固化：LLM的答案被转成本地可复用物（规则/缓存/节点）
3. 有检索：同类问题下次会先查经验库
4. 有复用生效：检索命中后改变了回答路径
5. 有预测-验证：先给出预期，事后再对账
6. 有自我修正：预测失败会改规则
7. 有连续性：重启后仍能说出"我之前学到过什么"
