- 设计：星轨（综合洞鉴400框架分析 + 烛微401细部核对）
- 日期：2026-10-30
- 状态：已定方案，待施工

---

## 一、设计原则

1. **一切"活着/正常"字段必须带 source + measured_at**——否则=假观测
2. **采集面绝不阻塞热路径**——只append台账，不做同步校验
3. **语义面先有字典，不急校验**——软着陆，不一步到位
4. **时间面是L3/L5的时间维度**——不是独立层，共用聚合器
5. **L8只清册不实现**——空中楼阁，不投资源
