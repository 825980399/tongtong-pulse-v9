# 旧口径禁用读数清单 v2（335 批 · 审计链落地 · 替代 v1）

- **性质**：**禁用清单**——下列读数**不得再被引用**（含作为基线、作为对比分母、作为告警依据）。

  审计链要求有一处**唯一权威**可 grep。
- **处置原则**：原文报告**只追加注记、不删原文**（历史上下文要保留），引用方一律以本清单为准。
- **合并表**：本文末尾「开闸前置表」＝ 判定树 8 步 ＋ 本清单禁用项 ＝ **单张权威表**（不再两套口径）。

  3. **新增 A-11 / A-12**（洞鉴 334 实测暴露，见 §A-11／§A-12）；
