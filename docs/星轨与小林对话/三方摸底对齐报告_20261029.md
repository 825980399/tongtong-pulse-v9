### 洞鉴实锤（代码级）

```

_schedule_next_beat() = 先cancel在途Timer再新建（PulseHeart.py:396-407）

⇒ 5s < 9.5s：每一拍都在到期前被下一轮"救援"取消
⇒ gap一旦>19s就再也回不到≤19s
⇒ 永久livelock
```
