## 一、实测过程

1. 打开 SCNet 控制台 → 费用总览（余额被掩码，页面底部显示可用金额）

3. 创建镜像页 → 确认适配加速卡含 **GPU / DCU / 无加速卡**，镜像来源含 **镜像包/Dockerfile/外部仓库**

6. **资源规格确认：8核/27GB、16核/55GB（最大）、自定义** —— 纯 CPU 容器可下单

## 三、其他确认

- **镜像支持**：✅ 创建镜像页"我的镜像"可选；镜像来源含 AI社区/外部仓库/镜像包/Dockerfile/社区镜像
- **镜像包上传**：需先在**文件管理（E-File）**上传本机 docker save 导出的 tar，再到创建镜像页选"镜像包"+ 文件路径
- **SSH 服务**：创建镜像可选"需要"（平台自动安装）——便于终端进入容器
- **公网访问**：绑定外网 IP 后容器可访问公网（帮助手册确认）——与 10-03 实测一致
- **运行时限**：容器任务可设运行小时数；新版组 DCU-BW 单作业上限 72h（烛微 172 已确认）
- **队列选择**：CPU 规格落在 kshcnormal 队列（华东一区【昆山】资源）；DCU 队列 hx1hdnormal（华中一区【A区】95节点）/ kshdnormal（华东一区【昆山】612节点）
