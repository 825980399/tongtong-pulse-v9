## 五、API 密钥注入预案

1. **原则**：密钥不进镜像、不进代码、不进 SCNet 持久盘；
2. **注入方式**：运行时环境变量（容器启动时 `-e` 注入）或运行时挂载（SCNet 文件管理上传到运行目录，用完即清）；
3. **处置**：镜像内 `config.py` 凭证位留空，启动脚本检测缺失 → 明确报错（不静默降级，遵守协作清单"降级必须产出可观测标记"准则）；
4. **外脑指向**：SCNet 公网可访问 → 保持现有 `deepseek-v4-flash` 默认；若受限 → 断网模式（S5 场景优先）。
