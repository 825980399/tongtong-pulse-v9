- 基础镜像 `python:3.11-slim` + `libgomp1`（faiss-cpu 依赖）
- 依赖层与代码层分离（利用 Docker 缓存）
- COPY 代码目录：nucleus / organs / base / functions / hardware / tools / pulses / somatics / utils（9 个顶层代码目录，**models 按设计不打包**）

### .dockerignore（根目录）
排除：`.git/` `.github/` `data/` `logs/` `tmp/` `tests/` `tools/ci/` `docs/` `*.md` `models/` `.bak_*` 密钥/凭证/缓存/IDE 件

- 核心必需：requests
