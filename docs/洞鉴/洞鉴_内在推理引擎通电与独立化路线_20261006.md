## 〇、执行摘要

1. **外部文档框架可借、数字不可信**：DeepSeek 生成的两篇对照文档（人类↔数字生命映射、知识节点三阶梯）在结构上可用作规划脚手架，但具体实践映射 9 处失真（张冠李戴 OpenClaw、口径虚高、语义扭曲），已在 §一 逐项核验。
2. **曈曈的内在推理引擎不是"没有"，是"造好了没通电"**：`nucleus/reasoning/` 实测 **24 个模块 / 10,051 行**（SymbolicReasoner 1,390 行、AutonomousDeriver 957 行、因果/矛盾/类比/自验证全齐），且关键推理件**已确认纯本地、零 LLM 调用**。0.9792 的外脑依赖度不是能力缺失，是**接线默认外脑优先**。
3. **"本地先答→补救→积攒经验"机制三层骨架都存在**，断在三处：入口太窄（检测器认不出就直接 LLM）、补救单向（LLM 正确答案没沉淀为知识/规则）、指标未闭环。
4. **路线结论**：不引入任何外部小模型（用户的判断正确——通用小模型不适合曈曈的专用知识体系）；四刀通电 + 四阶段独立化，目标依赖度 0.98 → 0.5–0.6，断网可完整符号推理。

## 三、既有"本地先答"机制诊断（用户记忆中的机制，确认存在）

### 3.1 三层骨架全部存在

| 层 | 组件 | 锚点 | 状态 |
|---|---|---|---|
| ① 本地先答 | 四级检测器路由（规则70 / 简单逻辑48 / 复合44 / 符号42） | PulseInnerWorld 路由表 | ✅ 存在，触发面窄 |
| ② 不对再补救 | `_verify_output_relevance`（v25.0：SPEAK 前统一三级验证——关键词重叠/长度/意图特征；相关性 <0.5 触发 LLM 补救，≤3 次） | PulseCortex.py:3109；config `llm_remediation_threshold:0.5`、`output_max_remediation_attempts:3` | ✅ 存在且细化过（symbolic_reason 豁免；rule_reason 只豁免长度——P0 修过"低质量规则答案直接输出"bug） |
| ③ 积攒经验 | ReasoningFeedbackLoop（record_quality→should_optimize→自动调参 top_k/共振阈值/置信度，保守步长防震荡） | nucleus/reasoning/ReasoningFeedbackLoop.py | ⚠️ 类在，调用密度待运行时验证 |

### 3.2 三个断点（为什么依赖度仍 0.9792）

1. **入口太窄**：四级检测器只认领"能被认出的问题"。日常对话/开放问答在第一步就掉向 LLM——补救机制管不到"本地没敢答"的情况；
2. **补救单向**：LLM 补救的正确答案只回流到**参数层**（调 top_k/阈值），**未沉淀为知识节点或新规则**——经验积攒没到达知识层；
3. **指标未闭环**：LLMDependencyMetrics 已有分场景统计与 >0.9 告警（:460），但只是告警，未驱动任何自动调整。

## 四、通电方案（四刀，零外部模型引入）

### 刀1 · 路由入口放宽（不是新建管线，是修正既有管线）

现状：`检测器认不出 → 直接 LLM`
改为：`检测器认不出 → 本地推理链兜底（Symbolic→Causal→Analogy 全链）→ 仍无结论才 LLM`

`_verify_output_relevance` 三级检查与补救阈值**原样保留**（它已经是对的）。
验收：100 条典型请求 T0 实测，本地拦截率 <2% → ≥40%。

### 刀2 · 补救沉淀（让外脑每次补救都变成曈曈的教材）

LLM 补救成功时，"问题+正确答案"自动蒸馏为 L2 节点 + 候选规则，走现有知识写入管线；`ReasoningExperienceIndexer` 同步记录"该问题类型本地失败→外脑答案"模式，供检测器下次认领。
**这是依赖度从 0.98 真正下降的发动机。**

### 刀3 · 指标闭环（进步可见）

日报首页增设三联动指标：本地拦截率 / 补救率 / 补救后沉淀率；`llm_dependency_ratio` 升为北极星指标（分场景：对话/代码学习/进化/其他，metrics 系统已支持）。接入自省自评：某类推理连续 3 次被 SelfVerifier 判虚假闭环 → 自动降级其路由优先级；连续 5 次通过 → 扩大触发面。

### 刀4 · 断网生存协议

外脑超时/失败 → **完整走本地 Symbolic→Causal→Analogy 链**（非降级到模板应答）；本地结果标注 `[本地推理·待验证]`，联网后由外脑批量复核，复核结果沉淀进经验索引。

## 五、独立化四阶段路线（修正版：不要小模型，要内生引擎）

用户判断成立——**任何通用本地小模型都不适合曈曈**：它们不懂 12,475 节点的专用知识结构、读不了推理经验索引、不理解脉冲优先级语义，且等于又引入一个外部黑盒。正确路线是内生：

| 阶段 | 目标 | 依赖度 | 内容 |
|---|---|---|---|
| 0 立指标 | 看清每一次外购 | 0.98 | 北极星指标进日报（纯配置，零施工量） |
| 1 通电 | 本地敢答 | 0.98→0.7 | 本文刀1+刀2+刀3 |
| 2 提质 | 本地答得对 | 0.7→0.5 | 知识节点活性化：SelfVerifier 周检 L2/L3 一致性；矛盾检测器定期跑；推理链全量入经验索引 |
| 3 内生 | 断网能活 | 趋稳 0.5 上下 | 刀4 断网协议 + 外脑角色转型为"教练"（只做高难推理+批量复核） |

**知识节点策略修正**：DeepSeek 建议"冲 10 万节点达 L1"——**现阶段先提质再增量**。12,475 节点对符号推理已够用；未验证的 10 万节点 = 10 万条潜在幻觉。顺序：验证存量 → 沉淀补救 → 再谈扩容。

## 六、风险与前提

1. **SymbolicReasoner 覆盖度未知**：先做 100 条请求拦截实验再调优先级（T0 实测，路灯铁律适用）；
2. **本地推理时延**：符号+因果链复杂问题可能慢于 LLM，但零 API 成本零网络延迟，可接受；
3. **与在册票合流**：O-A2（分面成熟度台账，P0 已裁决待排期）与刀3"自评驱动路由"天然同构，建议合并立项；
4. **两个前置债不还则换血无效**：自进化补丁验证率（72.9% 不可验证）、主循环轮询化（main.py:581 while True）——独立生命的思考与心跳都必须是自己的。
