# 压测报告模板 v1（319 批 · 可复用件）

> 采集：`python tools/stress/collect_stress_baseline.py --loop <N> --json data/stress/loop_<N>.json`
> **S/L 双栏**：S 圈＝沙箱（只证机制）；L 圈＝活体（才证自转）。**通过线只属 L 圈**——禁止用沙箱数据宣布"自转成功"。
> **开三环、闭四环**：执行环（第四环）在 per-item 洪峰未消化前**不真执行**（星轨+小林 2026-10-19 裁定）。

> **★代次规则（331 批刀5 · 跨进程计数不得拼接）**
> - `proc_gen = pid<PID>@<进程创建时刻>`，创建时刻由内核记账、**无法伪造**（与 321 刀4 的活体 PID 同判）。
> - 计数面（`runs` / `productive_total` / `zero_total`）**必须自带代次标签**：任何跨进程的 runs 直接相加都是假账——上一进程的 11 拍 ＋ 新进程的 20 拍 ≠ 31 拍。
> - 重启后 `runs` 从 0 重计属**预期**；要跨圈比较须先对齐 `proc_gen`，代次不同的两串数**不得合并**。
> - psutil 不可用时记 `pid<N>@unknown`，**不填 0**（0 会被读成"1970 年起的进程"）。
