> **★代次规则（331 批刀5 · 跨进程计数不得拼接）**
> - `proc_gen = pid<PID>@<进程创建时刻>`，创建时刻由内核记账、**无法伪造**（与 321 刀4 的活体 PID 同判）。
> - 计数面（`runs` / `productive_total` / `zero_total`）**必须自带代次标签**：任何跨进程的 runs 直接相加都是假账——上一进程的 11 拍 ＋ 新进程的 20 拍 ≠ 31 拍。
> - 重启后 `runs` 从 0 重计属**预期**；要跨圈比较须先对齐 `proc_gen`，代次不同的两串数**不得合并**。
> - psutil 不可用时记 `pid<N>@unknown`，**不填 0**（0 会被读成"1970 年起的进程"）。

## 〇-1、K1 判据（★333 批刀3 固化：同代次累计 20 拍）

> **判据原文（写死，不得口头放宽）**：
> **同一进程代次内累计 20 拍，productive_total / runs ≥ 15/20，且 `productive` /
> `reviewed` / `report` 三列同报** ⇒ 本代次 K1 达成。

| 项 | 规则 |
|---|---|
| 计数单位 | **一个 `proc_gen` 一条独立计数**（`pid<N>@<创建时刻>`） |
| 跨代次 | **不得拼接**：上一代 11 拍 ＋ 新代 20 拍 ≠ 31 拍；只能**分别计数、分别判定** |
| 重启清零 | 属**预期**（代次切换），不是退化；本代次 `runs` 从 0 重计 |
| 拍数不足 20 | 记 **pending（未达可判窗口）**，**不得记 0、不得记未达成** |
| 三列同报 | 缺任一列（如 `report` 未取到）⇒ 本代次判 `三证不全`，不得只报两列就算过 |
| 退化告警 | 同代次内 `productive` 连续 ≥3 圈为 0 ⇒ 命中退化告警（见 §七） |

**读法**：`[317刀3][产出率] ... runs=N productive_total=M rate=X proc_gen=<代次>`
—— 先看 `proc_gen` 是否与报告头一致，再看 `runs` 是否 ≥20，最后看 `rate`。
**三者任一不符即不得下"K1 达成"结论。**

## 〇-4、RSS 熔断线 / 判定线（两线都写死，不靠人记）

| 线 | 阈值 | 动作 |
|---|---|---|
| **降级线** | 峰值 RSS **≥ 10GB** | 该圈**降级为单圈观察**：只跑 1 圈即停、记录峰值与增量，不并入多圈趋势（洞鉴 4.1） |
| **判定线** | 期末 RSS **≥ 12GB** | **判定线第八项失败** ⇒ 本圈记为「不合格圈」，不得宣布压测通过 |

- 两线读数**必进报告头**（期末 / 峰值 / 每圈增量三行），不得只写在正文里。
- 增量口径：`期末 RSS − 开跑 RSS`；**连续 3 圈为正且累计 ≥2GB** ⇒ 按泄漏嫌疑排查（与 §七 退化告警同看）。
- 熔断线**不阻断只读巡检 / 心跳 / W1**：RSS 只决定「这一圈算不算数」，不改系统行为。

**三条件式（三条同时成立才判脱节，K2 不得开）**：

| # | 条件 | 判据 | 读数出处 |
|---|---|---|---|
| ① | **判死档真开** | `mode == "judge"`（不是 review/silent） | `baseline.m92.mode` 或 `[319刀3]` 打印 |
| ② | 任务面非空 | `reviewed > 0`（同窗 `[317刀3]`） | `[317刀3][产出率]` |
| ③ | 闸口**连续缺席** | `[319刀4]` 同窗连续 **≥3 窗**无新行 | `[319刀4] 判死条目消费` |

**缺任一条件 ⇒ 不得判脱节**，只能记 `不可判（condition_k）`：
- 仅 ②不满足（`reviewed=0`）⇒ 任务面空（318刀4 归因），与对表无关；
- 仅 ①不满足（`mode=review`）⇒ 判死档未开，**闸口 0 是预期**；
