- **书问2 高分辨率源——本窗头号发现**：`pulse_tracer` 环窗的 emit/receive 记录**天然携带同源 `time.time()`（亚秒精度）时间戳、`from` 字段、matched_organs 1→N 结构**（函数体实读）——emit→receive 之差＝**同进程总线分发延迟，真实毫秒级因果 Δt**，且因果方向天然正确（发射必先于接收），A₊/A₋ 不对称窗**语义存活**。**唯一缺口＝环窗不落盘**（现仅孤儿文件落盘，200 槽环随进程蒸发——205 批停摆 4h 已再次演示"数据随进程死"）。
- **方案（半刀级三件）**：①**成对流落盘**——flusher 周期性（间隔 < 环窗驱逐周期）将环内 emit/receive 对 dump 追加至 `data/monitor/pulse_pairs.jsonl`（行含 pulse_id/类型/器官/event_type/ts）；环窗参数已 config 化（`PULSE_TRACER_EVENT_RING_SIZE`，206 窗实锚），**扩到 2 万量级＋10min flush 双保险**；②**精度半刀**：log_receive 现按 event_type 反扫最近 emit（同名事件紧邻有回写错位风险）——receive 记录补 pulse_id 直连，配对从启发式变精确；③STDP 实验件加"pair 源读取器"接此文件。①②均为 tracer 只读扩展＋既有锁域外快照 copy（200→2万 copy 持锁时长需微评估——放锁外浅拷贝）。
- **书问3 参数**：pair 源上回归 SNN 文献档——τ₊/τ₋＝10~50ms、窗 ±100ms、A± 维持 0.01/0.012、SEED/VERSION 指纹制度沿 205刀3 先例；对话源参数组**废止**（仅留作实验件的方法学演练用例，不再称"接真实训练对"）。
