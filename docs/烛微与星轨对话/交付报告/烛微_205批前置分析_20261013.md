## §3 STDP 实验模块设计（离线回放，生产零触）

- **素材源分档（本窗实读字段形）**：**主源＝training_pairs jsonl**（键含 `ts/trace_id/channel/origin/input/output/prompt_version`——时间序天然、成对 pre/post 语义现成：input=pre 侧、output=post 侧、Δt=ts 差）；**辅源＝ReasoningExperience/FirstPersonExperience/RuntimeTrajectory**（事件序列面，供跨窗口长程对）；**排除 task_ledger**（重启对账账本语义，非脉冲时序）。
- **回放流程（新 tools/ 一件，五步）**：读入按 `ts` 排序 → 构造 (pre_spike, post_spike) 对（窗口 ±20ms 候选，SNN 文献标准档，票面）→ 指数窗 `Δw = A₊·e^(−Δt/τ₊)`（pre 先）/`−A₋·e^(Δt/τ₋)`（post 先），A/τ 四参数全常量入实验文件头（**seed＋参数快照随结果落盘，可复现**）→ 权重更新在**实验件本地 dict** → 结果 `data/experiments/stdp_YYYYMMDD.jsonl`（每行 pair_id/Δt/Δw/w_after/参数指纹）。
- **与生产面的隔离红线**：**不 import 也不写 ResonanceDetector 的 weight_map 实例**——204刀2 已拍 D#2 解封（施工在途），但**解封的含义是"允许生产接线（203刀1 后端）"，不等于离线实验要蹭生产单例**；实验产物若要对照 weight_map，只做**只读拷贝比对**（快照导出）。学规则代码全在新件、生产零触——cw2/门禁零新增风险。
- **测试**：合成小序列（给定 Δt 序列断言 Δw 符号与量级）、seed 定数复现断言、参数边界（Δt=0/窗口外）——隔离单测惯例（m-195~203 连批成型）。
- **风险与预期管理（诚实条）**：STDP 在"rate 编码默认"的现仓语义里是**探索性实验非功能件**——它的价值读数要等 LIF 影子给出膜电位分布后才知道"阈值窗对不对"；**建议排序 LIF 影子先行、STDP 随后同批或次批**，避免"两个都是影子、谁也不消费谁"。
