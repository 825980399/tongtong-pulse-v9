1. `:188` `cur_max = max(raw.values())`；`:189` `norm = raw / cur_max` ⇒ `max(norm) ≡ 1.0` ⇒ `:202` `norm_max` **恒为 1.0**。

4. ⇒ `delta = |actual − sim| ≡ 0`。**把 `ref` 改成任何常数、把窗长改成任何值，只要分子被 bound 在 1.0，它照样是 0。**
