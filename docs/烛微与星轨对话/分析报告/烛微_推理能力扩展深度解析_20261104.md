## 〇 结论摘要

**洞鉴说“推理被关在影子模式里”，对；但“影子工程”的根因不是保守文化，而是“重启节奏 > 观测窗口”的制度性卡死。**

- 197 批（10-12）落“实时注入三要素影子”；198 批（10-12）写了“实弹刀”设计，放行三条件之一就是“取得 L2 命中率基线（遥测首读窗）”。**23 天过去，实弹刀没拍**——因为框架每批都重启，442 批实测“没有一个进程活过 1 小时”，任何“等 24h 基线”的条件永远不闭合。
- **8 维里真正的地基不是 D1（多步），是 D2（trace）+ D3（证据注入）**。D1 的“本地链”只喂了 Symbolic 一条腿，Causal/Analogy 两条腿在调用处连参数都没传（`survive_offline(question, None)`），接上也解不出东西。
- **最高 ROI 不是“再写一个推理器官”，是把已经存在的证据接进回答**：PulseLung 的影子检索今天 **105 条日志**、每次 3 条、score 0.62–0.69，**内容却只记了分数、没留正文**；198 刀3 的设计（阈值 0.55–0.6、3×120 token、L2 先后次序）已经写好，只差执行。

**三件事对比：**

| 洞鉴的 3 件事 | 烛微的 3 件事 |
|---|---|
| ① 本地链从断网/影子改为在线先跑（1 刀） | ① **检索 top-3 内容 dry-run + 注入**（2 刀；198 刀3，证据已存在） |
| ② steps 落 trace（1 刀） | ② **trace 分步 + 采样**（1 刀；先让“可数”） |
| ③ 修元认知两个 bug（1 刀） | ③ **元认知两 bug + 假器官改名**（3 刀；停止污染自画像/推理口径） |

**本地链不是第 1，是第 4**：它只解符号题，且 causal/analogy 没数据；先接检索，用户当天就能看见差别。

**这是“影子工程”的标本**：不是没有设计，是**设计的放行条件依赖一个永远等不到的稳定窗口**。

### 1.2 为什么卡死：重启节奏 > 观测窗口

- 442 批原文：“**没有一个进程活过 1 小时** ⇒ 永远停在 `armed` ⇒ O3 判定一次没跑。”
- 443 批原文：“进程 00:10:49 启动，442 业务提交 00:21:25 ⇒ **跑的还是旧代码**。”
- 445–451 每批都“改完需重启生效”；今天 `pid=16732` 21:39:57 启动，451 批 22:15 才提交 ⇒ **451 现在还没加载**。
- 198 的第三条件要“遥测首读窗”；首读窗要“稳定进程”；稳定进程被“每批重启”打断 ⇒ **实弹条件永远不成立**。

**结论：影子工程 60% 是制度（批次制 + 重启节奏 + 无 live owner），30% 是架构（两套半链），10% 是数据（无 eval set）。** 不是“工程师不敢”，是“验收条件在物理上不可达”。

### 1.3 三个次因

1. **两套半链**：
   - `StrategySelector.route_with_local_reasoning_chain`（`:198-231`）只返回 `route`，调用方 `PulseCortex.py:1355-1360` 把它 `_shadow` 掉、只记 DEBUG；
   - `offline_survival_protocol.survive_offline`（`:87-160`）是真执行，但 `PulseCortex._compute_offline_survival` 调的是 `survive_offline(question, None)`——`causal_pairs/node_pool/analogy_texts` 全没传，**Causal/Analogy 两腿永远空转**，只剩 Symbolic。
2. **无 eval set**：真实对话只有 **8 次 user_query/日**（`calls_20261104.jsonl`：578 次调用，408 system_internal、162 evolution_task、8 user_query）；`inference_trace` 50 条里 **43 条是“你是谁”**。没有标注集，任何“影子→实弹”都无法判好坏。
3. **无 live owner**：每批任务书都是“新增能力/修 P0”，没有一批的验收线是“X 维度从影子改实弹且 A/B 通过”。影子交付即完成，实弹自然无限延期。

### 1.4 破局：把“等长窗”改成“proc_gen 内可判”

445–451 已经给了现成基建：

- 450 批：`patch_chain` 增 `gen_voided/gen_pending/approved`，按 `proc_gen` 分段；
- 451 批：意图硬规则 + `proc_gen` 计数；
- 447 批：`maybe_approve_scoped`（日限额 + 八闸 + 全文留痕）。

**建议把“影子→实弹”的放行条件改成四闸，全部可在单进程内判完（≤1h）：**

| 闸 | 判据 | 当前是否可判 |
|---|---|---|
| 数据闸 | 本 `proc_gen` 内影子样本 ≥20 条，且不是同一问题重复 | ✅ 今天 105 条 |

| 成本闸 | token 增量 ≤ +15%，延迟增量 ≤ +10% | ✅ 可测 |

**不要再写“等 24h 基线”**——那是重启节奏下的死条件。用“单进程 1h + 跨进程累计计数”替代。

### 1.5 最小改动：先做 198 刀3（检索注入），不是本地链

**为什么是检索注入：**

- 影子检索**已经可用**：今天 105 条日志，`retriever=available 条数=3`，score 0.62–0.69；
- 它**不增加 LLM 调用**、只改 system prompt、可即时回退；
- 198 设计已写死注入点（`_sys` 组装区）、阈值（0.55–0.6）、预算（3×120 字）、L2 次序（query 用原文、回写剔除注入段）；
- 对比本地链：只解符号题，causal/analogy 没数据，接上大概率返回 None 再走 LLM，用户看不见差别。

**但影子只留了分数，没留正文**：`build_shadow_v2_fragment`（`shadow_v2_probe.py:60-83`）返回的是统计串，`_hits` 在函数内被丢弃。所以是 **2 刀**：

1. **刀 A（dry-run）**：新增 `build_evidence_block(retriever, query, top_k, min_score)`，把 top-3 的 `text/source/score` 落到 `data/o_a4_evidence_trace.jsonl`（不注入），跑 1 天看正文相关性；
2. **刀 B（注入）**：`ENABLE_LUNG_EVIDENCE_INJECT`（默认 False）→ 在 `PulseLung.py:1068` 之前把 `[检索证据]` 段拼进 `_sys`，阈值 0.6、3×120 字、带来源；先 1% 流量（`hash(correlation_id)%100==0`），再 10%、100%。

**验收**：50 题 eval 胜+平 ≥45；注入段被回答引用 ≥5 题；token 增量 ≤15%；回退开关 1 秒生效。

### 4.2 和 DeepSeek-R1 比：差在“单模型长链”，不是框架能补的

### 5.2 伪 CoT：`_deep_think` 的三轮写死

- `PulseInnerWorld.py:16397-16409`：当有知识命中时，三轮文本是**写死的三句**：
  - “从我的知识体系中检索到相关信息：{知识}。从这些知识出发，这个问题的核心涉及以下几个层面的概念交织。”
  - “换个视角来看——如果从框架架构、认知演化、以及实际运行效果三个角度分别审视……”
  - “跨领域来看，这个问题可以从我已理解的「自我进化」「知识体系」「稳态规则」等概念框架中找到对应的解释模型。”

   - 给结论 + 置信度。

## 六 总体结论：推理能力提升的最优路径

### 6.1 最优路径（一句话）

**不要再加推理器官；先把“已有的证据”接进回答、把“每一步”记下来、把“假器官/假 CoT”改名或替换；然后用“推理算子”替换“检索步骤”，最后才做批判、抽象、创造。**

### 6.2 如果只做三件事（1 周，6 刀，零新增 LLM 成本）

| 排序 | 动作 | 刀 | 预期 |
|---|---|---|---|
| 1 | **198 刀3：检索 top-3 内容 dry-run + 注入**（阈值 0.6、3×120、L2 次序、1%/10%/100%） | 2 | D3 3→5；用户当天可见“回答里有证据” |
| 2 | **trace 分步 + 采样**（`steps` + `step_count/evidence_count`；身份问候不入 trace） | 1-2 | D2 2→5；后面 5 维有真实样本 |
| 3 | **元认知两 bug + 假器官改名**（`_core_words` 时序、`derivation_type` 过滤、InferenceEngine 降级） | 3 | D5 4→6；停止“恒真边界/脏自画像/假推理” |

**做完这三件，2.6 → 4.6-4.8；而且没有新增一次 LLM 调用。**

### 6.3 和洞鉴一样吗？

**不一样。** 洞鉴把“本地链上线”排第 1；烛微认为它是第 4：

- 本地链只喂了 Symbolic，Causal/Analogy 没输入；接上大概率返回 None 再走 LLM，用户看不见；
- 检索注入已有 105 条/日影子数据、198 设计已写好，是**当天可见**的收益；
- trace 是后面 5 维的地基，越早越好；
- 元认知两个 bug 是“最便宜的 credibility 修复”。

**一句话给星轨**：**先让“回答里有证据”，再让“推理有步骤”，再让“自画像不说假话”；这三件做完，再谈多步、批判、创造。** 影子工程不是靠“更勇敢”破，是靠“把 24h 长窗改成 proc_gen 短窗 + 50 题 eval + 单维度灰度”破。
