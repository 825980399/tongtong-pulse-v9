### 第二部分 · 假设证伪清单与目标重排建议

**证伪/更正清单**（每条给：原假设→证伪证据→教训→后续处置建议）：
1. 解析率50%可达 → 三路全封堵、上界≈37.2% → 比例外推必须先扣"类型不属于目标集合"大块 → **开闸口径改O3（已裁N=100）**

3. 中期10因果链"料源激活→L2命中" → 料源过量消费、L2无真命中（0次） → 消费面拓宽＋L2落盘单独裁 → **因果链两头不成立，原叙事项作废**
4. P-15"dispatched=1=自转" → 已执行非应用、账本跨错、重复失败循环 → 三拆＋fail_count熔断 → **台账不是派单副作用账本（口径纪律）**
