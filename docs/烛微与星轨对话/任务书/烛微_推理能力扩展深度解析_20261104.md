## 分析任务

在洞鉴分析的基础上，做以下扩展深度解析：

### 1. 影子工程的根因与破局路径
- 洞鉴发现"影子工程"是系统性瓶颈——先影子、永不实弹。为什么会形成这个工程习惯？是历史原因还是设计如此？
- 破局的最小改动是什么？能不能分步放，先放一个维度的影子→实弹，验证没问题再放第二个？
- 影子→实弹的风险边界在哪里？哪些可以先放，哪些必须保守？

### 2. 推理链接线的优先级排序
- 洞鉴列了8个维度，建议先做3件事。烛微再评估一下：除了洞鉴说的3件，还有没有更高ROI的切入点？
- 8个维度之间有没有依赖关系？哪个先做了，后面的会事半功倍？
- 给出一个分阶段落地路线图（P0/P1/P2），每阶段做什么，预期收益多少。

### 3. 与当前优化路线的合并
- 现在正在做P1路线（WARNING降噪/意图识别/对话体验校准等）。推理能力提升和当前P1路线是什么关系？是并行？是前置？还是可以合并？
- 哪些推理相关的刀可以塞进当前的批次里一起做？哪些必须单独排？
- 结合445-451批的进化闭环打通成果，推理能力提升能不能借势？

### 4. 对标差距的量化拆解
- 洞鉴给了10分制评分，但比较粗。烛微再细化一下：
  - 和DeepSeek-R1比，差在哪些具体能力点上？
  - 和Claude 3.5 Agent比，差在哪些具体能力点上？
  - 和顶级人类比，差在哪些具体能力点上？
- 每个差距点，要补什么才能补上？成本多大？

### 5. 假推理器官的处置方案
- PulseInferenceEngine返回占位符——是拆掉？还是真接？还是降级改名？
- 洞鉴发现的"伪CoT"（深度思考三轮写死）——是改成真CoT？还是先记录下来后面再说？
- 类似的"壳子器官"还有哪些？全仓扫一遍。
