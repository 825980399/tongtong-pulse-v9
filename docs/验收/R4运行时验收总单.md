## 4. 验收判据的「0 命中正控」

凡用「某串 grep 命中数 = 0」作**通过**判据的条目（B10/B18/B22），
必须同时证明「该串在反例下确实能命中」，否则 0 命中可能只是命令写错。

本批已备的正控用例：

```bash
python -m pytest tests/test_m117_ratchet_and_smoke.py -q   # 9 passed
python -m pytest tests/test_m117_tracer_flush.py -q        # 9 passed（含头判尾更正控）
python -m pytest tests/test_m117_path_norm.py -q           # 5 passed
```

其中 `test_m117_tracer_flush.py::test_02_negative_control_old_logic_blows_up`
是**正控**：同样 50 线程下，旧「头判尾更」逻辑必然放大到 >10 次写，
证明「≤2/窗」这个通过判据**有区分力**，不是恒真。
