## 刀1：周期档案落盘

**做什么**：从StreamMiner现有模式库里，把七类事件的真实周期抽出来，存成一份基线档案。

**怎么做**：
- 读 `data/stream_miner/patterns.json`，筛出七类事件（eyes.stream_frame / heart.beat / heart.alive / touch.hardware_snapshot / energy.metabolism_snapshot / spinal.inspection_report / digest.knowledge）的repeated+periodic模式
- 落盘 `data/world_model/periodic_profile.json`，每条含：
  - event_type
  - median_interval_sec（中位间隔）
  - p90_interval_sec（90分位间隔）
  - sample_count
  - predict_type（"periodic"=周期型 / "count"=计数型 / "burst"=突发型）
- **heart.beat过滤口径必须是 `type=="emit" AND organ=="心脏"`**（烛微修正：只按organ=="心脏"会把receive侧4888条混进来）

**验收**：
- 七类事件档案齐全
- heart.beat的median_interval在13s左右（不是0s，证明过滤口径对）
- eyes.stream_frame的median_interval在0.5s左右（证明是密集流）

## 刀2：分类型预测 + 分类型容差

**做什么**：废弃现有60秒一刀切容差，按事件类型分三型预测、分类型容差。

**三型分类**：
| 事件 | 预测型 | 预测目标 | 容差 |
|---|---|---|---|
| touch.hardware_snapshot | periodic | 下一分钟发生次数（2次±1） | ±5%标称周期 |
| energy.metabolism_snapshot | periodic | 下一分钟发生次数（2次±1） | ±5%标称周期 |
| spinal.inspection_report | periodic | 下一分钟发生次数（1-2次） | ±10%标称周期 |
| heart.alive | periodic | 下一分钟发生次数（4-5次） | ±5%标称周期 |
| heart.beat | periodic | 下一分钟发生次数 | ±5%标称周期 |
| eyes.stream_frame | count | 下一分钟条数区间（μ±2σ） | 不设时刻容差，区间命中即算对 |
| digest.knowledge | burst | 批次检测：gap>60s切批，预测下一分钟批数 | 不设时刻容差 |

**怎么做**：
- 改StreamMiner的 `_check_prediction_hits`，容差从固定60s改成按event_type查表
- 周期型（periodic）：按刀1产出的periodic_profile.json里的median_interval×百分比算容差
- 计数型（count）：不预测"下次什么时候来"，预测"下一分钟来多少条"，区间命中即算对
- 突发型（burst）：先检测批次（gap>60s切批），再预测下一分钟批数

**验收**：
- 废弃60s一刀切，按类型分级
- eyes.stream_frame不再因为"0.5秒来一条"而恒命中
- 七类事件各自有对应的预测目标

## 刀3：hit_rate日报表 + 失配告警通路

**做什么**：按事件类型算命中率、出日报表、失配告警真的有人能看到。

**怎么做**：
- 输出 `data/world_model/hit_rate_YYYYMMDD.json`，每天一份，含：
  - 每类事件的predictions / hits / hit_rate（滚动24h窗口）
  - 总hit_rate
- 失配告警：
  - hit_rate连续2个采样窗<0.5 → 触发告警
  - hit_rate连续5个采样窗<0.3 → 淘汰该模式
- **告警通路必须修通**（烛微发现InsightBoard query_count=0是黑洞）：
  - 走InsightBoard.post发条目
  - **同时**在 `health_snapshot.json` 里加 `world_model{hit_rate, mismatches}` 字段——这样liver监控和night_digest都能读到
- 对账点位：
  - 分钟级：挂TimeCore现有60s广播（不新建调度器）
  - 日级：并入04:00 night_orchestration现有ledger sweep段

**验收**：
- 连续48小时七类事件hit_rate可计算可落盘
- 告警通路实测触发一次（可以临时把阈值调到很高，人为制造一次失配演练）
- violated零入队（红线回归：预测失败不触发补丁生成）
