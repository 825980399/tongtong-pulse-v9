## 三、段B｜长稳窗（由小林启动框架，路灯只读配合）

### 3.1 起窗流程（小林执行，路灯确认就绪）

1. 小林确认 **pending_patches 无待批补丁**（有则先清空或保持不批）；
2. 小林启动框架 `python main.py`；
3. 起窗后 1 小时内路灯核对日志无 `补丁已应用，3 秒后自动重启` 串（即未触发补丁自重启路径）；
4. 起窗即开始采样（采样周期 30s/点；6h=720 点，24h=2880 点；flush 5s 定时驱动，BATCH_SIZE 5000 永不触发，**无需调参**）。

### 3.2 窗内避让纪律（四条，全程）

1. **不批准任何 pending patches**（避免触发 `main.py:3541` 补丁应用→3 秒自动重启，污染内存曲线）；
2. **不投放 `shutdown_request.json`**（避免夜间编排退出通道触发 `config.py:5467` + `main.py:4051`）；
3. **不做任何代码面改动**（窗内零写盘 data/）；
4. 浏览器定期重启已置 0（刀0 ④），若观测日志仍见重启事件 ⇒ 立即上报（可能是配置未生效）。

### 3.3 t0 判定（三条件，由观测侧离线计算）

- C-1 一次性加载完成：`main.py:3273` 健康诊断完成日志 + 语义缓存装载（`data/cache/semantic_cache.jsonl`）+ 节点池首次 get_stats 成功——取三者的最晚时间戳；
- C-2 RSS 一阶差分滚动 10 点均值 < 2MB/min（纯后处理）；
- C-3 节点池稳态：total_nodes 相邻 10 点波动 < 2%（纯后处理）。
- **t0 = max(C-1, C-2, C-3)**；t0 之前样本只存档不判定；**若 6h 内三条件无法同时满足 ⇒ 判"填充期未结束"，不得输出斜率结论**。

### 3.4 判定公式（双判据 + 可比性分档）

1. 稳态段（t ≥ t0）线性回归斜率 ≤ **5.3MB/min**（现值 16 的 1/3）；
2. RSS 90 分位随时间**不单调上升**；
3. **可比性分档**：容器/镜像窗内 可比类 = 内存/节点/心跳/队列/命中/驱逐（①②③④⑤⑥⑦）；不可比类 = CPU 时间片/单轮耗时/五维打分耗时（Cython 未编译→Python 原生）⇒ 长稳窗结论只能用于"会不会涨、能跑多久"，**不能用于"比本机快慢"**。

### 3.5 停窗条件（任一即停）

① 到达时长（6h 拐点判定 → 通过后扩 24h）；② 任一判据失败提前停（斜率超阈 / RSS 触 6144MB）；③ 小林叫停；④ 框架异常退出（须留 pulse_crash.log 证据）。
