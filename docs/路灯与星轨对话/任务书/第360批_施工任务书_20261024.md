## A 组 · API 统一与付费止血（P0，本批首做）

### 刀0-1　三场景统一「免费优先、付费兜底」（核心）

**目标行为**：用户对话、高级任务（deep_think/code/complex_reasoning）、补丁/代码学习三类调用，**全部走同一个渠道选择器，按渠道池优先级免费优先，付费（deepseek/advanced）仅在免费渠道全失败时兜底**。

1. `config.py`：
   - `ENABLE_EVOLUTION_USE_CHANNEL_POOL`：**False → True**（让 SafeEvolutionExecutor 补丁/进化链走渠道池，不再直连付费端点）。
   - `USER_DIALOG_PREFER_PAID`：**True → False**（对话免费优先；保留开关，需要高质量对话时可切回）。
2. `PulseLung.py::_call_via_channels`（约 1844-1960）：高级任务分支（`_is_advanced_task` → `_build_advanced_channel` 插 priority=-1）**取消无条件插队**；advanced 渠道作为付费成员并入候选池，排序与 deepseek 一致（付费垫底）。
3. **高级任务质量门保护（不可省）**：advanced 任务先打免费渠道（优先 qwen-max/glm-4.7-flash 等较强免费档），若满足下列任一条件才回退付费 flash：连续 2 个免费渠道失败/超时、返回空或被 `CHANNEL_REQUEST_FIELD_POLICY` 截断、补丁产物预检不通过（完整性门禁/def 名匹配失败）。**禁止免费渠道一失败就直接付费**，必须至少尝试 2 个免费档。
4. 后台学习（`_prefer_cheap_channels`）维持免费优先；确认免费链全失败兜底到 deepseek 时，该次调用必须走刀0-2 埋点。
5. 校验：`_wrap`/`_call_remote_api` 默认参 `model="deepseek-v4-flash"` 仅作显示标签，实际请求 model 必须取自命中渠道的 `model` 字段（SafeEvolution 已如此，核对 PulseLung 全调用点一致）。

**验收**：
- 配置读回两个开关为新值；构造 caller=user_dialog / advanced / background_learning 三类候选，断言排序后第一个非熔断渠道均为免费渠道（deepseek/advanced 排在最后）。
- 高级任务在免费渠道返回坏结果时能回退付费（单测注入坏响应）。
- 全仓 grep 确认除渠道池/advanced 配置外无第三处直连 api.deepseek.com 的活跃调用（tests/tmp 除外）。

### 刀0-2　DeepSeek 付费出口全链路埋点（抓 v4-pro 来源）

**目标**：在框架所有通向 DeepSeek 官方端点的请求**统一出口最底层**埋点（建议落在 `nucleus/ssrf_guard.safe_http_json` 或实际 HTTP 发送层，按真实唯一出口选点；若进化链/其他模块绕过该层，必须在该层前再包一层），记录每次请求：
