### T2：P0-补丁2 approve_all_patches写入成功检查

**问题编号**：P0-补丁2
**优先级**：P0
**预估工时**：1-1.5h
**需重启框架**：❌ 否（可通过单元测试验证）

**问题描述**：
- `approve_all_patches` 调用 `_save_patch_list` 后不检查返回值
- WriteGuard拒写时仍返回 `{"ok": true, "approved": 3}`
- 用户误以为审批成功，实际状态未保存，后续应用全部跳过

**修改内容**：
1. 修改 `nucleus/reasoning/PatchManager.py` 的 `approve_all_patches` 方法（L424-443）：
   ```python
   # 修改前
   if _count:
       self._save_patch_list(self._pending_file, pending)
   return {"ok": True, "approved": _count}
   
   # 修改后
   if _count:
       _save_ok = self._save_patch_list(self._pending_file, pending)
       if not _save_ok:
           _module_logger.error(f"[补丁审批] 写入失败，审批未持久化")
           return {"ok": False, "approved": 0, "error": "写入失败（可能被WriteGuard拦截）"}
   return {"ok": True, "approved": _count}
   ```
2. 同样检查 `approve_patch` 方法（L396-422）是否有相同问题，如有则一并修复
3. 确认 `_save_patch_list` 和 `_save_json` 的返回值类型（bool还是其他）
