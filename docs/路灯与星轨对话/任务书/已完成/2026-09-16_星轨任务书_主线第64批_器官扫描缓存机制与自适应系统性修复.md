### T1 · P0 为`_scan_all_organs()`添加TTL缓存机制

**债务ID**：P0-性能根因（器官扫描组缺少缓存，CPU 60-70%）

**问题描述**：
- `nucleus/self_inspector.py:1514` `_scan_all_organs()`方法完全没有缓存
- 每次调用都全量重新解析62个器官文件
- 被12个地方调用，每秒触发1次，CPU占用60-70%
- 重复计算率>99%（文件内容几乎不变）

**修改文件**：
- `nucleus/self_inspector.py`
- `config.py`（新增配置项）

**具体修改点**：

#### 1.1 添加缓存数据结构（在`__init__`中）

```python
# 器官扫描缓存
self._scan_cache = {}  # {organ_name: organ_info}
self._scan_cache_time = 0.0  # 缓存时间戳
self._scan_cache_ttl = 300.0  # 缓存有效期（秒），从config读取
self._scan_cache_file_mtimes = {}  # {file_path: mtime} 用于文件变化检测

# 缓存统计
self._scan_cache_hits = 0
self._scan_cache_misses = 0
self._scan_cache_invalidations = 0
```

#### 1.2 修改`_scan_all_organs()`方法

**原逻辑**：每次都执行全量扫描
**新逻辑**：
1. 检查缓存是否有效（TTL未过期 + 文件未变化）
2. 缓存命中：直接返回缓存，记录hit
3. 缓存未命中：执行全量扫描，更新缓存，记录miss

```python
def _scan_all_organs(self):
    # 检查缓存是否有效
    now = time.time()
    if (self._scan_cache and 
        now - self._scan_cache_time < self._scan_cache_ttl and
        not self._check_files_changed()):
        # 缓存命中
        self._scan_cache_hits += 1
        return self._scan_cache.copy()  # 返回浅拷贝，防止外部修改
    
    # 缓存未命中，执行全量扫描
    self._scan_cache_misses += 1
    result = self._do_scan_all_organs()  # 原扫描逻辑移到这里
    
    # 更新缓存
    self._scan_cache = result
    self._scan_cache_time = now
    self._update_file_mtimes()
    
    return result
```

**注意**：原扫描逻辑（遍历目录、收集文件、并行解析）移到新方法`_do_scan_all_organs()`中，`_scan_all_organs()`只做缓存检查和调度。

#### 1.3 添加文件变化检测方法

```python
def _check_files_changed(self):
    """检查器官文件是否有变化，有变化则返回True（需要刷新缓存）"""
    for file_path, old_mtime in self._scan_cache_file_mtimes.items():
        try:
            current_mtime = os.path.getmtime(file_path)
            if current_mtime != old_mtime:
                self._scan_cache_invalidations += 1
                _module_logger.debug(f"[SelfInspector] 检测到文件变化，缓存失效: {file_path}")
                return True
        except OSError:
            return True  # 文件不存在，视为变化
    return False

def _update_file_mtimes(self):
    """更新所有器官文件的mtime记录"""
    self._scan_cache_file_mtimes = {}
    project_root = self._project_root or os.path.dirname(os.path.dirname(os.path.abspath(__file__)))
    organs_dir = os.path.join(project_root, "organs")
    if not os.path.isdir(organs_dir):
        return
    for dir_name in os.listdir(organs_dir):
        dir_path = os.path.join(organs_dir, dir_name)
        if not os.path.isdir(dir_path) or dir_name.startswith(".") or dir_name == "visual_engines":
            continue
        for file_name in os.listdir(dir_path):
            if not file_name.endswith(".py") or file_name.startswith("_"):
                continue
            file_path = os.path.join(dir_path, file_name)
            try:
                self._scan_cache_file_mtimes[file_path] = os.path.getmtime(file_path)
            except OSError:
                pass
```

#### 1.4 添加缓存手动刷新方法

```python
def invalidate_scan_cache(self):
    """手动使缓存失效（代码修改后调用）"""
    self._scan_cache = {}
    self._scan_cache_time = 0.0
    self._scan_cache_invalidations += 1
    _module_logger.info("[SelfInspector] 器官扫描缓存已手动失效")

def get_scan_cache_stats(self):
    """获取缓存统计信息"""
    total = self._scan_cache_hits + self._scan_cache_misses
    hit_rate = (self._scan_cache_hits / total * 100) if total > 0 else 0
    return {
        "hits": self._scan_cache_hits,
        "misses": self._scan_cache_misses,
        "invalidations": self._scan_cache_invalidations,
        "hit_rate": f"{hit_rate:.1f}%",
        "cache_size": len(self._scan_cache),
        "cache_age_seconds": time.time() - self._scan_cache_time if self._scan_cache else 0,
    }
```

#### 3.1 添加自适应TTL计算

```python
def _get_adaptive_cache_ttl(self):
    """根据系统负载自适应调整缓存TTL"""
    if not getattr(config, 'ENABLE_ORGAN_SCAN_ADAPTIVE_TTL', False):
        return self._scan_cache_ttl  # 自适应关闭，返回固定TTL
    
    # 从runtime_metrics获取当前CPU使用率
    cpu_usage = self._get_current_cpu_usage()
    
    if cpu_usage > 80:
        return getattr(config, 'ORGAN_SCAN_TTL_HIGH', 600)  # 高负载时延长到10分钟
    elif cpu_usage > 60:
        return getattr(config, 'ORGAN_SCAN_TTL_MEDIUM', 450)  # 中负载时7.5分钟
    else:
        return self._scan_cache_ttl  # 正常负载5分钟
```

#### 3.2 新增配置项

```python

ORGAN_SCAN_TTL_NORMAL = 300  # 正常负载TTL（秒）
ORGAN_SCAN_TTL_MEDIUM = 450  # 中负载TTL（秒）
ORGAN_SCAN_TTL_HIGH = 600  # 高负载TTL（秒）
```

**验收标准**：
