## 任务1：P1-43 推理模式使用不均衡 + QICA分类分数极低

### 问题描述

重启后约1小时，388次QICA分类数据显示：
- QICA平均分类分数：**0.418**（极低，理想应>0.7）
- 分数<0.5的占比：**88.7%**（344/388次）
- 分数>0.7的次数：**0次**（无一次高置信度分类）
- 方法分布：rule_reason 36.6%、knowledge_retrieve 16.0%、cognitive_compute仅2.6%
- 大脑皮层策略选择：13次全部"规则推理"，平均复杂度0.304

### 根因分析

1. **QICA 8通道融合权重可能不合理**：关键词通道占比过高，语义通道贡献不足
2. **策略选择机制简单**：只根据复杂度阈值选择，没有考虑意图类型
3. **cognitive_compute触发条件严格**：只有"技术推理"意图映射，但用户输入中技术问题较少
4. **简单问题用复杂路径**：内在世界自我发现"knowledge_low方法耗时3.5秒"

### 修复要求

1. **分析QICA 8通道贡献度**：统计每个通道（keyword/semantic/expansion/entity/sentence/context/complexity/feedback）在最终分类中的贡献占比
2. **优化融合权重**：根据贡献度调整权重，目标是平均分类分数提升到0.5以上
3. **增加cognitive_compute触发场景**：对比分析、深度分析、创造性思考等意图也可以触发cognitive_compute
4. **修复简单问题用复杂路径**：为简单问题（一般对话、情感表达）增加快速路径，避免走knowledge_low

### 验收标准

- QICA平均分类分数提升到0.5以上
- 分数>0.7的次数占比>10%
- cognitive_compute使用占比提升到5%以上
- 简单问题（一般对话/情感表达）响应时间<1秒
- 全库ruff F=0
- 新增单测覆盖优化后的权重和触发逻辑

## 任务3：P1-45 QICA refine_intent精修规则不足

### 问题描述

主线第3批QICA语义鸿沟修复后，残差15个错分中~9个仍是"知识查询黑洞"。诊断显示原型库与金标语料对齐良好（0.975），故非原型失配，而是多通道融合细粒度交互。

典型错分案例：
- "你和小林是什么关系" → 错归知识查询（应身份确认/关系查询，含人名+关系词）
- "为什么框架需要XX" → 可能错归知识查询（应技术推理/概念解释，含"为什么"+"需要"）

### 修复要求

1. **优化refine_intent精修逻辑**：增加低风险的精修规则
   - 含人名+关系词（"你和XX是什么关系"、"XX是谁"）→ 身份确认/关系查询
   - 含"为什么"+"需要/应该/必须"（"为什么需要XX"）→ 技术推理/概念解释
   - 含对比词（"和XX比"、"区别"、"差异"）→ 对比分析
   - 含"怎么/如何"+动词（"怎么实现XX"）→ 任务执行/技术推理
2. **精修规则必须可解释、可测试**：不能是黑盒权重调整
3. **不扩句式通道疑问句名单**：避免对158条语料过拟合
4. **回归测试**：158条语料准确率不降，残差错分减少

### 验收标准

- 158条语料准确率≥0.905（不降）
- 残差错分从15个减少到10个以下
- "你和小林是什么关系"类问题正确分类为身份确认/关系查询
- 精修规则有单测覆盖
- 全库ruff F=0

## 任务4：P2-42 L1→L2压缩升级为语义摘要

### 问题描述

对标报告发现：当前L1→L2记忆压缩是**截断式**（保留前N字），而非语义摘要。这导致：
- 截断位置可能切断关键信息
- 压缩后的记忆质量不稳定
- 长对话的关键结论可能丢失

### 修复要求

1. **分析当前L1→L2压缩逻辑**：找到记忆压缩的代码位置，理解当前的截断策略
2. **升级为语义摘要**：
   - 方案A（推荐）：使用本地关键词提取+句子重要性评分，保留最重要的句子
   - 方案B：调用大模型生成摘要（但会增加API调用，需评估成本）
   - 方案C：混合策略——短文本截断，长文本文本摘要
3. **保持向后兼容**：压缩失败时回退到截断式
4. **增加压缩质量日志**：记录压缩前后的长度、保留的关键信息数量

### 验收标准

- L1→L2压缩不再是简单截断
- 压缩后的记忆包含关键信息（可通过关键词匹配验证）
- 压缩失败时安全回退
- 全库ruff F=0
- 新增单测覆盖语义摘要逻辑
