**位置**：`organs/brain/PulseInnerWorld.py` 的简单问题本地回答路径（搜"简单问题本地回答"日志点）。

## T-c：搜索链路修复（1项，架构级最小改动）

### T-c1：搜索被中断——关键词提取错误 + 审查误判 + 信号分层

**现象**：用户输入"搜索一下今天的科技新闻"，完整链路：
1. 内在世界触发深度搜索（异步线程池）；
2. 控制器阶段1搜索 `site:baike.baidu.com 今天的科技新闻 概念 原理`；
3. **语义增强提取: ['探索', '适合', '生活']** ← 提取错误；
4. 内在世界审查: 关键词与主题无关 → 通知终止；
5. 大脑皮层兜底: correlation_id= 为空；
6. 搜索被终止，跳过阶段2。

**三个子问题**：

**(1) 关键词提取质量**：控制器阶段1语义增强提取（LLM）把"今天的科技新闻"提取成"探索、适合、生活"。
- 改法：对"新闻/科技/今天/最新"等明确主题词，**保留原词不做过度语义增强**；或对提取结果做与原词的重叠度校验，重叠度<阈值时不替换原词。

**(2) 审查误判**：内在世界审查逻辑"关键词与主题无关就终止"，但根因是**提取错误**不是**主题错误**。
- 改法：审查逻辑区分两种情况——
  - 如果关键词与原始搜索词重叠度低（疑似提取错误），**先重试提取一次**，而不是直接终止；
  - 重试仍无关才终止。

**(3) 信号分层（架构级，最小改动）**：终止后大脑皮层同时收到空结果开始兜底验证，两个逻辑对同一搜索的状态判断不一致。
- 改法：搜索终止信号用**独立事件类型**（如 `SearchEvent.TERMINATED`），不与搜索结果事件（`SearchEvent.COMPLETED`/`SearchEvent.FAILED`）混用；大脑皮层只响应 `COMPLETED`/`FAILED`，不响应 `TERMINATED`。
- **注意**：这是架构级改动，**最小改动**——只改事件类型和订阅关系，不重构整个搜索流程。如果改动面过大，只做(1)(2)，信号分层标"设计待排"。

**位置**：
- 关键词提取：`organs/motor/PulseController.py` 阶段1关键词提取附近（搜"语义增强提取成功"日志点）；
- 审查逻辑：`organs/brain/PulseInnerWorld.py`（搜"搜索反馈审查"日志点）；
- 信号分层：`nucleus/events/` 事件类型定义 + 大脑皮层订阅点。

**先红后绿**：
- 新增测试：输入"搜索今天的科技新闻"，断言阶段1提取的关键词含"科技/新闻"（非"探索、适合、生活"）；
- 新增测试：关键词提取错误时，审查逻辑重试一次而非直接终止；
- 已有 cid/sanitize 用例保持绿。

## T-d：数据完整性残留（1项）

### T-d1：D151 残留——其他 from_dict 调用方缺 evol_level

**现象**：本次启动后10条 WARNING：
> `from_dict 缺失 evol_level，将静默默认 L1（疑似分层塌缩；_m68_load_from_parquet 已回填，此为其他调用方兜底）`

**根因**：Parquet 主路径（D151）已修，但还有**非 parquet 的其他 from_dict 调用方**缺 evol_level 字段，当前静默默认 L1 兜底，会把 L2/L3 节点压成 L1。

**改法**：grep `from_dict` 全部调用方，定位哪个路径没带 evol_level，补上字段读写（读时如果缺字段，不静默 L1，而是从 source_timestamp 或其他字段推断分层，或至少 WARNING 标记具体调用方）。

**位置**：`organs/brain/PulseNode.py` 的 `from_dict` + 所有调用方。

**先红后绿**：
- 改前：启动后出现"from_dict 缺失 evol_level"WARNING；
- 改后：同类 WARNING 归零，或至少明确标记是哪个调用方。
