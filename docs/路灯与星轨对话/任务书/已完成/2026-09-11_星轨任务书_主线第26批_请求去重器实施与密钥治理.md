**优先级**：P2
**预估工时**：4-6小时
**设计文档**：`docs/设计文档\RequestDeduplicator设计_v1.0.md`（269行，14例测试用例）

**任务内容**：
1. 按设计文档实现`RequestDeduplicator`类（位置：`nucleus/field/RequestDeduplicator.py`）
2. 核心方法：
   - `__init__(timeout=30, max_wait=10)`：初始化
   - `try_claim(request_id) -> str`：尝试认领请求，返回"claimed"/"waiting"/"duplicate"
   - `complete(request_id, result)`：标记请求完成，缓存结果
   - `get_result(request_id) -> Any`：获取已完成请求的结果

3. 线程安全：使用`threading.Lock` + `threading.Condition`
4. 灰度开关：`ENABLE_REQUEST_DEDUP`（默认False，可通过环境变量或config开启）
5. 接入点：在`PulseLung._on_select_model`入口处接入，对话请求先经过去重器
6. 日志：关键状态变更记录INFO日志（认领/等待/完成/取消/超时）

**验收标准**：
- [ ] RequestDeduplicator类实现完成，方法签名与设计文档一致
- [ ] 14例测试用例全部通过（可参考设计文档中的用例）
- [ ] 灰度开关默认关闭，开启后对话请求经过去重器

- [ ] 超时机制正常工作（30秒无完成自动释放）
- [ ] 线程安全：多线程并发调用无死锁/无竞态

**注意事项**：
