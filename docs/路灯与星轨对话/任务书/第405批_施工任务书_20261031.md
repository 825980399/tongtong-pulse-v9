## 刀1（P1）5分析器超时分级+分片缓存+异步

### 背景

烛微406确认：SelfAwarenessEngine对5个分析器串行+统一30s超时，call_graph（110s）必然死。10/30 16:06那次全量自我认知，5个分析器全部超时>30s被丢弃，画像三维空。

### 施工要求

1. **超时分级**：call_graph 120s、knowledge_quality 60s、其余30s（现在一刀切30s是根因）
2. **分片+缓存**：
   - call_graph与knowledge_quality按文件哈希分片（每片≤120文件），片间并行2个
   - 以(file, mtime, size)为键缓存分析结果，落data/self_awareness/analyzer_cache.json，TTL 24h
   - 未变更文件直接复用缓存
3. **异步化**：
   - 分析器跑在独立线程池（2 worker）
   - get_portrait()只读最近一次成功结果+stale_seconds字段
   - 不许在请求线程里现算
4. **可观测**：每次分析器运行落一行{name, elapsed_ms, shards, cache_hit, ok}到data/self_awareness/analyzer_runs.jsonl（按天，保留30天）

### 验收标准

- 连续3次全量分析，knowledge_health/fake_loops/call_graph_health非空
- analyzer_runs里5个分析器ok=true且elapsed_ms<60s
