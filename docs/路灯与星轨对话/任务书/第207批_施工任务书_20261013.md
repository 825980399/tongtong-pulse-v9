### 刀2：B5真实语义裁定（案C回退式 · encoding_type槽记双口径）
**内容**：ResonanceDetector的weight_map映射改为案C回退式——post = target_organ if 非空 else event_type。

**依据**：烛微207前置§3——案C回退式，时间轴自然插值，encoding_type槽记双口径。

**具体改动**：
1. **ResonanceDetector的weight_map映射改为案C回退式**：
   - 原：`post = event_type`（简化映射，pre=source_organ, post=event_type, delta=1.0）
   - 改：`post = target_organ if target_organ非空 else event_type`（案C回退式）
2. **encoding_type槽记双口径**（烛微207前置§3架构实锚）：
   - weight_map值形态为`(weight, delay, encoding_type)`三元组
   - 简化对记`encoding_type='simplified'`
   - 真对记`encoding_type='real'`（target_organ非空时）
3. **开启前置**：
   - `RESONANCE_WEIGHT_MAP_ENABLED=False`（保持关，先观测后实弹）
   - 映射点每N次更新打一行分布INFO（半刀）
   - 跑一个重启窗看简化对分布形状（哪些器官×事件对最多、delta恒1.0是否有意义）
4. **config.py新增配置项**：
   - `RESONANCE_MAPPING_MODE = 'case_c'`（默认案C回退式）

**不做**：
- 不开启RESONANCE_WEIGHT_MAP_ENABLED（保持关，先观测后实弹）
- 不直切真语义（案C回退式时间轴自然插值）

**验收**：ResonanceDetector的weight_map映射已改为案C回退式；encoding_type槽已记双口径；config.py新增RESONANCE_MAPPING_MODE='case_c'；分布INFO已落地；隔离单测过（含映射断言）。
