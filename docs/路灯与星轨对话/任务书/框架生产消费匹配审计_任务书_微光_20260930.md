> 签发：星轨 ｜ 2026-09-30 ｜ 执行：微光 ｜ 性质：只读审计 ｜ 衔接：断链审查轨 B（已完成 21 项）
> 关联证据：烛微运行核验（报告消费率 29.9% 空 / 队列 14890 锁存）、微光运行核验（LLM 依赖度停摆 / 每日调度 77.9s=14倍 / 修复率 0.39%）、微光断链审查（21 项生产零调用）

## 一、目标与定位

**断链审查**回答"机制有没有人调用"；本任务回答**"调用链通了，但产出有没有被消费"**——即**能力空转审计**。

**判定**：能力（脉冲/写入/调度/缓存/修复/指标/报告）在生产侧被触发并产生产出，但**消费侧零读取/零命中/零下游** → 空转。

## 二、双向审计方法

### 生产测（产出侧 → 消费侧）
1. 枚举**生产方**：脉冲发射器（organs 各器官 on_xxx 发射）、写入器（日志/经验库/知识库/报告/jsonl/指标落盘）、调度执行器、修复/进化动作、缓存/索引构建器
2. 统计**产出量**（运行数据 data/ + 日志 logs/ 实读，含报告/经验/缓存/指标文件）
3. 查**消费方**：订阅器（register 订阅列表）、读取器（查询入口）、报告消费（consumed_by 字段）、下游器官
4. **产出有量、消费为零/极低 → 空转**，记空转率

### 消费测（消费侧 → 产出侧）
1. 枚举**消费方**：订阅器、读取器、查询器、报告消费方、指标引用
2. 查**数据来源**：来源文件/发射器/写入器是否存在、是否有产出
3. **消费声明存在、来源无产出/不存在 → 悬空消费**，一并记入
