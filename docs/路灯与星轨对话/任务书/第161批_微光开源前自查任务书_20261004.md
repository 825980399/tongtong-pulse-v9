# 第161批 微光开源前自查任务书（合规文档侧）（2026-10-04）

## 〇、任务性质与安全约束（★必须先读）

- **本任务以只读核对 + 文档产出为主**：允许读文档、读代码、读台账（只读打开）；产出落盘 `docs/微光/` 或 `docs/分析报告/`。
- **绝对禁止**：
  1. 修改 `data/`、`logs/` 下任何文件；修改任何生产代码；
  2. 执行/停止/重启框架或任何 python 主进程；
  3. 运行带 `--apply/--fix/--rewrite` 写盘参数脚本；
  4. 删除、移动、重命名文件（除交付物落盘外）。
- **背景**：160 批收口 + 三远程推送后即将开源（Gitee/OpenI/GitHub 三平台）。本次为合规文档侧预演，与烛微技术侧并行；供第三方全面分析前消残余。

## 一、自查项 1：PII 文档侧核对（前平台 T4 八项恢复评估前置）

### 背景
三巡 T4 清理执行清单 8 项冻结待新平台第 2 巡恢复评估：文档脱敏/commit 邮箱/openi URL 去手机号/补「生日」规则/删 tmp PII 探针/导出包复扫/push 前终扫。

### 产出要求
1. **文档脱敏复核**（只读）：`docs/` 下检索典型 PII 模式（手机号/邮箱/身份证/姓名+生日组合），列出**仍含明文**的文件清单（不修改，只报告）
2. commit 邮箱现状：git log 作者邮箱是否含真实邮箱（只读统计）
3. openi remote URL 是否仍含手机号（`git remote -v` 只读核对）
4. tmp/ 下 PII 探针残留清单（只读列出）
5. 每项给"已达标/待清/待补"三态结论
