### 刀1：脉冲语义层扩展（第一层 · 通用）
**内容**：Pulse契约扩展为芯片无关的中间表示，新增三个字段。

**依据**：DeepSeek建议第一层脉冲语义层 + 洞鉴发现（时间戳已落地，只需要补幅度字段）。

**具体改动**：
1. `nucleus/pulse_types.py`的`Pulse`类新增三个字段：
   - `amplitude: float = 1.0`（幅度字段，SNN的膜电位强度/光脉冲的功率）
   - `spike_type: str = 'rate'`（编码类型枚举：'rate' | 'temporal' | 'graded'）
   - `wire_format: str = 'json'`（序列化格式预留：'json' | 'binary'）
2. 三个字段都有默认值，**默认零行为变化**（向后兼容）。
3. 在Pulse类的docstring里说明：这三个字段是为类脑芯片（SNN仿真/光脉冲硬件）预留的芯片无关中间表示。

**不做**：
- 不改任何已有脉冲的生成逻辑（默认值=现在的行为）
- 不改脉冲的分发/消费逻辑
- 不加任何门控（纯字段扩展，观测不门控）

**验收**：Pulse类新增三个字段（amplitude/spike_type/wire_format），默认值=1.0/'rate'/'json'；隔离单测过（含字段断言+向后兼容断言）。

### 刀2：权重表示层四元组化（第二层 · 升级复用synapsys）
**内容**：升级synapsys/ResonanceDetector为权重映射，四元组（pre/post/weight/delay）+encoding_type。

**依据**：烛微发现（synapsys子系统已存在，是频率统计版突触壳，无塑性规则）+ 洞鉴建议（权重表四元组化）+ DeepSeek建议第二层权重表示层。

**具体改动**：
1. `nucleus/synapsys/ResonanceDetector.py`新增`weight_map`（字典），键=(pre_id, post_id)，值=(weight, delay, encoding_type)。
2. 四元组结构：
   - `pre_id`: 突触前神经元ID
   - `post_id`: 突触后神经元ID
   - `weight: float = 1.0`（突触权重）
   - `delay: float = 0.0`（突触延迟，秒）
   - `encoding_type: str = 'rate'`（编码类型，与Pulse.spike_type对齐）
3. 新增方法：
   - `get_weight(pre_id, post_id) -> tuple[float, float, str]`（查询权重）
   - `set_weight(pre_id, post_id, weight, delay=0.0, encoding_type='rate')`（设置权重）
   - `update_weight(pre_id, post_id, delta: float)`（更新权重，用于STDP）
4. **默认关闭**：weight_map初始化为空字典，不影响现有共振检测逻辑。

**不做**：
- 不升级ResonanceEngine/VotingEngine/OrganProtocol（那些是第三层的事）
- 不加STDP学习规则（那是P2批的事）
- 不把weight_map接入任何脉冲流（纯数据结构，观测不门控）

**验收**：ResonanceDetector新增weight_map四元组结构（pre/post/weight/delay/encoding_type）；隔离单测过（含增删改查断言）；默认空字典零回归。
