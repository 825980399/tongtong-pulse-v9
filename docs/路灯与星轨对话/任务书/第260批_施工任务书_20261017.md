## 三、刀2 · 望远镜乙案真望远镜（P1）

### 刀2.1 定位
- **文件**：`tools/lfi_self_awareness_compare.py`
- **问题**：delta≡0是代数恒等式（norm_max≡1.0、ref冻结1.0、activity被bound）——两套逐项相等⇒delta≡0

### 刀2.2 改动（~10行，全部离线工具面）
```
新增  _load_prev_row(curve_path) -> dict | None
        读曲线最后一行（因_evaluate_checks在append之前，最后一行即"上一轮"）
        返回 {ts, actual_overall, approx_running_state}
run_once内，:228之后：
        prev = _load_prev_row(curve_path)
        prev_actual  = prev["actual_overall"] if prev else None
        prev_gap_days = (now - prev["ts"]) / 86400 if prev else None
record内新增键（只加不改名不改义）：
        "sim_mode":        "prev_snapshot"
        "prev_ts":         prev_actual的来源时刻
        "prev_gap_days":   round(..., 3)
        "delta_vs_prev":   round(abs(actual_overall - prev_actual), 4)  # 无prev时写None，不写0.0
        "prev_source":     "legacy_mirror" | "telescope"
```

### 刀2.3 四条硬约束（写成代码，不写成说明）
1. **冷启动绝不写0.0**。无上一行时delta_vs_prev = None + delta_void_reason="冷启动无历史样本"
2. **旧delta保留但判死**。继续写delta（≡0，同日内两套恒等）并令checks["delta_legacy_void"] = True
3. **过期即作废**。prev_gap_days > 2 → delta_void = True、reason="上一行过期"
4. **prev_source显式断代**。曲线现有3行全是mirror产物，故第一个乙案读数的prev来自legacy行，必须标legacy_mirror，从第二行起才是telescope

### 刀2.4 验收
- 连续两晚活体跑到03:0x，且approx_running_state首次为true，此时看delta_vs_prev > 0且prev_source=telescope——三件同真才算望远镜成立；任一件缺，按247 N1定性仍是镜子，走丙案（改名"漂移记录器"）
