# 第160批 下 施工任务书（2026-10-04）

## 〇、施工前提与安全标注（★必须先读）

- **本批为停框架施工批**（★醒目标注）：7 刀中 6 刀需停框架窗口（改主存储加载路径/内存扫描/回捞写盘）。**施工时机 = 160 上A 验收 + 活体重验通过之后**（小林重启框架完成上A 重验 → 再停框架 → 本批施工 → 再重启验收），**不得与上A 施工混在同一窗口**。
- 施工期间框架必须处于**停止状态**；若在跑，`recover_flag_from_bak.py` 自守卫直接退出。
- 冷却棘轮已期满（restart_count=7 > 3，24h 已过）→ **施工前后启动框架须在确认提示输入 `n` 拒绝补丁应用**。
- 每刀独立提交 + 灰度开关独立 commit（沿 159 惯例）；pre-commit 门禁 15-18 分钟，完成即报。
- **依据**：烛微《烛微_160下前置分析_A案设计与L收口_20261004.md》（含 §二 实施设计、§五 L-4 修复设计、§七 施工票）+ 星轨《星轨_烛微160下采信单_20261004.md》。
