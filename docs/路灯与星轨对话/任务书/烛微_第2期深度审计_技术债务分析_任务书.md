### 格式要求（按新规范 v1.0）
每个问题必须包含：
1. **主体与锚点**：数据源精确路径 + git HEAD + 观测时刻
2. **提取算法**：如何从记录/文件推导，禁止无来源的人工挑串
3. **判定规则 + 命令**：一条可直接粘贴执行的命令，含 `-X utf8`
4. **稳定性声明**：S结构型 / T时间窗型 / V活体型
5. **交叉验证**：至少两条独立来源通道
6. **改法建议**：具体怎么改，改哪里
7. **风险评估**：改动可能影响什么，怎么验证不引入新问题
