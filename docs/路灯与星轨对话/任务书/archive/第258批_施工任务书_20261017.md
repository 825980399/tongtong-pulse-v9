## 二、刀1 · 孤儿心跳线（P0）

### 刀1.1 定位
- **文件**：`utils/pulse_tracer.py`
- **落点**：`flush_to_file`内:499之后、:532写盘之前（此时new_orphans已算、events_snapshot在手，五个数全齐，无需重算）

### 刀1.2 内容（INFO）
- **内容**：`[孤儿判定] 基数=N 未回填=M 平反=X 通配=W 孤儿=K`
  - N = 环内emit条数（sum(1 for e in events_snapshot if e.get("type")=="emit")）
  - M = matched_organs为空的emit数（判定前的原始嫌疑面）
  - X = 被订阅表平反的条数（:373 continue计数）
  - W = subscription_count("**")——必须带这一项：没有W，心跳线自身仍无法区分「健康」与「失明」
  - K = len(new_orphans)

### 刀1.3 节流（必做，否则造新噪音海）
- **新增**：`_ORPHAN_HEARTBEAT_EVERY_SEC = 3600`；2s闸下每小时一行，一夜≤24行

### 刀1.4 首选增强（一行代码把失明变自证）
- **当K == 0且W > 0时改打WARN**「判定面可能被万能监听器短路」

### 刀1.5 验收
- 重启后日志中出现`[孤儿判定]`前缀的INFO行（每小时一行）
- 当K == 0且W > 0时，出现WARN「判定面可能被万能监听器短路」
