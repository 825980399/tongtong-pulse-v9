## T-96a（P0）：进化通道接入渠道池

### 现状
第95批分析发现：
- 进化引擎 `SafeEvolutionExecutor._call_llm_for_repair` 直接读 `REMOTE_API_CONFIG`（DeepSeek 官方 API）
- 不走渠道池，不享受火山免费额度
- 导致：火山免费额度浪费，DeepSeek 官方 API 收费

### 改法
1. **进化通道改走渠道池**：
   - `_call_llm_for_repair` 不再直接读 `REMOTE_API_CONFIG`
   - 改为走 `PulseLung` 的渠道选择器（按优先级选渠道）
2. **新增开关**：`ENABLE_EVOLUTION_USE_CHANNEL_POOL`（默认 False，灰度开启）
3. **保留兜底**：渠道池不可用时，回落 `REMOTE_API_CONFIG`

### 验收
- 进化通道默认走渠道池
- 渠道池不可用时回落官方 API
- 既有调用零回归
- 相关单测全绿
