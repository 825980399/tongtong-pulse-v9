3. **数据模型/挂载/共基建不动**，只换判据字段逻辑
4. 重跑探针后预期：真空转率 → **接近 0%**（对齐微光 v2）；五类守恒仍 435=435
5. 交付：小修提交 + 更新交付报告（附修正后实测分布 consumed/archived/design_declined/event/true_idle）

**偏差 2 已裁定**（无需改动代码，docstring 标注即可）：「70 命中」=任务书立项时点侦察快照；账本口径 = PCM 全量 `pcm_total=5421`（declared 4580 / idle 840 / wired 1 / consumed 0），在账本 docstring 标注口径变更说明。
