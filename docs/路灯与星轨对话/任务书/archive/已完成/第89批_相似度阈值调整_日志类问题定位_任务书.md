## T-89b（P1）：method=空 日志类问题定位能力设计

### 现状
291 条「方法体为空」样本中 167 条（57.4%）method 为空（全 ERROR 型、file 多为裸器官标签）。
这类问题无方法名 ⇒ 无 original_code 的天然锚点 ⇒ LLM 补丁结构性不可能过闸。

### 任务
设计"日志 → 方法/代码位点"定位能力：
1. 按异常栈帧定位：从 Traceback 中提取文件+行号，反查对应方法
2. 按日志调用点定位：从日志消息反查打印该日志的代码位置
3. 评估可行性，出设计方案（本批不改代码，只出设计）

### 验收
- 设计文档：定位方案 + 可行性评估 + 改动量估算
- 明确哪些类型的日志类问题能定位，哪些不能
