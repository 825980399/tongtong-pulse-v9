## 二、刀1 · 262刀1去毒（P0）

### 刀1.1 定位
- **文件**：`nucleus/field/InfoField.py`
- **问题**：V窗一开就会拿到dead_events=[]并被误读成"没有死数据"——这是本批最紧急的一条，须先于任何验收

### 刀1.2 改动（两处）
1. **万能条件不计入dead_events**：`_match_condition:2541—2543`或`audit_ghost_listeners:2467—2494`内，把万能注册（event_types含"*"或为空）单独归类，不计入"该事件有消费者"
2. **ghost_listeners/dead_events加universal_only**：dead_events与ghost_listeners各加一列universal_only: bool（或matched_by列出命中者身份），让"只有血管在看"显形而不是被算成健康

### 刀1.3 验收
- 重启后dead_events不再恒空表——万能条件单独归类，不计入"该事件有消费者"
- ghost_listeners/dead_events各加一列universal_only: bool（或matched_by列出命中者身份）

## 三、刀2 · 丙-1判据红线（P1）

### 刀2.1 定位
- **文件**：`utils/pulse_tracer.py`
- **问题**：丙-1若照261写的「route_matched > 0 → 平反」，会把257抓出来的永零失明在"对的表"上原样重建——而且比EventBus那枚更难发现，因为这次表没选错

### 刀2.2 改动
- **改动**：判据红线——三态一律以real_matched_count为准，绝不用matched_count（写进注释与函数名，防后来者图省事接回matched_count）
```
real_matched_count > 0            → 平反（当场权威）
real_matched_count == 0 且 有万能命中 → 不平反，标universal_only（这正是"只有血管在看"的真孤儿候选，价值最高的一格）
real_matched_count == 0 且 无命中     → 真孤儿候选
route_matched 缺失(-1/无键)          → 退回matched_organs回填＋白名单（保守回退，与200刀1同语义）
```

### 刀2.3 验收
- 重启后判据红线落地——一律以real_matched_count为准，"只有血管在看"单列不平反

## 四、刀3 · 直调族入白名单（P1）

### 刀3.1 定位
- **文件**：`utils/pulse_tracer.py` :24—26 `_REPORT_ENDPOINT_WHITELIST`（现仅EnergyEvent.METABOLISM_SNAPSHOT一项）
- **问题**：pattern_prewarm/pattern_prediction是「循环内emit、循环外一次性批消费」（:2620 vs :2638）——一个consumer调用对应最多3个pulse_id，没有一一对应关系，回填模型天然表达不了

### 刀3.2 改动
- **改动**：把两族加入_REPORT_ENDPOINT_WHITELIST，每项必须带注释写明"进程内直调消费，出处批号＋消费方文件行号"
  - pattern_prewarm：出处260刀3，消费方InfoField.py:2637 get_pattern_prewarm_consumer().on_prewarm(_prewarm)
  - pattern_prediction：出处260刀3，消费方同上族，由stream_miner周期预测链路

### 刀3.3 验收
- 重启后两族加入_REPORT_ENDPOINT_WHITELIST，每项带注释写明"进程内直调消费，出处批号＋消费方文件行号"

## 五、刀4 · 血管万能条件打observer（P2）

### 刀4.1 定位
- **文件**：`organs/body/PulseBloodVessel.py` :128—135
- **问题**：血管的共振条件写的是event_types: ["*"]，注释自述「★v24.0修复：订阅所有事件以追踪各器官活跃」；而nucleus/field/InfoField.py:2666 _match_event的if pattern == "*" or pattern == event_type: return True ⇒ 血管对每一条脉冲都命中

### 刀4.2 改动
- **改动**：先打observer标记（observer=True），然后再考虑改为显式窄订阅
- **具体操作**：血管的共振条件打observer=True标记——让"观测者"显形，不改变EventBus与_conditions路由表不同源的事实

### 刀4.3 验收
- 重启后血管的共振条件打observer=True标记
