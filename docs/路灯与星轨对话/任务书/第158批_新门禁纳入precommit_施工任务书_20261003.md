## 二、挂载机制说明（先读，避免做错方向）

- 仓库无标准 `.pre-commit-config.yaml`，门禁链 = **本地 git hook**：`.git/hooks/pre-commit`（Shell 脚本）。
- hook 内已有 1.8 段门禁（如 `check_silent_exc_arity.py`、`check_broken_chain_gate.py` 等），模式统一：
  ```sh
  GATE_X="$ROOT/tools/ci/check_xxx.py"
  if [ -f "$GATE_X" ]; then
    "$PY" "$GATE_X"
    st=$?
    if [ "$st" -ne 0 ]; then
      fail "xxx 门禁未通过（...）"
    fi
  fi
  ```
- **注意**：`.git/hooks/pre-commit` 位于 `.git/` 下，**不入 git 版本库**。本次改动仅本地生效，无法用 git 提交 hook 本体——交付形式 = 修改 hook + 验证 + 交付报告（报告中记录修改前后 diff 描述，供换机/重装 git 时重挂参考）。
