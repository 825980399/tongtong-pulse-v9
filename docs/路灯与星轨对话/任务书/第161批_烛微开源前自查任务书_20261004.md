# 第161批 烛微开源前自查任务书（技术侧）（2026-10-04）

## 〇、任务性质与安全约束（★必须先读）

- **本任务以只读分析 + 文档产出为主**：允许读代码、读日志、读数据（只读打开）；产出物落盘 `docs/分析报告/`。
- **绝对禁止**：
  1. 修改 `data/`、`logs/` 下任何文件；修改任何生产代码；
  2. 执行/停止/重启框架或任何 python 主进程；
  3. 运行带 `--apply/--fix/--rewrite` 写盘参数脚本；
  4. 删除、移动、重命名文件（除交付物落盘外）。
- 如需临时验证用独立只读探针（不落盘或只写 `tmp/`）。
- **背景**：160 批收口 + 三远程推送后即将开源（Gitee/OpenI/GitHub 三平台）。开源前需自查硬项，本次为技术侧预演，供第三方全面分析前消残余。

### 产出要求

3. 给出"开源前可归零子集"清单（哪些必须清零、哪些可带红基线但加说明）
