## 一、背景与动机

已确认三处「**机制齐全但生产零调用**」断链（同型）：

| # | 断链 | 证据 |
|---|---|---|
| 1 | 降频闭环：`assess_load_level/set_level` 生产零调用点 → 等级恒 LOW 永不降频 | 烛微运行核验（git grep 实证） |
| 2 | ToolRegistry 工具选择引擎：定义完整（注册/查找/get_best_tool），**生产零消费方** | 星轨 155 批实测（仅自测 `__main__`） |
| 3 | ScriptExecutor 脚本引擎：main.py:475 创建单例，**生产零执行调用**，`tools/script_library/` 空目录 | 星轨 155 批实测 |

**怀疑**：全框架同型断链不止这三处。本任务做一次**全量排查，保证不漏**，为「断链修复批」（T-工具面-1/2/3 合流）提供完整面。

## 二、目标

交付一份**全框架断链全量清单**（机制齐全但生产零调用/零消费方/零持久化），含接线方案与 P 级。

## 三、范围（双方一致，独立全量）

- **扫描对象**：全仓生产代码 `nucleus/`、`organs/`、`functions/`、`hardware/`、`utils/`、`tools/`、`main.py` 及全部可执行入口（含 `pulses/`、`base/` 等运行时目录）
- **排除**：`tests/`（测试面另议）、`.bak_batch*`、`tmp/`、`data/`（运行数据）、`docs/`（文档）
- **识别模式**（断链判定）：
  1. 单例 getter 定义（`def get_xxx()` + 全局 `_xxx = None`）但**全仓调用点 = 0**
  2. class 引擎/管理器定义完整（≥5 个方法、有 docstring 宣称职责）但**无生产调用方**
  3. 注册/管理入口（`register_xxx`/`ensure_xxx`/`save_to_library`/`create_tool` 等）定义但**无消费方**
  4. 数据/工具目录声明（`script_library`/`patch_dir` 等）存在但**零落盘/零读取**
  5. 配置开关/阈值存在但**生产零读取**（同降频断链型）

## 四、双轨分工（并行独立 + 互读交叉）

| 轨 | 执行者 | 方法 | 交付 |
|---|---|---|---|
| 轨 A | 烛微 | **静态权威扫描**：AST 全仓（定义 vs 调用点差集），逐项列证据（文件:行 + 调用计数） | 断链清单 v1 + X 表初版 |
| 轨 B | 微光 | **独立静态复扫**（独立工具/方法，同范围）+ **活体窗动态命中验证**（对候选断链做 20-30 分钟运行观测，确认"运行时确实不被触碰"） | 断链清单 v1' + 动态观测记录 |

**互读交叉**：完成后双方互读对方清单 → 分歧入 X 表（谁证据硬谁上）→ 合并去重为最终清单。
