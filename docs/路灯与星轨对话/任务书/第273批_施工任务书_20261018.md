## 二、刀1 · 丁步首起用确定性任务（P1）

### 刀1.1 定位
- **问题**：丁步现在"能起、不能答"——subagent_worker.py只走DETERMINISTIC路径（echo/sum/hash/noop），不调LLM。⇒说明书分析任务没有op⇒真起后得到的是"键名清单"而不是分析产物。
- **解决方案**：丁步首起用确定性任务（hash/sum/echo），不翻ENABLE_SUBAGENT_RUNNER——显式dry_run=False直调3条＋3条硬造失败。

### 刀1.2 改动（六次调用，一次共窗验完6项）
1. **成功路径3条**（确定性任务）：
   - ①`{"op":"hash","data":"<方法体文本>"}`——预期result.sha256存在、exit_code=0
   - ②`{"op":"sum","nums":[1,2,3]}`——预期result.sum=6、exit_code=0
   - ③`{"op":"echo","payload":"hello"}`——预期result.echo="hello"、exit_code=0

2. **失败路径3条**（硬造失败）：
   - ④超时：`{"op":"hash","data":"<大payload>"}`＋timeout=1——预期[subagent_runner]子代理超时（%ss），已清理
   - ⑤非零退出：非法input（截断json）——预期[subagent_runner]子代理非零退出code=2，弃结果
   - ⑥预算拒：`task.budget_tokens=99999`——预期[subagent_runner]拒绝真起：任务预算99999超过上限4000

### 刀1.3 验收（现成字段，零新埋点）
| 动作 | 判据 |
|------|------|
| 起 | SubagentRunResult.returncode ＋ duration_ms |
| 跑 | output_file里result.deterministic == true、result.model == 解析值、task_keys/sha256等按op出现 |
| 回 | exit_code == 0 且 stats 键存在 |
| 超时 | 造一条timeout=1＋大payload的任务 ⇒ 期望[subagent_runner]子代理超时 |
| 非零退出 | 造非法input（截断json） ⇒ 期望[subagent_runner]子代理非零退出code=2，弃结果 |
| （附）预算拒 | 传task.budget_tokens=99999 ⇒ 期望[subagent_runner]拒绝真起 |

### 刀1.4 两条禁用验收指标（防假绿）
1. **不得用llm_call_count判成败**：PulseLung:1872—1876无条件记SCENE_LUNG⇒真起与否、回退与否在计量面上不可分
2. **不得用"分析产物"判成功**：worker无LLM能力⇒说明书任务真起后返回的是task_keys ack，status="success"——应改为"成功判据＝动作六项全绿；产物判据推迟到戊步"

## 三、刀2 · 心跳线两行修正（P2）

### 刀2.1 定位
- **问题1**：心跳线口径错位（257设计时漏了min_age）——23:10:15 [孤儿判定] 基数=1000 未回填=1000 平反=0 通配=0 孤儿=0 主路自证=0 派发丢包=0——真因是_hb_M不查min_age、而_detect_orphans先按1.5s龄期跳过⇒启动风暴期1000条全"未到判定龄"⇒心跳线在启动窗会稳定虚报"未回填=满额"

- **问题2**：WARN分支把六个数丢了——00:48:52 WARNING [孤儿判定] 判定面可能被万能监听器短路（K=0 但 通配=1>0）——该哨的前提已过期（260甲案已删通配短路、262已过滤observer）；更要命的是WARN这行不带任何计数

### 刀2.2 改动（两行）
1. **_hb_M过龄过滤＋_hb_Y未到龄数**：
   - _hb_M加同min_age过滤（与_detect_orphans一致）
   - 新增_hb_Y（未到龄数）——启动风暴期能看到"未到龄"而不是"未回填=满额"

2. **WARN带六数并改触发条件**：
   - WARN也带六数（基数/未回填/平反/通配/孤儿/主路自证/派发丢包）
   - 触发条件改为K==0且未回填(过龄)>0（原"通配=1>0"前提已过期）

### 刀2.3 验收
- 重启后心跳线不再虚报"未回填=满额"——能看到"未到龄"数
- 重启后WARN带六数——不再在最可疑的时刻把读数全省了
