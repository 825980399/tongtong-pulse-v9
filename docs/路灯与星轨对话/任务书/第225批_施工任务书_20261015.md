## 一、定位与范围

225批＝**_emit→_send四向串味缺陷修复**（根据路灯224批交付报告强烈建议）：
- **问题**：`BasePulseOrgan._emit`（:266）调`self._send(event_type, payload, priority, ttl_ns, layer, target_organ)`（:289），但`_send`（:291）签名第3个位置形参恰为`target_organ` → `_emit`传入的整型`priority`被塞进`target_organ`槽。
- **影响**：错位不仅污染`target_organ`，还同步错位`priority`（收到ttl_ns）、`ttl_ns`（收到layer）、`layer`（收到target_organ）——即`_emit`调用的priority/ttl/layer全部传错槽。
- **严重程度**：该缺陷影响所有走`_emit`辅助方法的器官脉冲priority/ttl/layer语义——比幽灵突触更严重，必须先修再排电窗。

## 二、刀落点与改动

### 刀1 · _emit→_send四向串味缺陷修复

- **文件**：`base/BasePulseOrgan.py`
- **问题**：`_emit`（:266）调`self._send(event_type, payload, priority, ttl_ns, layer, target_organ)`（:289），但`_send`（:291）签名第3个位置形参恰为`target_organ`
- **改动方案**（改为关键字传参最稳）：
  ```python
  # 原（位置参数错位）：
  self._send(event_type, payload, priority, ttl_ns, layer, target_organ)
  
  # 改（关键字传参）：
  self._send(
      event_type=event_type,
      payload=payload,
      priority=priority,
      ttl_ns=ttl_ns,
      layer=layer,
      target_organ=target_organ,
  )
  ```
- **验收**：隔离实测——`_emit(priority=3, layer="L3")` → dump中`priority=3, layer="L3, target_organ=""`（正确）；不再出现四向串味
