## 三、三个口子的书面结论

> 任务书要求：逐条查「契约白纸黑字说默认关、代码却开着」是否真缺陷；确证则另立改代码票、本刀不施工。

### 口子 · 归档 id 93（`TestM96ApprovalGovernance::test_B1_local_switch_registered_false`）

- **开关**：ENABLE_M96_*（审批/渠道池灰度开关）
- **事实**：契约 96批 T-96a「默认 False（灰度）」vs 代码 True
- **结论**：**豁免**
- **理由**：第360批刀0-1 已正式翻闸（DeepSeek 付费止血），config.py 注释在位 ⇒ 属「契约文本滞后于裁决」，不另立改代码票
- **处置**：断言对齐 True

### 口子 · 归档 id 94（`TestM96ApprovalGovernance::test_B2_allow_core_registered_false`）

- **开关**：ENABLE_M96_*（审批/渠道池灰度开关）
- **事实**：EVOLUTION_CONFIG 真开关仍为 False（与契约一致）；红因是考题「最后命中即取」误命中 SELF_MOD_LEVELS 的 gate_keys 描述性 True
- **结论**：**豁免**
- **理由**：真开关现态与 96批 T-96b 契约完全一致（False）⇒ 不存在「契约说关、代码开着」 ⇒ 属考题扫描口径缺陷，改考题即收口，不另立改代码票
- **处置**：限定扫描 EVOLUTION_CONFIG，断言语义不变

### 口子 · 归档 id 95（`TestM96ChannelPool::test_A1_switch_registered_default_off`）

- **开关**：ENABLE_M96_*（审批/渠道池灰度开关）
- **事实**：同上（allow_core_auto_apply 真开关 False、描述表 True）
- **结论**：**豁免**
- **理由**：allow_core_auto_apply 真开关在 EVOLUTION_CONFIG 里仍为 False，与 96批 T-96b 契约「核心文件专用红线显式登记 False」逐字一致；红因同 94（误命中 SELF_MOD_LEVELS 里描述性 True）⇒ 考题缺陷，不另立改代码票
- **处置**：同 94

合计：3 个口子全部**豁免**，本刀另立改代码票 **0 张**。
