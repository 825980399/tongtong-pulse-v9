**全部**是 91d 事故形态（类方法体 base 8 → 模块级 0），**判据命中是正确的**（这类补丁本来就该拦）。

## 三、改法（判据不放宽，改为更强）

```python
# 旧：绝对条数当判据（随语料增长必然红）
self.assertLessEqual(len(_hit), 3, "命中面过大，需复核判据：%s" % [...])

# 新：形态断言 —— 命中落差必须恒为 8（单向：深→浅）；空集同样红
_deltas = {_m92_base_indent(_x["original_code"]) - _m92_base_indent(_x["modified_code"])
           for _x in _hit}
self.assertEqual(_deltas, {8}, "命中落差不全为 8 ⇒ 判据命中了新形态，须人工复核：%s" % _ids)
```

**为什么判别力更强**：

| 场景 | 旧断言 | 新断言 |
|---|---|---|
| 新增同形态事故样本 | 红（噪音，本该拦） | 绿（本来就该拦，不算误拦） |
| 新增异形态（如包进 if 致 base 变深） | 可能仍绿（条数没超） | **红并报 id** |
| 事故样本被清理 | 绿（0 条也满足 ≤3） | **红**（失去判别力要报出来） |
| 非 LLM 补丁被命中 | 红 | 红（原断言保留） |
