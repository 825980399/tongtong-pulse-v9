## 三、证据 2：任务书改法是恒真式

`test_03` 里第一行就是：

```python
_tags_then = [t for t in _real_tags()[0] if t not in _RECORDED_5]
_miss      = {t for t in _tags_then if not locate(t).get("file")}
```

`_miss ⊆ _tags_then`，而 `_tags_then` 已经把 `_RECORDED_5` 全部剔除 ⇒
**那 5 个永远进不了 `_miss`** ⇒ 只要它们在 `_GAP_TAGS` 里，就必然留在 `_still`。
于是：

```
set(_RECORDED_5) <= set(_still)   ⟺   set(_RECORDED_5) <= set(_GAP_TAGS)
```

右边与日志无关、与 `locate_issue` 无关、与 V3 开关无关 —— 是一条**静态常量检查**，
不是行为判据。`tmp/prove_tautology.py` 用 4 种环境实测：

| 环境 | `_still` 长度 | 子集式 |
|---|---|---|
| 空日志（一个标签都没有） | 16 | GREEN |
| 日志只有 3 个无关标签 | 16 | GREEN |
| 日志含全部 16 个缺口标签 | 5 | GREEN |
| 日志含全部缺口标签 **且定位器全命中** | 16 | GREEN |

最后一行是关键：**「定位器全命中」正是真回归（V3 漏开）的形态，子集式照样绿。**
照抄任务书改法，等于删掉断言还留着绿灯（铁律 276 同族：只挡告警不挡读数）。

## 四、证据 3：定稿判据 = 机制恒等式

```python
_expected = (set(T._GAP_TAGS) - _log_set) | set(_RECORDED_5)
assert set(_still) == _expected, (
    f"判红集合与机制不符：多判 {_extra!r}（…真回归）；"
    f"漏判 {_lost!r}（…分母或 `_GAP_TAGS` 漂移）；实得 {_still!r}")
```

等式右边两个来源，与实现一一对应：

1. `_GAP_TAGS - 当日日志标签` —— 日志里没出现的缺口标签，进不了 `_miss`，必判红；
2. `∪ _RECORDED_5` —— 那 5 个被剥出分母，也进不了 `_miss`，必判红。

等式两边都随日志漂移而漂移（漂移不再假红），但只要出现「日志里出现过却仍判红」
（= 它还能被定位），右边不含它、左边含它 ⇒ **必红**，且诊断直接点出元凶。

### A/B 对照矩阵（三判据 × 四场景）

| 场景 | 旧严格式 `== _RECORDED_5` | 子集式（任务书） | 恒等式（本刀） |
|---|---|---|---|
| V0 真环境（T0） | GREEN | GREEN | GREEN |
| V1 日志又少 3 个缺口标签 | **RED（假红）** | GREEN | GREEN |
| V2 日志内缺口标签可定位（真回归） | RED | **GREEN（假绿）** | RED |
| V3 `_GAP_TAGS` 少一个记录标签 | RED | RED | RED |

两列错法互补：旧严格式**对漂移过敏**，子集式**对回归失明**；恒等式两栏都对。
