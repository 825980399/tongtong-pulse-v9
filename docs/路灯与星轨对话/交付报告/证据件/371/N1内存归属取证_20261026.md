## 三、★曲线形状判定（本刀最有价值的结论）

**RSS 不是线性爬坡，而是「锯齿 + 平台」。**

证据：17:04 → 17:09（5 分钟）RSS **7.20 → 6.93 GB（−0.27GB）**，基线增长 **3.03 → 2.77 GB（−0.26GB）** 同步下降；
而 370 长窗记录 peak 7575.0MB、均值约 7GB 量级。

⇒ 这更像**「高位平台的涨落 + 周期性回落」**（GC/缓存淘汰在起作用），
**不是「每拍固定泄漏、永不回收」**的典型泄漏形态。

**这个区分很重要**：
- 若判「持续泄漏」⇒ 会去急于加内存限制/强制重启，可能治错；
- 若判「高位震荡」⇒ 该查的是**为什么平台这么高**（谁常驻占着 7GB），而不是「谁在漏」。

★同时如实标注：**5 分钟窗口不足以定趋势**（可能是 GC 拍后的自然回落）。
本刀只下「形状不是单调线性」这一条，**不下「已收敛」结论**。
