## 二、闸① 行动面（`_m340_judge_action_open`）

**锚点**：`nucleus/self_inspector.py:7999`（函数）；常量 `_O3_MISJUDGE_LINE=0.10`、`_M340_JUDGE_ACTION_MIN_TICKS=3`

### 实测读数

| 项 | 值 | 来源 |
|---|---|---|
| `judge_action_open` | **False（CLOSED）** | 日志 `[340判死] … 原因=action_closed（行动面开=False）` |
| severity 档拒收 | **大量**（somatics/reflex.py 3 条、utils/pulse_tracer.py 等逐条记 file+method） | 同上，逐条可 grep |
| `mode` / `sample` / `misjudge` | review / **PASS 与 provisional 混现** / 0.0 | `[326刀2][O3开闸]` 行 |

### ★措辞与实现不符（取证发现，非缺陷）

函数 docstring 写「**三取一**，缺一即不开」，而实现是：

```python
_mode_ok   = (str(mode) == "review")
_sample_ok = (str(sample).upper() == "PASS")
_mis_ok    = isinstance(misjudge, (int, float)) and misjudge <= _O3_MISJUDGE_LINE
_all_ok    = bool(_mode_ok and _sample_ok and _mis_ok)     # ← 是「与」，不是「或」
```

⇒ 语义应为「**三项全满足**（三取与）」，docstring 的「三取一」是**措辞误导**。
**只记录、不改**：动 docstring 也会动闸面文案，须另报裁决。

### 未过原因（按贡献排序）

1. **`sample` 不稳定**：同一代次内 `sample=PASS` 与 `sample=provisional` 交替出现
   ⇒ `_all_ok` 时真时假 ⇒ `streak` 反复归零，够不到连续 3 tick。
2. `misjudge=0.0` **不是瓶颈**（远低于 0.10）；`mode=review` **不是瓶颈**（一直为 review）。
3. ⇒ **唯一卡点就是 `sample`**，且是「间歇 PASS」，不是「一直失败」。

| 甲 | 查 `sample_verify_hard_candidates` 为何间歇 provisional（抽验样本不足？判据面未跑时降级？） | 低（只读定位） | **建议先做这个**：不碰闸，只定位间歇成因 |

### 4.1 ★断点定位（本刀最硬的一条）

**`data/` 全树不存在 `reload_stats.json`。**

- 写侧路径：`PulseNodePool._m349_reload_stats_path()` → `…/reload_stats.json`（`:2780`/`:2788`）
- 读侧：`PulseMetricsCollector` 通过 `m350_reload_stats_path()` 取同一路径（`:679` 附近 import）
- 实测：`ls data/**/reload_stats.json` **零命中** ⇒ 文件从未生成
- ⇒ `live_gate_ok(reload_stats=None)` ⇒ `_cond_recall` 判「回载统计不可用」⇒ 拦住

**⇒ 结论：回载链断在「写侧从未落盘」，不是「读侧没读到」。**
这个区分很关键：
- 若判「读侧路径不一致」⇒ 会去改路径解析（做错方向）；
- 实际是**写侧 `_m349_persist_reload_stats` 从未被触发到落盘分支**。

### 4.2 ★双口径矛盾（必须记下来，否则会被误读成「回载可用」）

同代次内同时存在两条完全相反的日志：

```
[338冷化] 召回 类=batch 请求=1 命中=1 命中率=1.0000 回载=可用
[350开闸] live_gate … 回载=None
```

**两者说的不是同一件事**：
| 口径 | 含义 | 数据来源 |
|---|---|---|
| `[338冷化] 回载=可用` | **本次召回**在内存里命中成功 | PulseNodePool 内存内即时判定 |
| `[350开闸] 回载=None` | **持久化回载统计**不可得 | 读 `reload_stats.json`（文件不存在） |

⇒ 看到「回载=可用」**不能**推断 `live_gate` 的回载条件满足。这是本刀要留下的防误读注记。

### 4.3 `heap` 读数漂移说明

任务书 T0（15:04 末拍）记 `heap=6749.4`，本拍（17:24）为 **1738.7**。
差异原因：`heap` 取的是 `PulseMetricsCollector` 当拍的堆量，**随 GC/缓存淘汰大幅波动**（与 371 刀1 观察到的 RSS 锯齿一致）。
⇒ **不要把 6749.4 当作稳定值引用**；判读一律以当拍日志为准（本刀建议后续引用都带时刻）。
