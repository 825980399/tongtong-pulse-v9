## 四、为什么不能反过来改 config

把开关改回 False 会让测试绿，但同时停掉在用的共振采样链 —— 358 批 C5 的诊断结论将失去数据源，
而冲突的真因是「测试把**可变配置默认值**当成了不变量」，不是生产配置错了。
