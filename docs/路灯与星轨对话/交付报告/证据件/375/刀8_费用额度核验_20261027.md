## 四、顺带发现（不在本刀范围，记账）

1. **`note` 是单值字段，两条说明互相覆盖**：额度未配置时「不代定」那句会被量口径的
   「不可判」盖掉，只剩后者。两件事都该说，但现在说不了两件。
2. **`state` 声明三态、实现两态**：docstring 写 `ok/tripped/unavailable`，
   实际代码只会产生 `ok` / `tripped`，`unavailable` 从未被赋值。
3. `*_CALLS` 两档仍为 None ⇒ 量口径长期「不可判」。要不要设、设多少是裁决题
   （本刀不能动 config 开关）。
