## 一、为什么不能靠静态 grep 定写面

静态盘点给出的是：测试里出现 **179 处 `data/` 字面量**、97 个测试件引用 `data/`、
其中 68 件"既有 data 引用又有写操作"。

按这个清单去重定向，会做 68 次改造。**但实测后真正写 `data/` 的只有 4 件**
（假阳性率 **72/76 = 94.7%**）。三条典型假阳性：

| 文件 | 静态看起来 | 实际 |
|---|---|---|
| `test_batch_backup_m50.py` | `data/evolution` × 5 处 | 是 `should_skip_dir("data/evolution")` 的**纯字符串入参**，不碰 FS |
| `test_distributed_e2e_m72.py` | 3 处 data + 6 处写操作 | 在 `tmpdir` 里造 `data/knowledge/parquet` 结构，不碰生产 |
| `test_m360_c_batch.py` | 提 `effect_verify` | `assertIn("356_effect_verify_passed", _src)` 源码文本断言 |

⇒ **结论：写面必须实测，不能按引用数推断。**

## 二、实测方法（三步）

1. **静态粗筛**降到候选（97 件引用 data/ → 68 件"有写操作"）；再补建候选
   （直呼台账名 / `production_data` 标记 / `data` 相对路径）= 76 件；
2. **全树探测**：`tests/conftest.py` 哨兵守卫 v2（同批 `06dad4f9`）—— 每会话前后对
   `data/` 全树做 `{path: (size, mtime_ns)}` 清单 diff（**7568 文件 / 0.87s**，只 stat 不读内容）；
3. **逐文件单跑**：每件候选独立 pytest 进程（独立桶、`--timeout=60 --timeout-method=thread`），
   跑完比对三态（新增/修改/删除）。**共 76 件、约 45 分钟。**

## 四、重定向方案：patch 模块级 REL 常量（不改测试、不改生产）

四个写入点的路径解析**都已支持注入**（铁律 158 的既有成果）：

| 生产点 | 现形态 |
|---|---|
| `criteria_window.CONVERGE_VOIDED_LEDGER_REL` | `os.path.join(_cw_repo_root(), REL)` |
| `evolution_budget._M335_BUDGET_REL` | `os.path.join(project_root_or_上溯, REL)` |
| `PulseVisualCortex._face_roster_path` | 测试自己拼 `ROOT + data/.t_face_roster` |

于是重定向只要把 **REL 常量** patch 成**绝对路径** ——
`os.path.join(root, abs)` 会丢弃 `root`（`os.path.join` 语义）⇒ 路径单点转向沙箱。
**生产代码零改动、被测测试零改动。**

落地（`tests/conftest.py`，autouse fixture `m366_redirect_data_writes`）：

```python
_M366_WRITE_REDIRECTS = (
    ("nucleus.evolution.criteria_window", "CONVERGE_VOIDED_LEDGER_REL",
     "data/reports/converge_voided.jsonl", "作废台账；常量仅用于路径拼接"),
    ("nucleus.evolution.evolution_budget", "_M335_BUDGET_REL",
     "data/evolution/evolution_budget.json", "预算侧账；常量仅用于路径拼接"),
)
```

- 目标路径 = `tmp_path/data/<原相对尾部>`；
- `PULSE_DATA_REDIRECT=0` 可关（用于"就是要写生产"的对照实验）；
- 模块不可导入 / 属性改名 ⇒ **print 明示跳过**，不静默放过（否则重定向悄悄失效）。

## 五、`data/.t_face_roster/` 为什么不算污染

`test_r5_face_roster.py` 注释写明：**名册路径必须落在 `data/` 内**（T-134b 白名单），
于是用独立子目录 `.t_face_roster`（git-ignored）隔离。

⇒ 这是**设计内**写入，不是污染。处理：全树探测里单列 `n_designed`，
**不计入 `dirty`**，但仍出现在明细里（不隐藏，只分类）。
