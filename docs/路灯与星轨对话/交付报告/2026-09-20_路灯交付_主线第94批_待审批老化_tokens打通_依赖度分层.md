## 4. T-94b LLM tokens / usage 打通（P1）

### 4.1 根因定位（T0 核实，★任务书前提被证伪）

| 任务书假定 | 实测 |
|---|---|
| 「tokens 恒 0」 | `data/llm_traces/calls_*.jsonl` 8 天 **5759 条**，`tokens>0` **2893 条（50.2%）** —— **不是恒 0** |

⇒ 「tokens 恒 0」实为「**进化引擎三个出口没有统一入口**」。E 组单测把该事实固化为可复算证据。

### 4.2 改法（三层打通，`parse_response` 签名零改动）

1. **适配器统一入口**：`BaseLLMAdapter.extract_usage(response) -> dict | None`（基类返回 `None`）；`OpenAICompatibleAdapter` 实现（缺 `total_tokens` 用 prompt+completion 补齐；三值全 0 / 非数值 / 无 `usage` ⇒ `None`，**不写假数据**）；`ExternalGatewayAdapter` **委托**兼容实现。

3. **留存器新字段**：`record(..., usage=None)` 写新增字段 `"usage"`；`tokens` 回落规则 = **显式 tokens 优先 > `usage.total_tokens`**（向后兼容）；`record_evolution_call` 透传；装饰器 `finally` 取用并**清空** `_m44_last_usage`（防脏读串到下一次调用）。
