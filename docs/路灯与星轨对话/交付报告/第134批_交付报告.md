## 二、T-134a · 出站白名单接线（SSRF 守卫前置）

**目标**：确保所有出站 HTTP 请求在 `urlopen` 前经过 `nucleus.ssrf_guard.is_safe_http_url` 的 fail-closed 校验。

**T0 核实结论（偏差）**：任务书标注的 `PulseLung.py:1000` 与 `PulseLung.py:2011` 两处接线点，经核实已于 **T-101c** 完成（方法 `_call_channel` 935-946 行、`_call_remote_api` 1979-1983 行均已含 `is_safe_http_url` 检查）。故本批实际只施工：
- `nucleus/knowledge/RssCollector.py`（`_default_fetch`，urlopen 前插入前置检查）
- `nucleus/knowledge/WikiQuerier.py`（`_default_fetch`，urlopen 前插入前置检查）
- `config.py`（`SSRF_TRUSTED_EXTRA_HOSTS` 追加 5 个 RSS 源域名：www.solidot.org / www.infoq.cn / feed.cnblogs.com / www.ruanyifeng.com / sspai.com）

**接线范式**（两处一致）：
```python
from nucleus.ssrf_guard import is_safe_http_url
_ok, _reason = is_safe_http_url(url)
if not _ok:
    raise ValueError(f"[SSRF] 拒绝出站请求: {url} -> {_reason}")
```
fail-closed：拒绝即上抛 `ValueError`，绝不静默放行。

**测试**：`tests/test_t134a_ssrf_wiring.py`（7 用例：scheme 拒绝 / 私网拒绝 / 白名单放行 / DNS 失败拒绝 / RSS 域名入表 / Rss+Wiki fail-closed）。
