## 四刀落地

### 刀1 影子规则表真生效修复（P0）
**根因定位**（逐层排除，非猜测）：
- `self_query_fastpath_explain` **有**调 `build_shadow_suggestion`（493.19 加的），explain 里字段非空；
- 影子规则匹配逻辑**正常**（实测 3 个概念 query 各命中对应规则）；
- **断点在 writer**：`record_self_query_shadow` 构造 `_row` 时不含 `shadow_suggestion`，只把 suggestion 写进另一个 `shadow_rule_compare.jsonl` → 影子日志 0 条带该字段。

**修复**：
1. `_row` 新增 `shadow_suggestion`：命中规则填建议 dict，不命中 `None`（任务书验收口径）。
2. `shadow_rules.record_shadow_compare` 格式改为**每条规则一条记录**，顶层带单数 `rule_id` / `primary_path` / `shadow_path`，同时保留 493.19 的复数 `primary_paths`/`shadow_paths` 向后兼容；返回值由 bool 改为写入条数 int。
3. 主笔答案**不变**（`shadow_suggestion` 只是 explain/影子行的记录字段，不进 answer、不写 QICA._domain_knowledge、不 emit）——实测「晚上好 曈曈」主笔答案仍在、不含影子路径。
