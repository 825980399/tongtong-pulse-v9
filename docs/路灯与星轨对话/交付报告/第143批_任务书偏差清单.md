## 偏差 1：T-143a 清洗范围远大于任务书描述（P0 级，最重要）

**任务书原文**：「有没有硬编码的真实路径（<ROOT>这种）/ 有没有真实用户名/手机号/邮箱 / 有没有API Key、密码」

**T0 实测发现**：任务书只点名了「路径 / 用户名 / 手机号 / 邮箱 / API Key」五类，
但全库扫描**新发现更高危的 PII**——**未成年人身份信息**：

| 类别 | 命中规模 | 危害 |
|---|---|---|
| 全名「任*曈」 | 39 处 / 22 文件 | 真实个人姓名 |
| 昵称「小*曈」 | 多文件（守名/称呼语料） | 指向未成年人 |
| 出生日期「[属主生日]」/「[属主生日]」 | 多处 | 未成年人身份要素 |
| 真名「任*林」 | 55 处 / 9 文件 | 创建者真实姓名 |
| 真实 Windows 用户名 | config.py 等 | 可关联真实主机 |

**处置**：按「取最严上限」原则，清洗范围**扩展**至全部上述类别，统一占位符：

| 原文 | 占位符 |
|---|---|
| 任*林 | `<CREATOR>` |
| 任*曈 | `<SELF_NAME>` |
| 小*曈 | `<CREATOR_DAUGHTER>` |
| [属主生日] / [属主生日] | `<BIRTH_DATE>` |
| `<PROJECT_ROOT>` | `<PROJECT_ROOT>` |
| `<SAFEGUARD_ROOT>` | `<SAFEGUARD_ROOT>` |
| `<HOME>` | `<HOME>` |

**红线遵守**：不改身份语句结构、不改花名（小林 / 路灯 / 星轨）、保运行时可用。

## 偏差 2：T-143a 遗漏两处，在 T-143d 复扫时补洗

1. `config.py:190` — User-Agent 联系邮箱 `pulsenet@example.com`

   → `<HOME>\.ssh`（通用化，不硬编码真实用户名）。

> 这正是「导出脚本内置复扫断言」的价值——清洗与校验闭环，自证清白。

## 偏差 3：T-143b 结论为「不重写历史」，改走「脱敏新仓首发」

**任务书原文**：「git log全历史检查，有没有真实邮箱/用户名 / 有漏的就修掉」

**实测结论**（详见 `第143批_git历史身份审计报告.md`）：

| 远端 | 状态 | 身份 |
|---|---|---|
| origin(gitee)/master | 已推 21 票 | **21/21 committer 真身** |
| openi/master | 已推 1 票 | author + committer 双真身 |
| openi 远端 namespace | — | **手机号 `187****9636`** |
| 本地未推 9 票 | 未 push | 已匿名 |

**为什么不「修掉」**：已推提交的 author/committer 一旦固化，重写需 `push --force`，
将破坏远端历史、影响任何已克隆者，且**铁律113（push 待授权）+ 红线（不重写已推历史）**双重约束。

**处置**：判定为**已推历史先头身份永久固化，不建议重写**；
建议路径 = **方案A「脱敏新仓首发」**——新建一个干净的公开仓库，
首发一版已清洗（本批 T-143a）的代码，历史从 0 开始，天然无真身。
本批已把本地新链 9 票全部匿名化为 `Tongtong Dev <dev@tongtong.local>`。

## 偏差 5：T-143d 导出的 docs 白名单需自行定义

**任务书原文**：「导出的包里只有代码、README、docs核心文档」

**实测问题**：`docs/` 下 40+ 文档混有大量**内部叙事**（任务书、交付报告、
分析报告、归档、审查报告），任务书未给「核心文档」的明确清单。

**处置**：本批在导出脚本中以 `PUBLIC_DOCS_ALLOW_FILES` + `PUBLIC_DOCS_ALLOW_DIRS`
**fail-closed 白名单**定义「核心对外文档」：

- 放行：`README.md` / `demo-quickstart.md` / `项目架构总览` / `项目结构树` /
  `完整进化路线与技术债务清单` / `比赛准备/` / `设计文档/` / `工具类文档/` / `操作手册/`
- 排除：`路灯与星轨对话/` / `分析报告/` / `归档/` / `archive/` / `审查报告/` /
  `验收/` / `台账/` / `性能报告/`

> 该白名单可由星轨后续按需增删；因 fail-closed，**新增目录默认不进包**，安全。
