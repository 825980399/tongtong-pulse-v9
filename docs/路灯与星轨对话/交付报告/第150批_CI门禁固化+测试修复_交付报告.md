## 3. T150-2 · PII 双锁静默覆盖修复（D150-13）

`tools/export_public.py::_load_owner_pii_patterns`（约 L188-227）修复：

**旧实现（缺陷）：**
```python
file_names = list(data.get("names", [])) or names      # 配置文件含该键 → 整段丢弃 env 注入真值
file_paths = list(data.get("path_hints", [])) or paths
```
`… or names` 使本地脱敏配置在含该键时**静默覆盖**环境注入（`PULSE_OWNER_NAMES`/`PULSE_OWNER_PATH_HINTS`）的真值，导致 CI 注入的属主 PII 在测试/导出时被吞掉。

**新实现（合并去重·非覆盖）：**
```python
merged_names = sorted(set(names) | set(file_names))
merged_paths = sorted(set(paths) | set(file_paths))
# 首调打印来源（env / file / env+file / none），防复扫刷屏
print("[export_public] 属主 PII 来源（合并去重·非覆盖）: names=%s(%d) paths=%s(%d)"
      % (_src(names, file_names), len(merged_names), _src(paths, file_paths), len(merged_paths)))
```

**测试隔离（D150-13 配套）：** `tests/test_export_public_m143.py` 的 `test_01_real_name_flagged` / `test_04_real_path_flagged` 各注入临时合成 `{"names":[],"path_hints":[]}` 写 `PULSE_OWNER_PII_FILE`，隔离本地真实 `.owner_pii.json`，`finally` 中恢复环境变量并 `os.unlink(cfg)`。PII 测试全绿。
