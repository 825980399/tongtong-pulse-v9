## 六、本批自身踩的 8 个坑（均在门禁被拦截）

| # | 坑 | 教训 |
|---|---|---|
| 1 | 多行 `from x import (` 的**开头行**被当插入点 → 语法错误 | 用**括号平衡**定位多行 import 的**结束行** |
| 2 | 插在 `from __future__` **之前** → 语法错误 | 跳过 `__future__` |
| 3 | 插在 `sys.path.insert()` 之后 → E402 | 插在**第一个顶层 import 之前** |
| 4 | CRLF 文件用 `\n` 模板 → anchor 失配 + 引入裸 LF | 先探测 `_eol`，**所有模板**统一替换 |
| 5 | `config.py` 追加块用 LF → 多 8 个裸 LF（已修，净变化归零） | 追加到 CRLF 文件必须用 CRLF 字节 |
| 6 | `eol` 变量 bytes/str 混用 → TypeError | 分成 `eol_str` 与 `eol_bytes` |
| 7 | **跨盘 `os.path.relpath`** → `ValueError: path is on mount`（**重复 2 次**） | 用 `safe_relpath(f, root)`，**基准是扫描根不是 `_PROJ`** |
| 8 | 补丁模板把 `return _out` 错写成 `return _v` → 返回类型错误但"能跑" | 改返回值/结构时**必须加结构断言** |
