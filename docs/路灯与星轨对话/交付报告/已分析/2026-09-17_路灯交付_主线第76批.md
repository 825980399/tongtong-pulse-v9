## 三、各任务修复明细

### T1 · P0 PulseLiver 静默 except 清理（`organs/body/PulseLiver.py`）
- 5 处 `except Exception:` + `pass` → `except Exception as e:` + `self._log(LogLevel.WARNING, ...)`。
- 日志含 `type(e).__name__` 与 `{e}`（不只记类型），文案区分 5 个场景。
- **控制流与返回值完全不变**（仍走回退/返回 0/None），仅增加留痕。
- 效果：长期红灯的门控测试 `test_liver_silent_fix_m42` **由 1 failed 转为 6 passed**。

### T2 · P0 InfluxDB 真实端到端（`tools/verify_write_only_e2e.py` + `nucleus/timeseries_store/influxdb_store.py`）
- 修 `_build_real_writer()`：先开开关 → 取单例 → **显式 `connect()`**（原单例只构造不连接）。
- 新增 `RealStoreAdapter`：真实 store 无 `counts` 属性 → 适配转发 + 计数，真实写入照常发生。
- `InfluxDBStore.connect()` 增加**凭证有效性校验**（开关 `INFLUXDB_VERIFY_CREDENTIAL_ON_CONNECT`，默认开）：
  凭证失效时返回 `False` 并记 WARNING，**不再返回假 True**。
- 详见：`2026-09-17_InfluxDB端到端验证报告_主线第76批.md`。

### T3 · P1 本地修复能力（`nucleus/reasoning/SafeEvolutionExecutor.py` + `config.py`）
- 新增本地可修类型 **`bare_return_none_in_except`**（except 内裸 `return None` 无日志 → 补 WARNING 日志）。
- **保守约束**：只处理带 `as <名称>` 的 except（有异常对象可记）；无 `as` 时**不动**，绝不臆造变量名。
- 灰度开关 `ENABLE_LOCAL_FIX_BARE_RETURN_NONE`（config 末尾追加，默认 True；置 False 即回到"转 LLM"）。
- ⚠️ **验收未达标**：任务书要求修复率 ≥20%。真实高频类型不适合本地自动修复，
  本批只补了其中语义明确的一类，**未为凑数放宽判据**（铁律56）。

### T4 · P1 git 初始化 + 首次提交
- 损坏 `.git` → 移为 `.bak_git76/`（**保留可回滚**，且被 `.gitignore` 的 `*.bak_*` 自动忽略，不入库）。
- `git init` → 检查 `.gitignore`（data/、logs/、__pycache__、.env 均已覆盖）→ `git add .` → 提交。
- 提交：`417a1c1  初始提交：曈曈PulseNet v9.5基线`，**1042 文件 / 465470 行**。
