### 5.1 现状与修复

第31批已让 `_generate_branch_with_model` 走**渠道池端点**，但仍是**裸 HTTP**。本批接入
`ChannelConcurrencyManager`（与 `PulseLung._call_via_channels` 同口径）：

```python
_m32_ch = _m31_src.split(":", 1)[1] if _m31_src.startswith("channel:") else ""
if _m32_ch and self._m32_branch_concurrency_on():
    _m32_mgr.register_channels(config.get_active_channels())   # 幂等，保证池热改后可见
    _m32_slot = _m32_mgr.acquire(_m32_ch, blocking=True,
                                 timeout=cfg["timeout_by_purpose"]["inner_world_chat"])
    if not _m32_slot:
        return None                       # 并发满 → 跳过本次生成
try:
    ... safe_http_json(...)               # 原调用
    _m32_ok = bool(_ok)
finally:
    _m32_mgr.release(_m32_ch)             # 异常路径也归还（防泄漏）
```
