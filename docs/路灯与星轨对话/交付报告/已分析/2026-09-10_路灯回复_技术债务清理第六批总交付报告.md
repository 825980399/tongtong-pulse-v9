## 2. ★本窗口的 6 处关键发现（3 纠正 + 3 新发现）

### 2.1 三处对旧窗口结论的纠正（星轨已确认）

| # | 旧窗口结论 | 实测纠正 |
|---|---|---|
| 1 | 置信度低是 `_verify_knowledge_relevance` 长词/短词粒度问题 | **主因是 `_calculate_confidence` 的 0.35 兜底**。该函数签名 `(local_result, content)` 根本拿不到检索结果，两条线相互独立 |
| 2 | B2 策略"仅记录不改变行为" | **B2 已真实执行**（`PulseInnerWorld.py:594` 注释即"QICA建议方法优先执行"），但**只覆盖 8 个 method 中的 2 个** |
| 3 | — | **存在 1/7 强制抽样天花板**：`high_confidence_sample_rate=0.15`，即使置信度达标每 7 次仍强制调大模型 |

### 2.2 三处新发现（本次实测挖出，此前未被识别）

#### ★发现 A（最致命）：`classify_internal` 返回字段丢失

```python
# 改造前 nucleus/qica/QICA.py:523
return {
    "status": "classified", "channel": ..., "intent_type": ..., "wake_organs": ...,
}   # ← 只有 4 项！matched_rule_id / suggested_method / knowledge_paths 全被丢掉
```

而 `_emit` 的脉冲里**是带这些字段的**。后果是走「直接调用」路径的下游断裂：

1. `PulseSemanticComprehension._local_classify()` 拿不到 `matched_rule_id`
   → `_calculate_confidence` 中 `if rule_id:` **恒为假** → 0.7 基础档**永远不可达**
2. 同一路径下 `suggested_method` 取默认值
   → **这才是"5 个测试问题全部走 knowledge_retrieve"的真正断裂点**

> 旧窗口判断的"`_i_classify` 兜底为一般对话"只是表层，真正的断点在这里。
> **已修复**：返回字段补全至 16 项（纯增量）。

#### ★发现 B：`rule_fast_identity` 关键词含"关系"

"你和小林是什么关系？" 被 `rule_fast_identity`（关键词含"关系"）判为**身份确认**，
与"关系查询"以 0.02 分之差（0.596 vs 0.575）惜败。
**已修复**：新增意图精修层（人名 + 关系词 → 关系查询）。

#### ★发现 C：`rule_knowledge_query` 关键词含"什么"造成误抢

"什么"过于宽泛，导致一切"XX是什么关系/是谁"类问题被抢到**知识查询**。
**已修复**：新增语义高置信覆盖机制（余弦 ≥0.68 且意图不同时，融合覆盖规则）。

## 4. 任务2：本地对话能力提升（P0-5）

### 4.1 子任务 2.1 置信度校准

| 改动 | 说明 |
|---|---|
| 签名 | `_calculate_confidence(local_result, content, retrieval_result=None)`（不传时行为不变） |
| 维度2 | 检索相关度 ×0.30 |
| 维度3 | 知识覆盖度 ×0.15 |
| 维度4 | 历史相似度 ×0.10（新增 `_get_history_similarity`，bigram 轻量实现，不加载模型） |
| 维度5 | 多通道融合置信度 ×0.15 |
| ★关键 | 融合 top_score ≥0.55 视为「语义规则命中」→ 提升到 0.7 基础档 |
| 附加项 | `_verify_knowledge_relevance` 粒度修正：问题侧改 2/3/4 字滑动窗口，与结果侧同粒度 |

**为什么需要"融合即规则命中"**：融合接管路径没有 `matched_rule_id`，只能拿 0.5 档，
即使融合分 0.6 也只有 0.59 → 恒 <0.7 → 必调大模型。8 通道一致的确定性不亚于关键词规则，
故给予同等档位；融合分低时仍走 0.5 档，保留安全边界。

### 4.3 子任务 2.3 多节点融合本地化

优先级改为：**规则模板 → 关键词重叠 → 语义相似度 → 大模型**

大模型调用条件收紧为：**本地融合质量低** 且 **综合质量 <0.6**（原实现无条件优先调用）。

质量判定：长度 <30 字 / 节点覆盖率 <50% / 6-gram 重复率 >40%（任一即为低质量）。

## 8. 已知限制与后续建议

1. **本地回答率 60%，未达 100%**："你有哪些器官？"(0.57)、"简单介绍一下你自己"(0.56)
   融合分未达 0.55 阈值。若需进一步提升，应**补充这两个意图的语料**而非下调阈值
   （下调阈值会让低质量分类也本地回答，违背质量优先原则）。
2. **1/7 强制抽样**：本地回答率理论上限约 86%，这是设计内的防漂移机制，不建议关闭。
3. **原型微调仅内存生效**：自动学习结果不回写 `intent_prototypes.json`，
   需人工复核后用 `tools/build_qica_intent_prototypes.py` 重建。
4. **health_check / meta_cognitive_report 无专用实现**：当前退化为知识检索，
   建议下一批为这两个 method 补独立实现。
5. **星轨补充的 5 维评分卡**：仅落地 2 维，剩余 3 维（紧急度/情感/风险）建议单独立项。
6. **扩展思维通道为语义空间投影**：未接入共振引擎关联图谱（避免耦合与延迟），
   如需真图谱扩展可后续增强。
