### T1 深度思考超时保护（P2-170）— ✅

**根因（实测到行号）**

```
用户长问题
  → PulseInnerWorld :2358  进程池 submit("_deep_think", q, 3)
    → :2360  _future.result(timeout=self._deep_think_timeout=45s)
      ├─ 成功 → 正常返回
      └─ 超时/异常 → :2375 主进程同步 _deep_think(max_rounds=3)   ← ★无任何时间预算
                         第1/2/3 轮各含一次大模型调用（_deep_followup / _generate_deep_insight）
  → PulseCortex 看门狗 :369（HeartEvent.BEAT 驱动）60s 到期
    → _cleanup_pending_inner_world() :2271 发射 41 字兜底，并 pop 掉 ctx
      ⇒ 内在世界稍后产出的完整答案因 ctx 已被回收而作废（用户只看到 41 字）
```

**修复设计（三层，全部带灰度开关）**

1. **配置层**（`config.py`，+14 行，5 项 + 注释）
   ```
   ENABLE_DEEP_THINK_TIMEOUT_PROTECTION = True   # 灰度总开关（False = 完全回退修复前行为）
   INNER_WORLD_DEEP_THINK_MAX_ROUNDS = 3
   INNER_WORLD_DEEP_THINK_TIMEOUT_SEC = 45       # 与既有 ADVANCED_TASKS.deep_think_timeout 对齐
   INNER_WORLD_DEEP_THINK_TOTAL_BUDGET_SEC = 40  # 多轮思考总预算
   DIALOG_TIMEOUT_FALLBACK_SEC = 60              # 看门狗阈值（原硬编码 60）
   ```
2. **内在世界层**（`PulseInnerWorld.py`，+125/−6）
   - `_deep_think(question, max_rounds, deadline=None)`：新增 **deadline**（由调用方按「推理开始时刻 + 总预算」计算，**包含进程池等待时间**）；
   - **第 2/3 轮前检查剩余预算**，不足则跳过 —— 因综合输出本就按 `len(thinking_rounds)` 分档，
     **天然"保留已完成轮次"**；第 1 轮永不跳过 ⇒ **绝不返回空**；
   - 每轮结束缓存部分结果（`_m27_cache_partial`），提供 `get_partial_deep_answer(question, max_age)`
     （**前缀匹配防串味** + 300s 过期）；
   - 完成日志增强：`问题长度 / 追问N轮 / 耗时 / 预算`（原仅 `问题='...' 追问N轮`）；
   - 异常降级分支同样缓存已完成轮次。
3. **看门狗层**（`PulseCortex.py`，+87/−11）
   - 阈值配置化（`DIALOG_TIMEOUT_FALLBACK_SEC`）；
   - 兜底优先复用 partial → 「我认真想了一下…我先说说我的初步理解（已思考 N 轮）：{partial}」；
     无 partial 时也换成人性化文案；超时事件记 **INFO**（问题长度/思考轮次/已等待耗时/partial 有无）；
   - 开关关闭 → 完全回退（41 字文案 + WARNING + 60s）。
