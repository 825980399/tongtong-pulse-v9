## 五、T-143d 对外发布导出脚本（P2）

1. **白名单 fail-closed**：`docs/` 只放行
   `PUBLIC_DOCS_ALLOW_FILES`（5 份根文档）+ `PUBLIC_DOCS_ALLOW_DIRS`（4 个目录），
   其余一律不打；**新增目录默认不进包**。
2. **全类别排除**：运行数据（`data`/`tmp`/`logs`/`models`/`hardware`）、
   内部文档（路灯与星轨对话 / 分析报告 / 归档 / archive / 审查报告 / 验收 / 台账）、
   备份（`.bak*`）、构建产物（`build`/`.o`/`.obj`）、CI 平台配置（`.gitee`/`.github`）。
3. **内置 PII 复扫断言**：导出后逐文件扫 10 类 PII 模式，命中即 **EXIT=1** 阻断；
   支持 `example.*` 保留域豁免、`tools/export_public.py` 自豁免、
   文件级 `# export-scan-skip-file` 标记（用于脱敏测试夹具）。
4. **默认 dry-run 安全**：不加 `--out` 只列清单不落盘。
