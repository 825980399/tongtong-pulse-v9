## 三、根因：代码学习 L1 的"四段式连环杀"

1. **胃写死平路径** `/自我理解/代码` 无类名粒度 → 所有类挤进同一组。
2. **无幂等** → 每轮 runA 把 888 份重复知识堆到 1483 个代码学习 L1 节点。
3. **runA 压缩走批量频率编码早退分支**"建了 L2 但不清理源 L1"，且 **L2 路径写成相对路径**（缺少 `/自我理解/代码/` 前缀）。
4. **runB 再压缩时去重命中自己建的 L2**，"完全重复跳过"却**照样删除源节点**；同时相对路径 L2 又触发新分组，每轮各删约 1483 个代码学习 L1。

→ 多轮后代码学习 L1 被清空（46 残留）。
