## 二、逐任务

### 刀1 · E侧预导出（E_proj 边集预名单）

- **运行方式**：`PYTHONPATH=<项目根> python tools/export_event_graph.py`，stdout 为 JSON
  （`version=v0.5` / `organ_count=57` / `event_type_count=157` / `edge_count=145` / `edges[]` /
  `wildcards[]` / `stats`）。
- **容错**：该工具 `import config` 时会在 stdout 前缀一行 `[Config] ...`（安全拦截提示，属 config 副作用），
  纯 `python ... > file` 后直接 `json.load` 会失败。刀1 脚本用 `json.JSONDecoder().raw_decode` 取首个
  `{...}` 对象，鲁棒解析（不依赖工具改版）。
- **投影口径**：`E_proj = {(emitter, subscriber) | edge ∈ edges, subscriber ∉ wildcards}`。
  通配订阅者 `PulseBloodVessel` 对所有已发射类型成广播边，不剔除会灌水名单 → 必须剔除。
- **聚合**：按 (emitter, subscriber) 合并，逐行附 `via_event_types[]`（连接该边对的事件类型集合）与
  `graph_edge_refs[]`（导出 JSON `edges[]` 静态边序号 E0 起，便于回放/回归剔除）。
- **头注**：参数指纹 / 导出窗 / 算法 / wildcards 剔除计数（145→41剔除→104净）／基础统计／confidence 与
  graph_edge_refs 口径说明，均按任务书要求落齐。
- **产物**：`docs/分析报告/图谱边集预名单_20261014.md`（92 行边对 + wildcards 附录）。

### 刀2 · 首跑复核操作指引

- 内容覆盖任务书 §二 刀2 的 7 步：① 启动曈曈重启窗（≥10min）② 运行 `gate_health_check.py`
  ③ 查 M1_PAIR_COVERAGE 转正（n/a→PASS）④ 查 M7_PAIR_FIELD_COMPLETE 转正（n/a→PASS）
  ⑤ 计算 R_runtime＝`distinct{(organ, target_organ)}` ⑥ 差集导出（E_proj−R_runtime）
  ⑦ 三谜裁决（双路分叉判定：新窗 pair 行按 (organ, target非空与否) 分路统计）。
- 准确性：命令与参数直接对齐 216 批 `gate_health_check.py` 真实 CLI
  （`--pairs-file/--log-file/--monitor-dir/--date/--json/--pair-cap/--heartbeat-nominal`）；
  八项指标名与状态（PASS/WARN/FAIL/n/a）取自工具源码实测。
- 附注：列出 217 窗 5 个已知非回归项（M2 首窗 WARN / M7 填充率=0 WARN / M5 旧窗遗存 / M6 心跳漂移 /
  M8 起停不对称），避免误判。
