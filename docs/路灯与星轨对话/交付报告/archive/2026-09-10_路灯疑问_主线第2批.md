## Q4 · InfoField L3 worker 数在 critical 时为 0 是否需要调整

**当前实现**：第1批补丁里 `critical` 仍保持 0 worker（保护性停机），只 moderate 从 1→2、heavy 保持 1。

**但**星轨拍板说"critical 保留 0 不动"，而我没在第1批报告里详细解释为什么。

**原因**：critical 时负载意味着系统在过载边缘，0 worker 是保护性设计——任何 L3 任务在 critical 时都应降级丢弃/排队，而不是再消耗 CPU 加剧过载。

**需要确认**：
- 是否要维持"critical 时 0 worker"（我建议是）
- 还是要把 critical 也调成 1（保证不断流，但牺牲部分保护）

**默认执行**：维持 0（如无异议）。
