### T-140a（P2）Parquet 快照 `Table.from_pylist` 兼容 ✅

**根因**：环境 pyarrow 升至 **25.0.1**，`pa.Table.from_pylist` / `pa.Table.from_batches` **均已移除**，
启动写快照即抛 `AttributeError: type object 'Table' has no attribute 'from_pylist'`。

**方案**：新增跨版本垫片 `nucleus/mnemosyne/pa_compat.py::table_from_rows(rows, schema=None)`，
三通道降级：
1. `pa.Table.from_pylist`（旧版 pyarrow 原生，语义最贴合，优先）；
2. `pa.RecordBatch.from_pylist(rows, schema=...)` + `pa.table(rb)`（25.x 起唯一保留的 pylist 构造）；
3. `pa.table(dict_of_columns, schema=...)` 按列转置兜底。
空 `rows` + 无 schema → 空表（保持旧行为）。

**改动面（实测 11 处，非任务书所称 1 处）**：

| `tests/test_cold_storage_batch_m81.py` | 1 |
| `tests/test_parquet_schema_m81.py` | 4（含 2 处 `.replace_schema_metadata(...)` 链式） |

**附带清理**：换用垫片后 4 个文件的局部 `import pyarrow as pa` 变为未使用（F401）→ 清理为
`import pyarrow.parquet as pq  # noqa: F401 - 可用性探测`（保留 pyarrow 可用性探测语义）。
