## 五、环境观察（cw2 指纹机制澄清）

`tools/ci/ci_common.py::extract_handlers` 的"静默 handler"定义：**不含 `Raise`、不含 `LOG_FUNCS` 调用**的 `except` 处理器（`LOG_FUNCS` 含 `silent_exc`）。故：
- 调用 `silent_exc` 的 handler **不算静默**（被过滤）→ 不会被计入"新增静默 handler"。
- 裸 `except: return False` / `except: _x = None` 这类**无任何上报/重抛**的处理器才是门禁要拦的"静默回潮"。

本批初版在刀1留 2 处裸静默 handler 触发 FAIL，改为 `silent_exc` 包裹后既合规又保留降级语义——此机制已在 `MEMORY.md` 铁律150 条目显式记录（新 handler 须无 except 或含 LOG_FUNCS/Raise）。
