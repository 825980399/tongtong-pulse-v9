## 一、T-110a：KAL 迁移收口 - 肝（P0）

### 根因
`PulseLiver.py` 在 `set_node_pool` 注入 `self.node_pool` 后，38 处直接调用 `self.node_pool.query/add/get_stats/get_instincts/instinct_count/remove/upgrade_to_instinct/downgrade_instinct`，与既有的 `_m69_kal_query`/`_m70_kal_*` KAL 桥并存，构成同一数据的两条访问路径（双轨漂移）。

### 改动（核心）
1. `set_node_pool` 注入 KAL 实例，保留原始 `self.node_pool` 供守卫/子实体交接：
```python
def set_node_pool(self, node_pool):
    self.node_pool = node_pool
    from nucleus.knowledge_access_layer import KnowledgeAccessLayer
    self._kal = KnowledgeAccessLayer(node_pool=node_pool)
```
2. `__init__` 增加 `self._kal = None`。
3. 38 处 `self.node_pool.X` → `self._kal.Y`（映射：add→add_node、query→query_nodes、get_stats→get_stats、get_instincts→get_instincts、`instinct_count`(属性)→`get_instinct_count`(属性)、remove→remove_node、upgrade_to_instinct→upgrade_to_instinct、downgrade_instinct→downgrade_instinct）。

### 验证
- 改后 `self.node_pool.` 实点直连：38 → **0**。
- 保留的 `self.node_pool`（无点）仅为 `if self.node_pool is None` / `hasattr(self.node_pool,'remove')` 等结构守卫，非数据访问双轨。
- 完整 diff：`tmp/diff_PulseLiver.py.txt`。

## 六、白名单注记（残余 `node_pool.` 正则命中的结构性引用）

任务书验收口径 `grep -c "node_pool\."`（正则）在三器官改造后仍有命中（肝 46 / 肾 18 / 胃 17），**全部为结构性引用，非数据访问双轨**，逐类如下，可安全白名单：

1. **框架注入契约**：`def set_node_pool(self, node_pool):` 方法名 + 参数 `node_pool`（正则命中 `node_pool(` / `node_pool:`），由 `main.py` 的 `set_node_pool(self.node_pool)` 调用，属对外契约，不可改名。
2. **原始池保留供守卫/交接**：`self.node_pool = node_pool`（注入点）、`self.node_pool = None`（init），`if self.node_pool is None` / `if self.node_pool:` 等空值/真值守卫，`hasattr(self.node_pool, 'remove'/'get_instincts'/...)` 能力守卫；肾的 `_ce.set_node_pool(self.node_pool)` 子实体裸池交接。
3. **KAL 构造参数**：`KnowledgeAccessLayer(node_pool=node_pool)` 中的 `node_pool=`。

上述任何一类若强行消除，都会破坏框架注入或子实体依赖交接，违背“行为保持”原则。本批以 `self\.node_pool\.`（转义点）**= 0** 作为双轨漂移消灭的硬性达标线，三器官均已达成。
