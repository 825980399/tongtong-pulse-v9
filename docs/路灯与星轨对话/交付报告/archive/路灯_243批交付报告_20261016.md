### 档三 · dry_run 观测窗（`nucleus/reasoning/subagent_runner.py`）
- `import threading`（原缺）。
- 模块级：`_DRY_RUN_HITS = 0` ＋ `_DRY_RUN_LOCK = threading.Lock()`。
- `_bump_dry_run_hits()`（带 `global _DRY_RUN_HITS` 声明，消除 ruff F823）＋ `get_dry_run_hit_count()`。
- `run_subagent` 在硬闸（NO_MESSAGE_TOOL / CHEAP_MODEL）**之前**插入 dry_run 早返回：
  ```
  if dry_run:
      with _DRY_RUN_LOCK:
          _hits = _bump_dry_run_hits()
      _L.info("[subagent_runner] dry_run 拦截（观测窗）：prompt=%r 本窗累计=%d", ..., _hits)
      return SubagentRunResult("success", returncode=0, stats={"dry_run": True, "dry_run_hits": _hits}, ...)
  ```
- 语义正确性：dry_run＝不真起，硬闸仅护真起（dry_run=False 路径不变）。**从 0 到 1 里程碑**：开关全关时消化任务首次触发即产出"首条 dry_run 拦截行"。
