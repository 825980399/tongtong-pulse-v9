## 二、T-142a 重名修复（P2）

### 问题
`self_inspector.py` 的扫描缓存计数器名为 `_l2_hits` / `_l2_misses`，
与「语义缓存 L2」概念重名，导致运行日志中**两本 L2 账同名**，
已实际造成跨月误读（前置分析点名 D138-3，拖 4 天未修）。

### 关键发现：任务书处方名不可用
任务书原文要求改名为 `_scan_cache_hits` / `_scan_cache_misses`，
但实测发现 **`self_inspector.py:195-196` 已存在同名属性**
（「扫描缓存」L1 计数器）。若照搬任务书，将造成**属性覆盖**（AttributeError 级隐患）。
故本批改名落点为 **`_scan_cache_l2_hits` / `_scan_cache_l2_misses`**——
语义即「扫描侧二级缓存（organ_file / structure / method 三级缓存）」，
与 L1 计数器**分槽独立**，并保留"L2"字样以保持与灰度评估口径的对应关系。

> 该偏差已记入《第142批_任务书偏差清单.md》。

### 施工内容
1. `nucleus/self_inspector.py`（CRLF 保持）：
   - 声明 `:220-221` 改名；注释扩写说明消歧理由；
   - 日志文案 `:1943` `L2命中=` → `扫描L2缓存命中=`（兑现验收①）；
   - 统计计算 `:2178-2179`、返回字典键 `:2187-2189`（键同步改 `scan_cache_l2_*`）；
   - 三个增点 `:2221/2223`、`:2270/2272`、`:2306/2308`。
2. `functions/chat/chat_service.py`（CRLF 保持）：消费侧键同步 + 文案消歧。
3. `tests/test_organ_scan_cache_m64.py`、`tests/test_method_body_cache_m65.py`（LF 保持）：断言同步。
