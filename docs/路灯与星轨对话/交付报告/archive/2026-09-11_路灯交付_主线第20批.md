### 8.3 ★同一过程中发现的**真实缺陷**（非本批引入，请星轨裁决）

处置 #3 时发现：被恢复的那两行写法**本身有缺陷** ——

```python
_proc = subprocess.Popen(
    [_sys.executable, __file__],
    creationflags=subprocess.CREATE_NEW_CONSOLE,
    cwd=_project_root,
```

- `subprocess.Popen` **没有 `timeout` 形参** → 该调用会抛 `TypeError`，被下方 `except Exception as _spawn_e` 吞掉 → **`_spawn_self_restart()` 实际从未成功过，框架自重启功能不可用**（"接班进程启动失败"永远命中）。

- 这解释了并发会话为何删除这两行（它可能正在修这个缺陷），但它**没有同步更新测试**，导致门禁变红。

**我的处置**：本批**只恢复到第19批基线**（原样恢复，让既有护栏测试通过），**未做语义修正**（避免越界改动 + 破坏护栏）。**建议单开一条修复**：把 `timeout=` 改为 `_proc.wait(timeout=...)` 或去掉（Popen 不阻塞，本就无需超时），并同步更新该测试断言。
