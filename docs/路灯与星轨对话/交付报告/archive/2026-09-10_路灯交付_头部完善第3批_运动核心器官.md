## 五、F821 修复详情

**位置**：`organs/motor/PulseController.py` 第 99 行（`budget_guard` 装饰器 `_wrapper` 内）

**修复前**：
```python
                    try:
                        _budget.release(consumer)
                    except Exception as e:
                        self._log(LogLevel.ERROR, f'异常: {e}')   # ← 装饰器作用域无 self
```

**修复后**：
```python
                    try:
                        _budget.release(consumer)
                    except Exception as e:
                        _log = getattr(args[0] if args else None, "_log", None)
                        if _log:
                            _log(LogLevel.ERROR, f'异常: {e}')
```

**与裁决的差异说明**：
星轨裁决原文为 `if _log: _log(LogLevel.ERROR, f'异常: {e}')`（复用上方已取到的 `_log`）。
但上方 `_log` 仅在 `if not _budget.acquire(...)` 分支内赋值 —— 若 acquire 成功而 release 失败，
`_log` 处于**未绑定**状态，直接用会抛 `UnboundLocalError`，等于把 F821 换了个马甲。

故采纳裁决思路（复用 `_log` + `if _log` 守卫），但**在 except 分支内重新安全取值**，
并用 `args[0] if args else None` 防止 `args` 为空时 IndexError。语义与裁决一致，安全性更严。

**验证**：`tmp/test_batch20_motor_core.py::TestF821::test_04` 实测 —— 构造 release 恒抛异常的
ResourceBudget，走完 `budget_guard` 包裹的方法，断言返回值正确且日志被记录（而非抛 NameError）。
