  ```python
  self.lung = self._create_organ(PulseLung, "肺")
  if getattr(config, "ENABLE_EVOLUTION_USE_CHANNEL_POOL", False):
      try:

  ```
  受 `ENABLE_EVOLUTION_USE_CHANNEL_POOL` 开关保护（**不改运行开关**，仅复用既有开关）；异常降级为 warning，不影响启动。

### T-97b（P1）偏差标注 → 无需改动
- 实测 `SafeEvolutionExecutor.run_in_subprocess`(L5304)→`_run_subprocess_once`(L5173)→`evolution_worker.run_evolution_worker_captured`，**复用同一渠道池选择逻辑**，不直连 `REMOTE_API_CONFIG`。任务书"subprocess 不享免费额度"前提不成立 → 保持偏差清单，未改动代码。

### T-97c（P1）额度类型 + 每日补充 ★先红后绿
- **根因**：`ChannelQuotaMonitor` 无额度类型概念，协作奖励渠道（每日返额）与固定额度渠道混用同一降优先级/暂停逻辑，协作奖励会被误判耗尽。
- **改动**：
  1. `config.py`：6 个协作奖励渠道加 `"quota_type": "daily_reward"`（ark-seed-21-turbo / ark-ds-v4-flash / ark-seed-evolving / ark-ds-v4-pro / ark-glm-5.2 / ark-seed-character）；固定额度渠道默认 `fixed`。
  2. `ChannelQuotaMonitor.py`：
     - 新增 `quota_type_of()` / `daily_reset_hour()`（默认 11）/ `_ensure_daily_reset()`（按今日日期幂等清零 daily_reward 用量）/ `tick_daily_reset()`；
     - `is_exhausted()`：daily_reward 直接返回 `False`（永不暂停）；
     - `apply_to_channels()`：daily_reward 不降优先级/不暂停（仅触发每日重置）；
     - `save()`：快照新增 `daily_reset` 持久化；`_load()` 读回 `daily_reset`；模块顶部补 `import datetime`（修 F821）。
  3. 门控单测 `tests/test_quota_type_m97.py`（新建，8 用例）。
- **先红后绿**：
  - 首跑 `test_quota_type_m97.py` **5 failed**（`quota_type_of` 对标注 daily_reward 的渠道返回 `'fixed'`）。**根因**：5/6 渠道的 `quota_type` 编辑因 Edit 批量"假成功"（仅落 1 处）未落地 → 逐条读回字节核对补回 → 复跑 **8 passed**。
  - `test_quota_monitor_m32.py` 因 `ark-ds-v4-flash` 现标 daily_reward 被豁免降优先级/暂停 → 7 failed。修复：其 `setUpModule` 已对 `quota_limit` 解耦（第62批），**同源补 `quota_type="fixed"`**（测试验证固定额度逻辑，与生产 daily_reward 解耦；daily_reward 豁免由 `test_quota_type_m97.py` 覆盖）→ **34 passed**。
- **验证**：`test_quota_type_m97.py` 8 passed、`test_quota_monitor_m32.py` 34 passed。
