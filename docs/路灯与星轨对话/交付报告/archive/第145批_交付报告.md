### T-145a（P1）占位符运行时渲染

**问题**：代码中真名被替换为 `<SELF_NAME>` 等占位符，但**没有任何渲染器**，
导致运行时问"你是谁"会直接答出带尖括号的字符串（如 `我是曈曈，全名<SELF_NAME>`）。

**方案**：在 `config.py` 建立**单一真值源**渲染基础设施，在配置加载末尾做内存内渲染，
代码与公开仓库**仍保留占位符**（零 PII 泄露面）。

**新增基础设施（config.py，+108，位于 `# [M102-CFG]` 后）**：
- `PLACEHOLDER_VALUES`：`<SELF_NAME>`→"曈曈"、`<CREATOR>`→"创建者"、
  `<CREATOR_DAUGHTER>`→"小曈"、`<BIRTH_DATE>`→"2020年"
  （均可用环境变量覆盖，如 `TTP_SELF_NAME`）
- `_PLACEHOLDER_RE` + `render_placeholders(text)`：单字符串渲染（幂等）
- `render_placeholders_deep(obj, value_keys=None)`：递归渲染
- `find_unrendered_placeholders(obj)`：审计残留占位符
- `_apply_placeholder_render()`：模块加载末尾对
  `DIGITAL_LIFE_REGISTRY.display_name`、`SEED_MEMORIES[].value`、
  `INNER_WORLD_CONFIG.identity_rules` 值**原地渲染**
- **★刻意不渲染**：`keywords` / `space_path` / `aliases` / `personas` 键
  （内部匹配键若被渲染会破坏检索语义 —— 铁律147 占位符掩码禁用于功能字符串）

**运行时出口接线（5 处）**：
1. `PulseLung.py:888` 渠道 system prompt：`_sys = _render_placeholders(_sys)`
2. `PulseLung.py:2018` 直连 system：`content: _render_placeholders("你是曈曈，...（全名<SELF_NAME>）...")`
3. `PulseLung.py:2679` 基础身份 prompt：`prompt = _render_placeholders(prompt)`
4. `PulseInnerWorld.py` `_persona` 定义块后：`_persona = _render_placeholders(_persona)`
5. `PulsePersonalityKernel._core_anchors` + `PulseSelfAwareness._get_identity_snapshot` 同步渲染

**实测验收**：`display_name` / `seed.value` / `Lung.system` / `anchor.*` / `snapshot.*`
全部渲染为真名；`keywords`/`space_path` 保留占位符；渲染幂等；未注册占位符不误伤。**ALL PASS**
