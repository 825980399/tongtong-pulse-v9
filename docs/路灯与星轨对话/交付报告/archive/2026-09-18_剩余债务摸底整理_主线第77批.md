## 七、本批"顺手修复"的漏洞

1. **`nucleus/ssrf_guard.py:52` 静默异常 → 加 DEBUG 日志**
   受信任主机集合解析失败时原为 `except Exception: pass`。
   该处是 **fail-closed**（集合变小 → 判定更严格，安全方向正确），
   但静默会导致"合法 API 被拒却查不到原因"。修复后留痕，**判定语义完全不变**。
2. **两处过期注释更正**（`main.py:996`、`DailyScheduler.py:6`），避免后续批次重复投入。
