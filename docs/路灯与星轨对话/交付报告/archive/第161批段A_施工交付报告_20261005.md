## 八、★ 本段沉淀的 10 条复用教训（已置顶记忆库）

1. **派生层扫描口径必须与源层完全对齐**（豁免/转义/模式集/保留域四者缺一即失衡）——更严=自锁，更松=漏检
2. **同一概念必须复用单一真相源** —— 本段**复现三次**（S3 内部域、S2 进包判据、A3a 豁免集）
3. **锚点/行号必先勘察再动手** —— 161段B 锚点全漂移；A3a「9 处哨兵」实测 0 命中
4. bash 内嵌 Python 写 `\n` 会被转义吃掉 ⇒ 复杂补丁改用 `.py` 脚本文件
5. `&&` 链中任一步被沙箱拒绝会**静默中断后续且不报错** ⇒ git 写操作用 `dangerouslyDisableSandbox` 并分步验证
6. **`git reset` 必须精确指定路径**，否则清空暂存区会误伤他方已暂存文件
7. **cw2 静默 except 本段触发 6 次**（含 `except FileNotFoundError: pass`）⇒ `silent_exc` / `contextlib.suppress`
8. `git show HEAD:file` vs 工作副本 diff 有 **autocrlf 假差异** ⇒ 归一或用 `git diff HEAD`
9. 长任务用 `run_in_background`，**禁用 `nohup &`**（子 shell 退出即回收，曾白等 30 分钟）
10. 判进程存活要**匹配 `cmdline`**，不能只看进程名（`mypy.dmypy` daemon 极易误认）
