## 2. 真实落点核实

### 2.1 入口放宽判定（`offline_survival_protocol.survive_offline`）
- 判据：以 `llm_reply` 为空 / 纯空白 作为「外脑（肺模型）不可达」的唯一口径（与 cw3 既有对话回退语义一致）。
- 开关：`OFFLINE_SURVIVAL_ENABLED`（模块级常量，默认 `True`）；置 `False` 时完全退化为原委派行为（零回归保障）。
- 在线（有实质回复）→ `return (False, None)`，调用方在线路径不变。

### 2.2 兜底行为（`run_offline_chain`：Symbolic → Causal → Analogy）
- 腿1 符号推理（`SymbolicReasoner`，对任意问题可用，解出即用）；
- 腿2 因果校验（需结构化 `causal_pairs` + `node_pool`）；
- 腿3 跨域类比迁移（需 `analogy_texts` 一对文本，置信度 ≥ `ANALOGY_ADOPT_CONFIDENCE=0.5` 方采纳）；
- 三腿均未解出 → 返回诚实「partial」结果（`method="symbolic_partial"`，带本地尝试证据），**绝不返回空模板应答**；
- 结果统一标记 `[本地推理·待验证]`、`verified=False`（恒待联网外脑复核）。

### 2.3 路由委派分支放宽（`PulseCortex._on_inference_result`）
- 原逻辑：外脑不可达 → 静默委派 `LungEvent.SELECT_MODEL` / 模板降级。
- 放宽后：优先调用 `_compute_offline_survival(fallback_prompt)`，本地链解出则采用（`method="offline_local"`）落入统一 `if answer:` 输出，**不再静默委派 / 模板降级**；本地也未解出则仍委派外脑（在线路径不变）。
- 直调 `survive_offline`，无 `try/except`（cw2 零新增静默 handler）。

### 2.4 联网复核缓冲
- `enqueue_recheck` / `drain_recheck` / `pending_count` 进程内缓冲；离线结果登记，联网恢复后由外脑批量复核沉淀。
