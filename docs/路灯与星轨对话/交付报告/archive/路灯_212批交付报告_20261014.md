## 二、四刀落点与改动

### 刀1 · PAIR 闸轮转参数（按日分文件）
- **文件**：`utils/pulse_tracer.py`
- **改动**：`_get_pair_path()` 由单文件 `data/monitor/pulse_pairs.jsonl` 改为按日分文件
  `data/monitor/pulse_pairs_YYYYMMDD.jsonl`；**去除全局 `_pair_path` 缓存**，每次实时拼装当日
  文件名（跨午夜调用须重算日期）；同日追加、每日首次 flush 创建新文件。
- **闸门**：`ENABLE_PULSE_PAIR_DUMP` 保持 `False`（等 213 批开）。

### 刀2 · TARGET_ORGAN 开闸
- **文件**：`config.py`
- **改动**：`ENABLE_TARGET_ORGAN_FIELD = False → True`。
- **机制**：tracer 填充率统计体（`:241-265`）原已就绪，开闸后每 **500** 次 emit 由
  `pulse_tracer` 打一行「填充率 INFO」（输出至 stderr，由生产日志收集入 pulse.log）。
- **口径**：填充率=0 判"闸开、无人声明"（不判缺陷、不回退）。

### 刀3 · LIF 时间兜底 flush 半刀
- **文件**：`nucleus/lif_shadow.py`
- **改动**：`LIFShadow.__init__` 新增 `flush_interval`（默认 `300.0`s）与 `_last_flush_ts` 锚点；
  `observe()` 在计数触发（`_count % flush_every == 0`）之外，增加**时间兜底**分支——
  当 `now_ts - _last_flush_ts >= flush_interval` 且 `_samples` 非空时强制 `flush()`（即使样本数
  <200，防低频器官饿死）；`flush()` 成功落盘后更新 `_last_flush_ts`。
- **闸门**：`ENABLE_LIF_SHADOW` 保持 `False`（等 213 批开）。

### 刀4 · SPIKE 读数出口半刀
- **文件**：`nucleus/synapsys/SpikeExecutionBackend.py` + `config.py`
- **改动**：`PythonSNNBackend` 的 `emit/on_spike/update_weight` 各计一次，新增
  `get_backend_stats()`（返回 `backend/emit/on_spike/update_weight` 计数快照）；
  `config.py` 新增 `ENABLE_SPIKE_BACKEND_STATS = False`（开闸前默认关占位）。
- **闸门**：`SPIKE_BACKEND_ENABLED` 保持 `False`（等读数出口验证后再开）。
