## 八、★ 工具坑（高复用，已沉淀记忆库）

1. **长任务必须用 `run_in_background`**（工具托管）；**禁用 `nohup &`** —— 子 shell 退出即回收，本轮曾因此让全量门禁只活几秒却误判"在跑"，白等 30 分钟。
2. **判断进程存活要匹配 `cmdline`**，不能只看进程名 —— `python` 名下常驻 `mypy.dmypy` daemon 极易被误认成 pytest。
3. **`git show HEAD:file` vs 工作副本 diff 有 autocrlf 假差异**（索引 LF / 工作树 CRLF），须归一或用 `git diff HEAD`。
4. **cw2 静默 except 坑**（本轮复现两次）：`except Exception: pass` 必被拦，须 `except Exception as _e: self._log(...)` 或 `silent_exc`。
5. **全量 pytest 的 SystemExit 假象**：`FAILED=0` + 无汇总行 = 没跑起来，**不是**全绿。
