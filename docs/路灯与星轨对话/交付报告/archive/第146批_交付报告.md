<details><summary>为什么「import 期原地渲染」是缺陷（点击展开）</summary>

它会把数据源里的 `<SELF_NAME>` 在 **import 时**就地替换成真值。后果有二：
1. **不可逆** —— 一旦渲染过，PII 扫描器再也扫不到占位符形态，丧失「掩码 → 出口渲染」的防线；
2. **真假混杂** —— 模块早于 main 的路径拿到已渲染值、晚的路径拿到未渲染值，行为随 import 时序漂移。

移除后改为「数据源恒为占位符，只在 5 个出口统一渲染」，语义收敛为单一真值源。
</details>
