## 四、T-g：FAISS ADD_UNDERFLOW 根因与修复

### 4.1 根因（**实测确认，非任务书猜测**）

任务书列了 3 个候选根因。实测结论：**根因是「向量维度与索引维度不一致」，且第 1、3 项均被排除**：

- 任务书候选 1（单条向量 → 1 维数组）：**排除**。`vecs = np.array([v for _, v in vectors])` 恒为 2 维 `(n,d)`；空保护 `:115-116` 已存在，故非空数组问题。
- 任务书候选 3（IVFFlat 样本 < nlist）：**未触发**。`nlist = max(1, int(sqrt(n)))`，`n >= nlist` 恒成立；且失败用例走 FlatL2（`n=200 < 100000`）。
- **实测根因**：`stage_faiss(200, 64, ...)` 使用**单例** `get_faiss_store()`，其 `_dimension` 取自 `config.VECTOR_DIMENSION`（**512**，见 `faiss_store.py:414`；`VECTOR_DIMENSION=512` 实测），却喂入 **64 维**向量 → `IndexFlatL2(512).add((200,64))` 抛 **空消息 AssertionError**（faiss 维度断言）→ `_build_index` 的 `except`（:143）捕获后 `self._index=None`，**且 `_vectors` 未落盘** → `get_stats()["vector_count"]=0` → `stage_faiss` 判 `0 >= 200` 为假 → `status=ADD_UNDERFLOW`。

红测输出实证（`tmp/m82_tg_red.txt`）：

```
[faiss_store] WARNING [M73-T1] FAISS 索引构建失败: AssertionError:      ← 空消息 = faiss 维度断言
{'status': 'ADD_UNDERFLOW', 'index_ready': False, 'stored_vectors': 0, 'vectors': 200, 'dim': 64, ...}
```

### 4.2 改动（`nucleus/vector_store/faiss_store.py` 3 处）

| 位置 | 改动 |
|---|---|
| `:115-127`（`_build_index`） | ① `vecs = np.atleast_2d(vecs)`（防 1 维）；② **维度一致性校验 `vecs.shape[1] != self._dimension` → WARNING + 跳过索引构建 + 向量落内存**（保证暴力余弦可用，`vector_count` 不丢） |
| `:140-147`（IVFFlat 分支） | 样本数 `< nlist` 时 WARNING + **降级 FlatL2**（避免 `train` 断言） |
| `:197-205`（增量路径） | 同样 `np.atleast_2d` + 维度校验，不一致时 WARNING + 跳过本次增量（既有索引保持可用），不崩 |

关键代码（`_build_index`）：

```python
            ids = [vid for vid, _ in vectors]
            vecs = np.array([v for _, v in vectors], dtype=np.float32)
            # [第82批 T-g] 单条向量时 np.array 可能得到 (d,) 1 维数组，faiss add 要求 2 维
            vecs = np.atleast_2d(vecs)
            if vecs.shape[0] == 0:
                return
            # [第82批 T-g] 维度一致性校验：与索引维度不符时告警并跳过（不崩），
            #   向量仍落内存 → search 走暴力余弦回退，检索正确性不受影响；
            #   否则 index.add 会抛空消息 AssertionError 且向量丢失 → ADD_UNDERFLOW。
            if vecs.shape[1] != self._dimension:
                _logger.warning(
                    "[第82批 T-g] 向量维度不一致（实际 %d vs 期望 %d），跳过 FAISS "
                    "索引构建，保留向量走暴力余弦回退",
                    int(vecs.shape[1]), self._dimension)
                self._index = None
                for _vid, _v in vectors:
                    self._vectors[_vid] = _v
                return
```
