### T1　多步检索兜底链路根治（P2-196）✅ ★核心

**实现**（`organs/brain/PulseInnerWorld.py`，v2 出口）：

```python
_ok_n = sum(1 for _s in _step_results if _s.get("success"))
if _ok_n == 0 and self._m34_fail_return_none_on():
    self._log(LogLevel.INFO,
              f"真多步推理: {len(_step_results)}步全部失败 → 返回 None，"
              f"回落上层单次大模型兜底（P2-196）")
    return None
```

- 灰度开关 `ENABLE_MULTI_STEP_FAIL_RETURN_NONE`（默认 `True`）；关闭 → 复现旧的降级叙述。
- **仅在「全部步骤失败」时回落**：只要有 ≥1 步成功，仍返回原本的分步叙述（不误伤正常多步推理）。
- 该 INFO 日志同时是**探针**：一旦出现即说明多步检索确实走不通（沿用「修复即可观测」惯例）。

**门控（6 例）**：开关默认值 / 全步失败返回 None / 关闭复现叙述 / 命中时正常返回 /
