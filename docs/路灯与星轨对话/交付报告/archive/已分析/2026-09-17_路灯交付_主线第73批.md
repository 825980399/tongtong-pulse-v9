## 1. 各任务交付

### T1 · P0 FAISS 索引构建修复

**根因（实测确认，非猜测）**：`nucleus/vector_store/faiss_store.py` 的 `add_vectors` 原逻辑为
`if not self._faiss_available or self._index is None: <写入内存并 return>`，即只有 `_index` 已存在时才写入索引；
而初始化后 `_index` 始终为 `None`，于是**每次 add 都落入内存分支并直接 return，索引从未被构建**（`_index` 恒 None）。
→ `search` 恒走 `_brute_force_search`（暴力余弦），`fast_ops.fast_vector_search` 的 `FAISS_FAST_OPS_MIN_CANDIDATES=5000` 阈值形同虚设。

**修复**：
- `add_vectors`：当 `_index is None` 且 faiss 可用 → 合并内存 `_vectors` + 新向量（去重）→ `_build_index`；否则增量 `self._index.add`；IVFFlat 训练量超 2× 时自动重建。
- `search`：FAISS 路径计数 `self._search_faiss_count += 1`；暴力回退路径一次性 WARNING + `self._search_brute_count += 1`。
- `save`/`load`：正确持久化并恢复 `_vectors`（`save` 写 `.vectors.npy`，`load` 优先从 `.npy` 恢复、回退 `index.reconstruct`），并恢复 `_index_trained_count`。
- 新增诊断接口：`is_index_built()` / `rebuild_index()` / `get_index_stats()`（含 `index_type` / `trained_count` / `search_faiss_count` / `search_brute_count` / `rebuild_count` 等）。
- IVFFlat 构造补显式 `dimension` 参数（`faiss.IndexIVFFlat(quantizer, self._dimension, nlist, ...)`），修复 faiss 1.15 的 `d_in == quantizer.d` 断言失败。
- **保留暴力余弦回退路径**（faiss 不可用时零副作用）。

> **偏差标注**：任务书 T1 称「修改 `nucleus/fast_ops.py` 中 FAISSVectorStore 类」。实测 `fast_ops.py` 不含该类的实现（真实位置为 `nucleus/vector_store/faiss_store.py`）。按铁律T0「任务书常偏差，先实测核实」，修复落在真实文件，未改 `fast_ops.py`。

## 3. snapshot_active_nodes 口径确认结论（T3）

**结论**：`snapshot_active_nodes()` 返回**内存中热层 + 温层常驻节点数**（`self._hot + self._warm`），不含第69批冷热分离机制驱逐到磁盘的冷节点。

- `Parquet` 全量 = **12295**（含 L1/L2/L3 全部节点落盘主存储）。
- `snapshot_active_nodes()` = **5458**（仅 `self._hot + self._warm`）。
- 差异 6837 = 当前被冷存的节点数，符合第69批冷热分离设计（L1 常驻、L2/L3 按需加载、超额驱逐）。

**性质**：设计行为，**非 bug**。后续若需「全量节点数」应使用 Parquet 计数或 `PulseNodePool` 持久化统计，而非 `snapshot_active_nodes`。无需改代码。

## 4. 双读一致性实时比对实现说明（T4）

**目标**：生产负载下抽查 Neo4j 读结果 `neo4j_hit` 与节点内 `linked_nodes` 的一致性，异常时告警并自动回退，确保图库零风险接管。

**新增配置（默认关闭，全部带默认值）**：
```python
NEO4J_READ_COMPARE_RATE = 0.1                  # 抽样比对比例
NEO4J_READ_COMPARE_WARN_THRESHOLD = 0.05       # 不一致率告警阈值（5%）
NEO4J_READ_COMPARE_FALLBACK_THRESHOLD = 0.10   # 不一致率自动回退阈值（10%）
NEO4J_READ_COMPARE_MIN_SAMPLES = 10            # 触发告警/回退前最小抽样数（防首样本误判）
```

**机制（`PulseNodePool`）**：
- `get_relationships_neo4j(node_id, direction)` 走 Neo4j 读取后，按 `RATE` 概率抽样，将 Neo4j 返回关系目标集与节点 `linked_nodes` 目标集做集合比对。
- `_m73_compare_stats()` 惰性维护：`sampled / mismatch / mismatch_rate / inconsistent_nodes / force_fallback / last_warn`。
- **告警**：`mismatch_rate > WARN(5%)` 且 `sampled >= MIN_SAMPLES` → 日志 WARNING（不阻断）。
- **自动回退**：`mismatch_rate > FALLBACK(10%)` 且 `sampled >= MIN_SAMPLES` → `force_fallback=True`，后续读取直接走节点内 `linked_nodes`（图库读取被旁路，零风险）。
- `repair_inconsistent_node(node_id)`：经 `_m71_neo4j_store().add_node/add_relationship` 将节点及关系重新同步到 Neo4j，并从 `inconsistent_nodes` 移除（确认根因后定向修复）。
- `reset_read_compare()`：清零统计与 `force_fallback`（人工修复后恢复比对）。

**KAL 委托**：`get_neo4j_read_compare_stats()` / `reset_neo4j_read_compare()` / `repair_inconsistent_node(node_id)` 委托节点池实现，保持 KAL 单一入口。

**生效条件**：需 `ENABLE_NEO4J_GRAPH_STORE` + `ENABLE_NEO4J_DUAL_WRITE` + `ENABLE_NEO4J_READ` 三开关同开；默认关闭，零副作用。覆盖 `tests/test_faiss_index_fix_m73.py` 的 `TestT4DualReadCompare`（9 例）全部通过。
