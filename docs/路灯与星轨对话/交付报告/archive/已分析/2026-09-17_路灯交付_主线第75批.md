## 三、各任务修复明细

### T1 · P0 L3动态扩缩（滞回+冷却+平滑）— `nucleus/field/InfoField.py`
- 新增配置块 `config.L3_SCALING_STABILITY`（铁律C1，置于文件末尾）：
  `scale_cooldown_sec=60.0 / scale_step=1 / hysteresis_down_ratio=0.50 / hysteresis_up_ratio=0.70 / hysteresis_enabled=True`。
- `InfoField.__init__` 读取该块初始化 `_l3_scale_step / _l3_hysteresis_down_ratio / _l3_hysteresis_enabled`。
- `_auto_scale_l3_by_depth` 改动：
  - 突发扩容：`_target = min(_cur + step, max)`（原 +2 → 平滑 +1），且**同样受冷却约束**。
  - 阈值扩容：`_target = min(_cur + min(_delta, step), max)`（原 +1/+2/+3 → 平滑最多 +1）。
  - 缩容触发：`elif hysteresis_enabled and ratio <= hysteresis_down_ratio and ...`（加入滞回下阈值开关）。
  - 新增属性读取统一用 `getattr(self, "_l3_scale_step", 1)` 等带默认值（与同方法既有可选字段风格一致），避免既有 `__new__` 测试夹具缺属性崩溃。
- 回退：`hysteresis_enabled=False` 即退回旧「无滞回保持带」行为；`scale_step` 可调回旧跳变幅度。

### T2 · P1 肝模块类型bug — `organs/body/PulseLiver.py`
- `_get_background_tempo`：返回值类型守卫（`not isinstance(_t,(int,float)) or isinstance(_t,bool)` → 记 WARNING 并回退 `1.0`）。
- `_do_optimize`：`except Exception as e` 日志改为 `f"异步优化任务异常: {type(e).__name__}: {e}"`（铁律10，含异常类型）。
- 备注：`_data.get("fail_count",{})` / `_data.get("fingerprint",{})` 经核实是 dict-map（用于 `.pop`/`.get`/`[prefix]=`），默认值 `{}` **正确非bug**，未改动。

### T3 · P1 self_inspector 方法体定位 — `nucleus/self_inspector.py`
- 精确命中补记：`if target_node is not None: _body_loc_tick("exact", 0)`（此前漏记 → 精确率恒 0%）。
- 偏移试探：`abs(_delta) <= 1` → 计 `exact`（±1 属装饰器/解析 off-by-one），否则计 `offset_probe`。
- 方法名兜底：未命中时放宽到 `startswith` / 反向 `startswith` 前缀匹配。
- 结果：精确匹配率显著回升（测试 `test_精确匹配率显著提升` 断言 exact/(exact+offset+fallback) ≥ 0.5）。

### T4 · P1 队列消费稳定性 — `nucleus/knowledge/RssCollector.py` + `config.py`
- 超时 `per_source_timeout` 8 → **15**（读 config，默认 15；受 config 覆盖仍生效）。
- 新增 `_slow_threshold / _emit_priority` 字段（config 可配：`slow_source_threshold=3 / emit_priority=4`）。
- feed 加 `slow_count / deprioritized`；`pull_all` 慢源排最后（`sorted(key=(deprioritized, slow_count))`）。
- 超时源记 `slow_count`，满阈值 → `deprioritized=True`；成功重置。
- 新增静态方法 `_is_timeout_error(e)`；消化 `priority=self._emit_priority`。
- 回退：`per_source_timeout` 改回 8、`slow_source_threshold` 设大即可停用降级。
