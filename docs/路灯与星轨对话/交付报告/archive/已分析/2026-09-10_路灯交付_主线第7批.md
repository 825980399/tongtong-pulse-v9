## 二、各任务交付明细

### 任务1 · L3 扩缩容震荡修复（P1-67，最高优先级）

**配置项（config.FEATURE，4 项）**
- `l3_burst_growth_threshold`: 0.30 → **0.50**（突发增长阈值提高，抑制误触发）
- `l3_scale_up_cooldown`: 5 → **15**（扩容冷却拉长，避免刚扩就缩）
- 新增 `l3_min_workers` = **3**（最小 worker，不允许降到 2）
- 新增 `l3_scale_down_buffer_sec` = **30**（低于半载后需稳定 30s 才缩容）

**逻辑改造（nucleus/field/InfoField.py · `_auto_scale_l3_by_depth`）**
- 突发改为平滑扩：`target = min(cur+2, max)`，不再直冲上限
- 缩容加缓冲：低于 0.5 且持续 ≥30s 才允许缩，目标 `max(cur-1, min_workers)`
- 新增「低于半载持续计时」`_l3_below_half_since`
- `get_l3_scaling_stats` 补充 `min_workers` / `scale_down_buffer_sec` 字段
- 兼容性：base < min 时强制 base = min

**偏差核实**：任务书路径 `organs/core/PulseInnerWorld.py`、`nucleus/vector/VectorStore.py` 与现状不符，实际分别为 `organs/brain/PulseInnerWorld.py`、`nucleus/semantic/VectorStore.py`（已在第6批修正）。本次仅改动 InfoField 与 config，未触碰错误路径。
