## 三、各文件头部内容摘要

统一格式：`# -*- coding: utf-8 -*-` + 标题行 + `版本 / 设计 / 日期` + `职责 / 机制 / 定位`。

### 内分泌 endocrine（2）

**1. `PulseHormones.py` —— 激素器官 · 情绪检测与情感状态生产**
- 职责：承接 `HormonesEvent.DETECT` / `ChatEvent.MESSAGE` / `PersonaEvent.SWITCHED`，做情绪检测与归因、时间线与趋势感知、惯性平滑、社会性情感记忆衰减与主动关怀。
- 机制：`on_pulse` 分派 `_on_detect` / `_on_persona_switched` / `_on_status_request`；`_detect_emotion_all` → `_detect_emotion` + `_detect_social_emotions`，`_load_emotion_keywords` 装载关键词后 `_attribute_emotion_cause` 归因；`_apply_emotion_inertia` / `_apply_emotional_resonance` 平滑；`get_emotion_trend` 读 `emotion_timeline`；`_update_social_memory` + `_apply_social_decay` 维护 `social_memory`；负面情绪走 `_get_care_suggestion` 并发 `HormonesEvent.CARE_NEEDED`，`_write_emotion_log` 落盘；`get_internal_conflict_signal` 供上游冲突判别。
- 定位：内分泌层「激素腺体」，`always_online=False`、受 `enable_endocrine` 控制，情绪状态的唯一生产者。

**2. `PulseNeurotransmitters.py` —— 神经递质器官 · 细粒度化学状态池**
- 职责：维护 `NEUROTRANSMITTERS` 定义的多巴胺/血清素等递质，随 `ChatEvent.MESSAGE` / `HormonesEvent.EMOTION_DETECTED` 刺激升高、按 `decay_rate` 回落，提供三种粒度查询与快照。
- 机制：`on_pulse` → `_on_message` / `_on_emotion`；`_adjust` 夹取 `min/max`，`_decay` 逐拍回落，`_record_history` 记曲线，`_notify_listeners` 回调 `add_listener` / `remove_listener` 注册者；`get_level` / `get_all_levels` / `get_composite_state` 查询；`get_state_snapshot` / `load_state_snapshot` 持久化。
- 定位：内分泌层「神经递质池」，`always_online=True`、`feature_flag=None`（生命线核心不可关闭）。

- 定位：⚠ **注**：`BondingEvent.UPDATED` 广播已按 P3-5 作为孤儿脉冲移除，本器官**只回状态、不再发脉冲**（旧悬空块仍宣称会发射，属过时信息）。

**5. `PulseDNARepair.py` —— DNA修复器官 · 错误自愈与补丁生成**

**7. `PulseNurture.py` —— 养育器官 · 教育阶段推进与知识传承**

- 定位：遗传层包入口，不参与脉冲收发。

## 九、本轮踩坑记录（供后续复用）

1. **CRLF 文件用 `\n` 拼补丁串会 0 匹配** —— `tmp/patch_b21_b007.py` 首跑全部 `count==0`。修法：读入后先 `nl = "\r\n" if "\r\n" in text else "\n"`，把补丁串的 `\n` 全部替换为 `nl`。**凡改 `organs/` 下 CRLF 文件都要先判行尾**。
2. **`ruff.toml` 是 LF、业务文件是 CRLF** —— 同一个项目两种行尾，改配置时别套用业务文件的行尾假设（`OLD_TAIL` 硬编码 `\r\n` 导致首跑失败）。
3. **`os.devnull` 在 Windows 是 `nul`** —— 项目根目录恰好有个名为 `nul` 的文件（历史遗留），`py_compile.compile(cfile=os.devnull)` 会抛 `FileExistsError`。改用 `tempfile.mkdtemp()` 下的临时 `.pyc` 路径。
4. **`--config <backup.toml>` 是验证「配置改动前后差值」的利器** —— 用 `ruff check --config ruff.toml.bak_batch21` 复现改前数值，比手工推算可靠。
5. **ruff 的 E402 容忍 `sys.path.insert`** —— 删除悬空块后，即便 import 排在 `sys.path.insert(...)` 之后也不报 E402（第 1 批同款现象再次验证），所以「删悬空块 → E402 清零」在本项目是稳定打法。
