## 五、T-99c 面板「应用预设」POST（P1）

**根因**：面板前端“应用预设”用 `fetch` 发 `POST /params/apply_preset`，但 `HealthHandler` 之前**只有 `do_GET` 无 `do_POST`**，默认处理器对 POST 返回 **501**，预设无法应用；且原 `do_GET` 内含 `elif self.path.startswith('/params/apply_preset')` 分支，GET 即触发状态变更（违反幂等/安全方法语义）。

**修复**（`health_ui.py`）：
1. 删除 `do_GET` 内 `apply_preset` 分支（GET 不再变更状态，越界返回 404）。
2. 新增 `_is_same_origin()` 同源(CSRF)校验：比对 `Origin`/`Referer` 的 netloc host 与请求 `Host`，跨站返回 403。
3. 新增 `do_POST()`：同源时处理 `/params/apply_preset`，否则 404。

