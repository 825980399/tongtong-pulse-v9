## 四、逐任务详情

### T1　多步检索 v2 入口预判（P2-203）✅ ★核心

**实现**（`organs/brain/PulseInnerWorld.py` + `config.py`）

新增 `_m35_entry_probe(question, plan, core_words)`，插在 `_multi_step_execute_v2` **生成计划与核心词之后、步骤循环之前**：

```python
if self._m35_entry_probe(question, _plan, _core_words) is False:
    return None          # 0 次模型调用 → 直接交上层单次大模型兜底
```

两道判据（**均不含模型调用**）：

1. **领域预判**（有界采样，不新增重型依赖）
   - `node_pool.query(evol_level="L2", limit=SCAN_LIMIT)` 采样上限内节点；
   - 统计核心词可见命中数 `_hits`、命中节点平均 `trust_score`；
   - `_domain_weak = (_hits < MIN_NODES) and (_avg_trust < MIN_TRUST)`。
2. **命中率探针**
   - `_knowledge_retrieve("核心词 + 原问题")`（本地检索）→ `_validate_step_result` 质量门；
   - `_probe_weak = 未过质量门`。

**判定 = `_domain_weak and _probe_weak` → False（跳过 v2）**；其余一切情况返回 `None`（不确定）→ 照常进 v2。

**★保守策略（明确写进代码注释）**：任一信号充足、无核心词、池为空、池为 `None`、采样异常、检索异常、校验异常 —— **全部返回 `None`（放行）**。本方法**永不返回 `True`**："确定适合多步"没有安全判据。

**新增配置（4 项，均可调）**：
```python
ENABLE_MULTI_STEP_ENTRY_PROBE = True      # 灰度开关，关闭 = 直接进 v2（零回归）
MULTI_STEP_ENTRY_PROBE_SCAN_LIMIT = 800   # 采样上限（越大越准越慢）
MULTI_STEP_ENTRY_PROBE_MIN_NODES = 5      # 命中节点数下限
MULTI_STEP_ENTRY_PROBE_MIN_TRUST = 30.0   # 平均信任度下限（PulseNode 默认 50.0）
```

**★模型调用次数量化（门控实测，`tests/test_entry_probe_m35.py`）**：

| 场景 | 返回 | 模型兜底调用次数 |
|---|---|---|
| 预判拦截（`False`） | `None` | **0** ✅ |
| 预判放行（`None`） | `None`（全步失败） | **= 计划步数**（该用例为 4） |

**行为矩阵（8 分支）**：领域弱+探针空→拦截；领域强→放行；领域弱+探针命中→放行；池空 / 池 `None` / 池异常 / 检索异常 / 无核心词 → 全部放行（不确定）。开关关闭→放行。
