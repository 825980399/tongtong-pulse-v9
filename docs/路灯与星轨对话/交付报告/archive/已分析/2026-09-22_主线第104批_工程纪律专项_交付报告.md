## 2. 根因定位

### T-104a (D006) — 工程纪律 CI 缺位
- **根因**：工程纪律门禁分散、未形成统一 CI 流水线。仅 N7 静默except门禁（`.gitee/workflows/ci_silent_except.yml`）落地，缺全项目 ruff F、py_compile 语法校验、关键测试运行三道关口，无法在 push/PR 时自动拦截回归。
- **修复**：新建 `.gitee/workflows/ci.yml`，串起四道关口（ruff F → py_compile 全量 → N7 静默except → 关键离线测试），`on: push[master] / pull_request[master]`。

### T-104b (D157) — HTTPServer 队头阻塞
- **根因（实测无）**：经全仓扫描，生产环境 `HTTPServer(` 调用已全量升级为 `ThreadingHTTPServer`（第99批闭环），无单线程残留，故不存在队头阻塞根因。
- **固化**：新增 `tests/test_t104b_http_concurrency.py`，以 `ThreadingHTTPServer` 起含 `/slow`(1s) 端点服务，并发请求快端点须 <0.5s 返回，锁死"无队头阻塞"不回潮。

### T-104c (D169) — 故障面板部分全盲
- **根因①（ERROR 未桥接）**：此前只有 `BasePulseOrgan._handle_pulse` 脉冲异常路径调用 `record_error` 入 `error_snapshots`；框架内大量 `logging.error(...)` / `logging.exception(...)` 未接入，导致多数故障在 `error_snapshots` 中不可见（"9类故障全盲"部分成立）。
- **根因③（5051 零感知）**：`HealthUIServer.start()` 仅启动 `serve_forever` daemon 线程，**无存活看门狗**。若面板线程意外退出，HTTP/面板静默不可达，运维零感知。
- **修复**：
  - 在框架根 logger（`pulse`）挂 `ErrorCaptureHandler`，将 `pulse.*` 命名空间下 `ERROR/CRITICAL` 自动转写进 `error_snapshots`（幂等安装、防递归、桥接失败 fail-closed）。
  - `main.py` 启动即 `install_error_capture()`（下次重启生效）。
  - `HealthUIServer` 新增 `_watchdog_loop`：每 10s 巡检 `serve` 线程存活，死亡即 `record_error(pulse_type="health_ui", ...)` + `warning` 告警，使 5051 停服可感知。

### 3.1 `nucleus/runtime_metrics.py`（+65 行，LF 不变）

```python
# ===== 主线第104批 T-104c（D169）：logger.ERROR -> error_snapshots 桥接 =====
import logging
import traceback

class ErrorCaptureHandler(logging.Handler):
    """把 pulse.* 命名空间下 ERROR/CRITICAL 日志自动记入 error_snapshots。"""
    def __init__(self, level: int = logging.ERROR):
        super().__init__(level=level)
        self._reentrant = False
    def emit(self, record: logging.LogRecord) -> None:
        if self._reentrant:
            return
        try:
            self._reentrant = True
            _rt = get_runtime_metrics()
            _tb = "".join(traceback.format_exception(*record.exc_info)) if record.exc_info else ""
            _rt.record_error(pulse_type=record.name or "log", error=record.getMessage(),
                             traceback_text=_tb, lock_held=False)
        except Exception as _e:
            logging.getLogger("pulse.silent_except").debug("error_snapshot 桥接失败: %s", _e)
        finally:
            self._reentrant = False

_error_capture_installed = False
def install_error_capture(logger_name: str = "pulse") -> bool:
    """在框架根 logger 上安装 ErrorCaptureHandler（幂等）。"""
    global _error_capture_installed
    if _error_capture_installed:
        return False
    try:
        _lg = logging.getLogger(logger_name)
        for _h in _lg.handlers:
            if isinstance(_h, ErrorCaptureHandler):
                _error_capture_installed = True
                return False
        _h = ErrorCaptureHandler(level=logging.ERROR)
        _lg.addHandler(_h)
        _error_capture_installed = True
        return True
    except Exception as _e:
        logging.getLogger("pulse.framework").warning("安装 ERROR 捕获失败: %s", _e)
        return False
```
