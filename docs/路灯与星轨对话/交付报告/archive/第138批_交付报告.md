## 四、关键技术处置

### 4.1 T-138a：CC 检测器

- **口径**：`cc_visit` 会同时返回 **Class 级块**，本检测器**只取 Function/Method**（`type(_blk).__name__ in ("Function","Method")`），与 B3 分支账口径分离（前置分析 §1.6②）。
- **两级阈值**：
  * `SELF_INSPECTOR_B6_OBS_MIN=25` → per_file `ge25` 观察账（**不告警**，仅记趋势）；
  * `SELF_INSPECTOR_B6_GATE_MIN=50` → `blocks_ge50` **棘轮本体**，新成员（差集非空）→ `cc_ge50_new` 告警，**只降不升**。
- **基线格式**：`{"per_file": {rel: {ge25,ge50,max_cc,worst}}, "blocks_ge50": [...]}`；键统一 `/` 分隔。
- **首扫实测**（Python 3.12，本机全树）：`665` 文件、`239` 个 ≥25、`58` 个 ≥50，耗时 `6.88s`（与 137 期 5.9s 同量级）。worst：`PulseInnerWorld.py::_on_inference_request@526` CC=286。
- **注册**：`GLOBAL_DETECTORS["cc_growth"] = "_detect_cc_growth"`，可被 `skip_detectors` 消费。

### 4.2 ★ 关键发现：radon 未装在被管 Python（D137-3 的实证）

- 本机 `D:/Program Files/Python312`（框架实际运行解释器）**已装** radon 6.0.1；
- 但 WorkBuddy 被管解释器 `python 3.13.12` **未装** radon。
- 首次以 3.13 扫描时，`_si_cc_blocks` 的 `except ImportError` 走 `silent_exc` → **静默 0 检出**（不报错、不告警）。
- **这正是 T-138b 必须补声明的根因**：换机器/换解释器若不装 radon，CC 检测器**静默死亡 = 假绿**。已用 `dev-requirements.txt` 硬钉版本对冲。
- 检测器本身对该缺失**有可观测性**（走 `silent_exc(level="warning")`，非裸 pass），符合第124批「静默异常可见化」约定。

### 4.4 T-138d：语义缓存 L2（按 44 批设计文档落地）

- **口径裁定**（经星轨确认）：任务书 T-138d「相同语义的查询直接命中」按 **44 批设计文档 §2.2** 解读 —— 在 `PulseLung._call_via_channels()` **之前**查表，命中且过闸 → **直接返回缓存响应**（省一次大模型调用），而非「绕过知识检索」。
- **L1→L2 的实质**：L1 结构上**只回统计、绝不回内容**（故可生产常开）；L2 后该结构性保证消失 → 必须用**四道闸门**替代。
- **四道闸门**（全过才返回，任一失败 → 静默回落正常渠道调用）：
  1. **置信闸**：sim ≥ 阈值（沿用 L1 校准值 0.85）；
  2. **时效闸**：now − ts ≤ TTL（**1 小时**，按任务书口径）；
  3. **幂等闸**：origin ∈ {`user_query`} 且 prompt 无指代词/时间/UUID 标记 且 长度 ≥ 8；
  4. **质量闸**：缓存响应非空。
- **TTL 裁定**（经星轨确认）：L2 层**独立内存存储**，TTL **1 小时**；**不改** L1 的 7 天观测账（两层分层共存）。
- **淘汰**：超容量（2000）→ **LRU 按 `last_hit_ts`**（非写入 ts，避免淘汰"经常命中但很旧"的热条目——设计 §四的升级点）；过 TTL 懒删。
- **灰度**：`ENABLE_SEMANTIC_CACHE_L2` **默认 False** → 关闭时零副作用，逐字回 L1 行为。
- **写入**：仅 `user_query` origin；与 L1 `observe_call` 并列（L1 观测账不受影响，遵守 R5「命中不改留存语料」）。
- **接口**：`lookup(with_content=False)`（默认旧行为**完全不变**——已补测验证 L1 红线 `response` 不泄漏）。

### 4.5 静默except门禁：9 处新增 → 改 `silent_exc`（非白名单）

- L2 层初版 9 处 config 读取兜底为裸 `except Exception: return <default>` → CI gate 判「新增 9 处」。
- **按第124批既定惯例**（新增回潮应改造而非豁免）：**全部 9 处改为 `silent_exc(...)`**（含 level 白名单），复跑 gate **PASS**（净增=0）。未动用 `LOCATION_WHITELIST`。
