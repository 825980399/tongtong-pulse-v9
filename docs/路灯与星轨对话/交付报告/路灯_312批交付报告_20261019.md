## 二、刀1 · 图污染守卫

### 问题（烛微一手）
`data/call_graph/` 被测试合成图污染过**两次**：`graph_20261019_130440.json`、`graph_20261019_163701.json`，各 2,781B / **nodes 12 / edges 7 / stats.total_files=4**，`node.file` 全是 `pkg/a.py`、`pkg/b.py`、`pkg/c.py`。
消费侧原实现一律 `sorted(glob)[-1]` —— 只要合成图排在最后：
- `self_inspector._m305_load_graph_index` ⇒ dead_code 拿一张 4 文件图当判据，覆盖率与豁免集**全部失真，且看不出来**（读数仍是个正常数字）；
- `patch_execution_dispatch.load_call_graph_cache` ⇒ 牵连闸起点定位不到 ⇒ 整池 `blast=None` 转人工（fail-closed 把闭环掐死）。

### 改动
**新模块 `nucleus/data/call_graph_guard.py`**（单点判据，两处消费共用）：
- `judge_graph(graph, path)` → `(可用, 原因码)`：`too_few_nodes(<100)` / `too_few_files(<10)` / `synthetic_pkg(pkg/*)` / `synthetic_name` / `no_nodes` / `bad_json`；
- `select_latest_graph(dir)` → **从新到旧挑第一份合格图**，被拒的逐份留痕；全被拒 ⇒ `ok=False`（判据不可用，不猜）；
- 语义边界：**只判不改、不删、不写盘**。

两处消费接线：
- `nucleus/self_inspector.py::_m305_load_graph_index`：改走守卫，拒绝时打 WARNING；返回值新增 `graph_rejected`（本轮拒了哪些、为什么）；`graph_file/graph_mtime` 改取**实际采用**的那份。
- `nucleus/evolution/patch_execution_dispatch.py::load_call_graph_cache`：同守卫；并加了 `graph_dir` 可选参数（**只为隔离验证**，生产调用方不传）。

## 四、刀3 · DailyScheduler 留痕行 `isinstance` 守卫（310 欠账）

### 问题
309 加的留痕行读 `_res["risk_rescan"].get("changed")/.get("total")`。`rescan_high_risk_levels()` 走异常路径时可能返回 `None` ⇒ **留痕行自己抛 AttributeError**，把「回扫失败」升级成「整个每日拍失败」。留痕行比它观测的代码更脆，是典型的观测器反噬。

### 改动
新增模块级 `_m312_as_dict(value, where)`：`dict` 原样返回；其它类型 ⇒ 空 dict ＋ WARNING 留痕。调用点先兑 dict 再记 `changed/total`，并把兑过的值写回 `_res["risk_rescan"]`（下游读到的始终是 dict）。

### 实测
```
[312刀3] 存量高危回扫 返回非 dict（NoneType），按空 dict 处理
None -> {} ; dict -> {'changed': 3, 'total': 84} ; 留痕行可读: True
```

## 六、降级与遗留（如实）

- **D1 生产目录里的两份合成图未清**：`graph_20261019_130440.json`、`graph_20261019_163701.json`（各 2,781B）仍在 `data/call_graph/`。本批写入面不含 `data/`，**守卫已使其不可能被采用**（它们排到最新位时必被拒），但文件本身还在，清理由星轨/主人授权后执行。
- **D2 写侧未堵（真风险）**：`dump_graph_snapshot()` 仍可写生产目录，守卫只在**消费侧**。「小图不再能当判据」成立，但**小图仍会占滚动 7 份的配额**——每落一份合成图就顶掉一份真图。建议 313 批在写侧加门槛（`nodes < MIN_NODES` 拒写 或 文件名打 `graph_test_` 前缀并被消费侧排除）。
- **D3 牵连闸只验了「选对图」**：blast(prod)=0 与 311 口径一致；未在合成图场景下复现「blast=None」的反事实（反事实只证明了旧口径会取到 12 节点图）。
- **D4 活体未触发**：`_m312_as_dict` 只在「上游返回非 dict」时才有行为差异，真机需重启且上游真异常才走得到，本批以 helper 单测代替；图守卫的 WARNING 在活体的下一次 dead_code 扫描（若真遇到合成图）才会出现。
- **D5 观测**：本批窗口内 `data/call_graph/` 新增 `graph_20261019_181317.json`（nodes 6776）—— 说明有运行中的进程在落图，属正常新鲜度机制，非本批写入。
