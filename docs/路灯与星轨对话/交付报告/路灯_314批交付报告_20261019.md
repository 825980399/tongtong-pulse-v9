## 一、刀1（P0）· 掌握率直调修复

### 真实断点（烛微314批）

不是"分母难算"，是 **`code_learner.stats` 没有生产者**：全库 2 个读取方
（`daily_reader.py::append_mastery_section`、`PulseNarrativeSelf.py::_generate_weekly_report`）、
**0 个发射方**。两处都写 `InfoField.get_current("code_learner.stats")`，而这个方法的
三处语义叠加让读数「哑而不报错」：

1. 它是**脉冲历史查询**（`event_type == key`，脉冲自带 TTL，缺省 **5 秒**）⇒ 即便有人 emit，5 秒后照样读不到；
2. 它返回的是**脉冲记录 dict**（`event_type`/`payload`/`timestamp_ns`）而不是 stats 本体
   ⇒ `pulse.get("understood")` 恒为 `None`；
3. 于是 `source=unavailable` 与「读数真的是 0」长得一模一样。

### 改动

| 文件 | 改动 |
|---|---|
| `nucleus/code_learning_stats.py`（**新增**） | 唯一取数口 `get_code_learning_stats(info_field=None, organs=None, fallback_total=0)`：① `get_current` 兼容（认「脉冲嵌 payload」与「stats 本体」两种写法）→ ② 直调 `PulseCodeLearner.get_stats()`（器官表中文名/属性名/类名三套键）→ ③ 两路皆无 ⇒ `source=unavailable` + `gap=no_producer(...)`，**不返回 0 冒充读数** |
| `nucleus/self_awareness/daily_reader.py` | `append_mastery_section` 改走唯一口；分母优先器官自报、退 AST `method_count`；取不到时日报写**「已理解取不到（结构性缺口：…）」**，不再打印 `0%`；`numerator_source` 直接写取数路径（`code_learner.get_stats` / `info_field.code_learner.stats` / `unavailable`） |
| `organs/identity/PulseNarrativeSelf.py` | `_generate_weekly_report` 同改**同一函数**（掌握率文本「已理解 X/Y 个方法（掌握率 Z%）」），知识库文本兜底保留 |

- `_src` 新增值：**`code_learner.get_stats`**（真实生产者路径）；
- 生产侧缺失 ⇒ **标结构缺口，不标 0%**（0% 会被读成"学了个寂寞"，实际是"根本没接通"）。

### 实测（内存桩，不启器官）

| 场景 | source | understood |
|---|---|---|
| 脉冲记录嵌 payload（兼容路径） | `info_field.code_learner.stats` | 6677 / 8000 → 83.5% |
| 器官表直调 `get_stats()` | `code_learner.get_stats` | 6677（钳 100%） |
| 两路皆无 | `unavailable` | **None**（gap=`no_producer(...)`） |
| 器官表按属性名给（非 dict） | `code_learner.get_stats` | 10/20 → 50.0% |

日报渲染（桩值 123/1418）：`已理解 123/1418 个方法（掌握率 8.7%）` +
`numerator_source=code_learner.get_stats`；缺口场景渲染为 `结构性缺口：no_producer(x)`，
且全文**不含** `掌握率 0.0%`。

## 二、刀2（P1）· `get_current` 语义注释

`nucleus/field/InfoField.py::get_current` 补完整 docstring：

- **语义**：`_history` 倒序找 `event_type == key` 的**最近一条**脉冲；
- **TTL 出处**：`ttl_ns` 缺省 `5_000_000_000`（5 秒），`ttl_ns <= 0` 视为永不过期，
  `now_ns - timestamp_ns > ttl_ns` 即过期；
- **返回**：脉冲记录本身，**不是**"当前值"，业务数据在 `pulse["payload"]`；
- **踩坑史**：点名 314 批掌握率（0 发射方 + 5s TTL + 返回值形状三连）导致 `source=unavailable`
  与 0 无法区分；
- **正向指引**：要"当前值"语义请另建缓存/快照口（`set_global_awareness` / `get_global_awareness` 范式）。

调用点三处注释均引用该语义：`daily_reader.append_mastery_section`、
`PulseNarrativeSelf._generate_weekly_report`、`nucleus/code_learning_stats.py` 模块 docstring。
