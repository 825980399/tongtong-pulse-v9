## 二、刀1（P0）开自动重启保命

```
ENABLE_MEMORY_AUTO_RESTART     False → True
MEMORY_AUTO_RESTART_RSS_MB     9216.0 → 12288.0（12GB）
MEMORY_RESTART_COOLDOWN_HOURS  24.0 → 6.0
```

**开之前先量的两件事**（破坏性开关，不能盲开）：
1. **当前 RSS = 7736MB**，距 12GB 有 4.5GB 余量 ⇒ 开启**不会立即触发**。
   沿用 9216 则余量仅 1.5GB，正常波动就可能误杀 —— 这是抬阈值的理由。
2. **重启不丢快照**：内存重启走 `sys.exit(0)`，SystemExit 触发主循环 finally
   ⇒ `framework.stop()` 保存快照。已加守卫（不许改成 `os._exit`）。

**票面两处措辞与代码事实不符**（如实记录）：
- 第 4 条「触发时打 WARNING 留痕」—— **已有**（`main.py:3838`），本刀未改代码。
- 第 5 条「RSS 超阈值时 `_maybe_memory_restart` 返回 True」—— 该函数**不读 RSS**
  （判开关+互斥+计数桶）。RSS 判定在 `PulseMetricsCollector`（连续 2 次越阈），
  主循环靠 `_last_restart_armed` 才调它。单测两条分开写。

**冷却的真实边界**（写进配置注释）：本键**只在计数桶达 3 次上限被锁后**才生效；
前 3 次重启之间**没有最小间隔**。缩到 6h 影响的是"锁死后多久能再自愈"。

## 三、刀2（P0）内存泄漏归因 —— 只定位

结论先行：**主进程泄漏 94.2 MB/分钟**，到 12GB 需 0.8h、到 36GB 需 **5.2h**
（与 386 晚 5 小时卡死吻合）。但 **tracemalloc 归因仍不可得**。

386 刀3 修好后 `data/reports/memory/` 已有 **110** 份产物 —— 观测活了。取主进程：

| 时刻 | heap_mb |
|---|---|
| 07:52:14 | 6837.3 |
| 08:00:03 | 7573.8 |

```
7.82 分钟涨 736.5MB ⇒ 94.2 MB/分钟（告警线 10MB/min 的 9.4 倍）
⇒ 387刀1 的自动重启约 48 分钟后首次触发（保命但不治本）
```

**tracemalloc 拿不到的三层原因**：
1. 槽位限制：`_M339_PROBE_HOURS=(5,13)`，08 点走 `gc_objects` 档 ⇒ 下次要等 **13:00**
2. 109 份产物里 92 份来自子进程，而子进程 `tracemalloc_is_tracing=False`
   （主进程 tracing=True 但不在槽位；子进程在槽位但不 tracing ⇒ 两条路都堵）
3. 历史 17 份 tracemalloc 产物同样 `rows=0`

**四大嫌疑对账**：知识库快照 **1446MB（722.5 热档 + 723.5 冷备）是头号嫌疑** ——
每个自主迭代子进程一启动 heap 就 ≈9917MB，而 `image_mb` 仅 82.8MB（全是数据），
且它只活约 5 秒 ⇒ 那 9.9GB 是**启动即加载**的固定成本。

完整归因见 `docs/分析报告/路灯_387_内存泄漏归因_20261029.md`。

## 四、刀3（P1）零发射判据修正 —— 386 判错了两处

票面要求「先修前额叶（22 处发射器）」。查证结果：

### 前额叶**不哑，而且已经在发射**

- 我先查 `source` 字段（恒 0）差点误判；`pulse_pairs` 的发射方字段是 **`organ`**
- 前额叶当日有 **2 条** emit：`reflection.insight` + `narrative.record`（均 L2）
- 调用链：`on_pulse` ← `MouthEvent.SPEAK`（入队复盘）/ `HeartEvent.BEAT`
  ⇒ `_process_queue` ⇒ `_analyze_interaction`（11 处发射器**全在这一个方法**）
- BEAT 当日 1279 次，但复盘队列靠 SPEAK 入队；SPEAK 少 ⇒ 队列空 ⇒ 零发射
  ⇒ **属无输入，不是故障，不改任何业务代码**

### 血管：零发射 = **系统健康**

血管是「发现沉默器官才告警」，4 处发射器全在 `if _escalated_names:` 分支里
⇒ 它不发恰恰说明**没有器官失联**。386 把它列为"真哑嫌疑"是误报。

⇒ **386刀4 的判据「有发射器却零发射 ⇒ 真哑了」根本性不足**：
绝大多数器官都是**条件发射**，零发射可能只是"无事发生"。
