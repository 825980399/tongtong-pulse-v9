### ★ 2.2 为什么必须同时补「长度下限」（本批的核心判断）

**（a）只降阈值会放行"删掉大半方法体"的补丁。**
关3 的相似度是**对称**指标。补丁是**整段替换**（`_verify_in_copy` 的 `modified_full = full_content.replace(original_code, modified_code)`），当 LLM 输出被截断时 `M ≤ len(mod)`，于是

```
ratio ≈ 2*len(mod) / (len(orig) + len(mod))
```

令 `ratio ≥ 0.3` 解得 **`len(mod) ≥ 3/17 * len(orig)` ≈ 17.6%**。
对长方法（`PulseLiver._periodic_purity_check`，17,089 字符）**只需 3,016 字符即可过闸 = 允许删掉 82%**。

**（b）数学上可证：长度下限 1/3 不会拒绝任何"原阈值下可通过"的补丁。**
原阈值 0.5 下过闸 ⇒ `ratio ≥ 0.5` ⇒ 由上式 `2L/(L₁+L) ≥ 0.5` ⇒ **`len(mod) ≥ len(orig)/3`**。
⇒ 关3b 加的是**原阈值已经隐含蕴含**的条件，**零安全回归**，只堵住阈值下调新开的口子；对"同长度但重叠较少"的合法改写**完全放行**（这正是 T-89a 的目的）。

**（c）真实失败样本佐证**：2026-09-20 15:25:47 `similarity 0.09 < 0.5` ⇒ 反推 `modified` 仅剩原文 **4.7%** = **真截断**。这类补丁在 0.3 下仍会被关3 拦下；**真正需要关3b 的是 0.3~0.5 之间、长度却不足 1/3 的"长方法腰斩"区间**。
