| SCENE_LUNG 全库为 0 | `data/metrics/llm_dependency.json` 中 `肺回答`(SCENE_LUNG)=**2989**（非 0） | `record_llm_call(SCENE_LUNG)` 已在 `_call_via_channels` 入口接线（PulseLung:1790）。对话类埋点**早已闭环** |

## 二、本批实际改动（落在 B.3 + 门控）

### 改动 1 · 依赖度三向日志（`nucleus/LLMDependencyMetrics.py`）
- 新增 `dependency_three_way()`：把 `llm_call_count` 拆为 `进化(SCENE_EVOLUTION) / 对话(SCENE_LUNG) / 代码学习 / 其他`，并给出 `evolution_ratio` 与 `lung_ratio`。
- `log_hourly()` 追加一行三向日志：
  `[依赖度量·三向] 进化=0.XXXX 对话=0.XXXX 总=N (进化=a 对话=b)`
  `lung_ratio > 0` 即对话类埋点已闭环、口径真实化的直接证据。

### 改动 2 · 门控测试（`tests/test_lung_trace_m40.py`）
- `TestWriteFailureNonBlocking::test_44_write_failure_non_blocking`：留存写盘异常（`record()` 抛 RuntimeError）不得阻断主推理流程——主流程仍正常返回回复（满足任务书验证项"写失败不阻断"）。
- `TestDependencyThreeWay`：断言三向拆分 `lung>0 / evolution>0 / total=2`，空集安全返回 `0/0.0`，以及 `log_hourly` 确实发射 `[依赖度量·三向]` 含 `对话=`。
