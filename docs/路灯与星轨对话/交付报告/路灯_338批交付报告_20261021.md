## 本批踩坑（都是真金白银，已写入 MEMORY）

1. **cw2 首提被拦 6 处**：① 我把 `_m41_backup_keep` 的 `_n = 3` 改成 `2`，**handler 体变了 ⇒ 指纹变 ⇒ 算「新增静默 except」**（铁律150：指纹只绑 handler 体）。② 新文件里的 `except (TypeError, ValueError): pass/return None` 全被算。处置：全部补 `silent_exc` / `logger.debug` / `_log`。
2. **CI 脚本自己也要过门禁**：`check_typed_infer_guard.py` 的三处 `except` 一度被判「未跟踪 .py 含静默 handler」——加 `_log()`（名字在 `ci_common.LOG_FUNCS` 白名单内）才过。
3. **heredoc 会吃反斜杠**：用 `<<'PYEOF'` 写补丁脚本时，`'\r\n'` 被 MSYS 变成 `/r/n`，写出的文件直接 `SyntaxError`。改用 `chr(13)+chr(10)` 拼行尾。
4. **锚点错字**：`置信` 写成 `信度`，`count==1` 断言直接 0 命中——所以每个补丁脚本都必须 `assert count==1`，不能"看着像就 replace"。
5. **单测要按真实契约写**：`build_payload(spans=...)` 收的是 `(nid, (start,end))` **二元组**，我先按三元组写，测试红；改对后绿。**测试红了先怀疑自己写错契约，不要先改产品代码**。
6. **`heap_mb` 测不到不是 bug**：`pick_tier(None)` 返回 `G1_OBSERVE`（只观测）而不是 `G0_BLOCK`——档位语义是「不释放」，不是「拦死」。我第一版测试断言写错，对着实现改正。
