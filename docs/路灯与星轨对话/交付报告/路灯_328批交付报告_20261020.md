## 一、刀1 · A6 聚合收口（edge_types 逐边 kind 不抹平）

### 根因（T0 实测确认，与烛微327 §新风险1 逐字吻合）

`CallGraphAnalyzer.dump_graph_snapshot` 里写着：

```python
_k = str(_e.get("kind") or "static")
if _k not in _edge_types:      # ← 预设键只有 static/byname/event/entry
    _k = "static"              # ← 于是 unique_name / self_attr / typed_infer 全被折叠
```

活体图 `graph_20261020_203224.json` 实测：

| 口径 | static | unique_name | self_attr | event | byname | entry | typed_infer | 合计 |
|---|---|---|---|---|---|---|---|---|
| **逐边 kind** | **7626** | 1297 | 1118 | 217 | 51 | 34 | 7 | **10350** |
| 落盘聚合 | **10048** | — | — | 217 | 51 | 34 | — | 10350 |

`10048 = 7626 + 1297 + 1118 + 7` ⇒ **软推断被当成了硬自证**。危害不是数字错，而是
"判死/O3 三档分层"的依据正是硬软之别——聚合被打平后，任何按聚合取数的消费方都会把
"按名/自属性命中的软边"读成"静态硬边"，而**这种错看起来完全正常**。

1. **聚合不再折叠**：预设七类只用来固定输出顺序，任何 kind 都记在自己的档上；
   另落 `edge_types_total`（**独立字段**，不塞进 `edge_types` 字典，否则各档之和就不等于边数）
   与 `edge_types_source="per_edge_kind"`。
2. **消费方改读逐边（两级）**：
   - `--md` 三字段 / `evidence_tier` 打印 / O3 抽验 A 分层：**实测早已读逐边**

     ⇒ **无需改动**，本批只出证据；

     （`stats` 里根本没这个键，落盘写的是顶层）⇒ `_et` 恒空 ⇒ **`r1_in_live` 结构性恒 False**。
     318 起 R1 边早已进活体，读数却一直报"没进"，且没有任何报警。已改为
     **逐边统计为权威**、聚合仅作展示，并新增 `graph_edge_types_folded` 折叠条数（>0 即异常）。
3. **新自检断言 A6**（`CallGraphAnalyzer.a6_edge_kind_consistency`）三项判据：
   ① 逐边自洽 ② 聚合各档之和 == 边数（没丢边）③ 每档逐项相等（没折叠）。
   带 (路径, mtime) 解析缓存；图缺失/不可解析 ⇒ **UNAVAILABLE 不填 0**；

## 二、刀2 · 判据文案矛盾修复

### 问题

silent 分支打印一句话把两个量混在一起：

```
[307刀1] 图入边覆盖率 57.8%（…）低于让位阈值 55% ⇒ 判据不可用 …
```

**57.8 > 55**，却报"低于"——读的人只能怀疑是 bug。真相：决定档位的是**解析率**
（`< _RESOLVE_GATE_REVIEW=35%` 即 silent），覆盖率只是参考读数。
review 分支同理（只说"覆盖率处于中间档"，会让人以为覆盖率是闸门）。
活体 21:33 那轮覆盖率 65.2% 与解析率 36.6% **恰好都落在各自中间档**，靠巧合对上；
一旦两者不同档就是字面自相矛盾——这属于"迟早会咬人"的坑。

### 改动（只改打印，**档位判定一行未动**）

silent / review 两分支各拆为两行：

```
[328刀2] 让位判据：**解析率** 36.6% 落在中间档 [35.0%, 50.0%) ⇒ …
[328刀2] 参考读数（**不决定档位**）：图入边覆盖率 65.2%（有入边 4517 / 节点 6929，参考档 [55%, 70%)）
```

### 实测（`d2_wording.json`）

| 检查 | 读数 |
|---|---|
| review 档 | `mode=review`、解析率 36.58%、覆盖率 65.19%；两行分别引用各自读数 |
| 矛盾句式 | **0 条**（正则 `覆盖率[^。]*低于让位阈值` 全量扫描日志捕获） |
| silent 档（解析率压到 20%） | `mode=silent`；首行"解析率 20.0% < 让位阈值 35.0% ⇒ 档位=silent" |
| 逻辑不变 | review→review、silent→silent；`review_list_count` 与刀1 一致（580） |
