## 偏差 1（重要）：T-142a 改名落点与任务书不一致

| 项 | 任务书原文 | 本批实际 | 原因 |
|---|---|---|---|
| hits | `_l2_hits` → `_scan_cache_hits` | `_l2_hits` → **`_scan_cache_l2_hits`** | **任务书处方名已被占用** |
| misses | `_l2_misses` → `_scan_cache_misses` | `_l2_misses` → **`_scan_cache_l2_misses`** | 同上 |

**实测证据**：`nucleus/self_inspector.py:195-196` 已存在
`self._scan_cache_hits = 0` / `self._scan_cache_misses = 0`（第64批 T1 的**扫描缓存 L1** 计数器）。
若照搬任务书处方，改名将覆盖该属性 → L1 与"扫描L2"两套统计彻底混为一谈，
反而**加重**本批要消除的混淆。

**处置**：改名落点插入 `l2` 中缀 → `_scan_cache_l2_*`。
- 语义 = 扫描侧二级缓存（organ_file / structure / method 三级缓存）；
- 与 L1 `_scan_cache_hits/_misses` **分槽独立**；
- 保留 "l2" 字样，便于与语义缓存 L2 灰度评估的命名对应；
- 功能零变化（纯标识符改名 + 日志文案消歧）。

> 本偏差属**必要偏离**（任务书处方本身与现状冲突），非执行走样。
