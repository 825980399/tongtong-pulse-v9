- K1-1 窗口到期 → 计数归零后可再入库（`20 → 重置 → 1`）
- K1-2 同窗内仍封顶（`20 → 0`，未放宽）
- K1-3 重置可复现（第二轮同样归零）

**顺带清账**：`GROWTH_HUB_MAX_PER_WINDOW` 由"仅代码 getattr 兜底"转为 `config.py` **正式登记键**（含「0=关闭」语义注释）。该项在烛微 305⑧/306⑧/313② 三次挂账未做，本批因刀1要求"配置化上限"一并落地。
