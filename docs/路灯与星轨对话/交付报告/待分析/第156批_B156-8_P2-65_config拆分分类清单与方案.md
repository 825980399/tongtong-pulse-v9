## 三、拆分方案（分阶段，施工排后续批）

### A. 目标结构（按域分包，收敛 `config.py` 单点）
```
nucleus/config/
  __init__.py        # 向后兼容聚合导出（保留 config.X 旧引用不破）
  switches.py        # ENABLE_* / FEATURE_* / DEBUG_*

  storage.py         # Redis/Influx/Postgres/MQTT
  paths.py           # PATH_*/DIR_*/ROOT
  throttle.py        # TIMEOUT/RETRY/LIMIT/THRESH
  prompt.py          # PROMPT/TEMPLATE
  log.py             # LOG/LOGGER
```

- 用 `tools/scan_config_access.py` 全量输出属性→文件→类别映射，人工校验 OTHER(118) 的二次归类规则。

### C. 阶段 1（后续批施工）

### D. 阶段 2（后续批）

### E. 门禁与回归
