## 2. T-116b：C6 污染治理（核心）

### 2.1 语义变更（必须知道，影响下游判据）

`runtime_verified` 的语义从**「已验证过」**改为**「验证通过」**。因此所有形如
「已验证过就跳过」的守卫**必须**补判 `runtime_verify_result is not None`，否则
**验证失败的补丁会每轮被重新验证、反复重试**。本批已改 2 处守卫：

```python
# 旧：if _patch.get("runtime_verified"):
# 新：
if _patch.get("runtime_verified") or _patch.get("runtime_verify_result") is not None:
```

落点：`SafeEvolutionExecutor.py:2498`、`:2678`。
