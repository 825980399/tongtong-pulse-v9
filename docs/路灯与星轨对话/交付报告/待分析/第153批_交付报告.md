## 二、《T0 偏差》—— 任务书前提偏差与裁决

> 星轨裁决（2026-09-29）：三处偏差**全部接受**，验收按"真实接口为锚"执行。
> 裁决总则：契约测试必须以真实接口为锚——基类强制 vs 项目约定、process 函数式 vs detect 类引擎、器官 vs 工具。本次修正把测试口径从"任务书想象"拉回"代码现实"。

### 偏差 1：A1 STATUS_REQUEST 契约口径（条件断言）
- **任务书前提**：器官 `on_pulse` 对 `STATUS_REQUEST` 必返回非 None。
- **实测真相**：基类 `BasePulseOrgan.on_pulse` 仅要求返回 `dict|None`，**不强制** STATUS_REQUEST。STATUS_REQUEST 属**项目层"声明即服务"约定**——器官仅在 `get_resonance_conditions()` 的 `event_types` 中显式列出 `system.status.request` 时才须服务它。
- **修正**：A1 的 STATUS_REQUEST 正向断言**仅在该器官显式声明订阅时施加**；未订阅器官返回 None 合法（非违约）。
- **裁决**：✅ 接受。验收要求 harness 内须可追溯"哪些器官有条件断言、哪些无条件"，判定标准明确。
- **已落实（可机检）**：第一层 harness 顶部固化《STATUS_REQUEST 订阅表（实测 17 件）》：
  - 声明订阅 YES（A1 施回非 None，14 件）：PulseInferenceEngine / EnergyMetabolism / HealthMonitor / DeviceManager / EmergencyHandler / SpinalCord / DNARepair / ReproductionEthics / Evolution / BoneMarrow / SelfAwareness / Hormones / MotivationCycle / Growth
  - 未声明 NO（A1 不强制，3 件）：PulseFileDigester / PulseBloodVessel / PulseNeurotransmitters
  - 判定标准：`get_resonance_conditions()` 显式列出 `system.status.request` 即"声明订阅"。

### 偏差 2：视觉引擎接口分化（两类契约）
- **任务书前提**：4 视觉引擎共用 `process()` 五断言。
- **实测真相**：接口分化——`ocr_engine`/`pdf_engine` 为函数式 `process(file_path)`；`haar_engine`/`mediapipe_engine` 为 `detect(frame)` 类引擎（`HaarEngine`/`MediaPipeEngine`，无 `process`）。
- **修正**：按真实接口分两类契约，不强行统一。
- **裁决**：✅ 接受。验收要求两类契约断言清单分别列明、写入 harness 可机检。
- **已落实（可机检）**：`tests/test_visual_engine_contract_t153.py` 分两个测试函数——`test_process_engines`（ocr/pdf：process 五断言）+ `test_detect_engines`（haar/mediapipe：is_available 返回 bool + detect 返回 `(bool,float)` 二元组、无效输入不抛）。

### 偏差 3：P0 rich 非器官件（方法级契约）
- **任务书前提**：P0 rich 7 件按器官 5 断言测。
- **实测真相**：`ReasoningFormatter` / `MultiStepReasoner` / `CognitiveReflector` **非 `BasePulseOrgan` 子类**（纯工具/子模块），套用器官 5 断言无意义。
- **修正**：三件按**方法级契约**测试（方法名 + 返回契约 + 关键行为），不套器官 5 断言。
- **裁决**：✅ 接受。验收要求三件各自方法级契约清单，并注明与器官 5 断言差异；**严禁为凑断言给非器官件套壳**。
- **已落实（可机检）**：`tests/test_p0_rich_contract_t153.py` 对每个器官/工具件分别写针对性断言，文件头 docstring 列明方法级契约清单与差异说明；SelfAwareness 虽是大器官但确为 `BasePulseOrgan` 子类，走通用 5 断言 + 方法集专项（非套壳）。
