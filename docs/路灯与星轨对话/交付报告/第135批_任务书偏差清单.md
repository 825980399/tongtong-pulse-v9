## D-135b-1（实现侧时序说明，非任务书误差）

- **任务书标注**：T-135b 新增测试「经子 logger 发 3 条相同消息断言『聚合 N 次』」。
- **实测约束**：`LogAggregationFilter.filter` 的聚合摘要仅在「窗口结束后下一条同键消息」触发，且内置清理分支会在 `now - window_start > 2*窗口` 时丢弃计数。因此测试以 `window_seconds=300`、三条消息间隔满足 `窗口(300) < 间隔(400) ≤ 2*窗口(600)` 设计，使第 3 条消息精准触发「(聚合 1 次)」摘要，验证「聚合 N 次」可见性。**功能目标（子 logger 经 file_handler 能看到聚合摘要）已达成**。
- **影响**：无；属于对过滤器内部时序的精确适配，非偏离任务书意图。
