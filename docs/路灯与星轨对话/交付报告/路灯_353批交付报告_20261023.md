### 刀1（用户点名·P2）渠道池负载均衡轮询 · 方案A

**落点**：新增 `nucleus/llm/channel_balance.py`；`config.get_llm_call_target(preferred_model, caller="")` 起点不再恒为 priority 1。

两条硬约束（写进模块头，并各有测试守）：
1. **只 peek 不 acquire** —— 本模块只看 `available()`，不占许可；真正占用仍由调用侧 `acquire()` 负责。两边都占就是双重占用（铁律181）。
2. **扫描窗口在第一条付费渠道前截止** —— 均衡绝不把免费调用变成付费调用。全忙时退回首选并标 `all_busy`，**不会因为 deepseek 空闲就跳过去**。

实测（隔离探针 `probe_d1.py`，宿主可用渠道 3 条）：

| 场景 | 返回 | reason |
|---|---|---|
| 空载 | `zhipu-47-flash` | `default` |
| 首渠道并发占满 | `zhipu` | `concurrency_busy` |
| 免费渠道全占满 | `zhipu-47-flash`（首选） | `all_busy` |

留痕样例（可 grep `[353均衡]`）：
```
[353均衡] caller=probe_d1 picked=zhipu-47-flash reason=default
[353均衡] caller=probe_d1 picked=zhipu reason=concurrency_busy
[353均衡] caller=probe_d1 picked=zhipu-47-flash reason=all_busy
```

**覆盖面**：`get_llm_call_target(None)` 的 6 处绕行口（灵核 ×2 / 知识 ×2 / 控制器 ×2 / OCR ×1）自动获得均衡；`PulseLung._call_via_channels` 的多目标循环本就具备「忙即切」，无需改动。

### 刀4（P1）L0 看门狗潜意识超时 —— 本批最有价值的一条

**真因实证**（`logs/pulse.log` 三次复发的 `[P0-2诊断]` 栈帧）：

| 时刻 | 事件 | 栈帧落点 |
|---|---|---|
| 19:21:48 | boot | `PulseSubconscious.py:493` → `logging/__init__.py:1026 handle` → `self.acquire()` → `self.lock.acquire()` |
| 21:41:24 | stop | `PulseSubconscious.py:521` → `logging/__init__.py:1028 handle` → `self.emit(record)` |
| 23:03:00 | boot | `PulseSubconscious.py:493` → `logging/__init__.py:1026 handle` → `self.acquire()` |

⇒ 卡的是**日志 handler 的锁 / 写盘 I/O**，与「硬件探测同步阻塞」的初判方向完全不同。任务书列的失速假设（子进程等待、摄像头阻塞）**都已在前批处理过**。所以「把处理器移出 L0」不解决问题——不是业务逻辑慢。

处置三条（都不改 logging 架构）：
1. **降噪**：三条 `[342去线程]` 施工留痕 `INFO → DEBUG`。它们是"变更说明"不是运行信息，却每次 boot 都要过一遍 handler 加锁 + 写盘。字符串保留（342 测试按源码字符串断言，照过）。
2. **耗时归因**：boot/stop 各打一条
   `[353看门狗] 潜意识boot处理耗时=51ms reason=dream_timer slowest=dream_timer(38ms)`（实测 boot 52.3ms / stop 1.0ms，均远低于 5s 门限）
3. **看门狗判词**：新增 `_m353_classify_stuck()`，把卡死栈帧归类 `logging_io | handler_body | no_frame`，超时日志带
   `[353看门狗] 定位=<判词>（logging_io=卡在日志handler锁/写盘）`。**下一次复发第一行就能读出方向**，不必再翻 14MB 日志。

判据用**真实栈帧**验证：在自定义 `Handler.emit` 里抓 `traceback.format_stack()`（正是三次超时的栈帧形态）⇒ 判 `logging_io`（铁律193 须含已知正例）。
