## 二、各刀施工明细

### 刀0 · C 类路线①：形参注解 → 接收者类型推断

**改动**（`nucleus/self_awareness/CallGraphAnalyzer.py`）：

1. `_visit_func` 采集形参注解到 `self.param_types[qualname] = {param: TypeName}`（只认 `ast.Name` 与字符串前向引用，排除 `self/cls`）。
2. `visit_Call` 在 `raw_calls` 里加 `recv_type`（调用表达式的接收者在当前函数里的注解类型）。
3. `_resolve` 新增**档 4b**（置于"全局唯一同名函数"兜底之前）：有 `recv_type` 时走 `_m321_typed_target`，命中即 `kind="typed_infer"`。
4. 新增 `_m321_cls_tail_index()`（类短名 → {(完整类名, 模块)} 索引）与 `_m321_typed_target()`：**仓内同名类多义时不猜**（`len(cands)!=1 ⇒ return ""`）。
5. `_reset` 清 `_m321_cls_index` 缓存。

**实测（A/B，同一脚本 15–18s/次）**：

| 指标 | 320 末态 | 321 末态 |
|---|---|---|
| 解析率 | 0.6425 | 0.6353 |
| 边数 | 10,256 | 10,236 |
| 节点 | 6,842 | 6,842 |
| `typed_infer` | 0 | **7** |

7 条边抽样全部结构正确（如 `SemanticCache._append_line → CacheEntry.to_dict`、`ReportBus._dispatch → ReportEnvelope.record_consume_result`），**无误建**。

**为什么只有 7 条（重要偏差申报）**：烛微"3,372 条形参 / 注解覆盖率 50.5%"是**算术外推**，未扣除"注解是内置类型"这一大块。实测诊断：

- 带 `recv_type` 的调用点 **1,285** 条；
- 其中 `class_not_found` **1,270** 条 —— 注解是 `dict`(787) / `str`(323) / `Any`(118) / `list`(26) 等**内置类型，仓内无同名类**；
- `resolved` 仅 8 条、`method_not_in_class` 7 条。

⇒ 路线①的**真实可及面**只有 `ReportEnvelope`(9) / `ExternalOperation`(4) / `PulseNode`(4) / `Task`(3) / `SubTask`(2) / `Counter`(2) / `SymbolicProblem`(2) 等少量仓内类。**增益 ≈ +0.01pp，不可能到 +4.6pp**。本项按实测交付，不虚报。

### 刀1 · external 同名词表（护栏口径三次迭代）

**最终口径**：allowlist **只做"不进兜底"的否决**，**完全不参与 external 判定**。

```python
# _resolve 关 6：双闸
if self._is_external(rc, module_names) or self._m321_allowlisted(rc):
    return ""
```

- `_m321_allowlisted()`：`len(parts)>=2`、接收者不是 `self/cls`、末段名在 `_EXTERNAL_NAME_ALLOWLIST`（set/get/items/dumps/…共 78 个标准库与内建方法名）。
- `_is_external` 中原本想加的 allowlist 判定**已改为纯注释**。

**三次迭代经过（如实留档）**：

| 版本 | 做法 | external | unresolved | 解析率 | 判定 |
|---|---|---|---|---|---|
| a1 | allowlist 并入 `_is_external` | 43,842（+16,419） | 7,094（−15,954） | 0.8898（虚高） | **否决**：等于把 16k 条 `d.get()/x.items()` 当"外部"稀释分母 |
| a2 | 加 `self/cls` 守卫 | 42,032（+14,607） | — | — | **否决**：未根治 |
| a3（最终） | 退出 `_is_external`，改纯否决 | **27,425（+2）** | 23,514 | 0.6353 | 采用 |

**代价（诚实方向）**：否决 `unique_name` 兜底后，`unique_name` 边 1,520→1,285（−235），其中约 235 条转为 `unresolved`，超过 `typed_infer`(+7) 与 `event`(+208) 的补偿 ⇒ 解析率净 **−0.72pp**。这是"护栏收口必然牺牲部分虚高解析率"，已告知，不掩饰。
