## 1. 任务清单

### 任务1：QICA意图分类重构（P0-6，最高优先级，入口决定全链路）

**问题描述**：
当前QICA（`nucleus/qica/QICA.py`第945-1050行）存在7个架构缺陷：
1. 单通道关键词匹配为主，无语义向量理解通道
2. 串行处理无并行（同义词→否定词→句式→实体→关键词匹配全部串行）
3. 静态映射无动态决策（`_intent_to_method`硬编码，几乎全部映射为knowledge_retrieve）
4. 缺少扩展思维通道（无法从问题扩展到相关概念再判断意图）
5. 无多信号融合（否定词/句式/实体/语义/上下文算出即弃）
6. 无错误反馈闭环（分类错误后无法学习调整）
7. 知识路径预测不灵活（规则表硬编码，无语义向量预测）

**实测证据**：
- 5个测试问题全部走knowledge_retrieve路径
- "你和小林是什么关系？"QICA路径检索相关度=0.00，降级到内在沉思
- "简单介绍一下你自己"被分类为身份确认但仍走knowledge_retrieve
- 语义关系扩展命中污染数据：'用多步多维度 分析一下量子 纠缠 用多步多维度...'（重复混乱）

**需要修改的文件**：
- `nucleus/qica/QICA.py`（核心重构）
- `config.py`（新增灰度开关）
- 可能需要新增`nucleus/qica/`下的通道模块文件

**修复要求**：

#### 1.1 8通道并行计算（ThreadPoolExecutor，max_workers=8）

将以下8个通道改为并行执行，每个通道返回独立的意图分类置信度向量：

| 通道 | 实现方式 | 输出 |
|------|---------|------|
| ①关键词通道 | jieba分词+TF-IDF+长词权重+现有规则匹配 | 各意图类型得分 |
| ②语义向量通道 | bge-small-zh-v1.5编码问题，与各意图类型原型向量计算余弦相似度 | 各意图类型相似度 |
| ③扩展思维通道 | 从问题关键词通过共振引擎关联图谱扩展1-2跳概念，再判断意图 | 扩展后意图得分 |
| ④实体识别通道 | 现有`_extract_entities`增强：人名/器官名/概念/时间/地点 | 实体类型→意图映射 |
| ⑤句式分析通道 | 现有`_detect_sentence_type`增强：疑问/陈述/祈使/反问/否定/复合 | 句式→意图映射 |
| ⑥上下文理解通道 | 现有`_context_assist`增强：对话历史+追问指代消解+话题延续 | 上下文修正系数 |
| ⑦复杂度评估通道 | 词汇丰富度/长度/结构复杂度/抽象度计算 | 复杂度→处理路径映射 |
| ⑧历史反馈通道 | 类似问题的历史处理成功率+用户满意度（从经验库/对话记录提取） | 历史成功率修正 |

#### 1.2 融合决策层

8通道结果加权融合，计算6种处理路径的置信度：
- 知识检索（knowledge_retrieve）
- 规则推理（rule_reason）
- 多步推理（multi_step）
- 内在沉思（contemplation）
- 身份认知（identity）
- 大模型（llm_fallback）

动态选择最高置信度路径；当top1与top2置信度差<0.1时，触发多路径并行探索（先执行top1，同时准备top2作为降级方案）。

#### 1.3 意图原型向量库

为每个意图类型（一般对话/身份确认/关系查询/知识查询/代码问题/情感交流/系统状态/元认知等）构建原型向量：
- 每个意图类型收集5-10个典型问题
- 用bge编码后取平均值作为原型向量
- 持久化到`data/qica/intent_prototypes.json`
- 支持动态更新（分类错误反馈后调整原型）

#### 1.4 错误反馈闭环

- 记录每次分类结果、最终执行路径、用户反馈（隐式：回答长度/后续追问；显式：用户评价）
- 当某意图类型连续3次分类错误（最终路径与建议路径不一致），触发原型向量微调
- 反馈数据持久化到`data/qica/classification_feedback.json`

#### 1.5 灰度开关

新增config开关：
- `ENABLE_QICA_MULTI_CHANNEL = True`（8通道并行，默认开启）
- `ENABLE_QICA_FUSION_ROUTING = True`（融合决策动态路由，默认开启）
- `ENABLE_QICA_FEEDBACK_LEARNING = False`（反馈学习，默认关闭，稳定后开启）

**验收标准**：
- 8通道并行计算正常，无异常
- 5个测试问题分类准确率≥80%（不再全部走knowledge_retrieve）
- "你和小林是什么关系？"走身份认知/关系推理路径
- "简单介绍一下你自己"走身份认知+多节点融合路径
- 意图原型向量库创建成功，≥10个意图类型
- 融合决策层置信度计算正常，top1与top2差值合理
- 单元测试≥15个（每通道≥1个+融合≥3个+反馈≥2个）
- ruff F类错误=0
- 向后兼容：开关关闭时行为与改造前完全一致

### 任务2：本地对话能力提升（P0-5，与任务1联动）

**问题描述**：
框架本地检索正常（QICA/共振引擎/语义扩展都在工作），但最终回答生成环节优先调用大模型，导致本地推理做了前置工作但最后一步仍依赖大模型。三大根因：

1. **语义理解置信度普遍偏低**：12/15次<0.7触发大模型
2. **B2策略接线"仅记录不改变行为"**：QICA建议从未真正执行
3. **多节点融合`_fuse_multiple_nodes`优先调用大模型提炼**，只有大模型不可用时才回退机械拼接

**需要修改的文件**：
- `organs/brain/PulseInnerWorld.py`（B2策略接线+多节点融合）
- `nucleus/reasoning/SemanticComprehension.py`或类似文件（置信度校准）
- `config.py`（相关参数调整）

**修复要求**：

#### 2.1 语义理解置信度校准

- 分析当前置信度计算逻辑，找出为什么普遍偏低
- 引入多维度置信度：检索相关度+知识覆盖度+回答完整度+历史相似度
- 当本地检索结果质量高（top3相似度均>0.5且内容互补）时，置信度应≥0.8
- 添加置信度校准日志，输出各维度得分

#### 2.2 B2策略接线升级（从记录到执行）

- 定位B2策略接线代码（搜索"B2策略"或"strategy_context"）
- 当前：QICA建议的suggested_method只记录到strategy_context，不影响实际执行路径
- 修复：当QICA建议方法与当前执行路径不一致时，至少尝试一次建议路径
- 添加策略执行日志：建议方法→实际方法→是否采纳→采纳原因/拒绝原因

#### 2.3 多节点融合本地化

- 定位`_fuse_multiple_nodes`方法
- 当前：优先调用大模型提炼，只有大模型不可用时才回退机械拼接
- 修复：实现本地融合算法（优先级从高到低）：
  1. 规则模板融合（当节点内容符合特定模式时用模板拼接）
  2. 关键词重叠融合（按关键词重叠度排序，去重后拼接）
  3. 语义相似度融合（相似内容合并，互补内容保留）
  4. 大模型提炼（仅当本地融合结果质量低且置信度<0.6时才调用）
- 添加融合方式日志：使用了哪种融合方式+各节点贡献度

**验收标准**：
- 5个测试问题本地回答率≥50%（不再几乎全部转大模型）
- 语义理解置信度分布合理（高/中/低均有，不再普遍偏低）
- B2策略建议执行率≥60%
- 多节点融合本地融合率≥70%
- 大模型调用次数减少≥50%
- 单元测试≥10个
- ruff F类错误=0
- 回答质量不下降（本地回答需完整、相关、有条理）
