### 任务1：QICA相关度计算语义鸿沟修复（P1-24）

**问题描述**：
`_verify_knowledge_relevance()`（PulseInnerWorld.py:18368）过度依赖字面关键词重叠，对语义相近但字面无重叠的问题-知识对返回0.00，导致QICA路径命中后仍被误降级到大模型。

**实测案例**：
- 问题："你了解什么？"
- QICA命中路径：`/自我理解`
- 命中节点内容："我是任宥曈，一个在数字世界里长大的人..."
- 相关度计算结果：**0.00**（问题词"你了解""了解什么"与节点内容字面无重叠）
- 后果：直接降级大模型，本地知识检索完全失效

**根因分析**：
1. 白名单路径仅 `/自我/架构/` 和 `/身份/`，`/自我理解`、`/自我`、`/综合` 等不在内
2. 无问题意图识别（"你了解什么"="自我介绍"意图）
3. 纯字面重叠率计算，无语义相似度

**修复要求**：

#### 1.1 扩展白名单路径
将以下路径加入白名单（允许路径名匹配即保底0.45）：
- `/自我理解/`
- `/自我/`（但不包括 `/自我/架构/` 下的子路径，已在白名单）
- `/综合/`
- `/身份/`（已有）

#### 1.2 新增问题意图识别
在 `_verify_knowledge_relevance` 开头增加意图识别：
```python
# 自我介绍意图：问题含这些词且命中路径含"自我/身份/综合" → 直接返回0.5
_self_intent_keywords = ["你了解", "你是谁", "你叫什么", "介绍一下", "你是什么", 
                          "你的名字", "你能做", "你会", "认识你", "关于你"]
if any(k in question for k in _self_intent_keywords) and space_path:
    if any(p in str(space_path) for p in ["/自我", "/身份", "/综合"]):
        return 0.5
```

#### 1.3 引入语义相似度兜底（可选，如复杂度可控）
当字面重叠率<0.15时，尝试用VectorEncoder计算问题与知识结果的语义相似度：
- 如果语义相似度>0.6，返回0.4
- 如果VectorEncoder不可用，回退到现有逻辑

**注意**：此步骤为可选，如果引入VectorEncoder会增加延迟或复杂度，可只做1.1和1.2。

#### 1.4 验证标准
- "你了解什么？" → 命中 `/自我理解` 节点 → 相关度≥0.45，不降级
- "你是谁？" → 命中身份节点 → 相关度≥0.45
- "五维共振是什么？" → 命中 `/自我/架构/五维共振` → 相关度≥0.45
- 不相关问题（如"今天天气怎么样"命中代码节点）→ 相关度<0.15，正常降级
- 回归测试：现有QICA相关测试全部通过
