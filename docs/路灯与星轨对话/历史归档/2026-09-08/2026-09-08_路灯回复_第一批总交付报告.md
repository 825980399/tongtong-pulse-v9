## 二、任务8：D-1 节点注入修复（路径迁移，不删节点）✅

### 2.1 根因再修正（比批准方案更进一步，请星轨留意）

执行时通读代码发现根因比「内容级去重」更早一步：

- `PulseNode.node_id = _generate_id(value, source_organ)` 是**确定性**的（`PulseNode.py:84`）；
- 共振引擎那条 SEED 只改了 `space_path`、value 一字未动 → 重启注入算出的 node_id 与快照旧节点**完全相同** → `add()` 的**幂等检查**（`PulseNodePool.py:294`）先于内容去重命中，直接 return；
- 「五维共振」因 D-1 改了 value → node_id 变了 → 走新建 → 成功。

即：**同一节点 id 的路径永远不会被更新**。两个机制（幂等 + 内容去重）都指向同一修法——注入前按 value 找旧节点、迁移其路径。

### 2.2 交付内容

**`PulseNodePool` 新增两个方法**（脏活全部下沉，带完整注释）：
- `find_by_value(value, level=None, fuzzy=False, threshold=0.90)`：按 value **跨路径**查找已有节点。默认只做**精确匹配**（零误判；宁可漏迁不可误迁），`fuzzy=True` 时才启用字符集 Jaccard 模糊匹配（含阈值）。
- `update_node_path(node_id, new_space_path)`：路径迁移而非删除。顺序严格：旧路径摘池内索引 → 写新路径 → 共振引擎 `remove_node(旧路径)` + `index_node(新)` → 新路径重建池内索引/外置 WAL。日志格式按批准要求：`[种子记忆] 路径迁移: 旧路径→新路径, node_id=xxx`。

**`main.py` 最小改动**（5 行，只加调用不加逻辑）：`_inject_seed_memories` 注入前先 `find_by_value`，命中且 `update_node_path` 成功则 `knowledge_tree.register_path(新路径)` 后 `continue`；未命中走原有新建分支。
