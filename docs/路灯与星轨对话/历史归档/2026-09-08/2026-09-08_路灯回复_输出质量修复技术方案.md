## 二、调研结论（基于真实代码，标注与任务书偏差）

### 偏差澄清 1：B2 策略接线是"设计如此"，非 bug
`organs/brain/PulseCortex.py:468-490` 注释明确写明：
> ★B2【P1】StrategySelector 接线（只记录不改变行为）……当前不改变推理行为——实际方法仍由内在世界决定，此处仅记录差异供分析。

### 偏差澄清 2：根因2 模板真实位置 + 过滤漏检机制
- "【种子记忆】/【关联发现】"模板在 `organs/brain/PulseSubconscious.py:4531-4545`（**梦境推演/潜意识消化**用），本应在"无人时"后台运行。
- 但对话里出现，是因为**知识库已被污染**：`data/knowledge/pulse_l1_snapshot.json:7584` 的节点 value 本身就是 `"我了解到，[曈曈] 【种子记忆】[自我状态] 系统当前处于light负载状态……（由10条认知融合而成）。此刻的我——"`。
- 真正漏检点在 `PulseInnerWorld._is_internal_knowledge_node`（:7711-7758）：它用 **`value.startswith(_pf)`** 检查 `[自我状态]` 等前缀。但污染节点是 `"我了解到，[曈曈] 【种子记忆】[自我状态]……"`——`[自我状态]` 在**文本中间**而非开头，且 `【种子记忆】/【关联发现】/此刻的我` 根本不在过滤列表 → **漏检放行**。

### 偏差澄清 3：`_verify_knowledge_relevance` 路径桥接漏洞（垃圾未被降级的根因）
`PulseInnerWorld._verify_knowledge_relevance`（:17956-17978）：只要 `space_path` 名含问题任一 2 字主题词，直接 `return 0.45` 保底相关。
- 当 QICA 把"共振引擎"错配到 `/身份/自我`（`_path_norm="身份自我"`），问题词"自我"是"身份自我"子串 → **桥接命中，返回 0.45 ≥ 0.10** → 不触发降级 → 垃圾节点直接输出。
- 这是相关性 guard 形同虚设的核心原因，任务 C 必须收紧。

### 偏差澄清 4：知识库比任务书描述污染更深
- `node:e00700285cdef321`（`pulse_l1_snapshot.json:7545`）—— **把用户问题"曈曈，什么是共振引擎？"直接存成了知识节点**（来源=耳朵/chat，space_path 一长串混乱路径）。
- 全库**无"共振引擎"正确定义节点**（grep 仅命中这一个污染问题节点；`SEED_MEMORIES.py` 也无）。
- 即：即使 QICA 检索正确，也找不到答案，最终仍会降级——任务 D 必须补充正确知识，否则"诚实兜底"是唯一结果。

```
用户问"什么是共振引擎"
  → [根因1] QICA 概念匹配误把"共振引擎/引擎"映射到 /身份/自我（动态学习注入的错误映射）

  → [根因2] _is_internal_knowledge_node 用 startswith 漏检中间标记 → 污染节点被选中
  → [根因3] _verify_knowledge_relevance 路径桥接返回0.45 → 不降级
  → [输出] "我了解到，[曈曈]【种子记忆】[自我状态]……" 答非所问
```
