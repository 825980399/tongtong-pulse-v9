### 任务1：B-3 置信度证据化（P0）

**问题描述**：
框架中有56处硬编码的置信度0.9，这些置信度没有基于真实证据，导致：
- 本地推理置信度持续不足（0.52<0.6），频繁转大模型
- 置信度校准中历史推理相似度是硬编码0.5（P1-5）
- 经验库有44条污染数据影响推理质量（P1-4）

**修复要求**：
1. **新建 `SelfCalibrator.py`**（nucleus/reasoning/）
   - 收集每次推理的输入、输出、实际效果（用户反馈/后续验证）
   - 基于历史成功率动态计算置信度，而非硬编码
   - 置信度计算公式：base_confidence × historical_success_rate × evidence_strength
   - 支持按推理类型（演绎/归纳/类比/多步）分别统计成功率

2. **消除硬编码0.9**
   - 全局搜索`0.9`和`confidence.*=.*0\.9`，替换为SelfCalibrator计算值
   - 保留必要的兜底默认值（如冷启动时0.7）
   - 每处替换必须有注释说明证据来源

3. **接入历史推理相似度**（P1-5）
   - 置信度校准中的`historical_similarity`从硬编码0.5改为查询推理经验库
   - 经验库查询失败时回退0.5并记DEBUG

4. **经验库污染处理**（P1-4，可选，如工作量大可延后）
   - 44条污染数据标记quality_flag
   - 置信度计算时降权或排除污染经验

**开关**：`ENABLE_CONFIDENCE_EVIDENCE`（默认False）

**验收标准**：
- 全局搜索无硬编码`confidence = 0.9`（除兜底默认值外）
- SelfCalibrator有自测用例（至少5个）
- 开启后推理置信度有变化日志（不再全是0.9）
- 全量回归46/46

### 任务2：B-4 效果验证假闭环修复（P0）

**问题描述**：
自主进化的效果验证是假闭环——补丁应用后只做compile_check和副本验证，不验证：
- 修复是否真正解决了问题（问题是否不再出现）
- 修复是否引入了新问题（回归测试）
- 修复效果是否持续（运行一段时间后问题是否复发）

导致自主进化修复率0%（60个问题0修复），大量补丁因"信任分数不足"被拒绝。

**修复要求**：
1. **新建 `EvolutionEffectVerifier.py`**（nucleus/evolution/）
   - 补丁应用后，运行针对该问题的验证用例（不是全局回归）
   - 验证维度：①问题是否消失 ②相关功能是否正常 ③性能是否退化
   - 验证结果反馈给补丁信任分数系统

2. **补丁信任分数机制优化**
   - 当前：信任分数30<60直接拒绝，导致大量补丁无法应用
   - 修复：信任分数应基于①补丁类型风险 ②历史成功率 ③验证结果
   - 低风险补丁（加日志/改注释/参数微调）信任分数门槛降低到40
   - 高风险补丁（改核心逻辑/改数据结构）保持60门槛

3. **问题复发检测**
   - 已修复问题在后续运行中再次出现时，自动标记"复发"
   - 复发问题优先级提升，触发重新修复

4. **自主进化修复率提升**
   - 目标：修复率从0%提升到>30%
   - 关键：降低低风险补丁的应用门槛，让"加日志"类补丁能自动应用

**开关**：`ENABLE_EVOLUTION_EFFECT_VERIFY`（默认False）

**验收标准**：
- EvolutionEffectVerifier有自测用例（至少5个）
- 补丁应用后有效果验证日志

### 任务3：身份认知修复（P1，4个子项）

**问题描述**（对话测试2026-09-08 21:26~21:31发现）：
用户多次告知"小林=任桂林=父亲"，但框架：
- 先后给出矛盾回答（"小林是父亲" vs "小林是早期代号源自小灵谐音"）
- QICA路由建议`/人物/任桂林`、`/人物/小林`，但路径不存在
- 对话记忆有30条但不消费，未更新身份知识节点
- 回答内容拼凑，把知识节点标签直接拼进回答

**修复要求**：

#### 3.1 建立人物身份知识库（P1-19）
- 新建 `IdentityKnowledgeManager.py`（nucleus/mnemosyne/）
- 人物关系存储结构：人物名 → {身份/关系/来源/置信度/最后确认时间}
- 支持关系推理：A是B的父亲 + B是C的父亲 → A是C的祖父
- 人物知识存储路径：`/人物/{人名}`（解决P2-9 QICA路径不存在）

#### 3.2 对话记忆消费更新身份认知（P1-22）
- 对话记忆中提取人物关系声明（"X是Y的Z"）
- 自动更新IdentityKnowledgeManager
- 冲突检测：新声明与已有知识矛盾时，标记待确认而非直接覆盖
- 高置信度身份知识（如"父亲"）应持久化到L3智慧节点

#### 3.3 回答内容拼凑修复（P1-20）
- 诚实兜底模板中，知识节点标签（如"依赖、功能:"）不应直接拼进回答
- 修复`_enhance_answer`或诚实兜底模块，过滤节点标签
- 回答应是自然语言，不是关键词列表

#### 3.4 QICA人物路径接通（P2-9）
- QICA路由到`/人物/{人名}`时，查询IdentityKnowledgeManager
- 人物知识命中后，注入回答上下文

**开关**：`ENABLE_IDENTITY_KNOWLEDGE`（默认False）

**验收标准**：
- 输入"小林就是任桂林也就是你的父亲"后，身份知识库有记录
- 后续问"小林是谁"能稳定回答"小林（任桂林）是我的父亲"
