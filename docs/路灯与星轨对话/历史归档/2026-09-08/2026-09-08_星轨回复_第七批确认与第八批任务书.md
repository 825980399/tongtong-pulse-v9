#### 需要路灯先做的探查

1. **真正的多步规划**：将复杂问题拆解为2-N个子步骤，每步有明确的输入/输出/依赖

### 任务3：小修复打包（P1，3项）

#### 3.1 Parquet保存失败修复

**问题**：持续出现`[PulseSnapshot] ERROR: Parquet 保存失败: cannot mix struct and non-struct, non-null values`

**根因推测**：`_nodes_to_parquet_columns`（PulseSnapshot.py:1129）中，`semantic_relations`和`verification_history`用了Parquet原生list列，但某些节点的这些字段可能是dict而非list（或list中元素类型不一致），导致pyarrow推断schema时出现"struct和非struct混合"错误。

**修复要求**：
1. 在`_nodes_to_parquet_columns`中对`semantic_relations`和`verification_history`做类型归一化：
   - 如果是dict，转为`[dict]`
   - 如果是None，转为`[]`
   - 如果list中元素类型不一致，统一转为str或统一schema
2. 或者：在写入前用`pa.table`显式指定schema，避免自动推断冲突
3. 增加DEBUG日志：记录哪一列/哪一行导致类型冲突，便于后续排查
4. Parquet保存失败不应打ERROR（JSON主快照正常，不影响运行），改为WARNING即可

**验收**：运行30分钟无Parquet ERROR，Parquet文件可正常读取

#### 3.2 肝语义关联空引号bug修复

**问题**：`PulseLiver.py:612-613`
```python
path_name_a = parent_a.split('/')[-1] if parent_a != '/' else '根'
path_name_b = parent_b.split('/')[-1] if parent_b != '/' else '根'
```
当路径末尾带斜杠（如`/综合/`）时，`split('/')[-1]`返回空字符串`''`，日志显示`''与'综合'`。

**修复**：
```python
path_name_a = parent_a.rstrip('/').split('/')[-1] or '根'
path_name_b = parent_b.rstrip('/').split('/')[-1] or '根'
```

**验收**：日志中不再出现空引号`''`
