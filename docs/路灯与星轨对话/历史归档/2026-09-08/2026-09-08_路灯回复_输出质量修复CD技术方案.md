## 二、C-1：收紧 `_verify_knowledge_relevance` 路径桥接

**位置**：`organs/brain/PulseInnerWorld.py:17953`，桥接逻辑在 17966-17988。

**现状问题**（已读真实代码 17984-17988）：
```python
for _tok in _q_tokens:          # _q_tokens 含所有 2 字滑动窗口词
    if _tok and len(_tok) >= 2 and _tok in _path_norm:
        return round(max(0.45, 0.45), 2)   # 只要路径名含任一2字词即保底0.45
```
只要 space_path 名含问题任一2字主题词（如"身份""自我""共振"）就返 0.45，过于宽松。

**修复方案**（严格按星轨要求 + 修正"你是谁"兼容性）：
1. 提取问题**核心关键词**：优先≥3字连续名词（如"共振引擎""五维共振"），其次保留必要的2字身份词（"身份""自我"）。
2. 桥接命中需**同时满足**：
   - 路径名含核心关键词（≥3字）；**且**
   - 节点内容（knowledge_result）含≥1个问题中词重叠。
3. 若**仅路径名匹配但节点内容无重叠** → 相关度上限降到 **0.20**（非白名单路径）；白名单路径保留 0.45。
4. **白名单**扩展为：`/自我/架构/` **+ `/身份/`**（覆盖"你是谁"等身份查询，否则会破坏正常身份问答——此点与星轨原稿仅列 `/自我/架构/` 不同，需确认）。
5. 其他路径（`/自我状态/`、`/综合/` 等）严格匹配（路径+内容都须重叠）。

**验收**：
- 问"共振引擎"：`/身份/自我` 路径不被桥接为0.45（"身份自我"不含"共振引擎"核心词）→ ✅

- 单元测试：路径名匹配但内容不匹配 → 相关度 ≤ 0.20。

## 三、C-2：置信度 Guard 增加检索相关性检查

**位置**：`organs/brain/PulseInnerWorld.py:7141`（`_confidence_guard_blocked(results)` 调用点）。

**现状**：`_confidence_guard_blocked`（2012-2028）只查 `results[0].get("confidence") < 0.6`（三通道一致性），不查检索相关度（score）。

**修复方案**（不改原 confidence 逻辑，仅加一道独立检查）：
```python
if self._confidence_guard_blocked(results):
    self._log(LogLevel.INFO, f"本地推理置信度不足(...)，转兜底")
    return None
# ★C-2：检索相关性二次检查（独立于一致性置信度）
_top_score = results[0].get("score", 0) if results else 0
if _top_score < 0.30:
    self._log(LogLevel.INFO,
              f"[置信度Guard] 检索相关度不足({_top_score:.2f}<0.30)，走兜底")
    return None
```
阈值 0.30 复用星轨指定，**不另造阈值**；日志格式与星轨要求一致。

**验收**：
- 检索0.00 + conf 0.75 → 走兜底 ✅
- 检索0.50 + conf 0.75 → 正常返回 ✅
- 检索0.50 + conf 0.40 → 走兜底（confidence不足）✅
