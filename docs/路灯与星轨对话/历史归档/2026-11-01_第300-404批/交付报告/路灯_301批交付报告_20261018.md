## 三、本批真施工（3 项）

### 刀2 · novelty 换现成编码器 ✅

`nucleus/InsightBoard.py`：

- 新增 `_m301_batch_novelty(texts)`：用现成 **`nucleus/semantic/VectorEncoder.py`** 对同批候选文本批量编码，
  novelty = `1 − 与同批其它条目的最大余弦相似度`，钳 `[0.05, 1.0]`（避免「完全重复」被判 0 而整条消失）。
- `_m290_score_entry(entry, novelty=None)` 增可选入参：传入真 novelty 优先采用；否则回退 290 批的内容长度代理。
- `dump_to_disk` 先批量算 novelty 再逐条打分。
- **零回归保险**：编码器不可用／返回 None／异常 ⇒ 全部回退长度代理（隔离测试已验 `_m301_batch_novelty([]) is None`）。
- 只在日拍（03:00 低频）路径调用，**不在热路径**。

验收实测：`_m290_score_entry(同条目, novelty=0.2)` 得分 0.2 < 代理口径 1.0 ⇒ 传参生效。

### 刀3 · 假设进 verification_learning_hub ✅（290 批降级的补完）

- `nucleus/mnemosyne/verification_learning_hub.py`：`record()` 新增末尾参数 `origin: str = ""`（向后兼容），
  落库字段 `"origin": (origin or "")[:64]`。
- `nucleus/InsightBoard.py` 新增 `_m301_dispatch_hypotheses(kept)`：日拍落盘后，对 Top-N 中
  **想象／洞察／类比／梦境族**（`source=="imagination"` 或 type 含 imagination/insight/analogy/dream）
  且 `score >= INSIGHT_HYPOTHESIS_MIN_SCORE`（默认 0.5，可从 config 覆盖）的条目，
  调 `hub.record(organ="想象", task_type="hypothesis_verification", ..., origin="imagination")`。
- `dump_to_disk` 末尾调用（受 try/except + silent_exc 保护），命中数写入 payload 的 `hypotheses_dispatched`。

验收实测：`hub.record(origin="imagination")` 落库 `origin='imagination'` ✔（用 tmp 路径测试，未碰 data/）。

### 刀4 · 梦境三元组重组扩多样性 ✅

- `config.py` RUNTIME_PARAMS：`subconscious_counterfactual_chance` **0.3 → 0.35**（按任务书「上调 0.35 而非加模板」）；
  新增 `subconscious_triplet_recombine: True`（dict 键，不产生模块级空转键）。
- `organs/brain/PulseSubconscious.py` 新增两个方法：
  - `_m301_triplet_recombine(seeds)`：复用 `analogy_engine._TRIPLET_PAT` 从**两个不同域** seed 各抽一条三元组，
    拼出三种新句式之一；抽不足两条 ⇒ 返回 None（沿用模板，零回归）。
  - `_m301_score_candidate(text, concepts)`：用 290 批评分器给候选句打分（不可用时返回 0.0）。
- `_trigger_inspiration_surge` 接入：`inspiration = _random.choice(templates)` 之后，
  **三元组候选与模板候选同台竞争，高分者胜出**（即「评分器淘汰」），胜出时打 INFO 行 `[301刀4] 三元组重组候选胜出`。
  ⇒ 未新增模板，多样性由重组而非扩模板获得。

验收实测：两域种子「温度是分子平均动能的度量」／「信任是长期交互的积累」⇒ 拼出
「温度—分子平均动能的度量」与「信任—长期交互的积累」分属两个领域……；短文本无三元组 ⇒ 返回 None 沿用模板。
