### 刀3 · 线程落差快照（`dc702aaa`）

票面要「OS 线程名快照」，但 **CPython 取不到原生线程名**。本件**不编造名字**，
给三样可验证的：①Python 侧全量清单；②`native_only` = OS tid 集合 − Python ident 集合（附 CPU 时间）；
③`new_tids` 与上一拍差分（定位「哪一拍新增」）。

**域自检实测**（本机 3.12.6）：子线程 ident 全在 OS tid 内、`py − os = 0` ⇒ **同源**，可当绝对数读；
而一个只有 4 条 Python 线程的裸进程已有 **3** 条 native-only（BLAS 原生线程）
⇒ 这就是 `GAP_IDENT_DOMAIN_SLACK = 5` 的取值依据。取不到 OS tid ⇒ `state=unavailable` / `count=None`，
不填 0（铁律276）。

限流三触发（首告警 / 再涨 ≥5 / 每 12 拍），其余返 **None**；快照滚动有界 8 份；埋点只落在
`PulseLiver` 已判 warn 分支内（`:546`），不动 `next_gap_state`／采样间隔／调度；
`python_side_threads` 全程**不持 `_LOCK`**（观测面不许变成新卡点）。

反向验证 7 场景 7 PASS（V1 拿不到填 0 / V2 不做差分 / V3 阈值 >5 / V4a 双调用点 /
V4b 挪出 warn 块 / V5 持锁，各自命中）。**live 实拍**见第六节。

### 刀4 · try 块平衡静态闸（`3453ae1c`）

票面给「自动补全**或**直接拒收」两条路，**本刀选拒收，并有实证**：

用真代码形态跑生产口径四关 —— 截断版（丢 handler）被拒；而用 `except Exception: raise` 补上后
**四关全绿**，但行为从「降级 `return None`」变成「向上抛 `RuntimeError`」。
即：自动补全会把 12 次失败变成 **12 次静默行为回归**。该事实钉成 `test_14` 常驻判据。

关2a 用 **tokenize** 数语句级 `try`/`except`/`finally`（字符串/注释/属性名/装饰器一律不计数，
铁律227），只在两种**必然语法非法**形态拒收：`try > handler`（unbalanced）、
有 handler 无 try（orphan，片段起点落在 try 内部）。两条都必然让关2 的 `ast.parse` 失败
⇒ **不改变任何补丁的通过/拒绝结论**，只换理由：

```
before: expected 'except' or 'finally' block (<llm-patch>, line 35)
after : try 块不平衡：2 个 try / 1 处 except+finally，缺 1 处收尾（第 35 行的 try
        没有对应 except/finally）；片段末行='# ===== 阶段5 结束 ====='
        （入库前静态闸拦截，未进入副本验证）
```

**能力边界如实**：它是**下界探测器**不是完整校验器（一缺一形态仍由关2 兜住），
`test_13` 把这个假阴性钉成预期行为。

反向验证 7 场景：**首轮 6/7，V2 抓出一个真缺陷** —— 原因函数用 `else` 兜底，把 `ok`/`unknown`
也描述成「片段窗口错位」（铁律166 同型）。已改为**按状态显式分支** + `test_12` 加反面判据，
复跑 V2 命中 `test_05/09/12`。

### 刀5 · 内存增长率定位（`0224d862`，零产品改动）

   `runtime_metrics` 的增长率一直报 **10–36 MB/min** 并常判「疑似泄漏」⇒ **该指标失真**。
2. 真在涨的是**启动 2 小时内的新代**（RSS 3728 → 6065），前 14 分钟冷装载就 +1410MB
   （≈100MB/min）；老代是新代的**饱和态**样本，口径不同源，不能直接比（铁律271）。

**top 增长类型**（跨 13 代一致性）：`dict` 13/13、`list` 13/13；`set` 4 代且**稳定 +3.0 万**、
`function` 2 代**稳定 +1.6 万** ⇒ 增长是「**定量整块**」不是缓慢渗漏。

**但算术否掉了解释力**：heap +2.0GB 对应可见对象仅 +13.4 万（≈15KB/对象不可能）
⇒ 约 **95% 增量落在 `str`/`bytes` 等未被 GC 跟踪的类型上**。

**硬证据（本刀最值钱的一条）**：尺寸维度**从未采到过一行** —— 108 份快照里 17 份

⇒ 四类全 0 是「**没采到**」被写成「**真是 0**」（铁律276 同型）。

另三条：GC **588 次**共回收 16.6 万对象（每次中位 200 个）却吃掉 **347s** 墙钟 ⇒ 占用是**可达对象**；
