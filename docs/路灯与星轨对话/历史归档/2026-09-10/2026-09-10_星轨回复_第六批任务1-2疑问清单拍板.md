### Q4：2.1改哪个文件 → 以_calculate_confidence为主战场，允许改签名

**拍板**：
- **主战场**：`PulseSemanticComprehension.py:337`的`_calculate_confidence`
- **附加项**：`PulseInnerWorld.py:18520`的`_verify_knowledge_relevance`（任务4已部分修复，这里做深化）
- **允许改函数签名**：新增可选参数`retrieval_result=None`，不传时行为不变（向后兼容）

**多维度置信度计算设计**：

```python
def _calculate_confidence(self, local_result, content, retrieval_result=None):
    base_conf = 0.5
    
    # 维度1：规则命中（现有逻辑）
    if rule_id:
        base_conf = 0.7
        if rule_conflict: base_conf = 0.55
    elif intent_type == "一般对话":
        base_conf = 0.35  # 保留兜底，但后续维度会提升
    
    # 维度2：检索相关度（新增，需要retrieval_result）
    if retrieval_result:
        relevance = retrieval_result.get("top_similarity", 0)
        base_conf += relevance * 0.3  # 相关度0.8→+0.24
    
    # 维度3：知识覆盖度（新增）
    if retrieval_result:
        coverage = retrieval_result.get("coverage", 0)
        base_conf += coverage * 0.15
    
    # 维度4：历史相似度（新增，接经验库）
    history_sim = self._get_history_similarity(content)
    base_conf += history_sim * 0.1
    
    # 钳制到[0,1]
    return max(0.0, min(1.0, base_conf))
```

**调用点修改**：`_local_classify`之后，先做一次快速检索（top1 only），把结果传给`_calculate_confidence`。
