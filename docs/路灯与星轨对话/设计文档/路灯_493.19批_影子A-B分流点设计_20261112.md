## 2. 分流点选择（结论：选 A）

| 候选 | 位置 | 判断 |
|---|---|---|
| **A（选）** | `organs/brain/PulseCortex.py:976-1011` 每条 chat 的 fastpath 影子入口 | 覆盖全量 chat、与 `offline_active()` 无关、`ENABLE_M4937_SELF_QUERY_SHADOW=True` 下每条都写影子行 → **样本充足、是主分流点** |
| B（不选） | `PulseCortex.py:2084-2092` 断网降级 offline_local 链 | 需 `_m485_llm_degraded()` + `offline_active()=True`，生产正常态样本为 0（493.18 实证），不能做 A/B 主分流 |

> 关键约束：分流必须绕开 `nucleus/self_index/offline_local.py:229` 的
> `offline_active()` 早退，否则正常态零样本（493.18 刀3 断点）。

接法（下一批）：在 A 处写影子行前，按分桶结果决定 `group`/`variant_id`，
影子态**同时算 A/B 两候选但都不 emit**（沿用 `fastpath.py:190` "照常计算但不答、不 emit"），
把两候选落 `answer_a`/`answer_b`；`winner` 由后续人工标注 `labeled_correct`
+ 显著性判定回填，绝不在影子态直接替换线上回答。

## 3. 分桶规则

- **确定性 hash 分桶**：复用 `nucleus/llm/semantic_cache.py:1033-1038` 口径
  `_bucket = int(hash_text(key)[:8], 16) % 100`。
- **分桶 key = session_id**（不是 query）：同一会话稳定落在同一组，避免同会话跨组污染。
  session_id 由 493.18 刀3 兜底保证非空（`offline_local:<proc_gen>` / Cortex `ctx.get`）。
- 前置：`config.py:9450 ENABLE_M49311_SESSION_ISOLATION` 当前 **False**，稳定分桶前需先打开
  （本批不动任何开关）。

## 4. 灰度比例与放量纪律

| 阶段 | 流量 | 进入下一阶段的条件 |
|---|---|---|
| 观测 | **1%** | 影子双跑稳定、`labeled_correct` 标注回填、无线上回答变化 |
| 小流量 | **10%** | 主指标（误答率/正确率/latency）无劣化、样本量达下限 |
| 半量 | **50%** | Welch t 检验（复用 `ParamABTestEngine.py:26-100`）显著且方向正确 |

参照 `config.py:5700` "观测 ≥3 天后据语义一致率再决定放量"纪律。
照现有范式加**独立总闸**（默认 False、关则逐字回滚）+ 灰度比例常量 + 确定性分桶。

## 5. 判定口径（下一批）

- 主指标：误答率 / 正确率 / latency；显著性门槛复用 Welch t 检验或
