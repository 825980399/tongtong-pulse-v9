## 7. 易踩的坑速查

| 症状 | 真因 | 解法 |
|---|---|---|
| 补丁 anchor 全失配 | 文本模式读把 CRLF 译成 LF | **二进制读**，归一 LF 替换后还原 |
| 改配置默认值不生效 | config 里有**显式值** | 改 config，不改默认值 |
| `if not result:` 判空失效 | 返回的是 **truthy dict** | 用 `isinstance(result, dict)` |
| 导入报了 `__init__` 导出的同名类 | 包 `__init__` 重名导出 | `importlib.import_module("a.b.C")` |
| 测试重定向后默认参数还指旧路径 | 默认参数**定义时求值** | 一律 `root=None` + 运行时读 |
| `rmtree(ignore_errors=True)` 没删掉 | Windows 静默失败 | 逐文件 `os.remove` + `os.rmdir` |
| 命令里 `python -c` 内容被吃掉 | bash **反引号 = 命令替换** | 写脚本文件 |
| E402 计数忽高忽低 | 把 `Found N errors.` summary 行算进去了 | 只数含 `": E402"` 的行 |
| `tail`/`head` 报错 | coreutils 不可用 | 用 Python 探针 |
| 测试失败但代码看着对 | 契约变更（口径/字段变了） | 先判定是"缺陷"还是"契约变更"，契约变更要**同步测试** |
| 统计出"成功率 51%"很悲观 | **测试污染混进生产数据** | 先剔污染（结构性判据），再统计 |
