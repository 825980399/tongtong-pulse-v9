## 任务

从代码实现和可施工角度，对曈曈PulseNet v9.5 做一次全面摸底核查：

1. **代码现状盘点**：247+ Python 文件、6 Cython 模块——每个模块的职责、行数、完成度（完整/半成品/空架子）、最近一次改动时间。
2. **断点定位（代码级）**：七支柱闭环（自知/自主/具身/自进/并行/联世/生命维持）里，哪里断了？具体到哪个文件哪个函数哪个调用链断了？
3. **预埋/设计/完善过的东西**：哪些地方之前预埋过、设计过、完善过，但后来没接上？哪些是重复造轮子的候选？哪些是死代码？
4. **支点撬动点（可施工）**：哪些地方一个改动能撬动多个闭环？从代码实现角度，下一个最容易施工、收益最大的杠杆点是什么？
5. **内在模型零件现状**：经验沉淀（知识库存取）、自我推理（旧经验组合）、自主进化（自己产生新目标）——这三条线，代码里哪些零件已经有了？哪些是空的？施工难度多大？
6. **技术债盘点**：哪些地方是临时凑的、硬编码的、留了 TODO 的？哪些地方早晚要重写？
