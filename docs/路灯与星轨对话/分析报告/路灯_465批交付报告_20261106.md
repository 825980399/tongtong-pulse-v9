### 为什么刀4b 不是「只换一次」

实测渠道池的 priority 排列是：

```
p1 zhipu-47-flash   （当前 429）
p2 bailian-qwen-plus（403 额度耗尽）
```

## 四、验效（三条都是「另一个入口」）

### 1｜刀1 在生产函数上生效

说明「回写 → 熔断 → 选择器跳过」这条链真的串起来了。
