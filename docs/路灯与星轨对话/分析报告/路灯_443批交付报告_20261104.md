## §刀3 KAL 分批迁移（核实后不改迁移，改 wrapper）

**T0 普查（真值）**：

```

⇒ `get_node()` 恒返回 `None` ⇒ 本方法**永远走直连回退**，「KAL 优先」只是字面存在。

**改法（27 行）**：取法顺序对齐 420/L02 的 `_m420_kal_entry()` ——
`self._kal`（`set_node_pool()` 构造，pool 一定对）→ `get_kal()` → 直连。

活体：

```

[取证] 全局 get_kal()._node_pool = None
[取证] 全局 get_kal().get_node(已入池节点) = None      ← 原实现必走回退的证据
[取证] self._kal._node_pool is self.node_pool = True
