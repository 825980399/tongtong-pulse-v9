## §3 刀3 · P0-3 固定兜底话术统一终态

**问题**：453 的话术是「重试分支的副产品」——`can_retry=False` 或信号量占满时静默返回 None 走 Ollama，同类失败体验随机。

**修法**：`final_failure_result()` 成为**唯一终态入口**，位于 `retry_slot()` 之外：
- 有部分结果 → `这次没查到足够依据，我先把能确定的说一下：…`（最长 60 字）
- 无结果 → `这个问题我暂时答不准，你可以补充一个具体场景`
- 快速失败 → `稍后再试`
- `M453_USE_FIXED_FALLBACK=False` ⇒ 统一返回 `None`（回到 Ollama 回退），不再分路径。
