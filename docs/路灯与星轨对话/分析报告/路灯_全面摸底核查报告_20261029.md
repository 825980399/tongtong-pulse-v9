### 5.4 三条线的合成判断

```
经验沉淀：  采集 ● → 摘要 ● → 蒸馏 ✗（delegated 290 / returned 0）→ 检索 △（只影子）
自我推理：  向量检索 ● → 组合算子 ✗ → 图路径 ✗ → 结论输出 △
自主进化：  动机 ● → 起意 ●（问候语级）→ 目标容器 △（1 条模板）→ 目标驱动 ✗ → 选题 ✗
```

> **三句话**：**沉淀断在最后一跳；组合缺算子；目标只有容器。**
> 三条线都**不缺数据、不缺触发**，缺的都是「**上一环的产物被下一环读走**」这一步。这与七支柱的断点高度同构 —— **全系统的通病是「写入侧完备、读取侧缺失」**，而不是能力不足。
