缺 level 处数 top：`PulseMetricsCollector` 67 / `PulseNodePool` 53 / `PatchManager` 50 /
`PulseInnerWorld` 34 / `PulseLung` 32 / `runtime_metrics` 28 / `health_ui` 26 …
（全量明细：`tmp/m430_d3_done.json`）

### 3.2 做法

- AST 取 `end_lineno/end_col_offset`，插在**调用右括号之前**；尾部已有逗号则插在逗号之后（避免 `,,`）；
- ★**全程按 `bytes` 操作** —— CPython 的 `col_offset` 是 UTF-8 **字节偏移**，含中文行按字符索引会越界（429 教训）；
- 每文件独立：按字节判主导行尾 → 统一 `\n` 处理 → 按原行尾回写；
- 每文件插完立刻 `py_compile`，失败即**该文件原地回滚**并记录，不中断整批；
- 有 `**kwargs` 的调用不插（无法保证不会重复传 level）。

结果：**263 文件 / 1271 处，失败 0**。
