### 5.2 唯一的真 bug（`_evaluate_learning_effectiveness`）

```python
try:
    path_dist = self.node_pool.get_path_distribution()
    ...
except Exception:
    nodes_after = 0          # ← 只置 0
```

`nodes_after=0` ⇒ `nodes_growth = -nodes_before`（一个大负数）⇒ 下游判「效果不佳」并**累加一次失败**；连续 3 次就**强制切换学习目标**。即：**「知识分布查询炸了」被记成「学习把知识毁了」。**

本文件在 367 后续 E11 已立过同一条规矩（「无样本 ≠ 零成功率」），此处是同类混淆的反向（**错误 ≠ 零**）。修法：置 `_nodes_query_failed` 降级标记，下游不据此计失败（不累加、不清零、不切换），并按「没样本 INFO / 读取失败 WARNING」分开措辞 —— 两件事不能都写成「效果不佳」。
