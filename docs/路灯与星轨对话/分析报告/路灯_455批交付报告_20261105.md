**改动 3 处，缺一不可（少一处就「有标记没生效」）**

1. `organs/body/PulseLung.py`（CRLF，+5 行）：454 的种子合并点给每条打 `seed_override=True`；
2. `nucleus/evidence_injection.py`：新增 `seed_min_score()`（`_cfg_num("M454_SEED_MIN_SCORE", 0.55)`）+ `score_floor(item, base, seed_min)`；`build_injection` 的准入改为**逐条取各自下限**（种子 0.55、其余仍是 0.65，口径没一起松）；

**本批自加的一条（任务书没写，理由在此）**：排序上让种子**沉底** ——
`pool.sort(key=lambda _x: (1 if _x.get("seed_override") is True else 0, -_qw(_x)))`。
原因：种子 `quality_weight≈0.8`（人工 confidence），而真实检索命中在 reward 缺失时 qw≈0.5；若按 qw 混排，0.55 进来的种子会把**真正相关的经验挤出 top_k=2**，注入段反而更不相关。种子是「补源」不是「抢位」。

**仍走净化/去重/top_k**：0.54 的种子照样被丢（单测 `test_seed_below_055_still_dropped`），300 字种子照样被 `max_chars` 截断。

## §2 刀2 · `nucleus/reasoning/hypothesize.py`（新建 443 行）

**为什么不复用 `_generate_branch_with_model`（烛微 H1/H2/H3）**：那条通道是 **45s 裸 HTTP**（`timeout_by_purpose["inner_world_chat"]`）⇒ 一次假设就能顶穿 453R 的 34s 总预算；它把结果写进**1 小时 TTL 的 `_model_cache`**（键=核心词+分支名）⇒ 不同问题互相串味；它的成功判据是「任意 ≥15 字文本」⇒ 分不清假设与事实。

- **自己的超时**：`timeout = min(8.0, deadline - now - 10.0)`；剩余 `<12s` 直接 `skipped_no_budget`；`timeout <1s` 也跳过（不为 0.4s 发一次 HTTP）。
- **不复用 `_model_cache`**：不读不写、不做跨请求缓存。
- **参数**：`max_tokens=320`、`temperature=0.4`（走 config，可秒级调）。
- **端点**：`endpoint_resolver`（生产 = `_m31_branch_endpoint`）→ 渠道池优先 → `REMOTE_API_CONFIG`；出口走 `nucleus.ssrf_guard.safe_http_json`（可打桩）。
- **请求 deadline**：`begin_request()` / `request_deadline()` / `end_request()` 挂在 ContextVar；由 `PulseInnerWorld._ir_build_context` 在「Cortex 收到问题」那一刻登记。

## §3 刀3 · JSON 契约与解析

`parse_hypotheses(text, allowed_ids, max_hypotheses)` 的五道闸：

| 闸 | 行为 |
|---|---|
| 围栏 | ` ```json … ``` ` 自动剥离（模型最常见的「不按表格填」形态） |
| JSON | `json.loads` 失败 ⇒ `parse_error`，**绝不把原文当结论**（单测断言语义：`"我觉得"` 不出现在返回体里） |
| `speculative` | 必须 `is True`，缺失或 false ⇒ `parse_error`（分不清假设与事实就不收） |
| `evidence_ids` | 只认本次提供的 id；未知 id 丢弃并计 `dropped["unknown_evidence_id"]` |
| `confidence` | 夹到 [0,1]；**无有效 evidence_ids ⇒ 封顶 0.3**；最多 2 条，超出计 `over_limit` |

**空 content 的留痕**：`reason` 里带 `finish_reason / completion_tokens / reasoning 字数`（86/87 批「推理模型吃光 max_tokens」教训），便于 456 据实调参而不是猜。

## §6 刀6 · 计划追加 `op=hypothesize`

- 触发：含 `假设/如果/假如/会不会/可能/推测/推演/会怎样/什么情况下`，**且** 不命中事实型正则 `(是什么|是啥|多少|哪一年|哪年|几点|多大|多久|谁|什么意思|的定义)`；
- 最多 **1 个**；`step_id` 接在计划末尾；`depends_on` 指向最后一个前序步骤（= 提供证据的那一步）；
- 事实型优先：「可能是什么原因导致报错」同时含「可能」和「是什么」⇒ **不触发**（单测钉住）；
- `ENABLE_M454_PLAN_V3=False` 时整段不进入（沿用 454 回退路径）。
