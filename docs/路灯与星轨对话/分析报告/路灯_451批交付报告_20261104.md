### 为什么"全是 unknown"（分两层说清）

**第一层：意图分类没坏，但被"短句惩罚"带偏了。**
`nucleus/qica/IntentChannels.py::ch_complexity` 有两条：

```python
scores["一般对话"] += (1.0 - complexity) * 0.6
scores["情感问候"] += (1.0 - complexity) * 0.5
```

**越短的问句这两个"低信息量"意图加分越多**。短句问日志/代码时关键词通道给分有限，
`(1-complexity)*0.5` 就把 `情感问候` 顶上来。

**第二层：现有的语言学精修救不回来。**

```python
_CONFUSABLE = ("知识查询", "一般对话", "概念解释", "追问澄清")
```

`情感问候` **不在**可改写集合里 —— 一旦判成它，7 条语言规则一条都不跑。
再往下一层，`PulseCortex._map_qica_result_to_intent` 把 `情感问候` 映射成路由意图 **身份**，
于是"问日志""问代码"全变成"问身份"。

## §2 刀2 · 对话体验评分校准

**改动**：`organs/core/PulseMotivationCycle.py` **+37 −4**

### 评分是怎么算的

**纯规则，不是 LLM 评的**（`_on_inference_result`）：

```python
_confidence = payload.get("confidence", 0.5)
if   _confidence >= 0.8 → reward 0.5+c*0.4, 情绪["满足","自信"]
elif _confidence <  0.4 → reward 0.1,       情绪["挫败","不确定"], 压力 0.7
else                    → reward 0.3,       情绪["平静"]
```

### 后面 5 条为什么是 0.0 / 0.1

不是"回复差"，是 **`confidence=0.0` 的来源被误读**：本地答不了时 `PulseInnerWorld`
发的是 **委托事件**：

```python
self._emit(InferenceEvent.RESULT, {
    "question": ctx.question, "answer": None,
    "method": "meta_not_search", "confidence": 0.0, ...})
```

`answer=None` + `method=meta_not_search` 的语义是**「交给大模型」**，而评分代码把它当成
**「我答砸了」**。后果是双环：

```
本地答不了 ──► 记一条"挫败"体验（reward 0.1）
                     │
                     ▼
        以 derivation_type=unknown 进推理经验库
                     │
                     ▼
   下次经验路由命中它（unknown ⇒ 408刀1 不产答案）──┐
                     │                              │
                     └──── 又是"本地答不了" ◄────────┘
```

### 修法（两条）

1. **委托 ≠ 答得差**：`method ∈ {meta_not_search, inference_fallback_to_lung,
   delegated_to_lung, meta_honest}` **且** `answer` 为空 ⇒ 记**中性事实**
   （reward 0.3 / 情绪["平静"] / 压力 0.1），模式标 `delegated`。
   ★只放过"确实委托"这一种；`method=rule` 给空答案**仍按低分**处理（真失败不能洗白）。
2. **`confidence=None` 不再炸**：`payload.get("confidence", 0.5)` 在键存在且为 `None` 时
   返回 `None`，`None >= 0.8` 直接 `TypeError`，而该方法**外层没有 try** ⇒
   整条体验记录被打掉。非数值一律按 0.5 处理。

### 活体数据（真实 RESULT 载荷回放）

```
委托兜底（answer=None/meta_not_search/confidence=0.0） mode=delegated reward=0.3 tags=['平静']
委托兜底（inference_fallback_to_lung）                 mode=delegated reward=0.3 tags=['平静']
真·低质量（有答案但置信度低 0.1）                        mode=low       reward=0.1 tags=['挫败','不确定']
高置信度（0.9 + 有答案）                                mode=high      reward=0.86 tags=['满足','自信']
confidence=None（旧代码会 TypeError）                  mode=mid       reward=0.3 tags=['平静']
```
