### 3.2 并发锁：真两线程实测

```

第二路: skipped_locked=True applied=0
底层 apply 实际调用次数 = 1（必须 1）
```

理由写在代码里：排队会让「进程退出 finally」卡住等满一整轮 apply；跳过更安全，下一拍还会再来。
