## §2-§4 · 本地三算子（新建 `nucleus/reasoning/local_ops.py`，228 行）

| 算子 | 成功 | 失败语义（不编造） |
|---|---|---|
| `compare(operands, dimensions, evidence)` | 逐维对照，数值优先、文本兜底，返回 similarities/differences/evidence_ids/confidence | `insufficient_evidence`（证据 <2 条 / 操作数不足 / 某对象无证据 / 维度无素材）；缺维度列 `unknown_dimensions` |
| `exclude(candidates, criteria, evidence)` | must/negations/min_score 筛选，`dropped` 带 item+reason+index | **全排除 ⇒ 返回原集合 + 告警**，不静默清空 |
| `quantify(metric, values, unit)` | sum/mean/ratio/count 与中文别名，可从证据文本抽数字 | `insufficient_numbers`；零分母单独标记，绝不返回 0 冒充 |

实测：

```
compare(方案A/B, [性能,复杂度]) → 性能相同 [90,90]，复杂度不同 [3,7]，confidence 0.5
exclude 全排除 → status=all_excluded，kept=原 2 条 + warning
quantify(sum, [10,"20个",30]) → 60.0 条；quantify(sum, ["没有数字"]) → insufficient_numbers
```

三条纪律：纯本地 **0 次 LLM**、0 次网络、0 次写盘；异常一律 `silent_exc` 留痕。
