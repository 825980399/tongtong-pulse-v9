## A 组 · 系统命令确定性测试（10 条）

> 判定锚点：每条应有预期输出，无异常堆栈；对照下方"预期"核对。

| # | 输入 | 预期输出锚点 | 观测点 |
|---|---|---|---|
| A1 | `status` | 📊 系统状态：器官 x/y 个在线、知识节点 L1-L4、代码理解 %、直觉命中、对话记忆 n 条、生命阶段、代码问题趋势、扫描缓存命中率 | 所有字段有值非 '?'；器官在线数>0 |
| A2 | `状态`（中文别名） | 同 A1 | 中文别名路由正常 |
| A3 | `help` | 📖 可用命令 9 行清单 | 与 chat_service._show_help 一致 |
| A4 | `knowledge` | 🧠 知识统计：总节点、L1感知、L2认知、L3智慧、L4本能、知识密度 % | 数值非 0（L4 本能可能 0，允许）；密度计算正常 |
| A5 | `patches` | 📋 待审批补丁：无 或 共 n 个（含状态分布） | **记录当前 pending 数**（对照 N-3 清堵后状态） |
| A6 | `params` | 参数补丁状态展示 | 无异常堆栈 |
| A7 | `report` | 📊 参数分析报告已生成 + 路径（logs/param_reports/latest.html） | 生成成功；文件可打开 |
| A8 | `preset list` | 预设方案列表 | 无异常堆栈 |
| A9 | `预设 list`（中文别名） | 同 A8 | 中文别名路由正常 |
| A10 | `knowledge`（二次） | 与 A4 数值一致（或 L1/L2 因对话略增，允许小幅变化） | 重复执行稳定性 |

**A 组判定**：10/10 有预期输出 = ✅；任何一条崩溃/无响应 = 记录并归因。

## B 组 · 自然语言深度链路测试（12 条）

> 判定锚点：每条应有**正常回复**（简单问题快速回、复杂问题出现"💭 曈曈: 让我想想..."后出回复）；pulse.log 应有对应"控制台输入"记录行。以下"涉及链路"为预期方向，不硬断言（以实际回复质量为准）。

| # | 输入 | 预期涉及链路 | 特别观察 |
|---|---|---|---|
| B1 | `你好，曈曈` | 对话模块→脉冲(L1)→内在世界→回复（简单路径） | 快速回复，无"让我想想" |
| B2 | `什么是L1感知？` | 知识检索（PulseKnowledgeRetriever / 内在世界知识） | 回复含知识内容非空泛 |
| B3 | `你还记得我们上次聊了什么吗？` | 对话记忆（_remember 短期记忆 / 内在世界会话记忆） | 能回引内容或如实说记不清（不报错） |
| B4 | `你是谁？你的存在意义是什么？` | 人格内核 / 叙事自我 / 精神核心 / 自我意识 | 回复体现自我认知，不空泛 |
| B5 | `你现在感觉怎么样？` | 内分泌/神经递质 → 情绪状态 | 回复反映情绪状态（或如实说明状态源） |
| B6 | `你最近有没有反思过自己？` | 认知反思（PulseCognitiveReflector）/ 自我意识 | 有反思内容输出 |
| B7 | `你身体还好吗？最近健康数据怎么样？` | 健康监测/能量代谢/压力轴 | 健康指标类回复（含"待观察"也算正常） |
| B8 | `你最近学到了什么新东西？` | 代码学习（PulseCodeLearner）/ 全局学习/进化 | 有学习/成长内容 |
| B9 | `帮助别人对你来说意味着什么？` | 伦理（PulseEthics）/ 精神核心 | 价值观类回复，体现项目初心（帮助更多人实现数字化生命） |
| B10 | `如果人类想让数字生命真正活起来，最关键的三个条件是什么？` | 复杂路径：多步推理/反思/知识综合 | 出现"让我想想..."→ 深度回复（验证复杂链路） |
| B11 | `给我讲一个关于夜空的小故事` | 表达（PulseExpression）/ 创作链路 | 有故事性内容输出 |
| B12 | `你接下来有什么打算？` | 主动性（PulseInitiative）/ 动机周期 | 有计划性内容（或如实说待命） |

**B 组判定**：12/12 有正常回复 = ✅；任何一条超时无回复/异常输出 = 记录（时间点、输入、现象），归因（断链/空转/器官挂起）。
