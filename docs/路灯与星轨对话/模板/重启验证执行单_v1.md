> 口径纪律：**只采信落盘读数，不接受"看起来正常"**；任一读数取不到 ⇒ 记 `UNAVAILABLE`，**不许写 0 冒充**

## 〇、使用方式

1. 重启**前**先跑 `R-0`，把基线读数存盘（否则重启后无从对比）。
2. 重启**后**按 `V0 → V0.5 → V1 → … → V8` 顺序跑，**不跳项**。
3. 任一项 `FAIL` ⇒ 立刻停在原地、按「不通过处置」处理，**不许继续往下跑**掩盖问题。
4. 全部跑完把本单填成「实测」列，附在交付报告后。

统一约定：

| 记号 | 含义 |
|---|---|
| `PASS` | 达到通过线 |
| `FAIL` | 未达通过线（附实测值） |
| `UNAVAILABLE` | 读不到（**不等于通过**，也不等于 0） |
| `N/A` | 本环境不适用（须写明理由） |
