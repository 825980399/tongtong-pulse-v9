七、关键决策记录
1. auto_apply_enabled 保持 False：自动应用补丁仍有安全风险，需人工审批。
2. 心跳降级到 L3：缓解 L0 生命线过载，需监控是否影响紧急响应。
3. 伦理审查同步化：消除「发射即通过」假闭环，超时降级仍需优化。
4. 代码学习反馈兴趣模型：形成「学习自己→更感兴趣」正循环，可扩展至对话学习。
5. 器官中文别名层：解决中文问题检索不到英文类名问题，需在检索时优先使用别名路径。
6. 权限校验统一：realpath + 前缀边界，防止路径穿越。
7. 快照软校验：允许校验和不匹配时加载节点，防止校验算法升级导致知识丢失，配合备份选择最大快照。
