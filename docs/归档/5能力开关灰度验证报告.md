三、验证细节
A. Parquet 列式快照
• 链路：PulseSnapshot.set_node_pool(pool) → save() → _use_parquet=True 时调 save_parquet() → pyarrow.write_to_dataset 按 evol_level 分区写盘。
• 证据：Parquet 快照已保存: 5 节点 → /tmp/gray_parquet_*/parquet，目录内生成 .parquet 文件。
B. 外置索引磁盘化
• 链路：PulseNodePool.set_index_store(store) → save_index_snapshot() → IndexStore.save_all() 落盘三张索引表（level_index/path_index/semantic_index）。
• 证据：save_all 返回三表 True，三张 .parquet 实际落盘，load_level_index() 读回 1 个键（evol_level 分组）。
C. 冷存储分治 + 按需加载 + compaction
• 链路：set_cold_storage(enabled=True) → add() 超容触发冷池 → load_batch_lazy() 按 _determine_pool 分流冷节点落盘 → get_all_including_evicted() 只读遍历（consume=False）→ compact_cold_storage() 去重压缩。
• 证据：20 节点全部冷盘落盘（in_cold_disk=20），get_all_including_evicted 返回 20 节点（无悬空），compaction 返回 before_files/after_files/dedup_count 等完整统计。
D. 探查策略自反馈
• 链路：ProbeStrategyMemory.record_round() → compute_strategy() 自适应阈值算重点集合 → 单例 get_probe_strategy_memory()。
• 证据：compute_strategy 返回 dict，两次 get_probe_strategy_memory() 返回同一实例。
E. 探查假设生成
• 链路：generate_hypotheses(issues) → 按 organ 分组 → 同型扩散（_SAME_TYPE_CANDIDATES）+ 相关类型（_RELATED_TYPES）。
