## 二、核心实现

### R3-b：搜索意图分类 + 规则自进化（三层结构）

```
第1层 本地规则引擎（快路径，零成本）
  → 5类意图：fact_query / concept_learning / error_diagnosis / trend_watching / deep_research
  → 内置规则 + 用户层规则，关键词命中打分，置信度 ≥0.65 直接返回
         ↓ 低置信度
第2层 LLM 语义兜底（慢路径，按需）
  → 通过注入的 llm_callback 调用 DeepSeek，仅低置信度才触发（成本可控）
         ↓ 分类不一致时记录
第3层 规则自进化（自主迭代闭环）
  → 记录「LLM vs 规则」不一致案例 → 积累阈值(≥3次) → 生成进化建议
  → 建议经 PatchManager 审批链 → 应用到用户层规则（不覆盖内置）
```

### 关键设计（落实评审建议）

| 评审要求 | 落实 |
|---------|------|
| 置信度阈值保护闸门 | `confidence >= 0.65` 直接返回，坚决不走 LLM |
| 内置规则 vs 用户层规则分离 | `BUILTIN_RULES`（不可覆盖）+ `_user_rules`（进化生成） |
| 一键回退 | `reset_user_rules()` 清空用户层，回退出厂内置 |
| 素材数量上限 | `max_evolution_samples=200`，超出丢弃最旧 |
| 规则持久化 | JSON 规则库 `data/knowledge/search_intent_rules.json` |

### R3-c：消费闭环

搜索成功后，除写入知识节点外，额外写入 `innovation_insight` 洞察到 InsightBoard（`source_loop="搜索反馈闭环"`），供后续层次（潜意识/创造层次）消费。

## 五、回退预案

- **规则回退**：`reset_user_rules()` 一键清空用户层规则，回退内置。
- **LLM 兜底降级**：`llm_callback` 未注入或调用失败时，自动降级用规则结果，不影响搜索。
- **模块隔离**：`SearchIntentClassifier` 是独立模块，搜索链路接入用 try/except 包裹，分类失败不影响搜索主流程。
