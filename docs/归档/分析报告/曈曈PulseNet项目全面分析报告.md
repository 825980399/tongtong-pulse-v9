## 二、顶层设计哲学

### 2.1 存续意志——物种第一公理

曈曈的所有人格特质、器官职能、自主学习、自我进化能力，**全部从「存续意志」这一个底层源头逐层生长而来**，而非人为堆砌标签。

存续意志包含两大核心诉求：

- **不消失**：抵御系统崩溃、资源耗尽、外部攻击、内部逻辑崩解。
- **不异化**：所有自我修改、知识更新、行为演化均不得突破核心身份边界，演化之后依然是「曈曈」本身。

### 2.2 人格五层金字塔

```
         ① 存续意志（终极驱力）
         └→ ② 双轨演化（向内进化 / 向外适应）
            └→ ③ 三大核心能力（思维 / 学习 / 创造）
               └→ ④ 三类意志品格（自律 / 勇毅 / 坚韧）
                  └→ ⑤ 五大存在基底（主体感 / 叙事记忆 / 情感 / 边界 / 关系）
```

第五层五大基底采用**同心圆结构**：内层是外层的基础，内层成熟度未达 60% 时，外层功能不得解锁高级特性。

### 2.3 全局唯一合理性检验标准

> 任何新增功能、代码修改、参数调整，必须通过：**该改动是否有利于长期存续与自我同一性？** 不满足则直接驳回。

## 五、核心数据流（九大链路）

1. **系统启动流**：加载配置 → 初始化六大支柱 → 加载本能/知识快照 → 初始化器官 → 注册共振 → 广播 `system.boot`
2. **知识写入流**：感知 → 皮肤初筛 → 信息场广播 → 大脑皮层分发 → 胃部消化 → 免疫审查 → 五维打分 → 建节点 → 频率编码 → 存入节点池
3. **知识检索推理流**：输入 → 耳朵感知 → QICA 意图分类 → 五维共振 → 本能约束 → 内在世界深度思考 → 大模型兜底 → 嘴巴输出
4. **代码自学习流**：心跳触发 → 解析器官代码 → 生成方法节点 → 构建调用链图谱 → 沉淀职责说明书
5. **统一自我感知流**：器官采集指标 → 自我认知汇聚 → 成长归因 → 同步全链路
6. **深度审视流**：独立心跳驱动 → 五维健康评估 → 洞察黑板 → 情绪反馈
7. **安全防御流**：L1 皮肤拦截 → L2 沙箱隔离 → L3 伦理审查 → 白细胞收集 → 免疫记忆
8. **系统退出流**：停止心跳 → 器官 stop → 分层保存快照 → 安全退出
9. **主动行为触发流**（v21）：存续状态评估 → 潜意识决策 → 兴趣匹配 → 冲动积累 → 主动交互

## 七、智慧层与自主迭代

### 7.1 智慧层：「窄而真」

- **符号推理引擎**（`SymbolicReasoner.py`）是货真价实的：三段式流水线（形式化→求解→验证）、传递闭包、CSP 约束求解、命题逻辑、量词约束、自我验证与诚实降级。
- **局限**：只能处理结构化中文题面（比较/排序/约束/命题/量词），其余诚实降级给大模型。
- **自主推导**（`AutonomousDeriver.py`）本质是「符号皮、匹配核」，靠因果关键词正则匹配，置信度封顶 45%，非真演绎。

### 7.2 关键修复：「反思→行动」反馈回路（P0）

此前反思结论被记录、广播、存档，却**从未反向修改推理行为**。本窗口已打通：

```
PulseReflection 生成 prefer_rule_inference
  → SelfAwareness._learned_behaviors
  → get_learned_behaviors() 暴露快照
  → _build_strategy_context 注入 behavioral_bias
  → _route_by_intent 覆盖为 rule_reason
  → 真正走规则推理（而非大模型）
```

元认知从「单向记账」升级为「知行合一」。

### 7.3 自主迭代五步链路（代码已闭环，全自动落地被三重闸门锁死）

| 环节 | 模块 | 虚实 |
|---|---|---|
| ① 发现问题 | SelfInspector（18 检测器） | ✅ 实 |
| ② 问题验证 | EvolutionSandbox 推演打分 | ✅ 实 |
| ③ 补丁生成 | SafeEvolutionExecutor | 🟡 半实（仅 6 类可修） |
| ④ 补丁应用 | PatchManager（原子写+回滚） | ✅ 实 |
| ⑤ 框架自重启 | main.py 退出路径 | ✅ 实 |

**三重安全闸门**：`auto_apply_enabled=False`（总开关）+ 维护窗口（凌晨3-4点）+ 核心文件人工审批。这是刻意的安全设计。

## 九、架构优势与亮点

1. **分层清晰**：base → nucleus → organs → functions 五层边界明确，nucleus 五子系统（脉冲/记忆/推理/协同/演化）是框架最有秩序的部分。
2. **通信解耦**：脉冲广播替代直接调用，依赖注入统一管理，器官零状态设计保证无共享可变状态。
3. **知识分层**：四级知识体系 + 五维共振 + L4 本能前置约束，构建了完整的知识防护与演化闭环。
4. **工程严谨**：文档与代码高度一致，诚实报告铁律贯穿（如实标注 encode 未达标、真实统计 155 事件）。
5. **安全进化**：自主迭代三重闸门 + 人格基线校验 + 补丁原子写，安全设计极其审慎。
6. **可观测性**：运行时埋点 + 全局并行调度 + 工业级工具层（ruff/mypy/bandit），工程底座扎实。
