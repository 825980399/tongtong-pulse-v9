## 一、R4 目标

把五层次从「各自为政」串成「循环增强」的整体：

```
生存(生命) → 认知(智慧) → 调度(协调) → 进化(创造) → 人格(精神) → 循环
```

**核心支点：存续状态指数**（对齐框架第一公理「存续意志」）。

## 二、现状诊断（代码实证）

### 2.1 「各自为政」的具体表现

当前 5 个器官**各自独立读**同一个 `get_existential_state()`：

| 层次 | 器官 | 消费方式 | 动作 |
|------|------|---------|------|
| 生命 | 心脏 PulseHeart | `_call_provider` | 心跳减速 |
| 智慧 | 主动意识 PulseInitiative | `_call_provider` | 调整交互策略 |
| 智慧 | 内在世界 PulseInnerWorld | `_call_provider` | 诊断源 + 未来推演 |
| 智慧 | 潜意识 PulseSubconscious | `_call_provider` | 探索节奏 |
| 精神 | 精神宪法 PulseSpiritConstitution | `_call_provider` | 存续状态 |

### 2.2 缺失的三条回路

1. **无「反馈回路」**：各器官只「读」状态，不「回写」动作结果。比如 R2 的自我保存成功 → 存续指数回升，这个反馈没有显式闭环。
2. **无「优先级协调」**：存续低位时，各器官各自降载，但没有统一的「谁先降、降多少」的协调。
3. **无「创造层次联动」**：存续状态变化没有驱动「创造层次」（自主迭代）——低位时应暂停迭代保留资源，高位时允许主动探索改进。

## 三、R4 设计（最小侵入，复用现有）

### 3.1 核心组件：`nucleus/SurvivalOrchestrator.py`（存续编排器）

新增一个轻量协调层（约 200 行），职责：

1. **单一事实源**：统一读取 `get_existential_state()`，产出标准化的「存续状态快照」dataclass。
2. **分发到五层次**：把状态快照分发给五层次代表器官（而非各器官自行读）。
3. **回路反馈**：收集五层次动作结果，回写存续指数，形成「感知→行动→反馈→再感知」循环。

### 3.2 关键设计：存续状态快照 dataclass（评审建议的预埋点①）

```python
from dataclasses import dataclass, field

@dataclass
class SurvivalSnapshot:
    """存续状态快照（统一封装 get_existential_state 输出）"""
    index: int = 50
    level: str = "medium"
    mode_switched: bool = False
    indicators: dict = field(default_factory=dict)
    timestamp: float = 0.0
    
    @property
    def is_low(self) -> bool:
        return self.level == "low" or self.index < 40
    
    @property
    def is_high(self) -> bool:
        return self.level == "high" and self.index >= 80
```

## 五、风险与回退

| 风险 | 防护 |
|------|------|
| 编排器成为单点故障 | 编排器只做「读 + 分发」，不替代各器官原有逻辑；编排器异常时各器官回退到各自读 |
| 回路反馈震荡 | 反馈加阻尼（阈值 + 冷却），避免存续指数被动作结果来回拉扯 |
| 侵入现有通信 | 编排器作为补充协调层，不改变脉冲信息场通信模式 |

**回退预案**：编排器用总开关 `SURVIVAL_ORCHESTRATOR_ENABLED`，关闭后五层次回退到「各自读」的现状。
