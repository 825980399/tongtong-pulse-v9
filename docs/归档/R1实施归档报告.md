## 二、关键实现细节

### PulseNode.py（7 处改动）

1. `__init__` 新增 `source_url: str = ""` 参数
2. 赋值处调用 `_sanitize_source_url()` 清洗脏数据
3. 新增静态方法 `_sanitize_source_url`（None/空/超长/非http/控制字符 → 置空或截断）
4. `to_dict` 新增 `"source_url": getattr(self, "source_url", "")`（向前兼容）
5. `from_dict` 新增 `node.source_url = data.get("source_url", "")`（旧快照自动填充空串）
6. `assess_trust`（创建时评估）新增域名信任加成（权重外化 config）
7. `evaluate_node_health`（运行时健康度）新增域名信任加成

### 域名信任加成逻辑（两处方法一致）

```python
_source_url = getattr(self, 'source_url', '')
if _source_url:
    try:
        from config import SOURCE_URL_TRUST_CONFIG
        _domain = _source_url.split('/')[2] if '://' in _source_url else ''
        _boost = SOURCE_URL_TRUST_CONFIG["domain_boost"].get(_domain, SOURCE_URL_TRUST_CONFIG.get("default_boost", 0))
        _trust_base = max(10, min(100, _trust_base + _boost))  # assess_trust 用 0-30 钳制
    except Exception:
        pass  # 配置缺失时静默降级
```
