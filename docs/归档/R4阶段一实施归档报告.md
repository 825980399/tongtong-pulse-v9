## 二、核心内容（评审定稿落地）

### 2.1 SurvivalSnapshot 标准数据结构体

统一封装 `get_existential_state()` 输出，字段定稿：

| 字段 | 说明 |
|------|------|
| `index` | 整体分数 0-100 |
| `level` | 整体等级 low/medium/high |
| `mode_switched` | 状态变更标志 |
| `indicators` | 六大维度分项 |
| `scores` | 六大维度分项分数 |
| `timestamp` | 状态变更时间戳 |
| `stable_duration` | 稳态持续时长 |

附带 `from_existential_state()`（兼容缺失字段）、`is_low`/`is_high` 判定属性。

### 2.2 五层次统一空钩子（接口定稿）

`SurvivalHookMixin` 提供 `on_survival_low()` / `on_survival_high()` 两个空方法，五层次动作矩阵已在 docstring 中定稿：

| 层次 | 低位动作 | 高位动作 |
|------|---------|---------|
| 生命层 | R2 自我保存闭环 | 正常节律、自愈待机 |
| 智慧层 | 停止外部搜索、收缩摄入、聚焦内部修复 | 开放搜索、知识关联、顿悟 |
| 协调层 | 全局并发降载、搜索降级、暂停后台、节流脉冲 | 全量调度、多引擎并发 |
| 创造层 | **强制暂停自主迭代/补丁/重构（高危稳定性锁）** | 允许审计/重构/进化 |
| 精神层 | 自我关怀叙事、稳定认知 | 自由表达、人格输出 |

### 2.3 全局开关

`SURVIVAL_ORCHESTRATOR_ENABLED = False`（阶段一默认关闭，完全无侵入）。

### 2.4 统一日志 TAG

`[SurvivalOrchestrator]`
