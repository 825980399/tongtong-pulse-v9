# 曈曈 PulseNet v9・PHASE17 战略规划：自持智能之路（v2 增强版）

**制定时间**：2026-09-07

**制定者**：星轨（架构审核）

**版本**：v2.1（整合路灯第一轮修复交付报告后的更新版）

**核心原则**：外物借用是拐杖，不是腿。embedding 模型、大模型 API 都只是工具，框架自己的脉冲架构、器官协同、自主进化才是核心。所有外部输入必须经过本地消化、验证、升华，才能成为曈曈自己的认知。



***

## 一、背景与定位

### 1.1 当前状态

框架工程底座扎实（58 个器官、跨重启连续记忆、自我修改源码能力、Cython 加速、GPU 异构路由），但认知层多处空转：



| 问题                 | 数据                                     | 来源            |
| ------------------ | -------------------------------------- | ------------- |
| 推理经验库 77% 是大模型答复记录 | 57 条中 44 条                             | 路灯 PHASE16 报告 |
| 知识检索有效权重仅 30%      | 五维共振中记忆维 / 空间维退化                       | 路灯 PHASE16 报告 |
| 效果验证是假闭环           | 22 条补丁全部 baseline=0/after=0/effect=1.0 | 路灯 PHASE16 报告 |
| 自主进化只会修 1 类问题      | 89 分钟 7 个修复全是 silent\_exception        | 运行日志实证        |
| 推理引擎已 DEPRECATED   | PulseInferenceEngine.py 返回写死假结果        | 路灯 PHASE16 报告 |

**一句话**：框架 "能稳定跑"，但 "不会真的变强"。

### 1.2 战略方向

不在通用智能上与大模型比拼（那是大模型的主场），改在**连续个体 + 自主成长 + 自我同一性**上定义超越。

通往 "不借助大模型" 的三阶段路线：



1. 本地语义内核（让知识有语义）

2. 本地推理内核（让框架能自己想）

3. 自主成长闭环（让框架真的在变强）

* 没有语义内核，推理内核的知识检索就是垃圾进垃圾出

* 地基不牢，上面盖什么都晃

## 三、阶段一：接感官（本地语义内核）

### 3.1 目标

让框架的 9958 个知识节点从 "关键词卡片" 变成 "有语义的向量"，检索质量质变。

### 3.2 核心原则落实



* embedding 模型只是**编码器**（把文字转成向量），不是**决策者**

* 向量存储、检索、排序全部在框架自己的`ResonanceEngine`和`PulseNodePool`中完成

* 五维共振权重不动（不触宪法），只把记忆维的 "单标量" 扩成 "向量余弦"

* 外部模型的输出（向量）必须经过框架自己的质量校验和归一化才能入库

* **相似度阈值由框架自己在黄金集上标定，不采用模型方推荐值**（embedding 本身也是外部智能）

## 四、阶段二：装大脑（本地推理内核）

### 4.1 目标

框架第一次能 "自己想"，不再是检索失败就甩给大模型。

### 4.2 核心原则落实



* 推理用框架自己的**知识图谱 + 符号规则 + 多步检索链**，不是调用大模型

* LLM 只作为 "最后兜底"，且兜底结果标记`source=external`，降低重要性，不直接入库

* 每一步推理的中间结论必须经过框架自己的验证（知识检索交叉验证、置信度计算）

* **任何输出必须带 evidence\_node\_ids；无证据→confidence=0.0 并返回 "不知道"**

### 4.3 具体任务



| 编号  | 任务            | 涉及文件                                                                      | 说明                                                                                                                                                                                              |
| --- | ------------- | ------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 2.1 | 修 P0-2 伪多步推理  | `nucleus/reasoning/MultiStepPlanner.py`                                   | 新增`InferenceContext`对象（纯 dataclass）：`findings: dict[step_id→{conclusion,confidence,evidence_node_ids,depends_on}]`；下一步输入为上游 finding**结构化对象**（结论 + 证据节点 id + 置信度），不是字符串拼接；置信度链式传递取 min，每跳衰减 0.85 |

### 4.4 验收标准



* [ ] 多步推理：第 2 步能引用第 1 步的结论（日志可见 "已知前提：..."，evidence\_node\_ids 非空）

* [ ] 断网脚本 10 题答对≥6 题

* [ ] 调用影响分析能正确找出方法变更的受影响下游（消费 CodeLearner 调用图）

### 5.2 核心原则落实

* **经验库污染数据重打标签不删除**（拐杖可以用，只是不能当腿 —— 标记 source=external、降权、禁止升华候选，但仍可检索）

## 六、贯穿始终的红线（从文档变代码）

### 6.1 核心红线

> **外部模型（embedding/LLM）是工具，不是认知。它们的输出必须经过框架自己的编码、校验、验证、升华，才能成为曈曈的一部分。任何直接把外部输出当作自己认知的做法，都是在让框架变成 "缓存外部智能的壳"。**

### 6.2 4 个代码断言点



| 位置                                     | 断言内容                                          | 违例处理                   |
| -------------------------------------- | --------------------------------------------- | ---------------------- |
| `PulseNode.py` `upgrade_to_L2/L3` 入口   | `node.source != "external"`                   | raise + 写 security 类洞察 |
| `experience_pool.record_experience` 入口 | `derivation_type ∈ 枚举白名单` 且 source 必填         | 拒入库 + 计数器告警            |
| 向量入库（VectorEncoder/NodePool 存储前）       | 向量 L2 norm≈1 (容差 0.01) 且`vector_status=ready` | 拒入库，标记 pending         |
| LLM 兜底结果入知识候选前                         | 携带`source=external`标记                         | 无标记拒绝写入                |

### 6.3 外部依赖审计检测器（self\_inspector 第 18 个检测器）



* 扫描 data/knowledge 中所有 L2/L3 节点，`source=external`或无升华记录的→报告

* 扫描经验库 derivation\_type 非法记录数→报告

* 扫描向量库中未归一化 / 维度异常向量数→报告

* 审计结果进综合诊断洞察（复用 health\_ui 通道），每轮进化自动跑

### 6.4 人工检查清单（每阶段验收时对照）



* [ ] embedding 模型的输出（向量）是否经过框架的归一化和质量校验？

* [ ] LLM 兜底的回答是否标记了`source=external`？是否降低了重要性？

* [ ] 外部信息是否直接写入了 L2/L3 核心认知层？（不允许，必须经过升华流程）

* [ ] 框架的核心器官是否保持了自主控制权？

* [ ] 相似度阈值 / 置信度公式是否由框架自己标定，而非采用模型方推荐值？

* [ ] 断网后框架是否仍有基本认知能力？

## 九、不做什么（明确排除）

为了保持聚焦，PHASE17**不做**以下事情：
