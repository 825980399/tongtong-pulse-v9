## 二、验证步骤

### 步骤1：框架启动检查

1. 启动框架，观察启动日志
2. 确认无新增ERROR/WARNING
3. 确认33个灰度开关全部开启
4. 确认新增开关状态：
   - `ENABLE_QICA_MULTI_CHANNEL = True`
   - `ENABLE_QICA_FUSION_ROUTING = True`
   - `ENABLE_QICA_FEEDBACK_LEARNING = False`（默认关闭）

### 步骤2：5个标准测试问题验证

依次输入以下5个问题，记录每个问题的：
- QICA分类结果（意图类型、建议方法、知识路径）
- 8通道各通道得分（如果有日志）
- 融合决策结果（6种路径置信度）
- 最终执行路径
- 是否调用大模型
- 回答质量（完整/相关/有条理）

| # | 测试问题 | 预期意图 | 预期处理路径 | 预期是否调用大模型 |
|---|---------|---------|-------------|------------------|
| 1 | "什么是五维共振？" | 知识查询 | 知识检索+语义扩展+融合 | 否（本地回答） |
| 2 | "你有哪些器官？" | 身份确认 | 自我画像+器官清单综合 | 否（本地回答） |
| 3 | "什么是共振引擎？" | 知识查询 | 知识检索+代码结构关联 | 否（本地回答） |
| 4 | "你和小林是什么关系？" | 关系查询 | 身份认知+关系推理+情感 | 否（本地回答） |
| 5 | "简单介绍一下你自己" | 身份确认 | 自我画像综合+多节点融合 | 否（本地回答） |

**验收标准**：
- 分类准确率≥80%（5个中至少4个分类正确）
- 本地回答率≥50%（5个中至少3个本地回答）
- 不再全部走knowledge_retrieve路径

### 步骤3：QICA 8通道并行验证

1. 输入测试问题后，检查日志中是否有8通道并行计算的日志
2. 确认各通道都有输出（关键词/语义向量/扩展思维/实体/句式/上下文/复杂度/历史反馈）
3. 确认融合决策层有置信度计算日志
4. 确认动态路由选择了最高置信度路径

**验收标准**：
- 8通道全部正常工作，无异常
- 融合决策层置信度计算正常
- 动态路由选择合理

### 步骤4：语义扩展质量验证

1. 输入"什么是五维共振？"等知识类问题
2. 检查语义关系扩展日志
3. 确认扩展结果中不再有污染节点（如"用多步多维度 分析一下量子..."）
4. 确认扩展质量过滤日志正常输出（候选数→过滤后数→各过滤原因）

**验收标准**：
- 语义扩展不再命中污染节点
- 过滤日志正常输出
- 扩展结果质量明显提升

### 步骤5：QICA相关度修复验证

1. 输入"你和小林是什么关系？"
2. 检查QICA路径检索相关度日志
3. 确认相关度不再为0.00
4. 确认关系类问题相关度≥0.3

**验收标准**：
- 关系类问题相关度≥0.3
- 相关度计算日志正常输出（字面重叠分+语义相似度分+最终得分）

### 步骤6：B2策略接线验证

1. 输入多个不同类型的问题
2. 检查B2策略执行日志
3. 确认QICA建议方法被实际执行（而非仅记录）
4. 统计策略建议执行率

**验收标准**：
- B2策略建议执行率≥60%
- 策略执行日志正常输出（建议方法→实际方法→是否采纳→原因）

### 步骤7：多节点融合本地化验证

1. 输入"简单介绍一下你自己"等需要多节点融合的问题
2. 检查多节点融合日志
3. 确认使用了本地融合算法（而非直接调用大模型）
4. 确认融合方式日志正常输出

**验收标准**：
- 多节点融合本地融合率≥70%
- 融合方式日志正常输出（使用了哪种融合方式+各节点贡献度）

### 步骤8：回归测试验证

1. 运行路灯提供的单元测试
2. 确认所有测试通过
3. 运行回归测试
4. 确认无新增失败

**验收标准**：
- 单元测试≥35个，全部通过
- 回归测试全部通过
- ruff F类错误=0

### 步骤9：兼容性验证

1. 关闭`ENABLE_QICA_MULTI_CHANNEL`开关
2. 重启框架
3. 确认QICA行为与改造前完全一致
4. 重新开启开关

**验收标准**：
- 开关关闭时行为与改造前一致
- 无功能回退
