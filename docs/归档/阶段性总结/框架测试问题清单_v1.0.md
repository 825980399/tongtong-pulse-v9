## 日志验证要点

输入问题后，检查日志中以下关键点：

| 验证项 | 日志关键词 | 预期结果 |
|--------|------------|----------|
| 本地回答 | `simple_query_local` / `本地回答` | 简单问题应本地回答 |
| 大模型调用 | `llm_used=True` / `转大模型` | 复杂问题才调用大模型 |
| 语义理解置信度 | `confidence=0.XX` | 简单问题应>0.7 |
| 百科查询 | `WikiQuerier` / `wiki通道` | 百科类问题应触发 |
| 知识检索 | `共振引擎` / `向量检索` / `top_k` | 知识类问题应触发 |
| 多步推理 | `多步规划` / `multi_step` | 复杂推理应触发 |
| 身份认知 | `IdentityKnowledgeManager` / `身份` | 身份类问题应触发 |
