## 十四、关键系统链路

### 14.1 对话主链路
```
用户输入 → 耳朵/控制台 → PulseLung(肺·大模型调用) → PulseInnerWorld(内在世界·推理)
    → PulseCortex(皮层·决策) → PulseMouth(嘴巴·输出) → 用户
```

### 14.2 知识消化链路
```
信息输入 → PulseStomach(胃·消化) → KnowledgeTree(知识树) → PulseNodePool(节点池)
    → 经验提取 → experience_pool.json(经验库)
```

### 14.3 自我进化链路
```
代码问题检测 → PulseCodeLearner(代码学习) → 补丁生成 → PatchManager(补丁管理)
    → 验证 → 应用 → 进化闭环
```

### 14.4 脉冲分发链路
```
器官产生脉冲 → InfoField(信息场) → 路由分发 → 目标器官处理 → 响应脉冲
```
