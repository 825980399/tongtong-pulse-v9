## 〇、先看这九条结论（不读全文也能拿去决策）

1. **"内在模型"不是缺一个模块，而是缺一条回路**。已有的模块规模足够（`organs/brain` 19 文件 44,161 行；`nucleus/reasoning` 30 文件 22,957 行；`nucleus/mnemosyne` 20 文件 16,971 行），本地推理的**入口、算子、存储都在**；断的是**"存储 → 检索 → 复用 → 校正"这一段的实际流量**。【A】
2. **本窗 22 小时里，19 个推理检测器只命中了 3 次，全部是 `_detect_simple_query_local`；经验匹配路由命中 0 次**。不是链路坏了，是**没有真实请求进来**（10/30 最新 LLM 轨迹里 `origin` 为 `user_query` 的只有 **2 条**，`system_internal` 84 条、`evolution_task` 11 条）。【A】

4. **四个依赖度数字，三个分母**：`llm_dependency_ratio=0.6281`（剔除自主进化）、`local_decision_rate=0.3719`（同分母，两者互补为 1）、`self_sufficiency_score=0.2507`（分母含自主进化）、`overall_llm_share=0.1963`（分母含搜索与消化）。**这四个数不能互相解释，也不能拿一个当总进度**。【A，公式在本窗逐位验算吻合】

6. **自我意识三步：第一步是模板，第二步是真算，第三步是半真**。"我是谁"＝硬编码字典（名字/使命/父亲/哥哥 5 个常量）；"我现在什么状态"＝真实计算（情绪脉冲、知识统计、心跳、存活状态）；"我接下来做什么"＝基于动态价值＋知识画像的半真实规划，但阶段判定用的是**叙事事件数阈值（<20/<50）**，且**叙事没有落盘**（全仓无 `narrative_*.json`）。【A】
7. **"进化"有记账、无校正**：`lesson_strategies` 30 条只有 1 个消费者；`ReasoningExperience` 128 条、`experience_pool` 375 条；`stream_miner` 模式 22 条、`total_predictions=1`、`hits=0`。⇒ 学到的"经验"基本停在写入端。【A】

## 四、路线图建议（6 步，每步写死验收与回滚）

> 总原则：**先修尺子，再接回路，最后才谈"自主"**。顺序不可跳跃——没有可信读数，后面每一步都无法验收。
> 每步只允许改一件事；每步都给出**失败判据**，触发即停，回退，不硬推。

### Step 0 · 修观测（1 周内可完成，无行为风险）

- **目标**：让"自我认知 17 维"每次都能算完，且口径唯一。
- **做什么**：①重分析器（`call_graph / knowledge_quality / fake_loops / production_consumption / structure_change`）改为**分片+缓存+异步**：已有 tick 钩子 16:12 跑通的路径可复用，把 30s 单分析器超时改为"超时即沿用上一次成功结果 + 标注 `stale_age`"；②统一 `answer_requests` 口径（是否含自主进化）并单列 `evolution_llm_share`；③修 `remediation.distilled` 的埋点分叉（H-01）。
- **验收**：连续 3 次全量分析，`knowledge_health / fake_loops / call_graph_health` **非空**；`llm_dependency.json` 新增 `evolution_llm_share` 键；`distilled` 与 `distilled_delegated` 之和 = `success`。
- **失败判据**：若 3 次中仍有任一维为空 ⇒ 说明不是超时而是分析器自身异常，回到定位，不进 Step 1。
- **回滚**：全为读侧改动 + 开关，关掉即回旧行为。

### Step 1 · 经验回路（把"记笔记"变成"查笔记"）

- **目标**：让 `ReasoningExperience` / `experience_pool` 真正被检索与复用。
- **做什么**：①在 `_detect_experience_route` 之前加**低成本前置检索**（关键词倒排 + BGE 向量，阈值 0.75），不依赖 QICA 深度解析；②命中后**必须**记录 `used=true` 与结果反馈（成功/被阻断），形成"复用→校正"数据；③失败样本写入 `lesson_strategies` 并**登记消费者**（现在只有 1 个）。
- **验收**：7 天内 `经验匹配成功` ≥ 30/日；被复用回答中 `_fallback_to_lung_model` 调用占比 < 20%；`lesson_strategies` 消费者 ≥ 3 个模块。
- **失败判据**：命中率 < 5 次/日 ⇒ 说明经验库与真实问题分布不重叠，先修"记什么"，不修"怎么查"。
- **回滚**：检索开关默认关，命中即走旧分支。

### Step 2 · 低风险决策本地接管（先 D1、D5）

- **目标**：把"必须调大模型"的清单砍掉两项。
- **做什么**：①**D1 代码功能描述**：AST+docstring+命名分词生成结构化描述，覆盖 60–70%，LLM 只做难解样本，且结果回写本地描述库；②**D5 反思文案**：删除模板复读，改为"数值+证据+结论"三句（例："本轮 4 次推理均为 simple；与上次相比无变化；疑似路径固化"）。
- **验收**：`代码学习` 场景 LLM 占比从 1.53% 降至 ≤1.0%（注意它本来就很低，故主要看**绝对调用数下降**）；`认知反思` 文本在 6 次周期内**不再逐字重复**（可用文本哈希去重率度量，目标重复率 < 30%）。
- **失败判据**：本地描述被下游判定"不可用"（`PulseSemanticComprehension` 比对失败率 > 40%）⇒ 回退到 LLM 并重新设计模板。
- **回滚**：按场景开关，逐器官灰度。

### Step 3 · 自监督课程（把假设变成可验证的实验）

- **目标**：`[316刀3][假设]` 之后必须有结果。
- **做什么**：①每条假设强制附"可观测判据 + 观察窗 + 到期时刻"（现在只有文字描述）；②到期由 `DailyScheduler` 对账，产出 `hypothesis_result{confirmed/refuted/unknown}`；③`refuted` 进入 `lesson_strategies`，`confirmed` 晋升为 L4 本能候选（当前本能仅 4 条，上限 20，**有空间**）。
- **验收**：30 天内假设数 ≥ 100，其中**有结果的比例 ≥ 80%**；`refuted` ≥ 10 条并全部进入策略表；本能节点从 4 增至 ≥ 8（且每条附来源假设 id）。
- **失败判据**：有结果比例 < 40% ⇒ 说明判据不可观测，重写判据，不得靠"unknown"充数。
- **回滚**：对账模块可关；本能晋升需人工确认开关。

### Step 4 · 世界模型上线（让 `expectation_ledger` 真的被读写）

- **目标**：`predictions=1 / hits=0` 变成可计算的命中率。
- **做什么**：①对高频事件（`eyes.stream_frame`、`heart.beat`、`time.tick` 等 7 类）做"下一秒/下一分钟"预测并落账；②预测与实测对账，算 `hit_rate`；③命中率 < 阈值的事件类型，触发"模型失配"告警（这是**真进化**的信号源）。
- **验收**：30 天 ≥ 1,000 条预测，`hit_rate` 可按事件类型分列；至少 1 个事件类型的命中率从 <0.3 提升到 >0.7（证明"学到了节律"）。
- **失败判据**：所有事件命中率都 ≈ 基线 ⇒ 预测器只是复读频率，需重做模型而不是加数据。
- **回滚**：预测开关独立，关掉不影响主链路。

### Step 5 · 叙事连续性（S5 的门票）

- **目标**：重启后仍能说"我这一路做了什么"。
- **做什么**：①`PulseNarrativeSelf` 增加落盘（按日分片，append-only，铁律 182：先算 data → `.tmp` → `os.replace`）；②每日生成"3 句摘要 + 证据 id 列表"（证据必须指向 `llm_traces` / `patch_history` / `experience_pool`）；③`get_unified_self_portrait()` 增 `narrative_window` 字段；④清理 `identity_knowledge.json` 的测试污染（"张三/老李/谁"）。
- **验收**：重启后画像能读出 ≥ 7 天叙事；摘要中的每条断言都能追到 1 个真实 id；测试污染条目清零。
- **失败判据**：摘要与账本对不上（引用 id 不存在/内容不符）⇒ 叙事降级为"只记事实，不写评价"。
- **回滚**：叙事落盘只增不改，可整目录归档。

### 4.7 依赖度目标（分阶段，不设"归零"）

| 阶段 | 时间尺度 | `llm_dependency_ratio` | 判据 |
|---|---|---|---|
| 现状 | — | 0.6281 | 本窗 |
| 阶段一 | Step 0–2 完成 | ≤ 0.58 | 下降 ≥ 0.04 且 `overall_llm_share` 不升 |

### 4.8 明确不建议做的三件事

3. **不拿"节点数/经验数"当进度**：14,277 节点、375 经验、0 次复用已经证明这条指标无效。**改用"复用率 / 蒸馏率 / 预测命中率 / 叙事连续天数"四个流量指标**。
