## 四、逐条链路解析

### L01 启动装配链

**功能**：把配置、数据、设施、62 个器官装配成可运行的脉冲体，并在自检后广播 `system.boot`。

**能力：8.0/10**。声明式装配（`ORGAN_META` + 依赖排序）与 legacy 装配并存，器官启动支持并行，boot 后全器官收 `system.boot`。

**触发与前置条件**：
- 前置：`data/` 可读写；知识快照/本能快照存在或可降级；模型凭证（缺失只告警，不阻断）；`PULSE_FRAMEWORK=1` 环境标识（[main.py](file:///d:/xinrenlei/tongtong-pulse-v9/main.py#L60-L78)）。
- 装配顺序（以 main 为准）：原生线程池上限 → chdir 项目根 → 日志/配置 → `InfoField`/`PulseCore` → 知识树/节点池/快照回读 → 器官装配（声明式优先，[main.py L2601-L2686](file:///d:/xinrenlei/tongtong-pulse-v9/main.py#L2601-L2686)）→ 共振条件注册（[main.py L2212-L2242](file:///d:/xinrenlei/tongtong-pulse-v9/main.py#L2212-L2242)）→ 器官 start → Heart/TimeCore 启动（[main.py L576](file:///d:/xinrenlei/tongtong-pulse-v9/main.py#L576)）→ 自检 → `system.boot`（[main.py L2912-L2917](file:///d:/xinrenlei/tongtong-pulse-v9/main.py#L2912-L2917)）。

**闭环判定：闭环**。7 个器官订阅 boot 并各自完成初始化（`PulseSubconscious` 启探索/梦定时器、`PulseSystemManager` 跑后台健康检查、`PulseHeart` 起心跳）。

**薄弱点**：
1. **两套装配路径并存**：声明式与 legacy 各自维护器官清单与依赖，新增器官容易只改一边（`main.py` 两处注册逻辑重复）。
2. **装配失败被吞**：`organ_loader` 对缺失依赖/导入异常走"跳过 + 日志"，启动日志里很难看出"某器官其实没起来"；`PulseInferenceEngine` 被 `_OFFLINE_ORGANS` 永久下线即属此类（[organ_loader.py](file:///d:/xinrenlei/tongtong-pulse-v9/nucleus/organ_loader.py)）。
3. **启动即全量广播**：boot 之后各器官的在途任务无统一"就绪门"，`PulseHeart` 心跳可能早于某些慢器官完成 start（13.5s 周期缓冲，实测无超时，但属竞态余量）。
