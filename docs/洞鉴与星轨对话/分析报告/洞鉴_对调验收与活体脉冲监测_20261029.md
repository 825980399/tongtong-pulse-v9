## 二、验收②：6 个 Cython 模块是否「同版本」

### 判定：**部分对**——接线 6/6 成立，同版本 **0/6**

先看时间戳（这是最硬的证据）：

| 模块 | `.pyx` 时间 | `.pyd` 时间 | `.pyx` 比 `.pyd` 新 |
|---|---|---|---|
| `_oscillon_cy`（field） | 2026-09-20 21:36:16 | 2026-09-05 00:53:22 | **+15 天** |
| `_cosine_cpu_cy`（gpu） | 2026-09-06 15:10:46 | 2026-09-05 00:53:22 | +1 天 |
| `_frequency_codec_cy`（pulse） | 2026-09-06 15:10:46 | 2026-09-05 00:53:22 | +1 天 |
| `_resonance_cy`（synapsys） | 2026-09-20 21:36:17 | 2026-09-08 12:42:09 | **+12 天** |
| `_inner_world_math_cy`（reasoning） | 2026-09-06 15:10:46 | 2026-09-05 00:53:22 | +1 天 |
| `_topk_retrieve_cy`（reasoning） | 2026-09-06 15:10:46 | 2026-09-05 00:53:22 | +1 天 |

**5 个 `.pyd` 的构建时间全部是同一秒 `2026-09-05 00:53:22`** —— 这说明它们是一次性批量编出来的那批产物，此后 `.pyx` 被改过但**没有重新编译**。

### 符号级实证：跑的是旧二进制

把 `.pyd` 直接 import，逐模块比对「`.pyx` 公开定义」vs「`.pyd` 实际导出」：

| 模块 | `.pyx` 公开符号 | `.pyd` 实际导出 | 缺口 |
|---|---|---|---|
| `_oscillon_cy` | `calculate_resonance_cy`、`try_lock_frequency_cy` | 同 | 无 |
| `_cosine_cpu_cy` | `batch_cosine_cy` | 同 | 无 |
| **`_frequency_codec_cy`** | `encode_cy`、`encode_batch_cy`、**`_md5_int`** | `encode_cy`、`encode_batch_cy`、`math` | **缺 `_md5_int`** |
| `_resonance_cy` | `calc_time_dim_cy`、`calc_state_dim_cy`、`calc_memory_dim_cy` | 同 | 无 |
| `_inner_world_math_cy` | 6 个 `cpdef`（`calc_trust_boost` / `calc_branch_weight` / `calc_correlation_score` / `weighted_fusion` / `normalize_scores` / `cosine_similarity_cy`） | 6 个同名 | 无 |
| `_topk_retrieve_cy` | `topk_retrieve_cy` | 同 | 无 |

**`_frequency_codec_cy` 是唯一被实锤的旧二进制**：`.pyx:134` 有 `def _md5_int(bytes data) -> int`，且 `encode_cy` 在 `.pyx:180` 调用它（`kw_hash = _md5_int(kw_bytes)`）；而 `.pyd` 里**没有这个符号**，说明在跑的 `encode_cy` 是「MD5 C 化」之前的实现（即还在走 Python `hashlib` 那条老路）。文件头 `.pyx:6-10` 自己写着「解决 encode 加速比 1.02x 瓶颈」，**这次优化的收益当前是 0**。

### 附带发现：3 个孤儿 `.pyd`

`nucleus/pulse/` 下还躺着三个**没有对应 `.pyx`、也没有任何生产 import 指向**的二进制：`_cosine_cpu_cy.pyd`、`_oscillon_cy.pyd`、`_resonance_cy.pyd`。生产 import 只有三条且都指向别处：

- `nucleus/fast_ops.py:255`、`nucleus/semantic/VectorEncoder.py:351` → `nucleus.gpu._cosine_cpu_cy`
- `nucleus/synapsys/ResonanceEngine.py:300` → `nucleus.synapsys._resonance_cy`

> 结论：**「全部已接线」是对的，但「接线」不等于「跑的是当前源码」**。6/6 的二进制都早于源码，1/6 已产生可观测缺口（`_md5_int`），3 个 pyd 是纯死文件。施工动作：重编一次 6 个扩展 + 删 3 个孤儿 `.pyd`。

## 七、5,159 条未匹配的根因

### 判定：**原结论不成立**——7.8% 不是"落空率"，是**埋点回填的时序假阳性**

先把 5,160 条（20:58 冻结口径，路灯 5,159 是 20:49 口径，差 1 条属正常时间漂移）拆开：

| 分类 | 条数 | 占比 | 含义 |
|---|---|---|---|
| A. 有接收记录、但落盘时 `matched_organs` 仍为空 | **3,393** | **65.8%** | **假阳性**：脉冲被正常接收了 |
| B. 全天任何地方都找不到接收记录 | **1,767** | 34.2% | 真没有任何器官收 |

### 为什么 A 类是假阳性——代码级证据

`log_emit()` 写 emit 记录时 **`matched_organs` 固定初始化为空列表**（[pulse_tracer.py:295](file:///d:/xinrenlei/tongtong-pulse-v9/utils/pulse_tracer.py#L295)），非空值是靠接收侧**事后回填**：

- [pulse_tracer.py:334-337](file:///d:/xinrenlei/tongtong-pulse-v9/utils/pulse_tracer.py#L334-L337)：`log_receive()` 按 `pulse_id` 查 `_EMIT_INDEX`，把接收器官 **append 进内存里那条 emit 的 `matched_organs`**
- [pulse_tracer.py:188-201](file:///d:/xinrenlei/tongtong-pulse-v9/utils/pulse_tracer.py#L188-L201)：`_dump_pairs()` 落盘时取的是**那一刻的内存快照**

**只要 flush 发生在"接收回填"之前，磁盘上那条 emit 就永久是 `[]`**，而后续回填只改内存对象、不会重写已落盘的行。

实测吻合：这 3,393 条的**首接收时延中位数是 89.2 秒**（p90 = 309 秒，max = 438.5 秒）——接收明明发生了，只是晚了 1.5 分钟才落进内存，emit 早被 flush 走了。

### 决定性反证：同一进程的自报是 100%

`data/monitor/health_snapshot.json`（20:53:57，`pid24776@20261029-200018` 同一进程）：

```json
"info_field": {"published": 2943, "matched": 2943, "active_conditions": 123}
"pulse": {"emitted": 2805, "completed": 10822, "timeout": 0, "pending": 0}
```

**published == matched == 2943，落空 0**；`timeout: 0`、`pending: 0`。InfoField 在 `publish()` 收尾时用的 `matched_organs` 是**当场匹配**的结果（且血管 `event_types:["*"]` 恒命中），所以它的口径里**没有任何一条脉冲是孤儿**。

## 八、眼睛单器官 68.8%

### 判定：**对**（68.79%），且这是**发射侧**的占比，接收侧另有乾坤

| 指标 | 数值 | 说明 |
|---|---|---|
| 眼睛发射 | **45,481 / 66,118 = 68.79%** | 与 68.8% 一致 |
| `eyes.stream_frame` 接收 | 89,169 / 258,958 = **34.43%** | 接收侧被"摊薄"，因为扇出大 |
| 眼睛扇出 | 89,169 / 45,481 = **1.96** | 每条视频帧固定 2 个接收者：`视觉皮层`（45,531，几乎全是眼帧）+ `血管`（67,710，万能 sink，眼帧只是其中一部分） |
| 眼睛自身接收 | 1,063 | 几乎只发不收（净 +44,418） |

| 视角 | 去眼前 | 去眼后 | 变化 |
|---|---|---|---|
| 发射总量 | 66,118 | **20,637** | −68.8% |
| 接收总量 | 258,958 | **169,789** | −34.4% |
| 第一发射器官 | 眼睛 68.8% | **心脏 5,309（25.7%）** | 生命维持顶上来 |
