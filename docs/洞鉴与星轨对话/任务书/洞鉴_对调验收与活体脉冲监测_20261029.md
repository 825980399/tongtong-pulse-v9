## 任务

### 第一部分：对调验收（核对路灯392的发现）

路灯392报告里有几条关键结论，你作为第三方独立验收：

1. **409个生产文件 / 25.9万行的盘点**：随机抽10个文件，验证行数/类数/函数数对不对。
2. **6个Cython模块全部已接线**：逐个验证 `.pyd` 和 `.pyx` 是否同版本（运行的是不是旧二进制）。
3. **3套调度器同被main装配**：去 `main.py` 里找证据，验证是不是真的同时装配。
4. **脉冲流量实测**：今日325076行pulse_pairs——你自己跑一遍统计，看数字对不对。

### 第二部分：活体脉冲监测分析

从 `data/monitor/pulse_pairs_20261029.jsonl` 里做活体脉冲监测分析：

1. **器官活跃度热力图**：57个器官，每个的发射次数/接收次数/净流量，哪些是"话痨"哪些是"哑巴"？
2. **闭环链路实测**：生命维持环/脉冲突发环/补丁闭环/决策环/自知环——每一环的实际脉冲流量是多少？哪里流量最大哪里断流？
