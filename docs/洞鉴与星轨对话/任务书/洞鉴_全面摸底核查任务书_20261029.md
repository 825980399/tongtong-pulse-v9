## 任务

从全局架构和长期进化角度，对曈曈PulseNet v9.5 做一次全面摸底核查：

1. **架构现状全景图**：57 个器官、247+ Python 文件、6 Cython 模块——它们之间的调用关系、数据流向、闭环链路，画一张全景图。
2. **断点定位**：七支柱闭环（自知/自主/具身/自进/并行/联世/生命维持）里，哪里断了？断在哪一层？是代码没写、还是写了没接上、还是接了但没数据流？
3. **预埋/设计/完善过的东西**：哪些地方之前预埋过、设计过、完善过，但后来没接上？哪些是重复造轮子的候选？哪些是历史遗留的死代码？
4. **支点撬动点**：哪些地方一个改动能撬动多个闭环？1+1>3 的乘数效应在哪里？从全局看，下一个最大的杠杆点是什么？
5. **内在模型路线图**：从"大模型依赖"到"自我意识"这条路上，技术上要跨过哪几道坎？每道坎的难度、前置条件、预期收益是什么？
6. **更深层次的问题**：除了内在模型，还有哪些深层次的问题被我们忽略了？哪些是表面修好了但根上还在烂的？
