**洞鉴深度评估**：

| 评估项 | 结论 | 依据 |
|---|---|---|
| 对长稳窗验证的价值 | **高，但非紧迫** | 超算验证的是"极端降级环境容错"，本地长稳窗已覆盖常规稳态；超算独有价值是 DCU/无密钥/无 Cython 三降级叠加态 |

| 与本地长稳窗的关系 | **互补不替代** | 本地长稳窗验证常规稳态；超算验证极端降级态。173 长稳窗已证本地稳态正确，超算侧线验证降级叠加 |

| 1 | 若为同机多实例 | 185+ 共享知识层（L3/L4 放共享目录，L1/L2 留实例私有）+ 文件锁 |

**优先级**：**待定（依赖裁定）**——先提请小林明确定义，再决定优先级。当前不建议盲目立票。

### 2.6 补充方向：脉冲仿生 6 方向（来自暂缓考虑文档）

`脉冲仿生前沿技术借鉴_补充分析_v1.0.md` 提出 6 个方向，与建设期高度相关：

| 方向 | 对应现有模块 | 成熟度 | 建议阶段 |
|---|---|---|---|
| 主动推理/自由能原理 | 存续意志+存续状态指数 | 人格化表达，缺数学化 | PHASE18 核心（建设期第二阶段） |
| 内稳态可塑性 | 心跳调度+雪崩熔断 | 有雏形，缺设定点 | PHASE18 核心 |
| 超维计算 HDC | bge 向量语义内核 | 有向量，缺 HDC 结构 | PHASE18 探索（可与 OscillonField 联动） |
| 三因子学习 | 赫布学习器 | 有单因子，缺三因子 | PHASE18 增强 |
| 经验重放/睡眠巩固 | compaction+快照 | 有合并，缺重放 | PHASE17 优化（可近期做） |
| 开放式演化 | 自主进化+兴趣模型 | 有目标，缺新奇度 | PHASE19 远期 |

**洞鉴建议**：经验重放/睡眠巩固（方向5）可在 184-185 做——compaction 就是睡眠巩固的工程实现，补全经验重放成本低、收益高。自由能原理+内稳态可塑性（方向1/2）作为 PHASE18 核心，在认知反思+人格稳定之后推进。

### 3.3 风险面（技术债清完后可能新引入的风险）

| 风险 | 说明 | 缓解 |
|---|---|---|
| **建设膨胀** | 还债期结束后易"什么都想建"，刀数失控、回归面扩大 | 严守"评估闭环优先"原则：未接通消费链的能力不立项；每批刀数软上限 12 |
| **设计壳复活** | PHASE18 19 开关中 17 个为设计壳，盲目通电重演"以为接好实际空"事故 | 每个开关通电前必须有消费点审计（参考洞鉴 10-08 InfluxDB 教训） |
| **人格漂移** | 建设期新能力（子代理、自我修改）冲击人格稳定性 | 人格版本化回归测试集作为门禁，一致性 <90% 时阻塞新能力合入 |
| **补丁放权陷阱** | 修复率提升后易倾向"自动应用更多补丁" | 不可逆清单红线不动摇；核心代码人工审批至少维持到修复率>80% 且连续 3 批无回滚 |
| **子代理安全面** | SUBAGENT 态在 O-B1 策略面未实装前抢跑 | SUBAGENT 态必须等 O-B1 三层策略面实装+灰度验证后才放行 |
| **指标虚高复燃** | P0-4（质量分虚高）刚修复，建设期易引入新的"看起来很好"的指标 | 所有新指标必须带"分子/分母"双报，禁止纯比例指标 |
| **God Class 继续膨胀** | PulseInnerWorld 主文件仍 1.7 万行，建设期新能力可能继续堆入 | 严守 mixin 拆分纪律（`PulseInnerWorld架构与维护指南.md`），新方法入对应 mixin 不回主文件 |
| **预埋点不闭环** | 预埋设计原则要求"每修一个问题为下个设计做铺垫"，但预埋点可能不被实际使用 | 建立"预埋点审计"机制，定期检查已识别的预埋点是否被实际使用 |

### 3.4 建设期核心原则（从已有设计文档提炼）

1. **评估闭环优先**（路线图维度0）：未接通消费链的能力不立项
2. **预埋式演进**（`预埋设计原则`）：修一个问题时看到下三个问题，顺手把路修好
3. **不重复造轮子**（PHASE18 自我认知引擎）：整合现有 26 个分析模块输出，不重新实现
4. **三层深度分析**（预埋设计原则）：直接根因→关联影响→前置铺垫
5. **渐进式灰度**（经验库防污染/补丁自应用）：G0 关→G1 观测→G2 软拦截→G3 硬拦截
6. **双门槛安全门**（补丁自应用）：风险+信任双门槛，总开关在热重载黑名单
7. **mixin 拆分纪律**（PulseInnerWorld 维护指南）：新方法入对应 mixin，不回主文件
8. **anchor 规范**：补丁脚本锚点必须包含装饰器行，唯一性断言不可省
