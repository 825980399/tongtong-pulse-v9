## T5 发布 SOP 固化（三平台统一）

```
① 扫(scan)   ：git 跟踪全文件 × (静态4+属主4含生日) + **commit 对象**（%ae/%ce）+ remote URL
② 掩码(mask) ：同一 7+1 规则装载点 + 同一反转义读法（防"输出前掩码"假门）
③ 导出(export)：tools/export_public.py（fail-closed 白名单）→ 生成 dist
④ 复算(verify)：对 dist 独立复扫 8 规则 = 0；对 git HEAD 复扫 = 0
⑤ post(push) ：三平台 push（openi/gitee/github）
⑥ 远端验(fetch)：git ls-remote 后 clone 抽检 —— **doc 内容 + commit author + remote URL** 三项
失败回退：任一步非 0 → 停止；已 push 的用 git filter-repo 重写 + 强推（须三方确认）
```
