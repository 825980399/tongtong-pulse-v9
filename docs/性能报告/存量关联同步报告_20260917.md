## 4. 增量同步与一致性监控（接口已就位，需 live Neo4j 运行）

第71批已在 `PulseNodePool` 提供以下接口，本批同步逻辑与之衔接：
- `sync_node_relationships(node_id)`：单节点关系增量同步（双写开启时调用）。
- `full_consistency_check()`：全量一致性检查（采样热/温节点，对比池与 Neo4j）。
- `get_dual_write_stats()` / `check_consistency(node_id)`：单节点级一致性。
- `import_nodes_to_neo4j.py` 支持 `--mode incremental` / `resume`（断点续传 checkpoint）+ `--require-real`。

本批新增 `verify_neo4j_sync.py` 在真实服务可用时可用 `--backend real` 直接对 Neo4j 做节点数/关系数/属性三方比对。

## 6. 真实落库待办（需用户配合）

1. 安装 Neo4j（Community/Enterprise）并启动（bolt://localhost:7687）。
2. `python tools/setup_local_databases.py install-drivers` 安装驱动。
3. `python tools/setup_local_databases.py init-neo4j` 建约束与索引。
4. 真实全量同步：`python tools/import_nodes_to_neo4j.py --source pool --mode full --require-real`
   （live 框架需注入节点池；或导出 Parquet 为 JSON 后 `--source <file>.json --require-real`）
5. 验证：`python tools/verify_neo4j_sync.py --backend real`
6. 一致性巡检：`PulseNodePool.full_consistency_check()`。
