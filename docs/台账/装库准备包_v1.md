# 装库准备包 v1（第121批 T-121c）

> 编制：路灯　｜　批准：星轨
> 生效：2026-09-24　｜　适用：曈曈 PulseNet dlib/face 装库（W5 合并窗）
> 定位：本批**只做装库准备**，不执行装库。装库动作留待 W5 重启窗，由星轨/小林操作。

## 0. 准备就绪确认（T-121c 实测）

| 检查项 | 现值 | 阈值 | 结论 |
|---|---|---|---|
| setuptools 版本 | 81.0.0 | <82 | ✅ 已钉 |
| dlib-bin 版本 | 20.0.1 | 20.0.1 | ✅ 在位（import dlib 通过） |
| face* 零条目 | data/identity 不存在；ENABLE_FACE_WELCOME_DIRECT=False | 装库前=0 | ✅ 零条目（诚实态，与 B17 一致） |

## 1. 装库时序（W5 一次重启窗）

1. 钉 setuptools<82（已满足，勿升级）。
2. `pip install dlib==20.0.1`（dlib-bin 已缓存/在位，离线优先）。
3. 冒烟 import：`python -c "import dlib, face_recognition"` 必须无异常。
4. 启动框架（小林手动重启）。
5. 进入 T+0 / T+5min / T+1h 三段验证。

## 2. T+0 验证（boot 即时）

| 判据 | 命令/来源 | 期望 | 异常处置 |
|---|---|---|---|
| 人脸识别=有 | `grep -a "人脸识别=" logs/pulse.log \| tail -3` | boot 后出现 `人脸识别=有`（库已装） | 仍 `无` → 装库失败/路径错，回滚 |
| boot 时间增量 | boot 行时间戳 | 较上次重启有增量（非冻结） | 冻结 → 看 B2 快照链 |
| 完整率 7/7 | `grep -a "\[boot完整率\] 订阅者=" logs/pulse.log` | 含逐器官终态，心脏=handled | 无此行 → audit 线程未起（B3） |

## 3. T+5min 验证（短窗稳定）

| 判据 | 命令/来源 | 期望 | 异常处置 |
|---|---|---|---|
| ERROR 滑窗 | `grep -ac "ERROR" logs/pulse.log`（近5min，排除 face 无关） | 无新增 face 相关 ERROR | 新增 → 看 face 模块栈，回滚 |
| RSS 增量 | 进程 RSS 采样 | 装库后 RSS 增量在预期范围（非暴涨） | 暴涨 → 内存泄漏，回滚 |
| presence 复现 | `grep -a "SWITCHED" logs/pulse.log` | 有人出现时 SWITCHED 发射，`current_user=访客` | 仍"小林" → 回 B19 九锚 |

## 4. T+1h 验证（长窗观测）

| 判据 | 命令/来源 | 期望 | 异常处置 |
|---|---|---|---|
| 影子行增数 | `grep -ac "\[face_welcome影子\]" logs/pulse.log`（ENABLE_FACE_WELCOME_DIRECT=True 时） | 出现且计数随识别增长 | 0 行且开关开 → 条件写反（B18） |
| _fc 计数 | face 特征计数指标 | 进入真实识别后递增 | 恒 0 → 识别未接通 |
| 误报人审 | 人工抽检 welcome 日志 | 误报率可接受 | 高误报 → 调 tolerance_override，回滚 |

## 5. 回滚命令清单

- 卸载：`pip uninstall -y dlib face_recognition`（保留 setuptools 81.0.0）。
- 关开关：`config.ENABLE_FACE_WELCOME_DIRECT=False`（装库前默认已 False）。
- 还原快照：若识别污染数据，从 `.bak_batch*` / 外介质恢复 `data/`（**当前 data/identity 不存在，无需还原**）。
- 重启回退：重启框架使开关/库状态生效，回 B1–B4 生死组复验。
- 紧急止损：若 RSS 暴涨或 ERROR 雪崩，直接停止框架进程，按上一步卸载。
