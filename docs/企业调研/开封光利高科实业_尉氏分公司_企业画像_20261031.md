## 一、一句话结论

**这不是一家独立公司，而是国家电网体系内、由国网河南省电力公司 100% 控股的集体企业（原"三产"）在尉氏县设的分支机构。** 它自身不具独立法人资格、无独立资质，承接能力靠母公司；母公司资质齐、业绩稳、中标活跃，但**涉诉量偏大、且被执行记录仍在持续新增**——合作前需要区分"这是电力系统的嫡系分包口"和"这家主体自身的偿债与涉诉状况"两件事，不能混着看。

```
       └─ 100% ─ 国网河南省电力公司
            └─ 100% ─ 开封光利高科实业有限责任公司
                 └─ 分支机构 ─ 尉氏分公司（及兰考、杞县、通许、祥符 4 家）
```

- 股东仅 1 位：**国网河南省电力公司，持股 100%，出资额 13,972.6 万元，投资日期 2020-07-15**
- 疑似实际控制人：**国务院国有资产监督管理委员会**，最终持股 100%，控制层级 3 层
- 企业性质标注：**国有企业 / 纯国有企业**；规模划型：**中型**；纳税人资格：一般纳税人，纳税信用 **A 级**

**这一条决定了它的商业逻辑**：它不是市场化竞争的民营施工队，而是国网河南电力在开封地区的**原集体企业（省管产业单位）**，主要业务来源是母公司系统内的电网基建、技改大修、运维服务。这也解释了下一节的现象。

同一母公司下的兄弟分支：兰考（2018-09-27，许保）、杞县（2018-09-25，杨磊）、通许（2018-09-21，娄辉）、祥符（2017-11-16，王坡）均开业；物业、电力洗浴、广告、开关、客户用电服务 5 家已注销。

### 4.1 2025-07-14 经营范围大改（重要变更节点）

| | 变更前（旧口径） | 变更后（现行） |
|---|---|---|
| 核心表述 | 高低压电器及成套设备、环网柜、开关柜、计量箱/柜的**设计、制造、加工、安装、销售** | 转为**许可项目 + 一般项目**的规范化表述 |

| 新增 | — | **通用航空服务**、文件资料印刷、餐饮服务 |

### 4.2 现行主营（按业务实质归并）

### 7.4 怎么读这组数字
1. **"被告 137 次"不是道德问题，是行业结构问题。** 电力施工企业作为发包方/总包方，被分包商、材料商、劳务队起诉是常态；36 条买卖合同纠纷基本都是材料款、租赁费、分包结算争议。案由结构（买卖 + 建设工程）印证了这一点，而不是民间借贷、担保代偿这类恶性信号。
2. **但"被执行持续新增"必须当信号看。** 2026 年 7 月、9 月、10 月连续三条新执行（含一条在尉氏县法院），说明**现金流是紧的**。这类省管产业单位的典型特征：活是系统内派的，钱是系统内结的，但结算周期长，一旦上游拨款延迟，下游分包商就先起诉。
3. **没上失信名单，说明不是"赖账"，是"周转不过来"。** 这两者对合作方的影响完全不同：前者是信用破产，后者是账期风险。
4. **分公司自身无独立涉诉记录**（公开渠道未见以分公司为当事人的案件），但分公司债务法律上由母公司承担——**查分公司等于查母公司**。

## 八、按用途给结论

| 你的用途 | 结论 | 关键动作 |
|---|---|---|
| **作为供应商/分包商给它干活** | 可以做，但要控账期 | 合同务必约定**母公司连带**或由母公司出具付款承诺；查清分包结算流程是否走国网系统审批（周期长）；预付款比例争取 ≥30% |
| **作为甲方采购它的服务** | 风险可控，资质要验原件 | 它的资质在**母公司**名下，须取得母公司资质证书复印件加盖公章 + 授权书；分公司签约要母公司盖章或出具授权 |
| **投标联合体 / 挂靠合作** | 谨慎 | 央企体系企业对外合作受国资委"三严禁"约束，挂靠基本不可行；联合体需走其内部审批，决策链长 |
| **债权催收 / 供应商准入** | 有账期风险，非信用风险 | 关注被执行新增节奏（每月查一次）；未上失信名单，诉讼保全通常能推动回款 |
| **求职/背调** | 央企体系、属地稳定 | 招聘平台标"私营/民营 1-49 人"是错的，实际是国网河南 100% 控股、分公司参保 49 人 |
