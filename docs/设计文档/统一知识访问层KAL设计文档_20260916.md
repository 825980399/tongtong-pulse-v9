---

## 一、背景与目标

### 1.1 问题

当前各模块**直接访问** JSON 快照文件与节点池：

- 访问点分散在各模块，没有统一的抽象层；
- 未来存储演进（JSON → Parquet → 分布式多模存储）需要改动**所有**访问点；
- 无法在不侵入业务代码的前提下做缓存、限流、可观测性。

### 1.2 目标

定义**统一知识访问层（KAL, Knowledge Access Layer）**，使底层存储可**透明替换**：

> 所有知识节点访问都经由 KAL；换存储 = 换 KAL 后端实现，业务代码零改动。

---

## 二、架构

```
业务模块
   │
   ▼
KnowledgeAccessLayer（接口 + LRU 缓存 + 单例）
   │
   ├── 后端 json（本批，基于节点池/快照）
   ├── 后端 parquet（第68批）
   ├── 后端 图(Neo4j) / 时序(InfluxDB)（第69批）
   └── 后端 distributed（第70批+）
```

**本批边界**：只实现接口 + json 后端 + 缓存 + 单例。
现有代码**仍直接访问快照**，KAL 为增量接入做准备 —— 因此本批对现有行为**零影响**。

## 三、接口清单

| 分类 | 方法 | 说明 |
|---|---|---|
| 基础 | `get_node` / `get_nodes_batch` / `get_all_nodes` / `iter_nodes` | 按 ID / 批量 / 全量 / 迭代器（内存友好） |
| 查询 | `search_by_keywords` / `search_by_path` / `search_by_evol_level` / `search_by_time_range` / `search_by_source_organ` | 关键词 / 路径前缀 / 进化层级 / 时间范围 / 来源器官 |
| 语义 | `semantic_search(query_vector, top_k)` | 当前暴力余弦，未来对接 FAISS/Milvus |
| 图 | `get_linked_nodes` / `find_path` | 当前基于 `linked_nodes` BFS，未来对接 Neo4j |
| 时序 | `get_activation_history` | 当前基于节点字段，未来对接 InfluxDB |
| 统计 | `get_node_count` / `get_node_count_by_evol_level` / `get_storage_size` | 节点总数 / 分层统计 / 存储体积 |
| 写入 | `save_node` / `delete_node` | 委托节点池，失败返回 False 不抛异常 |
| 存储管理 | `trigger_full_save` / `trigger_incremental_save` / `get_storage_backend` | 触发保存 / 查询后端类型 |
| 可观测 | `get_cache_stats` | 缓存 size / hits / misses / hit_rate |

## 四、基础实现要点

1. **数据源**：优先使用注入的 `node_pool`（内存，最快）；未提供时返回安全空结果，**绝不抛异常给调用方**。
2. **LRU 缓存**：`dict` 保序实现，命中移到末尾，超容量淘汰最久未用；容量由 `KAL_CACHE_SIZE` 控制（默认 10000）。
3. **单例**：`get_kal()` 返回全局唯一实例；首次调用可注入 `node_pool` / `snapshot` 依赖，`refresh=True` 可重建（测试用）。
4. **duck typing**：节点池方法名兼容 `get_all_including_evicted` / `get_all_nodes` / `get_all`，降低耦合。
5. **失败降级**：任何后端异常都转为安全返回值（空列表 / 0 / False）并留 DEBUG 日志。

## 五、配置

| 配置项 | 默认 | 说明 |
|---|---|---|
| `ENABLE_KAL` | `True` | KAL 总开关；关闭时各方法返回安全空结果 |
| `KAL_STORAGE_BACKEND` | `"json"` | 存储后端类型（json / parquet / distributed） |
| `KAL_CACHE_SIZE` | `10000` | LRU 缓存容量（节点数） |

## 六、使用示例

```python
from nucleus.knowledge_access_layer import get_kal

kal = get_kal(node_pool=pool, snapshot=snap)

node = kal.get_node("abc123")
batch = kal.get_nodes_batch(["a", "b", "c"])

# 大数据量用迭代器，避免一次性载入
for n in kal.iter_nodes(batch_size=1000):
    ...

# 语义检索（向量）
hits = kal.semantic_search(query_vector, top_k=100)

# 可观测
print(kal.get_cache_stats())
# {'size': 512, 'max_size': 10000, 'hits': 8931, 'misses': 1024,
#  'hit_rate': 0.897, 'backend': 'json', 'enabled': True}
```

| 批次 | 内容 |
