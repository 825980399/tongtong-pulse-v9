# 177批 · O-B2 设计稿（Standing Orders 文书四件套）

> 状态：设计稿（不实装）｜ 来源：星轨 177批 任务书 刀9 ｜ 关联票：O-B2

## 一、目标
为常驻自主任务建立「Standing Orders」持久化授权文书，含四字段：**扩授权 / 触发 / 闸 / 升级**。

## 二、四字段设计
| 字段 | 含义 | 取值示例 |
|---|---|---|
| 扩授权 | 允许自主执行的动作域 | `patch_apply` / `report_write` |
| 触发 | 自动生效的条件 | `night_orch` / `low_risk_release` |
| 闸 | 执行前必过的安全闸（**引用 O-B1 键名**） | `o_b1_sandbox=strict` |
| 升级 | 触发人工审批的条件（人工审批条件） | `severity>=P0` / `extern_api=true` |

## 三、闸与升级的桥接
- 闸：直接引用 O-B1 三层配置面键名（`sandbox`/`tool-policy`/`elevated`），保证策略一致。
- 升级：明确人审触发条件，不自动放行 elevated 动作；审批流复用现有人工裁决通道（登记册裁决）。

## 四、停窗预算
纯文书 + 数据结构设计，**0 停窗**；不改动执行引擎。

## 五、依赖
- 依赖 O-B1 键名先落地（闸引用）。
- 依赖登记册裁决通道（升级项）。

## 六、不实装项
- 不实装执行引擎侧的自动生效逻辑。
- 不新建持久化表（仅文书结构与字段定义）。
- 不接入审批 UI（仅声明升级条件）。
