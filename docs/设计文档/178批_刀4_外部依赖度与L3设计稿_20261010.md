## 一、外部依赖度（三指标基线，刀4 埋点）
复用 刀2 的 `ENABLE_SEMANTIC_CACHE_OBSERVE` shadow 规范（开关关→零计数/零 IO/零行为变化），新增 `nucleus/field/external_dependency_observe.py` 旁路计数：

| 指标 | 落点 | 含义 |
|---|---|---|
| `external_channel_calls` | `PulseLung._call_via_channels` 入口 | 外部渠道(LLM/搜索)调用发起次数 |
| `llm_used_false` / `llm_total` | `PulseSemanticComprehension` 判定出口 | 语义理解认为"无需外部 LLM、本地可处理"的次数与占比 |
| `delegate_browser` | `KnowledgeAcquisitionRouter` "browser" 分支 | 委托浏览器(自主探索路由)次数 |

⇒ **外部依赖度 = 1 − llm_used_false_ratio**（本地处理占比越高，依赖度越低）；`delegate_browser` 反映"框架自主探索"占比。基线值待下次运行窗收证。

## 二、L3 决策层设计（补"这次调用到底发不发"）
- **定位**：L3 是决策协同层，消费 L1 语义缓存(命中率/相似度) + L2 经验检索(相似历史) + L1 数据质量(可信度) 的结论，输出 `DecideResult(action, reason, matched)`：`复用 / 新发 / 退避 / 委托浏览器`。**不改变**渠道选择/熔断/并发（PulseLung 职责）。
- **与 刀2 关系**：RequestDeduplicator 是 L3 "复用/退避" 的执行手段之一；刀4 只埋"委托浏览器"计数，不与复用器重叠。
- **灰度**：G1 观测级(只记"若按规则会怎样")→ G2 建议级(写日志不拦截)→ G3 分项放行(退避→复用→合并)。**先观测、后建议、再决策**。
