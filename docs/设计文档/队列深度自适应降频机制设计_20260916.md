## 一、背景

### 1.1 问题

高负载时（如快照保存期间），**非关键操作**仍按原频率执行，与关键操作争抢 CPU 与 IO，
形成「越忙越积压」的恶性循环：

```
快照保存耗时长 → 持锁 → 其它操作等待 → 脉冲处理变慢 →
队列深度上升 → CPU 升高 → 保存更慢 → 队列继续上升 → ...
```

### 1.2 ★实测偏差（T0 核实）

任务书称「队列深度 2000+（上限 5000 的 42%）」。开工实测：

- L3 队列 **0 ~ 52 / 300**（日志 `[L3动态扩缩] 队列=37/300(12%)`）
- 快照保存耗时 **96.3s**（非任务书所称 7510s）

⇒ 任务书数据来自 22:00 高负载时段，**当前已回落**。
本机制因此定位为**防御性能力**：负载正常时完全不改变行为（LOW 等级系数 1.0）。

## 二、负载等级评估

`assess_load_level(queue_depth, cpu_percent, memory_percent, snapshot_saving)`

| 等级 | 队列深度 | CPU | 内存 | 其它 |
|---|---|---|---|---|
| `LOW` | < 500 | ≤ 50% | 正常 | — |
| `MEDIUM` | 500 ~ 1500 | 50 ~ 70% | — | 快照保存中（至少 MEDIUM） |
| `HIGH` | 1500 ~ 3000 | 70 ~ 85% | — | — |
| `CRITICAL` | ≥ 3000 | > 85% | > 90% | — |

**取最高维度等级**（保守优先）：任一维度告急即整体升级。

阈值可配置：`QUEUE_DEPTH_THRESHOLD_MEDIUM/HIGH/CRITICAL`。

---

## 三、降频策略

| 操作 | 正常间隔 | MEDIUM | HIGH | CRITICAL |
|---|---|---|---|---|
| 胃知识消化 | 30s | 39s（×1.3） | 60s（×2.0） | 暂停 |
| 器官扫描 | 300s | 390s | 600s | 暂停 |
| 代码学习 | 60s | 78s | 120s | 暂停 |
| 经验库清理 | 300s | 390s | 600s | 暂停 |
| 冷存 compaction | 600s | 780s | 1200s | 暂停 |
| **对话响应** | — | 不降频 | 不降频 | 不降频 |
| **心跳 / 生命体征** | — | 不降频 | 不降频 | 不降频 |
| **快照保存** | — | 不降频 | 不降频 | 不降频 |

★**白名单机制**：`ADAPTIVE_FREQ_WHITELIST` 内的操作（对话 / 心跳 / 快照保存）
在任何负载等级下都返回 `True`，`get_interval()` 恒为 0 —— **关键操作永不被降频**。

## 四、使用方式

```python
from nucleus.runtime_metrics import get_adaptive_controller, assess_load_level

ctrl = get_adaptive_controller()

# 1) 周期性地根据当前指标更新负载等级
ctrl.set_level(assess_load_level(queue_depth=qd, cpu_percent=cpu))

# 2) 非关键操作执行前询问
if ctrl.should_execute("stomach_digest"):
    do_digest()

# 3) 可观测
print(ctrl.get_stats())
# {'level': 'LOW', 'enabled': True, 'registered': [...],
#  'skipped': {...}, 'executed': {...}, 'whitelist': [...]}
```

注册自定义操作：`ctrl.register("my_op", base_interval_seconds)`。

## 五、安全与回退

| 保障 | 实现 |
|---|---|
| 总开关 | `ENABLE_ADAPTIVE_FREQUENCY`（默认 True）；关闭 → `should_execute` 恒 True |
| 关键操作免疫 | 白名单优先判定，恒返回 True |
| 只延后不丢弃 | 降频只推迟非关键操作的执行时机，内存态数据不丢 |
| 可观测 | `get_stats()` 暴露等级 / 跳过次数 / 执行次数 |
| 零回归 | LOW 等级系数 1.0，负载正常时间隔与改造前完全一致 |
