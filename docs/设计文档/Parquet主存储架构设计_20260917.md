- **批次**：主线第68批 T1/P0
- **日期**：2026-09-17
- **状态**：已实现（加载优先 Parquet + 回退 JSON + 完整性校验；JSON 备份可配置）
- **代码**：`nucleus/mnemosyne/PulseSnapshot.py`（`_m68_*` 系列方法）

## 一、背景与目标

### 1.1 优化前

| 项 | 状态 |
|---|---|
| JSON 快照 | **主存储**，479MB / 12295 节点，行式、无压缩 |
| Parquet | **仅额外副本**，17.4MB（压缩比约 27:1），未用于查询/加载 |

每次保存先写 479MB JSON、再写 17.4MB Parquet；加载时读 479MB JSON。
节点增长后 JSON 将达数十 GB，不可扩展。

### 1.2 目标

- **加载**优先 Parquet（列式、压缩），**完全不读** 479MB JSON
- **保存**优先 Parquet，JSON 降级为**可选**兼容备份
- Parquet 缺失/损坏 → 自动回退 JSON（数据不丢）
- 保存后完整性校验（各分片总行数）

## 三、架构

### 3.1 存储布局

```
data/knowledge/
├── pulse_knowledge_snapshot.json        # JSON（可配置是否仍写，默认写）
├── parquet/                              # Parquet 主存储（按 evol_level 分片）
│   ├── evol_level=L1/  (1368 行)
│   ├── evol_level=L2/  (7642 行)
│   └── evol_level=L3/  (3285 行)
```

实测（2026-09-17）：合计 **12295 行**，与内存节点数一致。

### 3.2 加载流程

```
load()
  ├─ PARQUET_AS_PRIMARY_STORAGE=True ?
  │    ├─ 是 → _m68_load_from_parquet()
  │    │        ├─ 命中 → 记录来源 "parquet"（JSON 完全不读）✅
  │    │        └─ None → 回退 _load_internal()（原 JSON 路径）
  │    └─ 否 → _load_internal()
  └─ 增量日志重放（第67批 T2）
```

行 → `PulseNode.from_dict(row)` 还原为节点对象（与 JSON 路径语义一致）。

### 3.3 保存流程

```
_full_save()
  ├─ 构建 snapshot
  ├─ SNAPSHOT_SAVE_JSON_BACKUP ?
  │    ├─ True（默认）→ 写 JSON（分批流式 / 原子写）
  │    └─ False       → 跳过 JSON，仅写 Parquet（主存储）
  └─ _m68_verify_parquet() → 记录各分片总行数
```

★**默认保持双写**：关闭 JSON 备份后若 Parquet 同时写失败将失去兜底，
故 `SNAPSHOT_SAVE_JSON_BACKUP` 默认 `True`，仅在确认 Parquet 稳定后再考虑关闭。

## 四、配置项

| 配置 | 默认 | 说明 |
|---|---|---|
| `PARQUET_AS_PRIMARY_STORAGE` | `True` | Parquet 主存储；关闭 → 完全回退 JSON |
| `SNAPSHOT_SAVE_JSON_BACKUP` | `True` | 是否仍写 JSON 兼容备份；关闭 → 只写 Parquet |
| `PARQUET_COMPRESSION` | `"snappy"` | 压缩算法（snappy 快 / gzip 压缩比高） |
| `PARQUET_SHARD_BY_EVOL_LEVEL` | `True` | 按进化层级分片 |
| `PARQUET_BATCH_SIZE` | `5000` | 分批写入大小 |

---

## 五、安全与回退

| 保障 | 实现 |
|---|---|
| 主存储可关 | `PARQUET_AS_PRIMARY_STORAGE=False` → 走原 JSON 路径，零行为变化 |
| 加载失败回退 | `_m68_load_from_parquet()` 任何异常返回 `None` → 回退 JSON |
| pyarrow 缺失 | 方法内 import 失败直接返回 `None` → 回退 JSON |
| 双写兜底 | JSON 备份默认开启 |
| 完整性校验 | 保存后统计各分片行数并记 INFO；不可用返回 -1（不阻断） |
| 来源可诊断 | `_m68_last_load_source`（`parquet` / `json`） |
