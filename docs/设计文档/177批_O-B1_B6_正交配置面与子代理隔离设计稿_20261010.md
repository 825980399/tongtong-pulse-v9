# 177批 · O-B1+B6 并刀设计稿（安全执行面拆分 + evolution_worker 隔离补全）

> 状态：设计稿（不实装）｜ 来源：星轨 177批 任务书 刀9 ｜ 关联票：O-B1 / O-B6

## 一、目标
将「沙箱执行策略」拆为 **sandbox / tool-policy / elevated** 三层正交配置面，并把 evolution_worker 子代理隔离面的「四缺三」补齐（进程隔离已具备；缺：独立会话、无消息工具、深度上限、廉价模型）。

## 二、三层正交配置面
| 配置面 | 职责 | 默认 | 落点 |
|---|---|---|---|
| sandbox | 代码执行沙箱等级（禁网/资源上限） | 严格 | config + SandboxCore |
| tool-policy | 工具调用白/黑名单与频率闸 | 保守 | config + ToolRegistry |
| elevated | 提权动作（写盘/重启/外部API）审批闸 | 关闭 | config + 人工审批 |

三者正交：任意组合可声明，互相不耦合；闸引用 O-B1 键名。

## 三、evolution_worker 隔离面补全（四缺三落点）
- 独立会话：worker 启动独立 `session_id`，不继承主链路会话上下文（防污染）。
- 无消息工具：worker 工具集剔除 `MessageBus/EventBus` 写入口（只读遥测）。
- 深度上限：递归/子调用深度硬上限 `EVOLUTION_WORKER_MAX_DEPTH`（默认 3）。
- 廉价模型：worker 默认走 `EVOLUTION_WORKER_CHEAP_MODEL`（已具备进程隔离，本项为第四项）。

## 四、停窗预算
纯配置 + 隔离面补丁，预计 **0 停窗**；改动仅 config 键 + evolution_worker 构造。

## 五、依赖
- 依赖 O-B1 键名先落地（闸引用）。
- 依赖 SandboxCore / ToolRegistry 现有接口。

## 六、不实装项（本稿仅设计，不落地）
- 不新建配置键（仅设计键名与默认值）。
- 不改动主链路会话继承逻辑（仅 worker 侧）。
- 不实现审批 UI（elevated 闸仅声明人工审批条件）。
