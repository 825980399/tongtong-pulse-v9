## 一、目标
建立目录级 `<能力目录>/SKILL.md` 规范与资源清单声明机制（**声明而非实现**），资源清单与 `tools/export_public.py` 白名单同面。

## 二、SKILL.md 字段集
| 字段 | 必填 | 含义 |
|---|---|---|
| name | 是 | 能力名 |
| scope | 是 | 适用目录/边界 |
| entry | 否 | 入口（声明） |
| resources | 是 | 资源清单（文件/工具/依赖） |
| risk | 是 | 风险等级（P0-P3） |

## 三、资源清单与导出白名单同面
- `resources` 直接映射 `tools/export_public.py` 白名单条目，保证「声明即进包面」。
- 资源清单变更须同步白名单，避免遗忘（PII 进包面一致性）。

- 每个能力目录顶层放 `SKILL.md`，框架按目录扫描加载（声明式，不改执行）。
- 缺 SKILL.md 的能力目录降级为「未声明」，不参与自动授权。

## 五、停窗预算

## 六、依赖
