## §4 身体层解封建议：边建边补（分档闸门）

**结论：不必继续等，也不应无条件放行——按解封步骤分档挂闸门。**

| 解封步骤（洞鉴身体层专项 §1.3 四步路径） | 对契约覆盖的依赖 | 建议闸门 |
|---|---|---|
| 步骤1（181-182）：观测级骨架 export_organ_inventory | **无**——只读导出名称/类型/健康度，不写器官行为 | **无闸门，可立即做** |
| 步骤2（183-184）：图谱构建（调用边） | 弱——静态分析为主，契约缺失不影响建图 | 无硬闸门；建议同步启动补缺 |
| 步骤3（185）：LFI 五维计算 | **强**——LFI 消费器官健康度/连通性，39.3% 器官零契约意味着 LFI 输入中近四成器官行为无防护网，指数可信度不足 | **挂闸门：严格口径 ≥50% 或 14 件 always_online 零覆盖清零** |
| 步骤4（186+）：数据流联动 | 强——图谱回写影响认知层决策 | 同步骤3 闸门 + 九大核心（大脑系统）契约率 ≥80% |

**理由**：
1. 任务书口径 51.8% 刚过线，但结构不均——核心脏器/内分泌 100% 而感知/免疫 25%、大脑 40%；身体层图谱的核心节点（大脑系统）恰是覆盖率洼地。
2. 观测级骨架（步骤1）是纯只读导出，与契约 harness 无耦合，"等覆盖率"对它不成立——继续等只会让 182 的器官清单导出（181 刀5 已排）无谓受阻。
3. LFI 是消费型指标，输入可信度决定指数价值；39.3% 零覆盖 + 14 件通电零防护是真实风险（173 长稳窗证明夜间无人值守时段器官自转是常态），步骤3 起必须挂闸门。
4. 补缺成本低（纯测试刀、零停窗、历史节奏成熟），3-4 批即可把严格口径推过 50%，与 183-184 图谱构建自然并行。
