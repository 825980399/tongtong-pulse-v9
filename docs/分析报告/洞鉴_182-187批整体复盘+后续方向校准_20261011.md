- **b. 预算校验=声明值校验**：只比对任务声明的 budget_tokens 数字，无 token 计量兑现。DETERMINISTIC 路径下无害；未来接 LLM 路径须补计量，否则条款③名实不副

### 3.3 刀B 共窗风险面与节奏
