### ⚠ 重挂须注意的行尾风险（本次实测发现，未越权改）

`core.autocrlf=true`，且 `.gitattributes` 仅有 `* text=auto` 与按扩展名规则
（`*.py eol=crlf`、`*.md/*.json eol=lf` 等），**无扩展名的 `tools/ci/hooks/pre-commit`
落到 `text=auto`** ⇒ 检出时可能被转成 CRLF；再跑安装器就会把 CRLF 装进 hook，
违反"hook 须纯 LF"。

- **当前状态安全**：模板与已装 hook 均为 `CRLF=0 / 8966B`。
- **建议（未实施，交星轨裁定）**：`.gitattributes` 增一行
  ```
  tools/ci/hooks/* text eol=lf
  ```
  本刀未改 `.gitattributes`（属仓库级配置，越出本刀施工范围，且非 `tools/ci/` 路径）。
