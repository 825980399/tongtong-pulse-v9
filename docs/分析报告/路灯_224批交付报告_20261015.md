## 一、T0 偏差核实（追源根因钉死）

全仓枚举 `target_organ=` 实参 + 广扫所有 `target_organ` 引用，结论：

1. **非字面量 kwarg 唯一一处**：`base/BasePulseOrgan.py:311` `target_organ=target_organ`（变量透传，默认 `""` str）。
2. **无任何** `target_organ=3` 字面量注入、无任何字典赋值 `pulse["target_organ"]=3`。
3. **根因＝位置参数错位**：`BasePulseOrgan._emit`（:266）调 `self._send(event_type, payload, priority, ttl_ns, layer, target_organ)`（:289），但 `_send`（:291）签名第 3 个位置形参**恰为 `target_organ`** → `_emit` 传入的**整型 `priority` 被塞进 `target_organ` 槽**。
4. **实锤验证**：`organs/core/PulseEnergyMetabolism.py:88-92` `self._emit(METABOLISM_SNAPSHOT, {...}, priority=3, layer="L3")` → dump 中 `target_organ: 3`（整型）完美吻合；全仓 629 行 `target_organ:3` 即各器官 `priority` 值透传。
5. **四向串味（连带发现，严重）**：错位不仅污染 `target_organ`，还同步错位 `priority`（收到 ttl_ns）、`ttl_ns`（收到 layer）、`layer`（收到 target_organ）——即 `_emit` 调用的 priority/ttl/layer 全部传错槽。**此串味超出 224 刀1 指定文件范围（BasePulseOrgan.py 非刀1指定件），本批仅闭环 target_organ 幽灵，串味修复建议单列批次（见 §七 降级项①）。**
