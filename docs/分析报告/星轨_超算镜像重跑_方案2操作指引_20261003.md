## 一、上传构建上下文到 SCNet（E-File 网页直传）

1. 登录 SCNet 控制台 → 左侧「文件管理」
2. **确认区域**：选择你领取的 **华东一区[昆山]**（各中心资源独立，选错会传错节点）
3. 进入用户主目录 → 新建文件夹，命名 **`pulsenet`**（纯英文，官方建议文件名不要中文/空格）
4. 进入 `pulsenet` 文件夹 → 点击「上传」→ 把整个 `docker_build_ctx` 文件夹内容拖入（或选文件夹上传）
5. 等待上传完成（113.7MB，网页直传视网速约几分钟）

> 提示：SCNet E-File 支持整文件夹上传，勿逐个文件传。若浏览器上传大文件夹卡顿，可用「命令行[E-Shell]」+ scp/rz 备选（官方文档 upload-example 路径）。

## 二、登录计算节点，探测容器运行时（关键一步）

在控制台「命令行[E-Shell]」或 ssh 登录你领取的华东一区节点，执行：

```bash
cd ~/pulsenet
# 依次探测可用的容器/镜像构建工具（按顺序，第一个命中即用）
which docker podman singularity apptainer buildah 2>/dev/null; echo "---"
docker --version 2>/dev/null || podman --version 2>/dev/null || singularity --version 2>/dev/null || apptainer --version 2>/dev/null || buildah --version 2>/dev/null
```

**分支判定**：
- 命中 `docker`/`podman`/`buildah` → 走 **路径 A（直接构建镜像）**
- 命中 `singularity`/`apptainer` → 走 **路径 B（Singularity 构建）**（超算常见，功能等价）
- 全无 → 走 **路径 C（裸环境 + slurm 作业直跑）**，详见 §五

## 三、路径 A：Docker/Podman 直接构建

```bash
cd ~/pulsenet
# 若 docker：直接构建
docker build -t pulsenet-test:20261003 .
# 若 podman：podman build -t pulsenet-test:20261003 .
# 若 buildah：buildah bud -t pulsenet-test:20261003 .
```

**若基础镜像拉取也超时**（SCNet 公网策略限制）：

```bash
# 法1：试国内加速器前缀
docker pull docker.m.daocloud.io/library/python:3.11-slim
# 法2：让管理员加载预置基础镜像（SCNet 镜像库一般有 python 官方镜像，控制台「AI 社区·镜像库」搜 python:3.11 拉取）
```

构建成功后冒烟验证（交互式起容器，确认框架能启动到降级路径）：

```bash
docker run --rm -it pulsenet-test:20261003 python -c "import nucleus; print('nucleus OK')"
# 或直接跑 main.py 短时冒烟（Ctrl+C 退出，验证启动到降级路径不崩）
docker run --rm -it pulsenet-test:20261003 timeout 60 python main.py
```

## 四、路径 B：Singularity/Apptainer 构建

```bash
cd ~/pulsenet
# 方式1：直接由 Dockerfile 构建（singularity 3.8+ 支持）
singularity build pulsenet-test.sif dockerfile://Dockerfile
# 方式2：若有 docker/podman 可先本地 build，再转 singularity
singularity build pulsenet-test.sif docker-daemon://pulsenet-test:20261003
```

冒烟：

```bash
singularity exec pulsenet-test.sif python -c "import nucleus; print('nucleus OK')"
```

## 五、路径 C：无容器运行时 → slurm 作业直跑（兜底，最省事）

其实**无容器也能跑**——这是 SCNet 主路径「文件直传+slurm」。写作业脚本 `run.slurm`：

```bash
#!/bin/bash
#SBATCH -p <你领取的队列>
#SBATCH -N 1
#SBATCH -n 16
#SBATCH --mem=100G
#SBATCH -J pulsenet_smoke
#SBATCH -o pulsenet_smoke_%j.out

module load python/3.11 2>/dev/null || true
cd ~/pulsenet
pip install --user requests psutil numpy pyarrow cryptography faiss-cpu
# 冒烟：先确认能启动到降级路径
timeout 120 python main.py || true
echo "SMOKE_DONE rc=$?"
```

提交：`sbatch run.slurm`，查看 `squeue -u $USER` 与日志。

## 六、公网连通性检查（上传前/构建前必做）

计算节点能否 curl 通模型 API 端点（决定测试阶段配不配密钥）：

```bash
curl -s -o /dev/null -w "%{http_code}" --connect-timeout 5 https://ark.cn-beijing.volces.com/api/v3 2>/dev/null; echo " <- ark"
curl -s -o /dev/null -w "%{http_code}" --connect-timeout 5 https://open.bigmodel.cn/api/paas/v4 2>/dev/null; echo " <- zhipu"
```

- 通 → 配测试用临时密钥（评估单 §三：先只配 ARK 一个渠道）
- 不通 → `local_fallback_enabled=True` 已配 qwen2 本地降级，框架仍可跑（对话质量降级），不影响运行上限验证
