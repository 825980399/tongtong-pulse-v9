## 三、L2 缓存先后次序（必须写死）

实弹刀命中 L2 语义缓存，缓存与注入的先后次序是红线，须写死以避免污染：

1. **检索 query 用「注入前原文」**：向 L2 / retriever 派发的查询文本，必须是**剔除注入段前的原始用户 query**，不得携带本批注入的三要素。
2. **回写缓存的答案剔除注入段**：命中后回写 / 落盘的缓存条目，其答案内容须**剔除注入段**（仅缓存原始问答，不缓存带注入的 `_sys` 产物）。
3. 次序不变量：`query(原文) → 命中判定 → 回写(剔除注入段)`；注入只在「组装 `_sys` 并送推理」阶段发生，不回流到缓存检索/落盘路径。
