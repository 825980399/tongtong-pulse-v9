## 2. ★根因发现：BOM 幽灵题——"同题重问烧一整天"的第一性原因

**候选5（进化消化）与候选1（LLM 精简）在 115 任务书里是两个候选；实证表明它们是同一个 bug 的两个投影，且真根因比 114 期"缺去重"更底层。**

### 2.1 完整证据链（/ca 实机复现 + 主线程独立复验，双通道）
1. `organs/body/PulseLiver.py` 首 3 字节 = `EF BB BF`（/ca 18:3x；主线程 19:0x 复验一致）。对照全仓 300 个 .py：受累生产文件**仅此一个**（另 `tmp_verify_influx.py` 非生产）；对照 `PulseKidney.py` 首 3 字节干净。
2. `self_inspector._read_method_body` 用 `encoding="utf-8"` 读入后 `ast.parse` 抛 `SyntaxError: invalid non-printable character U+FEFF`（主线程 19:0x 复现：utf-8 炸 / **utf-8-sig 正常**）。运行时 import 不炸（CPython 容忍 BOM）——**普通测试/运行全绿，唯工具链静默降级**。
3. 炸后落入 `_read_method_body_fallback` 缩进兜底 → **切片失控**：`refresh_runtime_params` 的"方法体"返回 3537 行/160KB = 文件尾全部 → :1506 之前**每个方法都"含有"**同一个真命中 `except Exception: pass`（:1506-1508，`_compress_group` 体内）→ 每方法一条 issue、行号漂移 1506/1507 → EvolutionLoop 的 `file:line:type` 去重键全线失效。
4. 新进程冷缓存跑真检测器（/ca 实机）：对 PulseLiver 产出 **~10 条同点重复 silent_exception**（refresh_runtime_params/set_node_pool/set_knowledge_tree/stop/on_pulse/...）——每轮 ~10 条幽灵进 45 发现池，其中 ≥2 条烧 LLM。
5. **为什么修复率恒 0%**：即使 LLM 修好 :1507，只要 BOM 在，兜底切片复扫继续再生幽灵（方法名不同、行号照旧）→ 验证永不通过 → 每 31 分钟一轮再问 → **今日三僵尸组 72 条 calls / 266,667 tok = 当日 token 42.1%**（`76bf9d15` Kidney 25条、`adbf413b` Liver 25条、`360a3e79` Liver 22条，首发 00:22:43–00:23:28）。
6. **引入窗口锁定**：`.bak_batch105`（09-22 13:33）无 BOM → `.bak_batch107`（09-22 18:26）有——**第 107 批（09-22 下午-晚间）某次保存写入**；三组首发 00:22 恰是当晚之后第一个进化轮。时间严丝合缝。
7. 第三题（Kidney `_m69_kal_query`）非幽灵：**真命中但在死代码**——`PulseKidney.py:852` 位于 `if __name__ == "__main__":` 自测段（:850–:868），生产永不执行；检测器无"跳过 __main__ 段"规则。

### 2.2 一刀清单（全部一行级，无逻辑改动；顺序即建议排期顺序）
| 步 | 改动 | 效果 |
|---|---|---|
| 1 | PulseLiver.py **去 BOM**（bytes 判前缀重写，或 utf-8-sig 读+utf-8 写） | 灭每轮 ~10 条幽灵 |
| 2 | 同文件 :1506-1508 `except Exception: pass` 加 DEBUG 留痕（:68 有现成注释模板） | 灭唯一真命中 |
| 3 | PulseKidney.py 删 :852-865 孤儿 `_m69_kal_query`（或 except 留痕） | 灭第三题 |
| 4 | 防御件：`_read_method_body` 编码改 `utf-8-sig`；兜底加"切片长度>2×(至下一 def 距离)即弃"保险丝；新增 `tools/check_encoding_hygiene.py`（BOM/可 parse 维度，300 文件 <1s）入晨检 | 防复发（不接运行时=按判据 V 类观察） |

**落地后量化预期**：SE 三题组归零 = 日省 ≈72 条 calls / 26.7 万 tok + 每轮 ~40s×3 的 LLM 延迟 + 发现池 45→~35 挤水。**这比任何缓存/冷却的收益都大，且是免费的。**
