## 一、刀1 · 图质量守卫三档（P0）—— dead_code 从「整体让位」改为「中间档出清单」

**问题**：305 刀1 的守卫是二值闸——覆盖率 <70% 整体让位 ⇒ dead_code 入料口长期为 0，这条线整条废掉（306 批交付报告 D1 已申报）。

**改动**（`nucleus/self_inspector.py`）：

| 档位 | 覆盖率 | 行为 |
|---|---|---|
| 判死 | ≥ 70% | `severity="low"` + `review_only=False`，进趋势门禁、可入队列 |
| **中间档（本批新增）** | **55% ~ 70%** | **只产出「待复核清单」**：`severity="info"` + `review_only=True` + `review_reason="graph_coverage=57.6%(<70%)"`；**不进趋势门禁、不进自动入队** |
| 让位 | < 55% | 只记 INFO，不产出问题 |

配套两处：

1. `tools/check_code_issue_trend_302.py`：dead_code 分两档计数——`dead_code`（severity≠info，进门禁）与 `dead_code_review`（info，**只观测不判 FAIL**）。
2. 「禁入自动入队」在结构上已成立：`EvolutionLoop.discover_all_issues()` 的 inspector 调用本就 `skip_detectors=["dead_code","cc_growth"]` + `min_severity="medium"`，info 级也过不了阈值——本批只把这条保证写成显式字段，不新增拦截代码。

**实测**（真实扫描）：


## 二、刀2 · 一级深化 `get_global_awareness()`（P1）

**改动**（三文件，全部只读聚合，不新增任何"读数"来源）：

1. `organs/brain/PulseSubconscious.py` 新增 `get_active_exploration_clues(limit=3)`：潜意识对外 getter，只读快照——优先深度探索队列（`state="queued"`），不足则按时间倒序补最近探索日志（`state="explored"`）；不触发探索、不改队列、不发脉冲。
2. `nucleus/field/InfoField.py` 新增唯一写入口 + 只读读口：
   - `set_global_awareness(payload, source="")`：**只存普通数据**（仅收 `learning_goal` / `exploration_clues` / `narrative_clues` / `gaps` 四键，其余丢弃）——防止把器官实例、锁、线程塞进缓存，让「快照」退化成第二份运行态引用。
   - `get_global_awareness()`：**绝不跨器官现调**（不 import 器官、不触发任何 getter），只读缓存 + 深拷贝，返回 `{as_of, source, stale_sec, status, learning_goal, exploration_clues, narrative_clues, gaps}`；`status ∈ fresh/stale/not_refreshed`，新鲜度阈值 `_GLOBAL_AWARENESS_STALE_SEC = 3600s`。
3. `nucleus/self_awareness/SelfAwarenessEngine.py` 新增刷新器 `integrate_global_awareness(organs=None, info_field=None)`（抄 `integrate_call_graph` 范式：开关/异常都不影响引擎）：
   - 三源聚合：内在世界 `get_active_learning_goal()` / 潜意识 `get_active_exploration_clues(limit=3)` / 叙事自我 `get_narrative_clues(limit=2)`
   - 器官解析：参数 → 模块级注册表 `set_awareness_organs()`（与 `set_dispatch_framework` 同范式）
   - **三种取不到都如实落 `gaps`**（`inner_world:missing` / `subconscious:no_getter(...)` / `narrative:error(...)`），不填默认值、不猜测

**实测**（注入三源假器官 + 真实 InfoField 实例）：

```
before: {'status': 'not_refreshed', 'as_of': 0.0, 'source': '', 'gaps': ['not_refreshed']}
refresh status ok  gaps []
after: fresh  self_awareness.integrate_global_awareness  {'goal': '搞懂调用图'}  2  ['因为x所以y', '于是学会了z']
copy-safe: 改返回值不影响缓存
no_organs: {'status': 'no_organs'}
```

`PulseSubconscious.get_active_exploration_clues` 单测（`object.__new__` 注入内部态）：

```
队列 4 条、limit=3 → [{topic:t1,state:queued,count:3},{t2},{t3}]
limit=0 → []；无任何内部态 → []
```

**层次纪律**：跨器官取数只发生在刷新器里；`get_global_awareness()` 是纯内存读——任何器官/报告/对话调它都不会触发别的器官干活（烛微指出的层次倒挂风险由此规避）。
