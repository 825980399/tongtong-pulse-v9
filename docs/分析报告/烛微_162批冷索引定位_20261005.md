## 三、三口径关系式（给星轨的口径说明方案）

**各层定义（用代码事实写，不用推测）**：

| 层 | 载体 | 计数含义 | 现值 | 刷新时机 |
|---|---|---|---|---|
| **全量物化层** | `data/knowledge/parquet/evol_level=L{1,2,3}/*.parquet` | 主快照全部节点（10-05 21:40 检查点） | **12,475**（460+8,448+3,567） | 全量检查点 `_m67_full_checkpoint`（`SNAPSHOT_FULL_SAVE_INTERVAL=21600`＝6h 窗口（`config.py` 本批工作树实测 `:4864`，首次取证 `:4836`）） |
| **热层（L1 常驻）** | `pulse_l1_snapshot.json` 的 `l1_count`/`nodes` | 当前 L1 热集，随每次 L1 快照保存刷新 | **460**（昨日读数 473） | `save_l1()`（主快照成功后同步，`PulseSnapshot.py:489-493`） |
| **冷层（侧车索引）** | `cold.index.json` | **被驱逐到冷存数据集的节点**的 `node_id→(file,rg,offset,level)`，level＝**驱逐当时的 evol_level**（`:2686`） | **5,530**（全部标 L1） | 仅 flush 成功 / compaction 成功（§一） |

**预期关系式（可作为门禁断言）**：

1. `parquet 总行数 == 主快照节点数` —— 实测 **12,475 == 12,475 ✓**
2. `pulse_l1_snapshot.l1_count == parquet 中 evol_level=L1 分区行数` —— 实测 **460 == 460 ✓**
3. `len(cold.index) == 冷存数据集 distinct node_id ≤ 冷存行数` —— 实测 **5,530 == 5,530 == 5,530 ✓**（当前无重复行）
4. **不成立也不应成立**：`cold.index ≠ 热层 L1`、`cold.index ≠ 主快照数`——冷层是**历史驱逐切面**，其 `level="L1"` 表示"驱逐时它是 L1"，与当前热层 L1（460）**无包含关系**。⇒ 微光第1巡"L1=473 vs cold.index=5530 分歧"是**跨层比较**，不是数据分歧。
5. **新鲜度断言（新增建议）**：`mtime(cold.index) ≥ mtime(cold/*.parquet 最新)`，落后即告警（当前实测差 **0.0 天**，因为两者都停在 09-28；但此断言现在**代码里不存在**）。
