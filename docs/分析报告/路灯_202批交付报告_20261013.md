- 新增混入基类 **`ChipAgnosticDims(TypedDict, total=False)`**，承载 `amplitude / spike_type / wire_format` 三字段
- `class Pulse(TypedDict)` → `class Pulse(ChipAgnosticDims)`，三字段经继承进入 Pulse 契约
- **不改 `PulseCore.emit`**、不改分发/消费、**不加门控** → 默认零行为变化

⚠️ **为何不用 `NotRequired`（实测结论，重要）**：
本模块有 `from __future__ import annotations`，注解被字符串化为 `ForwardRef('NotRequired[float]')`，
**CPython 3.12 的 TypedDict 在类创建期无法识别 NotRequired** —— 实测 `__optional_keys__` 为空、
三字段全部落入 `__required_keys__`（即被判为**必填**），直接违背"向后兼容"承诺。
`total=False` 是**类创建参数**、不受 PEP563 影响，运行时与静态检查口径一致。

**测试** `tests/test_pulse_semantics_m202.py`：**8 passed**
（三字段已声明 / 三字段为可选 / 既有字段仍必填 / 默认常量 / 取值域自洽 / 既有脉冲结构零注入 / 消费方兜底范式 / 芯片语义值可承载）
