## 一、可行性结论（已查证）

1. **核心依赖全跨平台**：requests / psutil / numpy / pyarrow / cryptography / faiss-cpu 均有 Linux wheel，pip 直装；Cython 为"编译专用"运行期可不装。
2. **框架自带平台分支**：`hardware_probe.py:151`（`os.name=="nt"`）、`sandbox_limits.py:150`（`sys.platform=="win32"`）——非 Windows 有既定路径。
3. **降级设计完备**：`local_fallback_model=qwen2:7b` + `local_fallback_enabled=True`；无硬件/无外网均自动降级不崩。
4. **密钥已收口**：config.py 全部渠道密钥走环境变量（第 33 批 API Key 收口成果），**镜像天然不含密钥**。

## 二、脱敏三层过滤（镜像内容清单）

| 层 | 进镜像 | 不进镜像 |
|---|---|---|
| 代码 | 项目发布面代码（已过 PII 门禁） | `.git`、`tests/`（运行期不需要）、`docs/` 内部件 |
| 数据 | 空知识库/合成测试数据（性能测试不需要真实记忆） | `data/` 运行数据（对话/经验库/知识快照）、`logs/` |
| 配置/密钥 | 模板 config（读环境变量） | 一切 `*_API_KEY` 明文、`.env` |

**本地模型**：`bge-small-zh-v1.5` ONNX（~90MB）打包进镜像（嵌入必需）；jina 613MB 不打包（生产 0 引用，微光已证）。

## 四、Dockerfile 草案（路灯施工时细化）

```dockerfile
FROM python:3.11-slim
WORKDIR /app
# 只装 [核心必需]+[功能必需]（可选功能容器无硬件自动降级）
COPY requirements.txt ./
RUN pip install --no-cache-dir requests psutil numpy pyarrow cryptography faiss-cpu
COPY <脱敏后代码目录> /app/
COPY <bge-small-zh 模型目录> /app/models/
# 密钥一律由运行环境注入，不进镜像
CMD ["python", "main.py"]
```

配套 `.dockerignore`：`data/ logs/ .git/ tests/ docs/ *.env .env`（具体按路灯提交面细化）。
