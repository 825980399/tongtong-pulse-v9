## 三、三类结构性缺陷（立票依据）

### 缺陷 1：知识检索相关性失效（P1）
- 现象：不同问题反复命中同一批无关节点——健康检查报告（A1/A3/E1/G3）、PulseCodeLearner 92 条融合模板（A2/B2/D3/F1）、"已理解5个方法"（E2/G2）
- 影响：9/26 提问答非所问，融合结果被当作万能答案复用
- 疑因：①检索相似度/排序失效（余弦或 BM25 退化）②359 污染节点干扰检索命中 ③索引与主快照不同步（微光发现 cold.index 5 天未刷新与此可能同源）

### 缺陷 2：融合输出格式化缺失（P1）
- 现象：回答含节点原始字段——"关联知识："、"直接知识：[综合]"、"[归纳升华]"、"已理解5个方法，入口方法:"
- 影响：4/26 提问输出未净化原文，格式碎片+标点错乱（"规律。，值得"）
- 疑因：融合组装（PulseLiver）直接拼接节点 value 未走格式化层

### 缺陷 3：占位符/碎片未填充（P2）
- 现象："unknown"未替换（F3）、"这是我第一次醒来"尾巴串入（A1/A2/D3）、C1"不是，也不是"残缺句、B1"56个器官"知识过期
- 影响：回答完整性/准确性受损
