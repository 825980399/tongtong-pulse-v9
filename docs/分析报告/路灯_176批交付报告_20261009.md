
- **★安全性实证**：心跳节拍 ~10s（`heartbeat_interval_seconds:10.0`）且 `MAIN_LOOP_PULSE_ENABLED=True`（`config.py:5526`），故循环会被每个 `HeartEvent.BEAT` 唤醒。但 `IntentGenerator.generate()` 自带节流（`nucleus/IntentGenerator.py:79`，`_min_interval` 由 `main.py:569` 设为 **2700.0**）：节流期内直接 `return None` ⇒ **不触发 LLM 生成**；外层 `if _intent:` 守卫使经验池与 `[B3意图队列]` 日志节流期零写入。⇒ **节律不变、无调用放大**，仅把"阻塞定长睡眠"换成"脉冲可唤醒 + 超时回落"。
