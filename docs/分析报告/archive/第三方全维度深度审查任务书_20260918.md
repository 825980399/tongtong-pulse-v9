## 〇、项目背景（30秒理解）

- **项目名**：曈曈 PulseNet v9.5，一个仿生数字生命/AI Agent 框架。
- **核心设计**：用约56个"仿生器官"（肺/胃/肝/心/大脑皮层/内在世界/人格内核等）模拟生命体的感知、消化、记忆、情绪、推理、进化等功能，跑在一个脉冲（Pulse）事件总线之上。
- **代码规模（实测，供校验，需你复核）**：主代码约20.6万行（`nucleus/` 约9.6万行/217文件，`organs/` 约8.1万行/68文件）；测试约4.2万行/190文件/3311例；文档约13.6万行/446份。
- **运行环境**：Windows 单机，Python 3.12.6，`D:\Program Files\Python312\python.exe`；项目根 `<PROJECT_ROOT>`。
- **数据规模**：知识节点约12295个；主快照 `data/knowledge/pulse_knowledge_snapshot.json` 约478MB；`data/` 总约3.4GB。
- **外部依赖**：火山方舟/DeepSeek/智谱等 LLM API（肺=模型调度器）；FAISS（向量）；Parquet（冷存）；InfluxDB 2.9（时序指标，已本地部署）；Neo4j（图，驱动已装、服务未装）。
- **协作模式**：规划方（星轨）+ 执行方（路灯）按批次迭代，已推进到第79批。**代码处于快速迭代期，部分模块可能改了一半，请如实记录"半成品"状态。**
