### A-4 分片稳定门禁方案（针对 89/90/111/178/50 漂移）

**根因分解（5 条，均有本轮证据）**

| 根因 | 证据 | 影响 |

| ① 工作树脏（未提交格式化/文档） | `git status --short`=225 行；T155-2 §六记"80 个外部格式化脏文件未并入" | 同一提交两次跑差 1~89 条 |

| ③ safe-delete 批量守卫在 session teardown 截断 | T155-2 §三-2：删 >50 触发 `SAFE_DELETE_BULK_CONFIRM_REQUIRED` → SystemExit，run2/run4 被截断，**teardown 22 ERROR** | 我环境 0 ERROR → 该 22 例纯属其沙箱 |

**方案（三片 + 指纹，替换"单一全量差集"）**

1. **片 1 · collect 门禁**：`--collect-only` 必须 `0 error`，节点总数写基线（当前 **4457**）；总数漂移 >±5 判红。成本最低，先拦半成品。
