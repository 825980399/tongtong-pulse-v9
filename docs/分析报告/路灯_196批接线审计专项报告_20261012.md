## 一、审计方法论

「有出口无扳机」在观测意义上的精确定义：**计数器/遥测点被定义并自增（有出口），但无外部观测消费方读取它（无扳机）**。
三档定案口径：

| 档位 | 含义 |
|------|------|
| 读侧零命中 | 全仓无生产消费方读取该字段（仅 test 隔离置 0） |
| 有消费方 | 存在读取/使用方（含器官内部自阈判断） |
| 有消费方但效果不可见 | 仅器官内部自阈使用，无外部观测出口（遥测/看板/诊断不可见） |
