## §〇 摘要（结论先行）

1. **信息源**：官网 openclaw.ai、GitHub 仓库（与官网双向锚定，LICENSE=MIT © 2026 OpenClaw Foundation）、docs 官方文档 42 页 .md 三源为准；媒体仅用于舆情时间线并标"二手"。已排除一个同名混淆品（CSDN 流传的 pip『openclaw』任务编排库）。
2. **一句话定位**：OpenClaw = 本地单 Gateway 进程 + WS 唯一控制面（role/scope 握手）+ 每 Agent 一个 SQLite + SKILL.md 文件夹技能 + ClawHub 发布级审计 + sandbox/tool-policy/elevated 三层正交 + 重启自动对账续跑。与曈曈同类（跑在主人机器上的常驻自主智能体），但工程闭环与治理的**机器可读化程度差一个量级**。
3. **任务书勘误 3 处**（§1）：①"无企业版/付费版"过时——OCE（Enterprise）2026-09-29 官宣，多租户+审计，1.0 待发（二手）；②"Pi Agent RPC runtime"已为历史别名：内置 runtime id=`openclaw`，`pi` 归一化于它，Codex/ACP 等可插拔（provider/model/runtime 三层概念）；③规模：391,182 stars / 82,239 forks / 9,140 open issues（API 10-02 快照）。
4. **最强三借鉴**（与已立案痛点同构）：
   - **O-A1 重启恢复协议**（`docs:gateway/restart-recovery`）：状态盘上先行；启动时把"标 running 但无存活任务"的行**单事务**改判 interrupted+记诊断回执；数秒后合成系统消息自动续跑，未送达回复随附免重做。直击 03:05 重启冷却账失明（N-2）、T-工具面-3、10:48:14 池复活竞态（N-5）。
   - **O-A2 分面成熟度台账**（`repo:qa/maturity-scores.yaml`）：50 面 × quality/completeness 分 + M0–M4 级 + LTS + `human_override` 留痕 + 打分归因（含 AI `codex` 与 commit sha）。直击"修复率 10.0%、62/85=72.9% 不可验证、自评写散文"的 P0-2。
   - **O-B3 入库前审计链**（`docs:clawhub/security-audits`）：按发布物查"名称/摘要/声明权限/实际内容自洽"，审计六态（Clean/Review/Warn/Malicious/Pending/Error）+爆炸半径分级+**拒收不可检字节码 `.pyc/.pyo/.pyd`**。C-1 注册表合一后自建工具入库正需同构"声明→检查→准入"。**供 C-1 参考**。
5. **最大结构性差异**：我方状态散落 JSON 侧挂账（`data/tool_strategy_memory.json` 带 `.bak/.bak.1/.bak.2` 三具残骸）；OpenClaw 铁律明写"状态与缓存一律 SQLite，禁新增 JSON/JSONL/sidecar"（`repo:AGENTS.md`）。这是重启失忆类缺陷的共同根因。
6. **口碑教训**：2026-03 CNCERT/国家网络安全通报中心风险提示与预警（注入泄密钥、误删数据、skills 投毒、漏洞、实例暴露公网），Gartner 评高风险（均二手，§5）。而其 SECURITY.md 坦承"trusted operator 模型，纯注入链不按漏洞处理"。**曈曈不可借鉴该信任模型**（O-C5），应按 CERT 建议反向设防。
7. **157 边界**：本批零施工；工具面条目标"供 C-1 参考/157 后落地"；不自建登记条目（§6 交星轨）。71.1% 为 157 已定案旧口径（设计性拒绝），不复用为欠账数。
