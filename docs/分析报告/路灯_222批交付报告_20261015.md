## 二、刀1 · int-3幽灵追踪（只读追踪＋告警断言）

- **问题**：pair dump emit 行 `target_organ` 恒为整数 3（1014 文件 1000/1000、1015 文件 820/820）。
- **改动**（`utils/pulse_tracer.py` `log_emit:255-260`）：
  ```python
  # ★第222批·刀1：int-3幽灵追踪——target_organ 必须为 str，非 str 视为幽灵来源并告警+归一
  if not isinstance(target_organ, str):
      logger.warning(
          "pulse_tracer.log_emit: target_organ 非 str 类型=%.80r"
          "（organ=%s event=%s→疑似幽灵源，已归一为空串）",
          target_organ, organ_name, event_type)
      target_organ = ""
  ```
  非 str 时打 WARNING（含 `organ`/`event` 定位信息），并**归一为空串**——既在 dump 层面防幽灵污染，也切断共振主链路 `_resonance_weight_update` 中 `if _tgt:`（int 3 为 truthy）灌入幽灵突触的理论风险（该链路受 `RESONANCE_WEIGHT_MAP_ENABLED=False` 默认关门控）。
- **验收**：告警断言已加；隔离验证 `log_emit("OrganX","evt.ghost","L1","pid-1",None,3)` → 触发 WARNING（精确定位 `organ=OrganX event=evt.ghost`）且 `target_organ` 归一为 `""`；正常 `str`（如 `"PulseMouth"`）保留。重启曈曈后若再有非 str 写入，日志可定位幽灵源器官/事件。
- **降级**：int 3 根因未定（运行时非字面源），本刀仅加告警+归一闭环防污染，未根除来源（留待重启观测取证）。
