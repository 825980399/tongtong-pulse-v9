# 星轨 · T-审计-2 两处偏差裁定（2026-10-03）

> 背景：路灯交付 T-自我审计-2 能力四态账本（`a690d76`），如实上报两处偏差：①真空转率 29.7% vs 裁定 0.0%；②能力清单 5421 vs 任务书「70 命中」。星轨查证生产报告字段后裁定如下。

## 一、偏差 1：真空转率 29.7% —— 判据字段用错，需小修（非重做）

### 根因（实测证据）

生产报告 JSON 字段实测（`data/reports/` 三类样本）：

| 字段 | runtime | self_cognition | evolution |
|---|---|---|---|
| `actions_triggered` | ✅ 有 | ✅ 有 | ✅ 有 |
| `routing_order` | ❌ 无 | ✅ 有 | ❌ 无 |
| `consume_results` | ❌ 无 | ✅ 有 | ❌ 无 |

**`routing_order` 仅 self_cognition 报告存在**——路灯用它判「event」→ runtime/evolution 的真事件报告（有 `actions_triggered`）全部漏判落入 `true_idle`，129/435=29.7% 与微光 v2「事件 28.3%」（109/385）高度吻合即由此来。

### 裁定

1. **事件判据改为（对齐微光 v2 §三）**：`actions_triggered` 非空 **或** `consume_results` 有记录且 `accepted=true`（可执行异常）→ 归位 `event`。
2. `routing_order` 非空**可作补充判据**（self_cognition 类）但不作主判据。
3. **修正路径**：T-审计-2 小修（改判据字段，数据模型/挂载/共基建不动），重跑探针后**预期真空转率 → 接近 0%**（与微光 v2 一致）。
4. 修完附实测分布：`consumed / archived / design_declined / event / true_idle` 五类守恒仍 435=435。

## 二、偏差 2：能力清单 5421 vs 「70 命中」—— 口径变更，账本以 5421 为准

### 裁定

1. 「70 命中」= 任务书立项时点（2026-10-02）的**侦察快照值**（PCM 源码通道 `source_paths` 早期实测），非固定基线。
2. 账本登记口径 = **PCM summary 全量（实测 `pcm_total=5421`**：declared 4580 / idle 840 / wired 1 / consumed 0，含磁盘通道+白名单豁免语义）——**以 5421 为准**，任务书「70 命中」字样作历史快照，不要求对齐。
3. 施工要求：在账本 docstring 标注口径变更说明（70=立项快照 → 5421=PCM 全量），防后人误读。
