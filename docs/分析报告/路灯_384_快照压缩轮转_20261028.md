## 五、一个必须记录的机制细节

`PulseSnapshot._cleanup_old_backups()` 找旧备份的判据是：

```python
if fname.startswith(base_name) and ".bak" in fname:
```

`.bak.gz` 的文件名**仍然含 `.bak`** ⇒ 压缩后的冷备**依然被轮转纳入**。
所以压完调一次轮转（或等下次保存）就会落到「只剩 `KNOWLEDGE_BACKUP_KEEP` 份」，
不需要另写删除逻辑 —— 本刀的 `--keep` 就是按这个语义做的。

**含义**：冷备不是"永久存档"。如果你希望 `.gz` 完全脱离轮转（长期保留多代），
需要把判据改成 `fname.endswith(".bak")`，那是另一件事，本刀没动。
