## 二、调研结论（2026-10-23 实时核验）

### 1. 智谱 BigModel（延续现渠道，增强）
- `glm-4-flash` 永久免费（已用，priority 1）
- **`glm-4.7-flash`**：GLM-4.7 免费版（2026-01-14 发布），编码/推理能力显著强于 4-flash，高频调用优化——**新增渠道**
- 端点：`https://open.bigmodel.cn/api/paas/v4/chat/completions`（复用 `ZHIPU_API_KEY`）
- 限速：免费渠道实测并发约 1

### 2. 阿里云百炼（DashScope · 新接入 ★）
- **`qwen-turbo`：每月 100 万 Token 持续免费**（非一次性，每月滚动）
- 新人专属额度：**每模型 100 万 Token（qwen-max/qwen-plus/qwen-turbo/deepseek-v4-pro/glm-5.2/kimi-k2.6 各自独立），总计 7000 万+，有效期 90 天**，仅华北2（北京）地域
- OpenAI 兼容端点：`https://dashscope.aliyuncs.com/compatible-mode/v1/chat/completions`
- API Key：控制台创建通用 Key（不绑定模型），免费额度自动优先抵扣；建议开启「免费额度用完即停」防扣费
- 环境变量：`DASHSCOPE_API_KEY`

### 3. 硅基流动（SiliconFlow · 新接入）
- **开源模型永久免费（平台限速内）**：`Qwen/Qwen2-7B-Instruct`(32K)、`Qwen/Qwen2-1.5B-Instruct`、`Qwen/Qwen1.5-7B-Chat`、`THUDM/glm-4-9b-chat`、`THUDM/chatglm3-6b`、`internlm/internlm2_5-7b-chat`、`mistralai/Mistral-7B-Instruct-v0.2`
- OpenAI 兼容端点：`https://api.siliconflow.cn/v1/chat/completions`
- 环境变量：`SILICONFLOW_API_KEY`

## 三、新渠道池设计（路灯施工·config.py 落地）

```
新增（3 渠道，按优先级插入）：
1. "zhipu-47-flash"：model=glm-4.7-flash，priority=1（智谱免费新版，取代火山主力位）
   api_url=https://open.bigmodel.cn/api/paas/v4/chat/completions
   api_key=ZHIPU_API_KEY，quota_limit=-1（不限量），max_concurrent=1
2. "bailian-qwen-turbo"：model=qwen-turbo，priority=2（每月100万持续免费）
   api_url=https://dashscope.aliyuncs.com/compatible-mode/v1/chat/completions
   api_key=DASHSCOPE_API_KEY，quota_limit=1000000（每月滚动），max_concurrent=4
3. "siliconflow-qwen2-7b"：model=Qwen/Qwen2-7B-Instruct，priority=3（永久免费）
   api_url=https://api.siliconflow.cn/v1/chat/completions
   api_key=SILICONFLOW_API_KEY，quota_limit=-1（平台限速内免费），max_concurrent=2

保留：
- "zhipu"（glm-4-flash）：priority 顺延为 4（免费存量主力，与新47-flash分流）
- "deepseek"（官方收费兜底）：priority 8（垫底收费）
- 本地 Ollama qwen2:7b 兜底不动

火山 ark-*（8 渠道）：enabled 改 False，注释标注「2026-10-23 免费额度耗尽，挂起待恢复；恢复后改 True 即可」——避免每拍失败重试消耗。
```

优先级最终：zhipu-47-flash(1) → bailian-qwen-turbo(2) → siliconflow(3) → zhipu-flash(4) → deepseek(8兜底)。

## 五、风险与验证

- **风险1**：百炼额度耗尽后若已实名且关闭用完即停会按量扣费 ⇒ 施工时 config 侧 `quota_limit=1000000` 与百炼"用完即停"双保险
- **风险2**：硅基免费模型限速 ⇒ max_concurrent=2 + 熔断参数沿用现有 health 配置
- **风险3**：渠道池扩容后 SSRF 白名单 ⇒ `SSRF_TRUSTED_EXTRA_HOSTS` 需加 `dashscope.aliyuncs.com`、`api.siliconflow.cn`（ssrf_guard 自动纳入渠道池 api_url 主机，双保险追加显式白名单）
- **验证**（重启窗）：渠道健康度行三新渠道各自 1 次成功调用；智谱4.7-flash 首次回答；火山渠道确认不参与轮询（enabled=False）
