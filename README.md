## 🌟 核心特性

### 1. 脉冲架构（PulseNet）
- 信息以脉冲形式在器官间传递，模拟生物神经系统
- 六档优先级队列（L0-L3 + 背压机制），动态调整处理节奏
- 信息场共振引擎，多器官协同决策

### 2. 56个仿生器官
- **九大系统**：感知、认知、情感、运动、内分泌、遗传、免疫、身份、核心
- 每个器官独立运行，通过脉冲总线通信
- 熔断机制保护，单个器官故障不影响整体

### 3. 自学习与自进化
- **代码学习器**：自动扫描代码问题，生成补丁，验证后自应用
- **经验蒸馏**：大模型输出沉淀为可复用经验库
- **全局学习器**：跨批次累积观测，自动调整策略
- **自我认知引擎**：定期生成健康诊断报告，发现问题自动修复

### 4. 内在模型孕育（进行中）
- L1记录层：所有调用、决策、结果可追踪
- L2蒸馏层：大模型输出沉淀为经验
- L3检索层：经验库、知识库高效召回
- L4决策层：简单任务先走内在模型，复杂任务再调大模型
- 目标：大模型依赖度从96.96%逐步降低到70%以下

### 5. 星轨+路灯协作模式
- **星轨（规划/验收）**：生成任务书，分析交付报告，更新技术债务清单
- **路灯（执行）**：领取任务，修改代码，运行测试，提交交付报告
- 已完成53批任务，持续清偿技术债务

## 🚀 快速开始

### 环境要求
- Python 3.10+
- 依赖：`pip install -r requirements.txt`

### 启动系统

```bash
# 启动系统（56个器官全部在线）
python main.py

# 运行健康诊断（自动扫描代码问题）
python pulse_doctor.py

# 查看系统状态
# 在控制台输入 status
```

### 配置API密钥

复制 `docs/部署指南_APIKey配置.md` 中的模板，配置你的大模型API密钥：
- DeepSeek（付费，优先）
- 智谱（免费，并发1）
- 火山方舟（免费，多模型）

## 📊 技术债务清偿进度

### 当前状态
- **已完成批次**：53批
- **在册技术债务**：31项（P0×4、P1×6、P2×16、P3×5）
- **健康诊断**：代码问题640个（持续修复中）
- **pytest基线**：2471 collected（2455 passed + 16 skipped，0 failed）

### 4个P0级债务（最高优先级）
1. **自认知闭环断裂**：自认知报告生成后无消费者，指标分虚高
2. **补丁验证空转**：补丁验证环节假通过，修复闭环不完整
3. **SERP污染**：经验库79.9%污染，锁死L3检索层
4. **质量分虚高**：健康诊断质量分92.99式虚高，不可信

### 战略原则
- **先还债，不新增**：在现有设计未落地、技术债务未清空前，不新增功能
- **小步快跑**：每批3-5项任务，优先无需重启框架即可验证的小任务
- **可回滚**：所有修改可验证、可回滚，保护记忆和人格连续性
